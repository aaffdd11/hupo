## 一、产品是什么

> **一台哑终端 + 一台云端专属主机 + 一个调度器。**
> 用户看到的是**一个聊天窗口**；底下是**多条 DSH 会话**，每条待在自己的工作区里；
> **调度器**决定"谁的话投给谁"，并按自己的时钟把这些话拼成用户看到的那一条时间线。

```
终端（Flutter / 平板优先）
   浮窗 = 唯一的聊天窗口；桌面 = 工作区图标墙
   ↓ HTTPS + WSS（调度器协议，不是 DSH 协议）
调度器（services/core，永续）
   ① 对用户的路由  ② agent 之间的邮政  ③ 归一化成一条时间线  ④ 账号与供给
   ↓ 容器内通道（本轮还没做）
用户容器（= 这个用户的整个世界）
   ├─ 一份专属 DSH
   ├─ 若干工作区（每个 = 一个目录 + 一条会话 + 桌面一个图标）
   └─ hupo 地盘（记忆索引 KV / 制品 / 审计）
```

**与 v7 的关系**：v7 仍有效；本文覆盖 v7 没有的三件事——**多租户、工作区作用域、统一窗口**。

**两条已经改了 v7 的话**（都有实测依据）：
- **`workspace root` 不是安全边界**——`dsh-fs-sandbox` 只约束**写**，"preserving the local filesystem's **read** behavior"
- **"算不出美元"的理由要改**——`dsh-token-meter` 存在且计数是活的（21/21 会话非零），但**无价格表、无 userId 维度、被 cache read 主导（98.6%–99.8%）** ⇒ 结论仍是"不显示估算美元"，理由改成"没有价格表且总量口径失真"

## 六、贯穿全程的规矩（不变量与纪律）

| # | 规矩 |
|---|---|
| **N12** | 界面作用域 = session 的 workspace root，不一致就报错 |
| **N13** | 跨作用域只走摘要与指针，不走原文 |
| **N14** | 主作用域可以不知道细节，但**不许替子作用域编细节** |
| **N15** | 切换作用域前必须先收口上一条气泡 |

| **N18** | agent 不许直接写 KV |

| **N20** | **动作可静默，事实不能静默**（**范围已扩大**：桌面多了一个物件**也算事实**） |
| **N21** | 同一用户一份 `DSH_HOME`（会话存储的键是绝对路径） |
| **N22** | **每个用户那条可见时间线**的 `seq` = **那条日志**已落盘最大 + 1，**只增不减**、**磁盘无空洞**（**P-l 甲**：一条可见时间线 = 一条日志，作用域只是 `scopeId` 标签）；同一时刻最多一条未收口消息 |
| **N23** | 协议必须带 `scopeId` 与来源（客户端可以先只显示"它"，**但字段现在就留**） |
| **N24** | **收起 ≠ 删掉**；删掉进回收站 30 天；不提供"删会话原文" |
| **N25** | 任何能让助手的写入变成"**下次开机自动读**"的路径都必须不存在；apply 只认主人原话；清单 root 只读；回退不需要助手 |

2. **测试楼层**：新验收**一律写 `test/unit`**——`test/widget` 一重构就过期（现在 **49 条挂 10**）
