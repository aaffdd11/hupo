# 索引 · 要问什么，读哪一份

> **这一页只做一件事：把"问题"翻成"该打开哪一份、哪一节"。**
> 它**不写结论、不写数值、不写状态** —— 结论住在它指的那一份里；
> **抄一份过来，那天就开始漂。**

> ⚠️ **默认只读前两行**（`AGENTS.md` + 热表）。**其余的按需打开，别通读。**

## 二、这些"份"是分层的（**每层只干一件事**）

| 层 | 家在 | 只放什么 | 硬规矩 |
|---|---|---|---|
| **L0 路由** | **本页** | **问题 → 文件 §节** | **零事实、零数值、零状态** |
| **L1 介绍** | `handbook/01` · `02` · `README` | 是什么 / 给谁 / 为什么 / 边界 | 每节一屏以内；要证据的断言**只许带指针，不许复述证据** |
| **L2 决策与判据** | `handbook/05-DECISIONS` · `08-SPEC` | 已拍板 + 判据（带 ID：`D*` / `N*` / `V*`） | **唯一有约束力的一层**；ID 全局唯一、可 grep |
| **L3 证据** | `dev/**` · `test/**` · git 历史 | 文件:行 · 测试名 · 实测读数 · 当时的坑 | **允许大、允许冷**；由上层指针指过来才读 |
| **L4 代码与产物** | `v2/**` | **唯一真相** | 文档只引用路径与符号，**不抄代码** |

**引用方向是单向的：L4 → L3 → L2 → L1 → L0。**
⇒ **一条事实只有一个家**；上层出现副本，就是漂移的开始。

## 三、分层靠什么撑住（**不靠记性，靠闸**）

```bash
node scripts/check-docs.mjs      # 文档闸：本地链接可达 + #锚点可解析 + L0 不许出现数值
```

- **指针失效 = 闸红**。所以"文档和实际不同步"会**在提交那一刻被拦住**，而不是等下次有人读到。
- **新增一层就要进闸的名单**（名单在 `scripts/check-docs.mjs` 里，一个数组）。
- ⚠️ **闸只保证"指针没断"，不保证"内容还对"** —— 内容对不对，只有跑硬闸才知道。
  ⇒ 所以任何"现状"都不许写死：**写"跑哪条命令"，不写"是多少"。**

## 四、发现两份文件说法不一致时

**裁决顺序：手册 → 代码 → 其他。**
⇒ **先按代码确认事实，然后回来改手册**（不要反过来）。
⚠️ 但手册与人格、`AGENTS.md` 是**开机清单里的 `strict`**：改它们要请主人补一条重建命令
（否则下次重启**拒绝启动**）。⇒ **攒成一批一次改**，别为文风反复动 —— 攒着的清单在
[`dev/00-PROGRESS.md` §九](dev/00-PROGRESS.md)。
