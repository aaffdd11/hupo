1. **批 1 那四件不再是"去旧代码里改"**，而是"**在新代码里从一开始就对**"。

2. **`03-DEVELOPMENT.md` §七 的文件索引**按"原地替换"写的；

   ⇒ 等新实现在 `v2/` 长齐、旧代码删掉之后，会**再升一版**把索引改回最终路径。

### 定档之后怎么改这份手册

| 改什么 | 怎么办 |
|---|---|
| **代码与手册不一致** | **先按代码确认事实，然后回来改手册**（不要反过来）——并在本页记一笔 |
| **结论变了** | **升版本**（v1.1 / v1.2…）+ 写清改了什么、为什么 |
| **只是补细节** | 升**次版本**（v1.0.1）+ 一行说明 |
| **想删一条结论** | ⚠️ **先确认它已经在别处有家**——上一轮删旧文档时，靠的就是"先把 N1–N11 搬进 `08-SPEC.md`，再删"。**顺序反了就会丢东西** |
| **想加数值** | 先想清楚它会不会过期。**会过期的数值只进 `08-SPEC.md` §十，或留在代码里** |
