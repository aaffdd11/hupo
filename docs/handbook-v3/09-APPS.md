# 09 · 小程序那一整套

> **这一份回答什么**：他可以让助手**当场做出一个小程序** —— 摆在桌面上、能自己存东西、能上网、
> 能问它的助手、能定时干活、能拍照。这一份把它**从头讲完**：它是什么、被关在多严的笼子里、
> 能要哪些能力、每一格自己的库、制品怎么发出去、用户端与"包"差在哪、
> 给"做小程序的 agent"的作业指导书、判据、以及**明确没做的**。
>
> **谁该读**：动小程序 / 容器 / 授权之前。

**三条读法**（缺一条就会读歪）：

1. 🔴 **凡涉及"跑的是哪一份 / 数据在哪"，这一份一律写清是哪一台、哪一层** ——
   宿主这一台 / 他盒子里 / 制品那一版（不可变快照）/ 活地址（他正在改的那一份）。
2. **阈值、上限、超时只住代码**与 [`08-SPEC.md`](08-SPEC.md) **§十**；
   正文说"跟着字算"、给常量所在的**文件**，**不抄数值**（抄下来的那一刻它就开始过期）。
3. **每条断言都指得出代码或判据**；指不出的**明写"未核实"**，不许含糊过去。

## 一、它是什么

### 1.1 一格 ＝ 一间 ＝ 一条对话 ＝ 一个制品

**一个小程序在四个地方是同一件事**，`id` 是它们共同的名字：

| 那一层 | 是什么 | 落点 | 谁按什么认它 |
|---|---|---|---|
| **屏幕上** | 桌面图标墙上的**一格**（图标 ＋ 名字） | 客户端 `widgets/app_desktop.dart` | `id` |
| **干活的地方** | **一间工作区** —— 助手在这一间里干活时 `cwd` 就是它 | `<他那一格>/workspaces/<id>/` | 目录名 = `id` |
| **说话的地方** | **一条对话** —— 那一间自己的会话与那条可见时间线 | 事件上的 `scopeId = id` | `scopeId` |
| **发出去的东西** | **一个制品**：一份登记（＋ 发过的话，一份不可变的包） | `<他那一格>/hupo/apps/<id>/` | `id` ＋ `rootHash` ＋ 血缘 |

> 主人定的形状：*"当我做一个 app 的时候，本质上是一个工作区。这一点你一定要确保。
> 那么你制作小程序，就是在那个工作区里面开。"* —— 落地见
> [`../dev/83-APP-WORKSPACE.md`](../dev/83-APP-WORKSPACE.md)、
> [`../dev/102-APP-BIRTH-SCOPE.md`](../dev/102-APP-BIRTH-SCOPE.md)。

**三条不许互替**（`docs/dev/90-APP-CONTRACT.md` §2.1，代码在 `src/apps.js`）：

| 维 | 是什么 | 不许拿它当别的用 |
|---|---|---|
| `id` | 别名 / 桌上那张脸 | **不拆 `id`** —— 拆了就是"每改一次就不再是同一个 app" |
| `rootHash` | **内容**（按路径排序后算出来的一枚 hash） | 不许进身份 —— 否则改一个字就换了个 app |
| **血缘** | **祖先边**（从哪一版长出来的、改过哪些文件） | 不许用**自称的**来源代替（自称的来源不算来源，见 §五） |

🔴 **"建工作区"这件事不靠模型记得**：造 app 的第一步由**服务端那一刀**做 ——
建目录 ＋ 登记 ＋ 把这一轮的 `cwd` 换过去（`src/apps-socket.js` 的 `create`）。
漏了它会出什么：文件躺回主目录、那一格点开是另一个空房间、**干活的那段对话谁也找不到**。
⇒ 所以派活那一路把 `id` **钉死成那一间自己**（模型随手写别的名字**一律不作数**），
"图标 = 那一间的门"是**结构**，不是约定。

### 1.2 两个原点为什么必须分开（**N1**）

> **N1：执行第三方代码的东西（小程序）绝不与持有令牌的原点同源。**（[`08-SPEC.md`](08-SPEC.md) §一）

| | **壳这一侧**（持令牌的那个） | **制品那一侧**（跑第三方代码的那个） |
|---|---|---|
| 住在哪 | 客户端 + 调度器，域名是 `w.<域>` | `apps.<域>`，**另一个原点** |
| 手里有什么 | **令牌**（`TokenStore`）、会话、账 | **什么都没有** —— 拿不到令牌、拿不到别人的字节 |
| 跑什么 | 我们自己的界面与逻辑 | **别人（助手）写的一份 HTML** |
| 谁嵌谁 | 壳把制品**嵌**进一个 iframe / WebView 里 | 它自己出不去 |

**为什么不能同源**：只要同源，制品里一行 `parent.document` 或一次 `fetch('/api/…')`
就能读到壳的存储、用壳的身份说话 —— 那等于**把令牌交给了第三方代码**。
分开之后，制品**只能**做两件它被允许的事：算/画（完全本地），
以及**对它自己那个原点**发一次请求（那几条窄口，见 §三、§四）。
铁律 1 那条 `sandbox` 取值、铁律 2 那条 CSP，都是这一条不变量的**执行手段**。

⚠️ **顺带得到"两端一致"的地基**：网页那一侧与安卓那一侧都**从同一个制品原点加载**，
所以它们**吃同一个响应头、走同一条路**（`docs/dev/147-APP-SQLITE.md` §一 F10）。

### 1.3 内置那几屏与真制品的区别

桌面图标墙上除了他自己的小程序，还有**两格内置的**：**设置** 与 **发现**
（`src/worlds.js` 的 `BUILTIN_SCOPES`；`src/apps.js` 的 `REFUSED_APP_IDS` 把
`main` / `settings` / `discover` 一起收成保留 id —— **保留名单 = 主线 ＋ 内置那几格**，这条等式不许破）。

| | **内置那几屏** | **真制品** |
|---|---|---|
| 是什么 | **我们自己画的界面** | 一份**别人写的 HTML** |
| 从哪来 | 打进客户端那一版包里 | 从制品原点取，走一条**现签的短时效 URL** |
| 有没有工作区 / 对话 | 有那一间（`scopeId` 是它们自己的名字），但**没有制品** | 两样都有，且 `id` 同名 |
| 能不能被助手造出来 | **不能** —— 保留 id 那道闸直接拒 | —— |
| 权限 | 没有"能力要授权"这回事 | 五样能力要他点头（§三） |

⚠️ **"发现"那一屏是只读的**：它只列别人发出来的东西，**它自己不能装** ——
`D4.18` 定的形状是"**一切操作都在对话里**"（造 / 看 / 发 / 撤 / 发现 / 装 / 卸 / 授权 / 撤权
一共九件工具，见 §五），屏幕上只有**桌面图标墙**、**加号**与**只读的发现**。
唯一一处"屏幕上的入口也能造东西"是桌面上那颗**空心加号**（§五 §1），
它造的是**空壳**，内容仍然只从对话里来。

### 1.4 一次"做一个小程序"到底发生了什么（**全景**）

```
他说"帮我做一个记账的"（在那条对话里，或在那一格自己的对话里）
   │
   ├─ 助手当场动手：把页面写进「那一间工作区」（它的 cwd）
   ├─ 助手调 app_create：建工作区（已存在则复用）＋ 登记 ＋ 声明能力
   │     └─ 桌面自己长出那一格（app/installed，瞬态）
   ├─ 他点开那一格 ⇒ 打开的是一条**活地址**（/w/<id>/…，§五 §3）
   ├─ 打开之前：把它**还没问过**的能力**一次问完**（§三）
   │
   └─ 之后：助手再改那一间里的文件 ⇒ 屏幕上自己就是新的（不用发布、不用刷新）
```

**"发布"是另一条路**（`app_publish`）：把它**现在那一份**打成一个**包**、放进共享库、给别人装。
它**不是**"他自己那份生效"的前提 —— 用户端**没有包**（§六）。

## 二、沙箱：三条铁律 ＋ 判据

三条都是**用代价换来的**，所以每一条都配了判据，而且判据**带负向对照**
（"把改坏的源码喂进去必须报"）—— 闸绿了但不是空转，靠它证明。

### 2.1 铁律 1：iframe 的 `sandbox` 取值**只有 `allow-scripts`**

`v2/apps/mobile/lib/widgets/mini_runtime_web.dart` 里那一行是
`sandbox = "allow-scripts"` —— **一个取值，多一个都不加**：

| 加/不加 | 会怎样 |
|---|---|
| **不加 `allow-same-origin`**（今天） | 制品活在**不透明原点**（opaque origin）里 |
| 🔴 **加了 `allow-same-origin`** | **等于没有沙箱**：制品与壳同源 ⇒ `parent.document`、壳的 `localStorage`、cookie 全都碰得到 ⇒ §1.2 那条 N1 当场作废 |
| 加 `allow-forms` | 不需要：CSP 的 `form-action 'none'` 已经把表单提交堵死了（代码更严） |

同一条判据还钉着 `referrerpolicy="no-referrer"`（别把入口 URL 当 referrer 漏出去）。

**它的代价（是设计，不是缺陷）**：不透明原点下 `localStorage` / `sessionStorage` / `indexedDB`
**一碰就抛 `SecurityError`** ⇒ 一个小程序**没有浏览器自己的持久化能力**。
要记住东西，走平台给的那条窄口（§四）。客户端那里也写着同一条理由。

**判据**：`v2/apps/mobile/test/unit/mini_sandbox_test.dart` 的 `P1-7`
（`sandbox='allow-scripts'`、**不许**出现 `allow-same-origin`、`referrerpolicy=no-referrer`）
＋ 紧挨着的**负向对照**：把 `allow-same-origin` 塞进源码、删掉 `sandbox`、
把 `allow` 写死、顺手加麦克风 —— **四种"改坏"必须各自报红**。
⚠️ **只有源码级判据**（那一份自己写着 web-only，VM 里跑不了 `dart:html`）——
**没有运行时判据**，如实记在这里。

### 2.2 铁律 2：制品文档的 CSP 是一条**写死的串**

服务端 `src/app-serve.js` 的 `cspFor()` 拼出来的响应头**逐字**是这一条
（顺序与内容都是故意的）：

```
default-src 'none'; script-src 'unsafe-inline'; style-src 'unsafe-inline';
img-src data: blob:; connect-src 'self'; base-uri 'none'; form-action 'none';
frame-ancestors <壳>
```

| 那一段 | 为什么是这个值 |
|---|---|
| `default-src 'none'` | **默认什么都不许**（fail-closed） |
| `script-src 'unsafe-inline'` · `style-src 'unsafe-inline'` | 制品是**一份自包含 HTML** ⇒ 样式与脚本**内联**；⚠️ **没有 `'self'`** ⇒ 它**引不了同原点的别的文件** |
| `img-src data: blob:` | 图片只能内联或现做；**没有 `'self'`** |
| `connect-src 'self'` | 只许对它**自己那个原点**发请求 —— 那就是 §四那条窄口。**别人的站一个都不在白名单里** ⇒ 它**出不去**；`net` 那一叠（§三）**按 app 叠在这后面** |
| `base-uri 'none'` · `form-action 'none'` | 堵住"改 `base` 之后把请求发到别处"和表单提交 |
| `frame-ancestors <壳>` | **只许壳嵌它**，别处嵌不了（⚠️ 不发 `X-Frame-Options`，靠这一条） |
| **没有 `media-src`** | 音频/视频**文件**一律取不到（`<audio src=…>` 落进 `default-src 'none'`）⇒ 想要声音只有 `AudioContext` **当场合成** |
| **没有 `font-src`** | 引不到外部字体 ⇒ 只用系统自带的字体族 |

**`connect-src` 按 app 算**：`netHostsFor()` 三道一起才算
（① 制品**声明了** `net` ② **他没关掉**（在 `granted` 里）③ `meta` 里那份名单）——
任何一种读不出来 ⇒ **空名单**（宁可连不出去，也不许"读不出来就放行"）。
拼响应头那一处在 `app-serve.js` 里按 app 调 `cspForApp()`；名单里的每一串**已经过
`apps.js` 的 `checkNetHosts`**（安全边界只有那一处），到 `cspFor()` 里只再兜一道**形状**。

**判据**：`v2/services/core/test/apps.test.js`（制品口：带 CSP ＋ **没有 X-Frame-Options**）·
`test/app-db.test.js` 的 **D7**（`connect-src` 只放它自己那个源 —— **明禁退回 `'none'`、明禁 `*`**）·
`test/app-net.test.js`（N1–N6，见 §三）· `test/app-live.test.js` 的 **V3**
（**活地址与制品同一条 CSP**）。
⚠️ **`connect-src` 只认 `'self'`（再叠声明过的站）** —— 退回 `'none'` 看着更严，
其实会让"对自己那个源发请求"这条**唯一的窄口**也断掉（`/db`、`/ask`、`/agent` 全部废掉），
而 `*` 那一头是**放开**。判据逐字钉着这两头。

### 2.3 铁律 3：**禁原生桥**

**原生那一侧不许有桥**，一条都不许：

| 不许出现的东西 | 现状（`grep` 得到的） |
|---|---|
| `JavaScriptChannel` / `addJavascriptInterface` / `evaluateJavascript` / `runJavaScript` | `lib/` 里**真代码 0 处**（唯一命中是注释） |
| 一个宽泛的"原生给页面递能力"的通道 | **没有** —— 原生那份运行时里连 `onAsk` 都**故意不接** |

> 代码里那句话值得抄下来：**"收了却做不到比不收更坏"**。

**原生那一层到底是什么**（`docs/dev/129-NATIVE-ANDROID-BUILD.md`）：

| 项 | 它是什么 |
|---|---|
| 载体 | **一个普通 `WebView`**，加载那条**现签的**入口 URL（制品仍然在**另一个原点**） |
| 存储 | **独立的数据存储** —— 那个 WebView 自己原点的存储它用得了，但它**读不到壳的令牌**（令牌在 Flutter 那侧的 `TokenStore` 里） |
| 导航 | **只许在制品自己那个 `origin` 里走** —— 纯函数 `miniNavigationAllowed`（`lib/models/mini_frame.dart`）：别的域名 / `javascript:` / `data:` / `file:` / 协议降级**全拦** |
| `ask` | **原生上没有**，而且**不假装有** —— 壳**不发** `hupo-ready` |
| iOS | 🔴 **商店版不发布小程序运行时**：装钩子那一步**只在 Android 上做**，`kNativeMiniRuntimeIOS` **恒假** |

**这条与"两端一致"是什么关系**（这是整套设计里最要紧的一处推导）：

- 桥**只有网页那一侧有** ⇒ 凡是"走壳的桥"的能力，**平板上那个小程序一件都用不了**；
- 而铁律 3 不许我们为了补齐它去装一条窄桥；
- ⇒ 于是**唯一**能把能力给到两端的路是：**让制品对它自己那个原点发一次请求**
  （`fetch` 在 WebView 里本来就能用）＋ 一个**按人按 app 签名的受限接口**。
  §四那条 `/db` 与 §三的 `/ask`、`/agent` **全是这个形状**；
- ⇒ 所以"两端一致"不是两边各写一遍，而是**天生同一份**（两边吃同一个 CSP 头、走同一条路）。

**判据**：`v2/apps/mobile/test/unit/mini_native_test.dart` ——
"这棵树的 `lib/` 里，原生桥 API **命中 = 0**"（还量了"扫过的文件数"防空转）
＋ **负向对照**：把"改坏的源码"喂给那个扫描函数 ⇒ **必须报出来**；
`test/unit/mini_runtime_test.dart`（Android 有 / iOS 没有 · 没装钩子就说实话 ·
`webview_flutter` 白名单 · 两端签名一致）；
`test/app-lint.test.js` 第 ③ 条（制品源码里出现 `webkit.messageHandlers` / `HupoNative` / `Android.*`
⇒ 报 `native-bridge`）。

### 2.4 沙箱通信认的是**挂载账**，不是域名

`event.origin === "null"` 是 opaque origin 的**正常**值 ⇒ **不能拿域名做校验**。
今天代码认的是三样（`mini_runtime_web.dart`）：① 这一帧 `viewId` **在挂载那本账里**
（`miniViewLedger.isHosted(viewId)`）② `origin` 是 `'null'` 或空串
③ `kind` 是我们认得的那一种。

⚠️ **未核实 / 无实现**：旧手册 §14.1 写着"沙箱通信必须改用**一次性 nonce**（打开时下发，关闭即废）"，
但 `v2/` 的 `.dart` / `.js` 源码里 `nonce` **命中 = 0** ⇒ **那条要求今天没有实现**，
代码走的是上面那三样。**别照 nonce 那句话去验收。**

### 2.5 一条平台层的事实：Web 上平台视图是**真的 DOM**

Web 上那个 `<iframe>` 是**真的 DOM 元素**，它**盖在 Flutter 画布上面**。
⇒ 平台视图一"铺满整屏"，画在画布上的**聊天浮窗就整个被它盖住**（点不着、也看不见）。
**规矩是**：平台视图的矩形**不许盖到聊天浮窗的矩形**，而"被盖住"那一档
（聊天展开着）**只压暗、不缩小、不圆角**；
同时往每一个 root（`document` ＋ 每个 shadow root）注一条
`pointer-events: none !important` 并在开/关之间切换 ——
**那就是"聊天的浮窗永远在最上面"这句话成真的东西**。
契约与判据：[`../dev/150-APP-FULLBLEED.md`](../dev/150-APP-FULLBLEED.md)（⚠️ 那一篇顶上写着
"**方向做反已撤**"—— **被撤的只有"铺满整屏"那半边**；"聊天在最上"、只压暗、以及
**服务端那条按 `pt`/`pb` 往页面 `body` 注 `padding` 的注入（今天壳不再写那两个数，
但服务端照旧认它们，老产物与老客户端要靠它）**都有效）·
[`../dev/145-MINIAPP-EATS-POINTERS.md`](../dev/145-MINIAPP-EATS-POINTERS.md) ·
`test/widget/mini_app_test.dart` · `test/widget/safe_area_test.dart`。

## 三、能力与授权

### 3.1 能力到底有几样、哪几样要他点头

**一共六样**，但它们分两档 —— 混成一档是这一整节最容易犯的错：

| 档 | 那几样 | 要不要声明 | 要不要他点头 | 出现在"打开时那张弹窗"里吗 |
|---|---|---|---|---|
| **天生就有** | **存储（`db`）** | **不用** | **不用** | **不在** |
| **要他点头** | **问一句（`ask`）** · **上网（`net`）** · **拍照（`camera`）** · **跟它的助手说话（`agent`）** · **定时（`tasks`）** | 要（声明 = "它想要什么"） | 要（他第一次打开时一次问完） | 在（还没问过的那几样） |

🔴 **两处必须说清，不然后面全读错**：

- **存储不算"要他允许的那样"**：`granted` / `unanswered` **两张表都不含 `db`**，
  弹窗里也没有它，设置页那张卡上**没有存储那一行、也没有那个开关**。
  它天生就有自己那一格库（§四）；老制品清单里那个 `db` **照样认**（只是今天没有意义）。
- **"问一句"和"跟它的助手说话"是两样，不是一样**：
  `ask` = **直连模型**问一句（没有工具、不记得上一句、不改任何东西，花他的钱）；
  `agent` = 把问题送进**它那一间**，由**那一间的助手**来答 —— **那个助手是有手的**
  （今天那一轮走"限定档"，见下）。两样**各判各的闸**。

服务端那张权限白名单是**六个名字**（`src/apps.js` 的 `PERMISSIONS`）；
客户端"要问的"是**五个**（`lib/models/app_grants.dart` 的 `knownWants`，`db` 不在里面）。
**两张表不是同一张**，这不是不一致，是"存储不用问"那一条的落点。

### 3.2 🔴 声明 ≠ 已给：三件事必须分开记

制品清单里那行 `permissions` **不是他写的**（是助手写的），它**不是他的签字**；
而他第一次看见一个小程序要什么，恰恰是**打开它的那一瞬间**。⇒ `/api/apps` 每格回**三样**：

| 字段 | 含义 | 谁写进去的 |
|---|---|---|
| `permissions` | **它想要什么**（制品声明的） | 助手（写进清单，随版本冻结） |
| `granted` | **你给了的** = 声明 ∩ 他点过头的 − 他拒过的（**滤掉 `db`**） | 他（`grant.json` 的 `allowed`） |
| `unanswered` | **还没问过他的** = 声明 − 给过 − 拒过（**滤掉 `db`**） | 现算 |

🔴 **"还没表态"必须与"他拒了"分开记** —— 混成一个集合只有两种坏结果，
而且两种都会真的发生：

| 混成什么 | 坏在哪 |
|---|---|
| 把"还没问过"当成"他拒了" | **一次没答就永远用不了** —— 他根本没表态，东西却废了 |
| 把"他拒了"当成"还没问过" | **每次打开都再问一遍** —— 他点过"不给"还问，那是骚扰 |

⇒ 所以落盘的是**两张表**：`grant.json` 里 `{allowed, denied, at}`。
`grants()` 要求 `allowed.includes(p)`（**默认不给**）；`unanswered()` 只看两张表都没提到过的。
写的时候对外**协议一个字没改**（`POST /api/app-grant {id, permission, allow}`）——
客户端与新老盒子照旧传那一份，"允许清单"在内部被翻成这两张表。

**老文件照旧认**（`apps.js` 的 `#grantBook`）：

| 盘上是什么 | 认成什么 | 为什么 |
|---|---|---|
| `{allowed, denied, at}`（今天） | 两张表 | —— |
| `{permissions: […]}`（那一版把"清单本身就当允许"） | **认成 `allowed`** = "他点过头" | 他点过的那几样**不许因为换了写法就作废** |
| `{denied: […]}`（那一版把"清单当关掉名单"） | 认成"**他表过态、不给**" | 同上，反方向 |

### 3.3 打开时"一次问完"（那张弹窗）

他**第一次打开**一个小程序时，把 `unanswered` 里那几样**一张窗列全**、一次问完
（`lib/widgets/app_grants_ask.dart`）。六条规矩（每条都有判据）：

| # | 规矩 | 为什么 |
|---|---|---|
| 1 | **一次问完** —— 一张窗列全，不是每样弹一次 | 一次一次弹是折磨；"傻瓜式"那条要求住在这儿 |
| 2 | **默认全开** —— 他按一下「就这样」就等于全给 | 同一个理由 |
| 3 | **关掉哪一样就只是那一样用不了**（人话里点明"别的照旧"） | 免得他以为关一样就废了整个小程序 |
| 4 | **弹窗自己不发请求** —— 它只把"他勾成什么样"交回给屏那一侧 | 那儿才有令牌、才拿得到回执；"没记下来"那一档也才说得出实话 |
| 5 | **划掉不算回答**（`barrierDismissible: false` ⇒ `null` = 没表态） | **替他记一笔"不给"才是假话** —— 什么都没记，下次再问 |
| 6 | **必须在他点开那一屏之前问完** | `net` 那一样的响应头就是照那本账算的 —— 问完再开，它才连得出去 |

`net` 那一行**多一句"它会连这几个站："**（域名清单本来刻意不上屏，
**只在弹窗里破例** —— 那是他点头才生效的几样里唯一会让他意外的细节）。

**设置页那张卡**（`lib/widgets/app_grants_card.dart`）是"**之后还能改**"的地方：
**跟弹窗同一本账**。三条"不画开关"（画个假的就是"页面在说假话"）：
① `granted` 字段**缺失**（老服务端 ⇒ **不知道**，`null` ≠ `[]`）② 认不出的名字 ③ 这一条路没接线。
**关掉是"现在不给"，不是"抹掉"**：文案里明说
"关了只是现在不给，别的什么都不动"，而且**关掉不删他已经存下来的东西**（判据钉着）。

**装别人的 = fork 成他自己的** ⇒ `app_install` 那条路上**没有"外来要先允许一下"那一档**：
清单里那份声明**原样带过来**（主人：*"别人发的东西直接 fork 下来就好了……代码都成自己的了。"*）。
⚠️ "刷新 / 分叉"那个选择**不是权限闸** —— 它是"别把他改过的那份盖掉"，默认分叉。

### 3.4 六样能力：形状、怎么调、被拒怎么说

> 总规矩：**被拒时页面拿到的是一句人话**（`text` / `error` 上），页面**照它说，
> 不许假装成功**；每一样**用不了的时候要能没有它也能用**（至少别白屏）。

#### 3.4.1 存储（`db`）—— **天生就有**

见 §四（那一节是它的正文）。

#### 3.4.2 问一句 `ask` —— 用**他的钥匙**问模型一句话

| 项 | 形状 |
|---|---|
| 什么时候用 | "一句话的事"：出题、起名、翻译 —— **不需要查网、不需要工具** |
| 怎么调 | 制品对它**自己那个原点** `POST /ask`，`{id, v, prompt}` ＋（第一次带 `{u,e,s}`，之后带 `{ticket}`） |
| 回来 | `{ok:true, text, left, max, ticket}`；被拒 ⇒ `{ok:false, error, text}`（**人话在 `error` 上**） |
| 闸 | **四道**：在他这儿 · 清单**声明了 `ask`** · **他允许了** · **配额还有**；**两条口同一道闸**（`/api/app-ask` 与 `/ask` 共用同一个函数，不许各写一份） |
| 花在哪 | 主人 / 单租户 ⇒ **他这台机器上的小代理**；**租户 ⇒ 过隧道进他盒子**（钥匙在他盒里） |
| 被拒怎么说 | 没声明 ⇒ 403「这个小程序没说要问话」· 他关掉了 ⇒ 403「你还没允许它用你的钥匙」· 超配额 ⇒ 429「今天问得够多了」· 太快 ⇒ 429；**被拒的那几条一个字都不花** |
| 数住哪 | `src/apps.js`（每天几次 / 两次之间最小间隔） |

#### 3.4.3 上网 `net` —— 只许访问**声明里那几个站**

| 项 | 形状 |
|---|---|
| 两样一起才算 | 清单里 `permissions: ["net"]` ＋ `net: ["api.…", …]`（白名单） |
| 谁起草 | **助手** —— 它**自己去访问确认过**，再把域名写进清单（它出网**不设限**，见下） |
| 谁执行 | 🔴 **浏览器 / WebView 自己**（CSP 是硬的）：他**点头** ⇒ 那几个站进 `connect-src`；**没点头 / 关掉 ⇒ 只有 `'self'`** |
| 名单是安全边界 | 它会被**拼进响应头** ⇒ 只认规规矩矩的**小写域名**（至少一个点、无空白、无通配、无端口、无路径、无 scheme）；认不出来就拒（**注册与建包两个入口都拒**），`cspFor()` 里再兜一道形状 |
| 只放它自己那几个 | 按 **app** 算（一个 app 的名单不会跑到另一个 app 头上） |
| 加新站 | **新的一版**（重发一次）—— **不许运行时自己往名单里加** |
| 被拒怎么说 | 页面上就是"取不到数据"（浏览器拦的）⇒ 页面要**如实显示**；名单不合形状 ⇒ 工具那侧当时就拒 |
| ⚠️ 看不见的那一半 | **制品发了哪些请求我们看不见**（CSP 由浏览器执行）⇒ 这一样**没有留痕**；挡住它的是**白名单** |

🔴 **两层的分工**（主人把语义说死的一条）：

| 谁 | 网 |
|---|---|
| **助手自己** | **不设限** —— 它查网、取数、核实靠的就是这个；我们只**留痕**（域名/时间/量，**不记正文**）。**没有"给助手出网列白名单"这一层**（那是拍过不做的） |
| **制品页** | **只许声明里那几个站** —— 浏览器/WebView 的 CSP 硬拦，**他能一键关掉** |

⇒ 一句话：**助手无限、app 有名单**；而 app 的名单是**助手写的**、**他能关**。

#### 3.4.4 拍照 `camera` —— **镜头不经我们的手**

| 项 | 形状 |
|---|---|
| 它和别几样不一样 | **谁执行 = 浏览器 / WebView 自己**（`getUserMedia` / `<input capture>`）；我们只做两件：① **要他点头** ② **按授予放开那一层门** |
| 我们碰不碰数据 | 🔴 **不碰**：**不替它拍、不落盘、不进聊天记录**（要存是它自己的事，走它自己那格库） |
| 门在哪 | 网页：iframe 的 `allow` —— **唯一合法写法**是 `allowCamera ? 'camera' : ''`；安卓：WebView 的 `onPlatformPermissionRequest`，**只认摄像头、只认授予过的那个小程序**，**麦克风照拒** |
| 没授予会怎样 | **门是关的**：页面里那句话**当场被浏览器/系统拒掉**（不是我们替它拦） |
| 被拒怎么说 | 页面要**如实说**（**不许转圈假装在拍**）；这一句写进了 `app_create` 的说明 |
| 旧小程序 | **不会自动有这个能力** —— 要拍照就得**重新声明一版**（与 `net` 加站同一条规矩） |
| 安卓清单 | 要有 `CAMERA`；`uses-feature` **不许写 `required="true"`**（没镜头的设备照旧能装） |
| ⚠️ 真机 | **未核实**：拍不拍得出来要**他拿安卓机试**（代码这一侧只能验"门开了没有"） |

#### 3.4.5 跟它的助手说话 `agent` —— **有手的那一个**

| 项 | 形状 |
|---|---|
| 和 `ask` 的分工 | `ask` = 直连模型问一句；**这一样** = 把问题送进**它那一间**，由**那一间的助手**答 |
| 怎么调 | `POST /agent {prompt}` ⇒ `{ok:true, jobId, state:'running'}`；再 `POST /agent {jobId}` 取回执 ⇒ `{state:'running'\|'done'\|'failed'\|'timeout', text}` |
| 凭据 | 与 `/db`、`/ask` **同一套**（入口签名换票）＋ **`jobId` 就是那张票**（绑人绑 app，里面记着"问的是哪一号、什么时候问的"）⇒ **伪造不出别人的回执** |
| 闸 | 没声明 ⇒ 403「这个小程序没说要跟你的助手说话」· 他关掉了 ⇒ 403 · 太快 / 今天够多了 ⇒ 429；**取回执不扣配额**（只有"问"那一趟记） |
| 每次都看得见 | 问题以「**来自小程序「它的名字」**」落进**那一间**的对话，助手怎么答也在那儿 —— **不许做成他看不见的暗线** |
| 🔴 限定档 | 替小程序跑的那一轮**不许有手**：一层**减法补丁**（`hupo-app-agent.yml`）把 `tool-bash` / `tool-pwsh` / `tool-jobs` / 三个 `tool-subagent*` / **`tool-skill`** 全关掉，**不挂能力层** ⇒ 只剩**看**（读文件 / 找文件 / 查网）。⚠️ 关的是 **`tool-skill`** 不是 `skill`（关错会把服务提供者也关掉 ⇒ 整台 dsh 起不来） |
| 🔴 但那一轮要能查网 | **保留**网络搜索与取页（`web` / `web-search-deepseek` / `web-fetch-http` / `tool-web`）—— 判据钉着"这几件**不许**被关掉"；真读数：它去查了 `deepseek.com` 并答出标语，而且自己说清"只做了联网查证，没动任何文件、没跑命令" |
| 等过头 | **不编答案**：如实回 `timeout`（页面说"它还在想，去那一间看"） |
| ⚠️ 如实说一条 | `tool-fs` 是**一整块**（读与写在一起），今天**关不掉一半** ⇒ 那一轮**还写得了它自己那一间**（`cwd` 就在那儿）⇒ 跑完**要核**、动过**要如实说**。要彻底只读得另起一个 `dsh profile`（那是 `strict`，要主人点头） |
| ⚠️ 租户 | **今天不接**（要过隧道进他盒子）：**如实 503「你那台还没跟上」**，不许假装 |

#### 3.4.6 定时 `tasks` —— 他允许了才跑，而且跑在**他盒子里**

| 项 | 形状 |
|---|---|
| 声明 | 清单里 `permissions: ["tasks"]` ＋ `tasks: [{id, title, everyMinutes, prompt}]`（每件四样：短名 · 名字 · 隔多少分钟 · **让它干什么**） |
| 跑在哪 | 🔴 **他自己的盒子里** —— 不是我们的云 |
| 🔴 四条铁规矩 | ① **注册制**（没声明 / 他关掉 ⇒ **一件都不跑**）② **串行**（一次只起一件）③ **先记再跑**（账记不上就不跑）④ **间隔兜底到下限**（少了这一条会变成"每个 tick 都跑一遍"） |
| ⚠️ `/tasks` 没有窄口 | **app 原点上不存在 `/tasks` 路由**（只有 `/db`、`/ask`、`/agent` 三条）—— 定时是**服务端调度器**的事，`tasks` 只是一个权限名 |
| 数字住哪 | 间隔下限 · 每天次数 · 最多几件 · 多久看一遍 —— **只住 `src/app-tasks.js`** |
| 结果去哪 | 🔴 **回到那一间对话**：以「**来自小程序定时任务「它的名字」· 这件任务的名字**」落进去 ⇒ **他看得见** |
| ⚠️ `prompt` 的分量 | 它会被**当成"他让它做的事"**去执行 ⇒ 作者（助手）**只许写他明确要的那种事**（工具与人格里都写死） |
| 被拒怎么说 | 清单不合形状 ⇒ **当场拒**（**不是偷偷夹住** —— 夹住会让他以为"我设的 5 分钟生效了"）；他关掉 / 没声明 ⇒ **一件都不跑** |
| ⚠️ 今天还没有的 | **"到点一定跑"不保证**（服务没起来 / 正忙 ⇒ 跳过，**不补跑**）· **租户那一侧不接**（如实记一句并跳过，不假装跑过） |

### 3.5 授权这件事**只有一处签字**：他

- 助手能**说清**它要什么、能**提申请**；**那一下永远在他手里**（设置页那张卡与打开时那张弹窗，
  同一本账）—— 这一条与 [`05-DECISIONS.md`](05-DECISIONS.md) 的 `P1` / `P2` 是同一条。
- `/api/app-grant` 那条口走**登录态**；**助手那条工具口碰不到它**。
- **以盒子为准**：租户的授予落在**他盒子里**；盒子不通 ⇒ **如实 503**，**绝不**写宿主那一份
  （写了也不算数）。
- **清空它存下来的东西**：那颗按钮**每个小程序都有**（不管有没有声明过什么），先过**二次确认**
  （"它存下来的东西会没掉，拿不回来"），**只有确认之后**才发那一条请求；没成 ⇒ 照服务端那句
  `text` 说，**不许静默、不许先说成了**。⚠️ **别的几样他给不给，都照样能清**（"我的东西我拿走"）。
  实现：服务端 `POST /api/app-db-clear {id}`；租户那一侧**在盒里落**，盒子不通 ⇒ 如实 503。

### 3.6 一句话不许错：**界面上不出现协议名**

`db` / `ask` / `net` / `agent` / `tasks` / `camera` **一个都不许上屏**；
人话只住 `lib/models/space_words.dart`（进**禁用词硬闸**）。
四个例子：`ask` → 「**想用你的钥匙问一句**」· `net` → 「**想连网取数据**」·
`camera` → 「**想拍一张照片**」· `agent` → 「**想跟它的助手说话**」；
认不出的名字 → 「还想再要一样东西」。**存储不摆成一行**（它不是一件要他允许的事）。

## 四、每一格自己的库

### 4.1 单元：一个小程序 ＝ 一个独立的 SQLite 文件

| 项 | 规定 |
|---|---|
| **落点** | `<他那一格>/hupo/apps/<id>/data.sqlite` —— 在 `versions/` **外面** |
| **后果** | 发新版**不动它** · 删那个小程序时**跟着它走**（`appDir` 整个挪进 `.removed/`）· **按人分开**（甲看不见乙的） |
| **不是** | 不是"一个人的所有 app 一张表" —— **一个 app 一个文件** |
| **谁碰得到文件** | 🔴 **只有壳**。制品**永远拿不到文件**，也拿不到别人的库（跨库那条路两道堵死，见 4.5） |

### 4.2 执行在**壳这一侧的子进程**里（为什么不是 worker）

| 路 | 结果 |
|---|---|
| **worker 线程 ＋ `terminate()`** | ❌ **打断不了一条正在跑的本地调用** —— 一条失控的递归会把整个进程卡住（探针实测：`worker.terminate()` 之后 CPU 还在烧） |
| **子进程 ＋ 到点 `SIGKILL`** | ✅ **能硬停**，而且杀完库还能开（SQLite 的热日志自己恢复） |

⇒ 所以：**一条 SQL 卡不死服务**。执行体是 `src/app-db-run.js` 那个**独立子进程**
（Node 24 自带 `node:sqlite`，零依赖），到点 `SIGKILL`。
**判据要看到"那个进程真的没了"**，不是"回了一句超时" ——
`test/app-db.test.js` 的 **D3** 直接去 `/proc` 看它没了（`sig=SIGKILL`）；
⚠️ 这一条是**被自己抓出来的**：第一版判据只验"回了那句话" ⇒ **照样绿**，
所以判据改成"去看它真没了"。

**代价（如实认下）**：每一次调用多一次进程往返（几十毫秒量级，探针读数在
`docs/dev/147-APP-SQLITE.md` §一 / §五）。**没做**进程池 / 常驻子进程 ——
那要另写生命周期与回收；这一步先要"正确"，不要"快"。

### 4.3 制品怎么用它：**对它自己那个原点发一次请求**

**形状**（与 `/ask`、`/agent` **完全同一个形状**）：

```
制品 → POST <它自己那个原点>/db
  第一次：{ id, v, u, e, s, op, sql, params }      ← u/e/s 来自它入口 URL 那三样
          ← { ok:true, rows, changes, lastInsertRowid, truncated, ticket }
  之后：  { id, v, ticket, op, sql, params }
```

**票是什么**：`base64url({u,i,v,e}) + "." + hex(HMAC(...))`（`src/app-db.js`）——
绑**人**（`u`）、绑 **app**（`i`）、绑**版本**（`v`）、有**到期**。
⚠️ **为什么要有票**：入口 URL 是**短时效**的（`src/app-serve.js` 的 `SIGNED_TTL_MS`），
而一个页面可能开着几小时 ⇒ 第一次用签名换票，之后用票。
⚠️ **票只在内存里算**（HMAC，不落盘、不上账）⇒ 重启就让所有票失效（可接受，页面刷新即可）。
⚠️ **权限每次都重查**（撤销立刻生效）。

🔴 **为什么这条形状是整套设计的地基**：网页那一侧是 opaque origin 的 iframe、
安卓那一侧是 WebView **顶层文档**，**两边都从同一个制品原点加载**
⇒ 它们**吃同一个 CSP 头、走同一条路** ⇒ **不需要原生桥**（铁律 3 没破）。
真浏览器端到端量过（一次性实例、不碰线上）：iframe 是 opaque origin，
`fetch('/ping')` **到得了服务器**（服务端看到 `origin: "null"`），
跨源预检真的发生而且过了；盘上真出现那个 `data.sqlite`。
读数与踩过的坑（`chrome --headless --virtual-time-budget` 按虚拟时间 dump，
而跑一条 SQL 要等一个**真**子进程 ⇒ 要真等就用项目自己的浏览器驱动，它按**墙钟**等）
在 `docs/dev/147-APP-SQLITE.md` §四·甲。

### 4.4 给它什么、不给什么

| | 内容 |
|---|---|
| **三条动作** | `run`（写/改）· `get`（一行）· `all`（多行） |
| **参数** | **一律绑定**（`?` 占位符）—— 页面不许拼字符串（那是注入的形状）；只认 `null` / 字符串 / 数字 / 布尔 |
| **一次一条语句** | 多语句**当场拒**；⚠️ **注释与字符串里的 `;` 不算**（真扫一遍状态）—— "一条语句干两件事"是绕过上限最省事的办法 |
| **建表 / 迁移** | `CREATE TABLE IF NOT EXISTS`；改结构用 `PRAGMA user_version` |
| **不许** | `ATTACH` / `DETACH` / `load_extension` / `VACUUM` / 显式事务 / 递归查询 / 别的 `PRAGMA` / `readfile`・`writefile` |
| **上限** | 每库字节 · 一条 SQL 长度 · 参数个数 · 带回行数 · 结果字节 · 单次时长 · 每分钟次数 —— **只住 `src/app-db.js`**（`08-SPEC.md` §十 是总表） |
| **留痕** | **拒的那几档**写审计（`db-deny` / `db-rate` / `db-full`）；**成了的不写** —— "谁想干什么被拦了"要查得到，每调一次写一行会把账淹掉 |

### 4.5 跨库那条路：**两道堵死**

1. **文本守卫**（`guardSql`）：按**词边界**拒 `ATTACH` / `DETACH` / `load_extension` / `VACUUM` /
   显式事务 / `readfile`・`writefile`（`attachment` 这种**列名不误伤**）。
2. **`setAuthorizer`**（在**子进程里**）：`ATTACH` / `DETACH` **直接拒** ·
   `PRAGMA` **只放行 `user_version`**（迁移要用）· `RECURSIVE` **拒**。

⇒ 就算第一道漏了，第二道也过不去；就算两道都漏了，那个文件也**只**在它自己那一格里
（路径由壳定死，**页面报的任何路径一个字节都不采信**）。
**判据**：`D2` —— `ATTACH` 两道都拒，**第二道是直接绕开守卫调的**（验的正是 `setAuthorizer`）；
变异：去掉 `setAuthorizer` 里那两行 ⇒ **D2 红**。

### 4.6 被拒的时候**各说各的话**

混成一句会让人一直重试 —— 所以这几档**分开**：

| 屏幕上发生什么 | 服务端说的是什么 | 页面该怎么办 |
|---|---|---|
| **满了** | 507「这个小程序的存储满了。」 | 如实说，并提示"清一清旧的" |
| **太频繁** | 429「……存得太频繁了」 | 等一下再试 |
| **一条查太久** | 503「这一条查得太久了……」 | 如实说，把范围写小 |
| **这条 SQL 本身不行**（动作/语句/参数不认、多语句、危险关键字…） | 400「这一条它没执行成功。」 | 如实说（那是页面自己的 bug） |
| **行数被截断** | 结果里带 `truncated: true` | **如实说"还有更多"**，别当成全部 |

⚠️ **存储没有 403 那一档**（它不用他允许；`403` 是 `ask` / `net` / `agent` 那几样的）。

### 4.7 他能清空、以及**明确还没做的那几样**

**「清空它存下来的东西」**：见 §3.5 —— **每个小程序都有那颗按钮**，
二次确认、拿不回来、与"给不给它用"无关；服务端 `POST /api/app-db-clear {id}`，
幂等（没存过也回 `{ok:true}`），**只删那一格存储**（连它旁边的 `-wal` / `-shm`），
**制品、工作区、那个 app 本身都不动**（下次打开是一个空库）。

**明确还没有的**（**不是"排后"**）：

| 没有的 | 说明 |
|---|---|
| **BLOB（二进制）** | 只认 `null` / 字符串 / 数字 / 布尔；要开得先定编码与上限 |
| **导出 / 带走** | 库不能导出成文件给他 |
| **跨 app 共享** | **没做，也不打算做** |
| **让助手读这个库的程序化口子** | 助手要查只能走"人话路径"（那是另一件事） |
| **iOS 侧这条能力** | iOS 商店版不许小程序运行时（铁律没变） |

⚠️ **`docs/dev/147-APP-SQLITE.md` §五 里"「清空」那颗按钮没做"那句已经过期** ——
它写的是那一条还没落地的当时；今天那颗按钮**每个小程序都有**（§3.5、§4.7 上面那一段，
判据 `D8` ＋ `G6` ＋ 客户端那两条）。**别照 §五 那句去验收。**

## 五、制品管线：从"他说要做"到"桌上有一格"

### 5.1 盘上有**两层**，别读混

| 层 | 落点 | 是什么 | 谁写 |
|---|---|---|---|
| **工作区（活内容）** | `<他那一格>/workspaces/<id>/` | **他正在改的那一份**：助手在这一间里干活时 `cwd` 就是它；里面还有一间自己的账 `.hupo.json` | 助手（在那一间里直接写文件）／`AppWorkspaces.ensure()` 建 |
| **制品库（那张脸 ＋ 可选包）** | `<他那一格>/hupo/apps/<id>/` | `app.json`（**登记**：名字/图标/入口/权限/版本计数/指纹）· `versions/<n>/`（**包**，不可变）· `grant.json` / `ask.json` / `tasks.json` / `data.sqlite`（**那一格自己的账与数据**）· `lineage.json`（血缘登记） · `.removed/`（软删的落点） | `Apps.register()` 写 `app.json`；`Apps.create()` 写版本目录；`noteLineage()` 写血缘 |

🔴 **`meta()` 读两层**（`src/apps.js`）：只有包（老 app）／只有活登记（还没发过）／两者都有
（**名字/图标/权限取活那份、版本/`rootHash`/字节取包**）—— 认人只有这一处，
所以"活的那一份"与"装来的 / 发过一版的"**不可能分成两套读法**。
`manifest()` 与 `read()` **只读制品那一层**，而且 `read()` **逐字节核 hash**
（对不上就抛，**不是"尽力画"**）。

**活地址 vs 制品地址**（两条路，别混）：

| | **活地址** | **制品地址** |
|---|---|---|
| 形状 | `GET /w/<id>/<rel>?e&s` | `GET /a/<id>/<version>/<rel>?e&s` |
| 取的是 | **那一间工作区里"现在那一份"** | **某一版不可变快照** |
| 谁在用 | **桌面那一格点开时**（`/api/apps` 的 `entryUrl` **恒签这一条**） | 发布 / 血缘 / 回滚那一侧 |
| 签名 | 同一把键、同一个 TTL、同样四道验 —— 只是 payload 里"取哪一份"那一格用**哨兵 `live`** | 版本号 |

⚠️ **这两条路的签名互不通用**（域分离）—— 制品签名拿到活地址上过不了，反之亦然。
⚠️ **`/api/apps` 里那个 `version` 字段照旧给**（协议字段一旦上线就冻结），
但它**不再是"能看见新内容"的前提**：活地址那条路压根不看它。

### 5.2 六步：他一句话 → 桌上那一格

> **这一节是"做小程序那个 agent"的流程**（给它的作业指导书在 §七，这里讲机制）。

| # | 这一步 | 机制上发生什么 | 落点 |
|---|---|---|---|
| 1 | **听懂要什么** | 拿不准的**先问一句**（名字、要记什么、要不要联网）；**不问"要哪个平台"**（只有他桌面这一个） | 人格 / 工具说明 |
| 2 | **动手造** | 🔴 **在那间工作区里写文件** —— 那张 `cwd` 就是它 | `workspaces/<id>/` |
| 3 | **建工作区 ＋ 登记** | 服务端那一刀（**不靠模型记得建目录**）：`ensure()` 建目录＋写占位页＋写 `.hupo.json`；`Apps.register()` 写 `app.json` | `src/apps-socket.js` 的 `create` |
| 4 | **桌面自己长出来** | 登记成 ⇒ 推一条 `app/installed`（**瞬态**：客户端收到就重拉清单） | `worlds.js` |
| 5 | **他点头** | 打开那一格时把 `unanswered` **一次问完**（§三） | 客户端 |
| 6 | **之后就是活的** | 助手再改那一间里的文件 ⇒ 屏幕上自己就是新的（§5.5） | —— |

**两道"他明说才许写"不只写在说明里**（说明是给模型看的，被绕进去了就一道也拦不住）：

- 服务端在**写盘之前**自己看一遍 —— **这一轮他到底说了什么**（`src/apps-consent.js`）。
  它**只读服务端自己记的当轮输入**（请求里就算写着"他明说了"也**一眼都不看**，
  与"身份只从令牌来"同一条纪律）；**认不出就拒**（保守默认），并在话里告他**该怎么说**。
- **"明说" = 语义上要了**，不是某一句格式：「做一个记账的」「我要一个能玩的小页面」
  「把数独内容放到小程序里面」**都算**；而且**"接着说"也算同一件事**
  （他先要了、接下来几轮讲怎么改 ⇒ 看**同一间里他最近说过的那几句**，窗口很小）。
  ⚠️ **助手自己发起的那一轮**（定时、重做、别人代投 —— 没有"他那句话"）**一律不许写盘**。
- **同一间的"再登记"不需要"明说"**：那一格**已经在他桌面上**（同一个 id），
  再登记一次不是"往他桌面上放一个他没要的东西"。⚠️ **只放这一种** ——
  主线里造新东西、在**别的小程序**里造东西，照旧要明说。
- **"里面不能再开一个"**：判据是"**现在这一间是不是已有的一个小程序 / 内置那一格**"
  （**不是** `scope !== main`）—— `main` 与**派活那一间**放行，小程序 / 内置那几格拒，
  拒的时候回一句人话（"回桌面上说一句……"）。⚠️ **那一句本身就是答复**，
  所以它**不额外**再喊一条"没做成"（§5.8）。

**那粒工具面一共九件**（`src/mcp-apps-server.mjs`，`D4.18`：一切操作都在对话里）：

| 工具 | 干什么 |
|---|---|
| `app_create` | 造/更新一个小程序（**内容可以不交** —— 那一间里已有的就是它） |
| `app_publish` | 发到「发现」给别人装 |
| `app_unpublish` | 把**自己发的**撤下来（别人手上那份还在） |
| `app_discover` | 看别人发了什么 |
| `app_install` | 把发现里的装到自己桌面（`mode: refresh\|fork`，默认分叉） |
| `app_grant` / `app_revoke` | 现在允许 / 现在不给某一样（**关掉不删已存的东西**） |
| `app_uninstall` | 真删那一格（连那一间的工作区、说过的话、存下的东西一起） |
| `app_list` | 看他自己的小程序 |

⚠️ **没有 `app_lint` / `app_run` 这两个工具** —— 自查是 `app_create` 回执里那一段，
"真跑一次"是**发布路径自己**的一步（见下）。

### 5.3 打开那一格：**是他正在改的那一份**

`/api/apps` 给出的 `entryUrl` **恒签活地址**；HTTP 侧那个分岔写在 `app-serve.js` 里：

```
const live = parseLivePath(pathname);
const hit  = live ? null : parseArtifactPath(pathname);
const version = live ? LIVE_VERSION : hit.version;
pending = live ? apps.readLive(...) : apps.read(...);
```

🔴 写成一条（"取哪儿"合成一个判断）就会**悄悄退回某一版快照** —— 那正是这一条要防的事，
所以那两行是**分开**的。

**活地址的白名单**（规则只有一处：`src/app-live.js` 的 `checkLiveRel()`，
而且它在**碰库之前**先跑）：

| ✅ 允许 | ❌ 拒绝（一条都不放行） |
|---|---|
| 那一间工作区里（含子目录）**不以 `.` 开头**、不在拒绝表里的文件 | `..` / 绝对路径 / 反斜杠 / 空段 / `.` / 控制字符 / 超长路径 |
| 入口只有一个（那一间清单里的 `entry`，默认 `index.html`；认不出的 entry 退回 `index.html`） | **任何一段以 `.` 开头**：`.hupo.json` · `.data/` · `.exp/` · `.removed/` · 临时文件 —— 那是工作区自己的账 / 他的数据 / 经验 / 回收处 / 原子写的中间产物 |
| | 保留目录 `build/`（那不是页面的一部分） |
| | 解析之后**跑出那一间目录**（第二道：防符号链接 / `..`） |

**老 app 没有工作区怎么办**：`readLiveApp()` 在没有那一间清单时，从**当前那一版**镜像一次
（走"装上来"同一条写路）。🔴 **只此一次** —— 镜像完清单就在了，之后**绝不再拿旧版顶替**：
他删掉的文件就是删掉了（V1·补 ③ 钉着：删了 ⇒ 404，不许把旧版画回来）。

**以盒子为准**（同 §5.9）：租户经**现有隧道**读**他盒子里**那份；**盒子不通 ⇒ 如实 503**，
**绝不**退回制品那一版，也**绝不**说"没这个文件"。

### 5.4 发布：把它**现在那一份**打成一个包

**发布不是"他自己那份生效"的前提**（§六）—— 它是"把它发给大家"那条路。

**一次发布跑过的闸**（顺序是刻意的，**任何一道拒 ⇒ 共享库一个字节都不动**）：

```
① 出界申报（两格：<scope>/.exp/ 与 <scope>/.data/）＋ 锚 ＋ 血缘
② 声明 ↔ 声明（清单与它自己自洽）
③ 声明 ↔ 字节（不多、不少、不换字节）＋ 外联申报（读不到 ⇒ 拒）
④ 形状声明（数据那一格）
⑤ ★ 真跑一次（最小判据）—— 入口那一份的脚本在一个最小壳里真编译、真执行，
     带硬时间预算；入口必崩 ⇒ 拒（理由点名哪个文件哪一行）
⑥ 之后才写盘：versions/<n>/ → index.json（带"跑过"的凭据）→ 审计
```

**打一版从哪来**：`snapshotWorkspace()` **从工作区读**（`workspaces.read(id)` →
`apps.create({files: ws.files})`）—— 也就是说"包"是**他正在改的那一份**打出来的。
⚠️ 工作区**一个文件都没有**（还没写 / 占位页被删了）⇒ **不重打**（那会把一个空目录打成一版）。
⚠️ 在"发"这一步之前，`publish` 分支会先比工作区 hash 与当前那一版 `rootHash` ——
一样就不重打。

**"真跑一次"证的是什么、不证什么**：

| 证 | 不证 |
|---|---|
| "能起来 / 入口必崩"；崩了**点名哪个文件哪一行** | **不是**"在主人屏幕上是什么样"（真机那一侧归浏览器驱动那条判据） |
| 每段脚本一个**硬预算**（到点截住） | **不做全量回归** |
| 外链脚本 / `type="module"` / JSON 数据块**不跑也不拦**（分级） | `type="module"` 那一档今天如实记 `skipped` —— **那是"不可算"，不是"验过了"** |

**上架预审**（发布流程的第一步，自动跑）：规则（产品层只读＋指纹）→ 申报 → 代码扫描 →
用量 → **评审 agent**（真那台 DSH；没接上 ⇒ **不自动放行**）；结论**绑 `rootHash`** 落档；
低风险自动放行、高风险找主人。运营方那一侧**独立再读一遍整份源码**，两份对不上 ⇒ `escalate`。

### 5.5 出去的那一份**就是清单声明的那一份**（**N31**）

> **N31**：往共享库／发现页出去的字节，**任一段以 `.` 开头的路径一份都不许有**，
> 而且**恰好等于**那一版清单声明的文件（**不多、不少、不换字节**）；
> `share:true` 而**没有可核起点（锚）⇒ 不出**。

| 项 | 规定 |
|---|---|
| **硬边界** | "在不在制品里"**只看路径**：**任一段**以 `.` 开头 ⇒ 不进制品、也不跟着装走 |
| **声明承重** | 每个包**自己的 `pack.json`** 说了算：`share`（**带锚**才出）· `one-to-one`（收方同意且可撤回）· `never`（缓存／记忆／账，**永不出**）。🔴 **读不到声明／认不出 ⇒ 拒**（默认最严，**不是**"当没有"） |
| **一条独木桥** | 上架／交付／制品口**共用一个出口检查**；往共享库写字节全仓**只有一个写入者**（`published.publish()`）。冒出第二个出口 ⇒ **红**（源码级判据钉着） |
| **可核起点（锚）** | `share:true` 必须带**核得出来、且血缘指得回**的来源 `rootHash` —— **自称的来源不算来源** |
| **常驻断言** | 🔴 **发布路径自带**（不是闸脚本里的技巧）：它跑在**碰第一个字节之前**；成功那条审计**带 seal**；🔴 **拒的时候共享库一个字节都不动** |
| **它压什么、不压什么** | 压的是**声明 ↔ 字节**（结构）。**不扫内容** —— 一份 `sk-` 之类的字符串黑名单**会误伤正经内容**，也**永远追不上下一个形态**。⚠️ 真机上"全库搜哨兵"那条闸**仍然保留**，它是**事后抽样**，与这条**不是同一件事**，两条都要有 |

**读侧用同一个规则、但拒法不同**（规则只有一处：`apps.js` 的 `refuseHiddenRelPath()`，
写侧在**动盘之前**、读侧在**读第一个字节之前**）：

| | 写侧（发布） | 读侧（制品口） |
|---|---|---|
| 拒法 | **不发布**（共享库零字节） | **回一条看得见的 403**（带 `code='hidden-path'` ＋ 一条能查的理由 ＋ 一条审计） |
| 为什么不同 | "不许出去" | **不是**为了悄悄弄坏 —— **拒绝要看得见**（不是白屏、不是假 404） |

⚠️ **老包里已有的隐藏路径从那时候起取不出来**（这个代价**已接受**），换来的就是"拒绝看得见"。
⚠️ 租户那份字节在**他盒子里** ⇒ 盒子内部口**认这个 code**、**不许过一趟隧道变回假 404**。
判据：`test/app-read-hidden.test.js` · `test/outbound-resident.test.js`（N31 那几条，
**每条带差分负向对照**）· `test/outbound-single-exit.test.js`（唯一出口）·
`test/apps.test.js` 的路径安全 / 路径解析 / 路径穿越三组。

### 5.6 装（fork）：**装上来就是他自己那份**

```
装之前：① 先拍工作区快照（先于任何覆盖；拍不下来 ⇒ 不许装）
        ② 工作区 hash ≠ 当前 rootHash ⇒ "他改过"
        ③ 他改过而没说怎么办 ⇒ needs-choice（选项：刷新 / 分叉），默认 fork
装：published.installInto() —— 把共享库那一版复制进他的制品库
分叉：apps.rollback 把指针拨回"他手里那份" ＋ noteLineage(上游 rootHash / 版本)
      ⇒ 工作区一个字节都不动
刷新 / 没改过 / 新装：mirrorArtifactIntoWorkspace()（制品库那一版 → 工作区）
```

🔴 **"分叉 = 记上游、留自己的"**：记忆落在 `hupo/apps/<id>/lineage.json`（**登记，不写进不可变清单**）。
⚠️ **不是权限闸**：`install` 那条路上**没有"外来要先允许一下"那一档**（§3.3）。
⚠️ **作者下架 / 删除之后，装过的人那份还在**（复制模型：装上来就是他的）。
⚠️ `needs-choice` 是"**要回头问他一句**"，**不是失败** —— 所以**不许**喊一条"没装成"（§5.8）。
判据：`test/app-install-fork.test.js`（S1 含**反例的正身**：没有快照就覆盖 ⇒ 他改的字节真会没）·
`test/apps-chain.test.js`（装上 ⇒ 复制进他自己的那一份）。

### 5.7 市场那一侧：上架 · 发现 · 更新

| 动作 | 走哪 | 关键规矩 |
|---|---|---|
| **上架** | 工具 `app_publish` → `published.publish()` | 见 §5.4/5.5；共享库那一份**不存作者真身份**（署名是**可换可弃的假名**，带键 HMAC；存量老值只读） |
| **下架** | `app_unpublish` | 只把那一格改成"没上架"；**别人手上那份还在** |
| **发现** | 屏上那一屏只读（`GET /api/discover`）＋ 工具 `app_discover` | 只列**上架了的**；**对外不给 `authorHash`**；**这一屏没有任何"装/发/改"的动作** |
| **装** | `app_install` → `installInto()` | 见 §5.6 |
| **更新** | 他装过的那一份有新版 ⇒ **升级判定** | 见下 |

**升级判定只有一处**（`src/app-upgrade.js`）—— 它比的是**契约版本**，不是 `rootHash`：

| 结论 | 什么时候 |
|---|---|
| `none` | 没有新版 / 就是这一版 —— **一个字节都不写**（不过度） |
| `held` | 他**显式留旧版**了（粒度**默认按用户整体跟**，某一个可以 `pin`） |
| `byte-swap` | **契约版逐字相同** ⇒ 整版换字节 ＋ 保数据，**不请 AI** |
| `ai-rewrite` | **契约版变了** ⇒ 请 AI 在那个实例自己的房间里走出来（**不是 mapping 表**） |
| ⚠️ | **任一侧读不出 ⇒ 抛**（`不可算`），**既不默认请、也不默认不请** |

🔴 **如实说**：**"请 AI 重写"那个执行器今天不存在** —— 交出来的是**那一处判定 ＋ 那本账 ＋ 判据**；
账本记的是"**这一次决定要请 AI**"，不是"AI 真的重写完了一遍"。
⇒ **"重写计数"今天读的是"决定计数"**。

### 5.8 更新了，为什么**正开着的那一屏会自己换上**

主人定的产品形状：*"前后端完全同步……后端增加内容前端显示是一一匹配的。不需要刷新。"*
今天它由**两条帧 + 一次收干净**组成 —— **两条的语义刻意不同，别混成一条**：

| | `app/update-available` | `app/workspace-changed` |
|---|---|---|
| 什么时候 | **某一版真的写下去之后** | **那一间工作区的内容变了** |
| 帧里有什么 | `{type, id, version, at}` ＋ 日志本来就会盖的 `seq` / `scopeId` | `{type, id, at}` —— **只有这三样** |
| **持久 / 瞬态** | **持久**（有号、落盘 ⇒ 重连与切回那一间都补得上） | **瞬态**（不占号、不落盘、重连**不重放**） |
| 客户端要判什么 | **判"比我新吗"** ＋ 按 `(id, 版本)` 去重 | **不判版本** —— 收到就重取 |
| 为什么这么分 | "**有一版新的**"是**盘上的事实**（他离线那会儿发的那一版，回来还得知道） | "**你正开着的那一页该重取一次**"是**现在这一刻**（回来后收到一条"刚才变了"是假话） |

🔴 **两帧里都不许有签名 URL**（`entryUrl` 短时效 ⇒ 落盘就是写一句迟早变假的话）——
客户端拿 `id` 自己去 `/api/apps` **现取**新的 `entryUrl`。

**客户端那一步**（一帧 = 一条 `entryUrl`）：

- 正开着的**就是它** ⇒ **现取一次清单** ⇒ 新 `entryUrl` ⇒ 新 `viewId` ⇒ **iframe 换掉**；
- **别的 app** ⇒ **一个像素都不动**（连接口都不多打一次）；
- **没开着**（在桌面上 / 在别的小程序里）⇒ 只记一笔"它有新版"；
  **下次点开它之前先重拉一次清单**（免得点开还是旧那一版）。
- **旧那一帧要收干净**：挂载那本账里销号 ＋ Web 那一侧真去退订 `onMessage`
  （不销的话，老那条全局监听还会替新页面把"问一句"再送一次 ⇒ **多花一次他的额度**）。
  ⚠️ `registered` 那本账**不许销**：同一个 `viewType` 只许注册一次，销了号再注册会**当场抛**。
- **去重按 `(id, 版本)`**（补发那条路必然重复送），而且**它不许在 `ingest` 里 `return`**
  （它是持久事件 ⇒ 必须继续走到 `timeline.apply`，否则客户端的游标停在那一号上、
  **每次重连都从这一号重放一遍**）。

**"改了那一份"是谁看着盘**：他改那一份的**主要方式**是让助手在**那个目录里干活** ——
那是**直接的 `write` 系统调用**，不经过我们任何函数 ⇒ 只能**看着盘**（`fs.watch` 递归）。
挂在某个写函数上的话，"改完屏幕上就变"只对那条路成立。
宿主只看**数据真在本机**的那些人；**盒里**看自己那一份并**经既有那条 `notifyHost`** 报给宿主
（用户那一屏连的是宿主）—— 那条通道会**排队补发**（连接恰好在重连时不许丢）。
只有白名单里的路径会叫（`.hupo.json` / `build/` / 临时文件被写 ⇒ **一次都不叫**）；同一间连着写会**合一合**。

**桌面那一格自己会变**（`D4.27` / `D4.28` / `D4.29`）—— 三件事各是各的：

| 状态 | 事实从哪来 | 屏幕上 |
|---|---|---|
| **在建** | `/api/apps` 的 `building`：入口那一份**不在**、或者逐字节还是我们写的那页占位 ⇒ `true` | **灰底 ＋ 灰图形 ＋ 中间一个转着的圈**；点它**不打开**，只说一句"还在做" |
| **在做** | `working`（与"那件怎么样了"读的是**同一本活账**） | 那一格**右下角多一个转着的小圈**（底色不变、**点它照样打开**） |
| **桌面刷新** | **三半缺一不可**：① 工作区内容直接变了**而且它不再是"在建"** ⇒ 推一条 `app/installed`（＝"桌面可能变了"）② 从某一间点 home 回来 ⇒ 重拉一次 ③ 这一屏从后台回前台 ⇒ 重拉一次 | —— |

⚠️ **拿不到那条事实（老服务端 / 盒代理）一律 `false`** —— **"不知道"不许画成"在建"，
也不许点亮"它还在做"**。⚠️ **不轮询**（买不到另外两种情形之外的正确性，却是持续的隧道流量）。

### 5.9 以盒子为准：**租户那一侧的数据只在他盒子里**

这一条对**每一条路**都成立（`/api/apps` · 制品口 · 活地址 · 授予 · 清空 · 删 · 重命名 · 复制 · 建）：

- **主人 / 单租户** ⇒ 读/写**本机那一间**；
- **租户** ⇒ 经**现有隧道**读/写**他盒子里**那份（内部口与制品口同前缀、同信任模型：
  **只在可信 UDS 上接**，公网口 404 且**不碰库**）；
- 🔴 **盒子不通 ⇒ 如实 503**（"这个现在打不开，等会儿再试试。"）——
  **绝不**退回宿主那份旧的，也**绝不**说"没这个文件"（他有，只是那台没应）。
  ⚠️ **这一条正是"两处库"那句假话的补口** —— 退回宿主那份就是那句假话又活过来。
- ⚠️ 一趟能带回来的就**一趟带回**（盒子那份清单**顺手把 `granted` 一起带回来**）——
  "每个 app 各问一次盒子"是判据抓出来的真缺陷（几十个 app 就是几十次隧道往返）。
  判据：`test/apps-box.test.js` 的 **B15** 一族
  （含"没签名 ⇒ 403，而且盒子一次都没被碰"、"公网口 ⇒ 404 且库一次都没被碰"）。

### 5.10 删：**真回收**，而且拿不回来

| 动作 | 拿走什么 | 留下什么 |
|---|---|---|
| `app_uninstall`（按 id） | 制品那一格（挪进 `.removed/`）· **那一间的工作区目录** · 那一间的对话记录 · 助手那边那一间的会话记录 | **审计与用量账**（不许跟着没）· 被拿走的号记在 `reclaimed.json`（那条日志**留号洞**，`N22` 的唯一例外） |
| `/api/room-remove`（按房间，补"还没有制品的那一间"那条洞） | **工作区目录** · 那一间的对话记录 · 助手那间的会话记录 | **不动制品库**（留痕里 `items.app` 如实 `false`）· 四道闸：`main` 拒 · **内置那几间**拒 · 制品库里还有它 ⇒ 拒 · 认不出 ⇒ 404 ＋ 人话 |

⚠️ **界面上不许说"还能拿回来"**（今天没有任何入口能把它装回来），但**必须**说清
"会一起拿走什么"，并**二次确认**。

### 5.11 没做成的时候：**要有一条人话**

工具那几条回的 `{ok:false, error}` 是**写给模型看的**（里头有内部短名、还有"工作区"这种**禁用词**）
⇒ **一个字都不许原样上屏**。所以**挂在唯一入口上**（`handleAppsOp` 外面那一层壳）：
**分类 → 一句固定的话 ＋ 那个小程序的名字**（`src/app-fail-words.js`），走现成那条通知通道。

| 情形 | 喊不喊 |
|---|---|
| **没做成 / 被拒（任何原因）** | **喊**（点名 ＋ 一个内部词都没有） |
| `needs-ask`（他本人没说要做）· `needs-choice`（刷新还是分叉）· `inside-app`（里面不能再开一个） | 🔴 **一个字都不喊** —— 这三件**不是失败，是"要问他一句"**（那几句本身就是答复），喊一条"没做成"就是**假话** |
| **成了** | **也不喊**（不许"狼来了"） |

⚠️ 三条"太大/太多"**分动作**：用户端（`create`）那几条**已经不该再出现**（他自己那份不查上限）；
它们今天只属于**发到市场那一步**（`publish`）⇒ 话要说成"**要发给大家的那一份**……**你自己那份照旧能用**"
（说成"没能存下"会让他以为**自己那份也没了** —— 那是假话）。

## 六、用户端 vs 包：**上限只在"包"那一侧**

> 主人定的形状（原话）：
> *"所谓的版本快照，只在市场中存在。不在用户端。用户 a 创建的，在他自己那里就是一段源代码部署；
> a 推到市场，就是一个包；用户 b 使用，实际上是把包拉下来变成源代码部署。用户 a 和用户 b 后续的
> 使用和部署，都是用的自己的，所以**不需要什么压缩**。"*

**一句话**：**用户端 = 一段活的源代码部署；"版本 / 快照 / 压缩 / 回滚"只属于"包"。**

| | **用户端**（他自己那一份 ＝ 桌面那一格） | **包**（市场那一侧） |
|---|---|---|
| 是什么 | **一段源代码部署**：`workspaces/<id>/` 里**现在那些字节** ＋ 一份**登记**（`hupo/apps/<id>/app.json`：那张脸） | **一个包**：不可变 `versions/<n>/` ＋ `rootHash`（发出去 / 装来的那一份） |
| 怎么打开 | **活地址** `/w/<id>/<rel>`（§5.3） | 制品地址 `/a/<id>/<version>/<rel>` |
| **尺寸 / 文件数** | 🔴 **一个都不查** | ✅ 查（单文件 / 整版 / 文件数，住 `src/apps.js`） |
| 什么时候成"包" | **不发就不成包** —— 助手在他那间目录里改文件，他屏幕上就是新的 | 发布那一步从工作区**打一版**；打不成 ⇒ **如实拒**（**他自己那份照旧能用**） |
| 怎么变 | **改了就是新的**（`app/workspace-changed`，§5.8） | 重新发布 ⇒ 新的一包；别人可以再更新 |
| 版本 / 回滚 | **没有** —— 他自己那份**没有版本可回退**（要留底 ⇒ **先发一版**） | 有（不可变版本 ＋ 回滚 ＋ 血缘） |

**为什么是这样**：他那一份**是活的**（他开发的过程就是对**当前这一版**改内容、改功能），
所以"落一版才看得见"这条规矩**在用户端不成立**；把"包"的那三道上限挂到用户端，
代价就是他会被一堵**我们造出来的墙**挡住（真机现场：助手为了塞进那一页，
开始"压答案 / 拆成两个图标"，然后停下来让他挑 —— 而那个小程序的**工作区里明明是 246KB 的活文件**，
制品那一版只有 17KB）。⇒ 结论：**同一份 300KB 内容，用户端过、打成包拒** ——
上限**没消失**，只是回到了它该在的那一侧。

🔴 **判据**（`test/app-user-side.test.js`，**每条都能反着验** —— 反着验是这一节的要害）：

| # | 判据 | 反着验（必须红） |
|---|---|---|
| **V1** | 写工作区 ＋ 登记**不因**单文件 / 整版 / 文件数被拒，且**不落** `versions/`、**不落** `current.json` | 把单文件上限加回 `AppWorkspaces.write()` ⇒ 红 |
| **V1′** | **同一个目录打成包**照旧被拒（上限没消失，只是回到了这一侧） | 把 `apps.create()` 那三道一起拿掉 ⇒ 红 |
| **V2** | `app_create` **可以不交内容**（那一间目录里已有的就是它，一个字节不动） | 把 `files` 又变成必填 ⇒ 红 |
| **V2′** | **没明说**照旧拒（`needs-ask` —— "他明说才许写"那条闸没被顺手拆掉） | 拿掉 `apps-consent` 那道闸 ⇒ 红 |
| **V3** | 活的那一份**改名 / 复制 / 删除**照旧能用（认人那一处 = `meta()`） | 让 `copy()` 对活的那一份直接抛 ⇒ 红 |
| **V4** | **只有包的老 app**（装来的 / 发过一版的）行为**逐字不变** | 把 `meta()` 改成只读 `app.json` ⇒ 红 |
| **V4·补** | 只有登记、还没有包时 `rollback` **如实说**"要回滚到的那一版不在" | 假装滚成功 ⇒ 红 |
| **V5** | 一份**很大**的页面走**真那条口**（工具 → 域套接字 → 登记）也成 | 把套接字那一行上限改回小一档 ⇒ 红 |

⚠️ **代价如实认下**：他自己那一份**没有版本可回退**（要留底就得先发一版）；
`app_publish` 之后**他自己那格里会多一个 `versions/<n>/`** —— 形状上"包"出现在他这一格里
是**刻意的**（发布这个动作本来就属于市场那一侧）。
⚠️ **包的数值还是我们定的**：他真去发一份很大的东西，会在"打包"那一步撞上那三道上限 ⇒
屏幕上是一条人话（"要发给大家的那一份……你自己那份照样能用"），**不是**自己那份出问题。

## 七、给"做小程序的 agent"的作业指导书

> **这一节是那一段**：核心里那个"替他把小程序做出来"的 agent **照着它干**。
> 它**可以直接整段抄给那个 agent**（规则、话术、自查表都在里面），
> 也可以对着它检查"那台 agent 有没有照做"。
>
> 它的**判据**：`src/app-lint.js`（写完当场自查，**纯函数**）＋ `test/app-lint.test.js`
> ＋ `apps-socket.js` 回执里那一段 ＋ `mcp-apps-server.mjs` 摊给模型看的说明。
> 它的**机制依据**在 §三 / §四 / §五（那几节是规范；这一节是**作业书**）。

### 7.0 先认清自己在哪儿（三条最要紧的现场事实）

| 谁 | 在哪儿 | 干什么 |
|---|---|---|
| **主人** | 桌面 / 某个图标的对话里 | 说一句需求（"帮我做个…"） |
| **那个 agent（你）** | **那个图标自己的那一间**（你的 `cwd` 就是它） | 写页面、声明能力、交付一句话说明 |
| **壳** | 他这台机器上 | 起 agent、执行存储 / 问话 / 定时任务、管闸与配额 |
| **制品** | 另一个原点上 | 一份**自包含 HTML**，跑在网页的 iframe 或平板的 WebView 里 |

1. 🔴 **一个图标 = 一间 ＝ 一条对话**；你写下来的东西**落在它自己那一间**。
2. 🔴 **你看不见浏览器**：写错了（引外部资源、碰 `localStorage`、连没声明的站）在你那儿**完全静默**
   ⇒ 所以 §7.6 那份自查**必须**过（回执里会当场摊给你看）。
3. 🔴 **两端都要能用**：同一份 HTML 同时跑在**网页**（不透明原点的 iframe）与**平板**（WebView）。

### 7.1 从需求到上桌：六步

| # | 这一步 | 产出 | 做完怎么知道对了 |
|---|---|---|---|
| 1 | **听懂要什么** | 一句话复述（"你要的是：…"） | 拿不准的**先问一句**（名字、要记什么、要不要联网）；🔴 **不问"要哪个平台"**（只有他桌面这一个） |
| 2 | **定能力清单** | 五样里选：`ask` / `net` / `camera` / `agent` / `tasks`（★ **存储不用选** —— 天生就有） | 只用**真正需要**的（多一样他就多一份要留意的）；**不确定先不加**（以后要加 = 再调一次 `app_create`） |
| 3 | **写页面** | 一份 `index.html`（样式/脚本**内联**） | §7.2 逐条过；拿不到数据 / 存不进去时**如实显示** |
| 4 | **声明** | `app_create` 的 `permissions`（＋ `net` 名单 ＋ `tasks` 清单） | 声明与用途**一一对上**；★ **存储不用声明**；别的几样**他第一次打开时会问你一遍**，他点头的才生效 |
| 5 | **自查** | `app_create` 回执里那一段"跟标准对不上" | 🔴 **有报必改**（改完再交）—— 只报不拦**不等于**可以不改 |
| 6 | **交付** | 一句人话（§7.5 的模板） | 名字 / 能做什么 / 会不会记住东西 / 联不联网 / 有没有定时任务 / **打开时他会看到一张弹窗**（**先说一声**） |

⚠️ **加东西 = 新的一版**：改页面或加能力都要**再调一次 `app_create`**（不许指望"它自己会变"）。

### 7.2 制品标准（页面那一份）

| # | 标准 | 为什么 |
|---|---|---|
| 1 | **一份自包含 HTML**：样式/脚本**内联**；**不许引外部资源**（CDN 脚本、外部样式、外域图片、外部字体、`@import`） | CSP 是 `default-src 'none'` ＋ `'unsafe-inline'` ⇒ 引了**取不到**，屏幕上就是空白 / 没样式 |
| 2 | 图片用 **`data:`** 或 `blob:`；图标用**内联 SVG / emoji** | 同上（`img-src data: blob:`） |
| 3 | 🔴 **不许碰 `localStorage` / `sessionStorage` / `indexedDB`** | 网页上它活在**不透明原点**里 ⇒ **一碰就抛** `SecurityError`。要记住东西 ⇒ 走 `/db`（★ **存储默认就有，不用声明**） |
| 4 | 🔴 **不许假设有原生桥**（`webkit.messageHandlers` / `HupoNative` / `Android.*`） | **禁原生桥** ⇒ 写了就是"点了没反应"（网页与平板都没有） |
| 5 | **不许开长连接**（`new WebSocket`） | CSP 不放它 |
| 6 | **不许靠"同原点的别的文件"** | `script-src 'unsafe-inline'` **没有 `'self'`** ⇒ 引不了 |
| 7 | 页面要有 `<title>`（它的名字） | 有些地方会用到；空着不好看 |
| 8 | **名字要短**（长度上限住代码）；短名只许小写字母 / 数字 / 短横 | 硬校验（超了 `app_create` 当场拒） |
| 9 | ★ **别自己留"状态栏 / 聊天条"那两条边距，也别把要紧的东西贴在底边** | 那两条边距**壳替你让**（版本不同、让法不同，但**都会让**）⇒ 自己再加一份 = 白边。⚠️ `position:fixed; bottom:0` 那种**顶不动**壳给的让位 ⇒ 要紧的东西走**正常文档流** |
| 10 | ★ **宽屏要铺得开，内容别只有一层** | 他是在**平板**上点开它的（小程序**全屏**打开，整屏都给它）⇒ ① 宽屏**自己铺开**（`repeat(auto-fit, minmax(…, 1fr))` 或按宽度分的 `@media`）—— **别把内容锁在一条窄栏里居中**；② **一页有主有次**；③ **别交"最小能跑"**：几块真有用的内容 ＋ **一处能点／能填／能选**的地方 ＋ 该记住的**记住**（`/db`）＋ **空／忙／错**三种说法。⚠️ **"复杂"不等于"塞没用的东西"** |
| 11 | 🎯 **要有"玩头"**（游戏/玩具：对手或关卡**每局得有变化** · **难度档** · **反馈/动静** · **记录**走 `/db`；工具：**内容分层**） | 他点名的那个例子："跟他下的时候，你会发现他的套路是一样的" —— **每局一模一样 = 没做**。🔴 要声音就 `AudioContext` **当场合成**（音频/视频**文件**取不到：CSP 没给 `media-src`）。⚠️ **趣味 ≠ 假话**（不许假装有 AI / 联机 / 真实数据）；他说"简单"就简单做 |

**外观基线**（同一条回执里给的那几条，都**只报不拦**）：

`no-viewport`（没有 `<meta name="viewport">` ⇒ 字小到看不清）·
`focus-removed`（把焦点框关掉了却没给替代样式）· `tiny-text`（字号太小）·
`gradient-text`（渐变字：对比度跟着底色变）· `no-wide-layout` · `thin-page` ·
`flat-play` · `no-feedback` · `no-page-title`。

⚠️ **字体只能用系统自带的**（引不到外部字体）：
`system-ui, -apple-system, "PingFang SC", "Noto Sans CJK SC", sans-serif`。
⚠️ **这几条是"机械可判"的那一档**，不是全部基线：对比度、留白节奏、状态齐不齐、
**内容够不够丰富 / 好不好玩** —— 今天**判不了**，靠 §7.1 第 1 / 6 步、起步页骨架与**他的眼睛**。
**明说，不当成已经做了。**

### 7.3 能力标准：存储（天生就有）＋ 要他点头的五样

> 🔴 **总规矩**：**声明只是"它想要什么"** —— 他**第一次打开**它时会看到一张弹窗
> （你声明过的那样样都问一遍，**一次问完**），**他点头的才生效**；他**随时能在设置里改**
> （关掉的那一样只是那一样用不了）。被拒时页面拿到的是一句**人话**（照它显示，
> **不许**假装成功）。
>
> 🔴 ★ **存储是唯一的例外**：**每个小程序天生就有自己那一格库** ——
> **不用声明、不用他点头、打开就能存**，它也不会出现在那张弹窗里。

#### 7.3.1 存储 —— 它要"记住东西"（★ 天生就有，不用声明）

- **什么时候用**：进度、历史、他填过的表、清单。**固定内容**（题库 / 词表）**别用它** —— 写进文件更省。
- **怎么调**：对它**自己那个地址** `POST /db`，`op` = `run` / `get` / `all`；
  **参数一律用 `?` 绑定**（不许拼串）；第一次带入口 URL 里那三样（`u`/`e`/`s`）换票，之后用票。
- **建表 / 迁移**：`CREATE TABLE IF NOT EXISTS`；改结构用 `PRAGMA user_version`。
- **不许**：一次多条语句 · `ATTACH` · 别的 `PRAGMA` · 递归查询 · 把钥匙 / 别人的数据塞进去。
- **上限**：每库字节 · 一条 SQL 长度 · 参数个数 · 带回行数 · 结果字节 · 单次时长 · 每分钟次数
  —— **数住服务端代码**（`src/app-db.js`），超了**当场拒**。
- **被拒怎么说**：**满了** 507 · **太频繁** 429 · **一条查太久** 503 · **这条 SQL 本身不行** 400 ——
  各说各的那句；行数被截断时**带上那个标记**；**页面要能"存不进去也能用"**（至少别白屏）。
  ⚠️ 存储**没有 403 那一档**（它不用他允许）。
- **他能清**：设置卡上那颗「清空它存下来的东西」（★ **每个小程序都有** · 二次确认、**拿不回来**）。

#### 7.3.2 问一句 `ask` —— 用**他的钥匙**问模型一句话

- **什么时候用**：出题、起名、翻译这种"一句话的事"，**不需要查网、不需要工具**。
- **怎么调**：`POST /ask`，`{prompt}`。
- **代价**：**花他的钱**（每天有次数上限、两次之间有最小间隔，数住代码）⇒ 别拿它当"随便问问"。
- **不许**：把用户的整本书塞进 `prompt`；把回答当"事实"（它是模型话）。

#### 7.3.3 网络 `net` —— 它要**自己去取数据**

- **两层的分工**：**你自己出网不设限**（你去查、去核实）；
  **制品页只许访问你写进它声明里的那几个站**。
- **什么时候用**：要他**实时**的数据（天气 / 价格）⇒ 声明 `net` ＋ 名单。
- **起草名单**：🔴 **你自己先访问确认过**再把域名写进去（只写域名本身：不许 `*`、端口、路径、`http://`；
  个数有上限，住代码）。
- **改名单 = 新的一版**（再调一次 `app_create`）；**关掉开关 ⇒ 名单立刻失效**（页面连不出去）。
- ⚠️ **看不见的那一半**：制品发了什么请求**我们看不见**（CSP 是浏览器执行的）⇒ 这一样**没有留痕**。
- **能静态就别动态**：让**你自己**取好、写进文件（零网络、离线也能用）—— **那永远是第一选择**。

#### 7.3.4 拍照 `camera` —— 镜头**由浏览器/系统直接给它**

- **什么时候用**：他要**拍一张**（扫码那是另一回事）。
- **怎么调**：声明 `camera`，页面里用 `getUserMedia` / `<input capture>`；**你这一侧没有服务端口**。
- 🔴 **他点头之前，页面里那句会被当场拒掉**（不是我们替它拦）⇒ 页面要**如实说**
  （**不许**转圈假装在拍）。
- **旧的小程序不会自动有它** ⇒ 要拍照就得**重新声明一版**（与 `net` 加站同一条规矩）。
- **麦克风仍然不给**（只放了摄像头这一样）。

#### 7.3.5 跟它的助手说一句 `agent` —— 要"想一想 / 查一查"

- **什么时候用**：需要**推理或查证**的一件事（"这周花钱正常吗"），而不是"一句话的事"（那用 `ask`）。
- **怎么调**：`POST /agent` 问 ⇒ 拿 `jobId` ⇒ 再 `POST /agent {jobId}` 取回执
  （`running` / `done` / `failed` / `timeout`）。
- 🔴 **那一轮是"限定档"**：它**能**查网（搜索 / 取页），**不能**动手（没有 shell、不能派活、不能用平台工具）。
- **代价与上限**：每天有次数上限、两次之间有最小间隔（数住代码）；等过头 ⇒
  如实说"它还在想，你去那一间看看"（**不许**编一个答案）。
- **它答的那一句会落在那一间对话里**（他看得见）⇒ **别在 `prompt` 里塞敏感东西**。

#### 7.3.6 定时任务 `tasks` —— 它要"按点自己做事"

- **什么时候用**：他明说要**重复**做的事（"每天早上看一眼…"）。⚠️ **一次性的活当场做完**，别排任务。
- **怎么写**：每件四样：短名 · 名字 · `everyMinutes` · **让它干什么**。
- 🔴 **`prompt` 会被当成"他让它做的事"执行** ⇒ **写成他会说的那种具体的一句**
  （"看看今天花了多少，一句话告诉我"）；**不许**写"随便逛逛 / 看看有什么能做的"。
- **上限**：最多几件 · 最短间隔 · 每天几次 · **串行** · 到点没跑**不补跑**（数住 `src/app-tasks.js`）。
- **结果回到那一间对话**；他**一键关掉**（关掉 ⇒ 一件都不跑）。

### 7.4 自查清单（`app_create` 回执里逐条给你；**有报必改**）

**会真的不好使（`errors`）**：

| 码 | 是什么 | 改法 |
|---|---|---|
| `external-resource` | 引了外部脚本 / 样式 / 图片 / 字体 / `@import` / WebSocket | 内联；图片用 `data:` |
| `browser-storage` | 碰了 `localStorage` / `sessionStorage` / `indexedDB` | 走 `/db`（★ 存储默认有，不用声明） |
| `native-bridge` | 假设有原生桥 | **删掉**（没有桥，两端都没有） |
| `ask-not-declared` / `agent-not-declared` / `tasks-not-declared` | 用了那件事却没声明 | `permissions` 里加上（⚠️ 存储**没有**这一条） |
| `host-not-declared` / `net-not-declared` | 去连没声明的站 | 写进 `net`（你先访问确认过），或改成让助手取好写进文件 |

**顺手看一眼（`warnings`）**：`host-unused`（声明了没用）· `no-entry-params`（调平台口却没读入口参数）·
`open-task-prompt`（定时任务那句太开放）· `no-page-title` · `no-wide-layout` · `thin-page` ·
`flat-play` · `no-feedback`。

⚠️ **自查看的是"屏幕上现在那一份"**：`app_create` 的 `files` 不给（内容已经写在它自己那间目录里）时，
自查会**从那一间把页面读回来**再查 —— 两条写法一样算数。
⚪ 例外：那一格还只是壳给的**占位页**（里面写着「这里还空着」）时，`thin-page` **不报它**。
⚠️ **它是"只报不拦"**：报了不改，东西**照样做出来** —— 但到了他屏幕上就是"点了没反应"。
**标准在这儿，改不改在你。**

### 7.5 交付标准（他脸上那句话）

**模板**（照这个说，别只说"好了"）：

> 做好了：**它叫什么**，点开就能用。它能**（做什么）**，会**（记住什么 / 不记住）**，
> （要联网的话）会去**（哪几个站）**取数据，（有定时任务的话）**每隔多久替你（做什么）**。
> 它要用的东西**它第一次打开时会问你一遍**，你随时能在设置里改。

🔴 **必须说清的**：① 它叫什么、能做什么；② **它会不会记住东西**（会 / 不会）；
③ 联网的话**去哪几个站**；④ 有定时任务的话**每隔多久做什么**；
⑤ ★ **打开它时你会看到一张弹窗**（问它要用的那几样）—— **要主动说这一句**：
  不然他点开看见一张窗会以为出了什么事；反过来说"你随时能在设置里改"仍然对；
⑥ ★ **它还能怎么调**（游戏 / 玩具：难度、对手、要不要记战绩）—— 多一句，
  **打磨那条路就铺到他脚下了**。

🔴 **不许承诺的四句**（说了就是假话）＋同一类的第五句：

1. **"它会一直跑着 / 它会自己去做事"** —— 只有**定时任务**那种，而且是"**到点跑一次**"；
2. **"它能装到手机上 / 发到微信里"** —— 做不到；
3. **"我帮你把权限改了"** —— **那一下永远在他手里**，你只能**说清**它要什么；
4. 🔴 **"它已经能用联网 / 用钥匙问话了"** —— **你声明 ≠ 他给了**；
   他还没点过头之前那几样都用不了。⚠️ **存储除外**：它天生就能用；
5. **"它什么都能干"** —— 它有明确的能力清单（§7.3）。

### 7.6 反模式（明确不许做的）

1. **引外部资源**（"反正能加载" —— 不能）；
2. **拼 SQL 字符串**（参数一律绑定）；
3. **把密钥 / 令牌 / 别人的数据写进页面或存储**（页面永远拿不到钥匙：要问话走 `ask` / `agent`）；
4. **把开放式的任务写进 `tasks`**；
5. **假装能力**（没声明就说"它能记住"；被拒了画成成功）；
6. **问他要技术细节**（AppID / 域名 / 证书 / "要哪个平台"）；
7. **不声明就想用**（`ask` / `net` / `agent` / `tasks` 用了才想起声明 ⇒ 那是 `*-not-declared` 那类报错；
   ⚠️ 存储不在此列 —— 它默认就有）；
8. **绕过白名单**（回头让他点"允许"来打通一个没声明的站 —— 那是**把风险推给他**）。

### 7.7 这一份标准怎么"有牙齿"

| 层 | 在哪 | 判据 |

### 8.2 负向对照：**"两端一致"这类断言最容易被自己的闸骗过去**

这一节是**这一份最值钱的四行**。四起事故都真的发生过，而且**每一次闸都是绿的**：

1. **闸要打在被测的那一侧**（V13 那一族）。浏览器那条路若只用 node 探针验，
   而探针把 `wss://` **写死**了 —— 客户端自己算出来的那一行（把流的地址算成 `ws://`）
   就**从来没被跑过**，于是"线上✅"可能是假话。
   ⇒ **规矩**：*客户端自己算出来的东西，闸要打在这一侧* —— 判据要**走页面自己建的那条连接**，
   不是另写一个探针。
2. **判据不许打在注释上**：一条"旧那一帧要退订"的源码级判据，若查的是
   `frame.contains('releaseMiniAppView(')`，而**文件顶上那段说明里也写着这个名字** ⇒
   把真正的调用注释掉**照样绿**。⇒ 判据只能**看代码行**（整行注释与行尾注释都去掉）＋
   逐字查调用那一行。
3. **判据要落在"后果"上，不落在"回执"上**：存储那条硬超时若只验"服务端回了那句超时"
   ⇒ **照样绿**；去 `/proc` 看**那个子进程真的没了**才算数。
4. 🔴 **"两端一致"最容易被自己的闸骗过去 —— 而且它骗的正是"只在一边验"**：
   "两边吃同一个 CSP 头"这句话**不能靠"两边各验一遍"来证明**（那是同义反复），
   它得靠**验那一个头本身**：
   - 只认 `'self'`（多了别的站就红）· 出现 `*` 就红；
   - `connect-src` **不许退回 `'none'`**（那是另一头的错法）；
   - **活地址与制品同一条 CSP**（同一个 `cspFor()`）；
   - 而且**租户那一侧要单独验**：`net` 的名单在盒代理那一路曾经**永远读不到"他点头了"**
     （盒代理没有 `grants()`，得读清单里带回来的那格 `granted`）—— 症状是
     **"他确实点了授予，页面却连不出去"**，而**单租户判据全绿**。
     ⇒ **"这条闸到底打在哪一台、哪一层"必须写出来**，否则"绿"只说明**被测的那一侧**是对的。

**另外两条如实说**（不是判据的错，是**判据还没写**）：

- **`MAX_TOTAL_BYTES`（整版）与 `MAX_VERSIONS`（版本数）没有独立判据用例**（§5.12）。
- 客户端那条沙箱判据是**源码级**（那一份自己写着 web-only，VM 里跑不了 `dart:html`）——
  **没有运行时判据**。

## 九、明确没做的

> **一条一行。** ⚠️ 这一栏**不是"排后"** —— 它是"**今天没有**"，
> 谁要用它就得**先把它做出来**，而不是假设它已经在了（`04-ROADMAP.md` §七）。

- **BLOB（二进制）不进那一格库** —— 只认 `null` / 字符串 / 数字 / 布尔。
- **库不能导出 / 带走**（没有"导成一个文件给他"那条路）。
- **跨 app 共享库没做，也不打算做**。
- **没有"让助手读这个 app 的库"的程序化口子**（助手要查只能走人话路径）。
- **iOS 侧没有小程序运行时**（商店版不发布；`kNativeMiniRuntimeIOS` 恒假）。
- **小程序没有麦克风**（只放了摄像头那一样）。
- **`/agent` 那一轮今天关不掉 `tool-fs` 的"写"那一半** —— 所以它写得了**它自己那一间**
  （跑完要核、动过要如实说）；要彻底只读得另起一个 dsh profile。
- **`ask` 没有"每次多少字 / 多少钱"那本账**（只有每天次数与最小间隔；usage 只记不拦）。
- **定时的"到点一定跑"不保证**，而且**不补跑**。
- **`tasks` 与 `/agent` 的租户那一侧不接**（要过隧道进他盒子）—— 遇到就**如实 503 / 记一句并跳过**，
  **不假装跑过**。
- **`/tasks` 在制品原点上没有窄口**（定时是服务端调度器的事，`tasks` 只是一个权限名）。
- **"请 AI 重写"那个执行器不存在** —— 只有判定 ＋ 那本账；"重写计数"今天读的是"**决定**计数"。
- **沙箱通信的"一次性 nonce"没有实现**（旧手册那句要求未落地，代码认的是挂载账 ＋ origin ＋ kind）。
- **最小"真跑一次"不替真浏览器**（它只证"能起来 / 入口必崩"，不证"在他屏幕上是什么样"）。
- **`type="module"` 的入口只"跳过、不误拒"**（那是"不可算"，不是"验过了"）。
- **拍照的真机那一下没验过**（要拿安卓机试；本机没有摄像头）。
- **"实例版本"没做**：能力体换版之后，那一版经验还适不适用 **仍然零判据**。
- **登记边那三条边的"可检查性"不等于"适用性可核"** —— 别把它读成那个意思。
- **发布没有"全量回归"**（只有分级的最小真跑）。
- **共享库 `versions/<n>/` 没有"已存在则拒"的显式检查**（靠版本号只增 ＋ id 全局唯一间接成立）。
- **`MAX_TOTAL_BYTES` 与 `MAX_VERSIONS` 没有独立判据用例**（未核实到专门闸）。
- **小程序那一套的"发布"今天只有工具那条路**（`D4.18`：屏幕上没有第二个入口）。
