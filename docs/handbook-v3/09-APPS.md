# 09 · 小程序那一整套

> **这一份回答什么**：他可以让助手**当场做出一个小程序** —— 摆在桌面上、能自己存东西、能上网、
> 能问它的助手、能定时干活、能拍照。这一份把它**从头讲完**：它是什么、被关在多严的笼子里、
> 能要哪些能力、每一格自己的库、制品怎么发出去、用户端与"包"差在哪、
> 给"做小程序的 agent"的作业指导书、判据、以及**明确没做的**。
>
> **谁该读**：动小程序 / 容器 / 授权之前。

**三条读法**（缺一条就会读歪）：

1. 🔴 **凡涉及"跑的是哪一份 / 数据在哪"，这一份一律写清是哪一台、哪一层** ——
   宿主这一台 / 他盒子里 / 制品那一版（不可变快照）/ 活地址（他正在改的那一份）。
2. **阈值、上限、超时只住代码**与 [`08-SPEC.md`](08-SPEC.md) **§十**；
   正文说"跟着字算"、给常量所在的**文件**，**不抄数值**（抄下来的那一刻它就开始过期）。
3. **每条断言都指得出代码或判据**；指不出的**明写"未核实"**，不许含糊过去。

## 一、它是什么

### 1.1 一格 ＝ 一间 ＝ 一条对话 ＝ 一个制品

**一个小程序在四个地方是同一件事**，`id` 是它们共同的名字：

| 那一层 | 是什么 | 落点 | 谁按什么认它 |
|---|---|---|---|
| **屏幕上** | 桌面图标墙上的**一格**（图标 ＋ 名字） | 客户端 `widgets/app_desktop.dart` | `id` |
| **干活的地方** | **一间工作区** —— 助手在这一间里干活时 `cwd` 就是它 | `<他那一格>/workspaces/<id>/` | 目录名 = `id` |
| **说话的地方** | **一条对话** —— 那一间自己的会话与那条可见时间线 | 事件上的 `scopeId = id` | `scopeId` |
| **发出去的东西** | **一个制品**：一份登记（＋ 发过的话，一份不可变的包） | `<他那一格>/hupo/apps/<id>/` | `id` ＋ `rootHash` ＋ 血缘 |

> 主人 2026-09-25 定：*"当我做一个 app 的时候，本质上是一个工作区。这一点你一定要确保。
> 那么你制作小程序，就是在那个工作区里面开。"* —— 落地见
> [`../dev/83-APP-WORKSPACE.md`](../dev/83-APP-WORKSPACE.md)、
> [`../dev/102-APP-BIRTH-SCOPE.md`](../dev/102-APP-BIRTH-SCOPE.md)。

**三条不许互替**（`docs/dev/90-APP-CONTRACT.md` §2.1，代码在 `src/apps.js`）：

| 维 | 是什么 | 不许拿它当别的用 |
|---|---|---|
| `id` | 别名 / 桌上那张脸 | **不拆 `id`** —— 拆了就是"每改一次就不再是同一个 app" |
| `rootHash` | **内容**（按路径排序后算出来的一枚 hash） | 不许进身份 —— 否则改一个字就换了个 app |
| **血缘** | **祖先边**（从哪一版长出来的、改过哪些文件） | 不许用**自称的**来源代替（自称的来源不算来源，见 §五） |

🔴 **"建工作区"这件事不靠模型记得**：造 app 的第一步由**服务端那一刀**做 ——
建目录 ＋ 登记 ＋ 把这一轮的 `cwd` 换过去（`src/apps-socket.js` 的 `create`）。
漏了它会出什么：文件躺回主目录、那一格点开是另一个空房间、**干活的那段对话谁也找不到**。
⇒ 所以派活那一路把 `id` **钉死成那一间自己**（模型随手写别的名字**一律不作数**），
"图标 = 那一间的门"是**结构**，不是约定。

### 1.2 两个原点为什么必须分开（**N1**）

> **N1：执行第三方代码的东西（小程序）绝不与持有令牌的原点同源。**（[`08-SPEC.md`](08-SPEC.md) §一）

| | **壳这一侧**（持令牌的那个） | **制品那一侧**（跑第三方代码的那个） |
|---|---|---|
| 住在哪 | 客户端 + 调度器，域名是 `w.<域>` | `apps.<域>`，**另一个原点** |
| 手里有什么 | **令牌**（`TokenStore`）、会话、账 | **什么都没有** —— 拿不到令牌、拿不到别人的字节 |
| 跑什么 | 我们自己的界面与逻辑 | **别人（助手）写的一份 HTML** |
| 谁嵌谁 | 壳把制品**嵌**进一个 iframe / WebView 里 | 它自己出不去 |

**为什么不能同源**：只要同源，制品里一行 `parent.document` 或一次 `fetch('/api/…')`
就能读到壳的存储、用壳的身份说话 —— 那等于**把令牌交给了第三方代码**。
分开之后，制品**只能**做两件它被允许的事：算/画（完全本地），
以及**对它自己那个原点**发一次请求（那几条窄口，见 §三、§四）。
铁律 1 那条 `sandbox` 取值、铁律 2 那条 CSP，都是这一条不变量的**执行手段**。

⚠️ **顺带得到"两端一致"的地基**：网页那一侧与安卓那一侧都**从同一个制品原点加载**，
所以它们**吃同一个响应头、走同一条路**（`docs/dev/147-APP-SQLITE.md` §一 F10）。

### 1.3 内置那几屏与真制品的区别

桌面图标墙上除了他自己的小程序，还有**两格内置的**：**设置** 与 **发现**
（`src/worlds.js` 的 `BUILTIN_SCOPES`；`src/apps.js` 的 `REFUSED_APP_IDS` 把
`main` / `settings` / `discover` 一起收成保留 id —— **保留名单 = 主线 ＋ 内置那几格**，这条等式不许破）。

| | **内置那几屏** | **真制品** |
|---|---|---|
| 是什么 | **我们自己画的界面** | 一份**别人写的 HTML** |
| 从哪来 | 打进客户端那一版包里 | 从制品原点取，走一条**现签的短时效 URL** |
| 有没有工作区 / 对话 | 有那一间（`scopeId` 是它们自己的名字），但**没有制品** | 两样都有，且 `id` 同名 |
| 能不能被助手造出来 | **不能** —— 保留 id 那道闸直接拒 | —— |
| 权限 | 没有"能力要授权"这回事 | 五样能力要他点头（§三） |

⚠️ **"发现"那一屏是只读的**：它只列别人发出来的东西，**它自己不能装** ——
`D4.18` 定的形状是"**一切操作都在对话里**"（造 / 看 / 发 / 撤 / 发现 / 装 / 卸 / 授权 / 撤权
一共九件工具，见 §五），屏幕上只有**桌面图标墙**、**加号**与**只读的发现**。
唯一一处"屏幕上的入口也能造东西"是桌面上那颗**空心加号**（§五 §1），
它造的是**空壳**，内容仍然只从对话里来。

### 1.4 一次"做一个小程序"到底发生了什么（**全景**）

```
他说"帮我做一个记账的"（在那条对话里，或在那一格自己的对话里）
   │
   ├─ 助手当场动手：把页面写进「那一间工作区」（它的 cwd）
   ├─ 助手调 app_create：建工作区（已存在则复用）＋ 登记 ＋ 声明能力
   │     └─ 桌面自己长出那一格（app/installed，瞬态）
   ├─ 他点开那一格 ⇒ 打开的是一条**活地址**（/w/<id>/…，§五 §3）
   ├─ 打开之前：把它**还没问过**的能力**一次问完**（§三）
   │
   └─ 之后：助手再改那一间里的文件 ⇒ 屏幕上自己就是新的（不用发布、不用刷新）
```

**"发布"是另一条路**（`app_publish`）：把它**现在那一份**打成一个**包**、放进共享库、给别人装。
它**不是**"他自己那份生效"的前提 —— 用户端**没有包**（§六）。

## 二、沙箱：三条铁律 ＋ 判据

三条都是**用代价换来的**，所以每一条都配了判据，而且判据**带负向对照**
（"把改坏的源码喂进去必须报"）—— 闸绿了但不是空转，靠它证明。

### 2.1 铁律 1：iframe 的 `sandbox` 取值**只有 `allow-scripts`**

`v2/apps/mobile/lib/widgets/mini_runtime_web.dart` 里那一行是
`sandbox = "allow-scripts"` —— **一个取值，多一个都不加**：

| 加/不加 | 会怎样 |
|---|---|
| **不加 `allow-same-origin`**（今天） | 制品活在**不透明原点**（opaque origin）里 |
| 🔴 **加了 `allow-same-origin`** | **等于没有沙箱**：制品与壳同源 ⇒ `parent.document`、壳的 `localStorage`、cookie 全都碰得到 ⇒ §1.2 那条 N1 当场作废 |
| 加 `allow-forms` | 不需要：CSP 的 `form-action 'none'` 已经把表单提交堵死了（代码更严） |

同一条判据还钉着 `referrerpolicy="no-referrer"`（别把入口 URL 当 referrer 漏出去）。

**它的代价（是设计，不是缺陷）**：不透明原点下 `localStorage` / `sessionStorage` / `indexedDB`
**一碰就抛 `SecurityError`** ⇒ 一个小程序**没有浏览器自己的持久化能力**。
要记住东西，走平台给的那条窄口（§四）。客户端那里也写着同一条理由。

**判据**：`v2/apps/mobile/test/unit/mini_sandbox_test.dart` 的 `P1-7`
（`sandbox='allow-scripts'`、**不许**出现 `allow-same-origin`、`referrerpolicy=no-referrer`）
＋ 紧挨着的**负向对照**：把 `allow-same-origin` 塞进源码、删掉 `sandbox`、
把 `allow` 写死、顺手加麦克风 —— **四种"改坏"必须各自报红**。
⚠️ **只有源码级判据**（那一份自己写着 web-only，VM 里跑不了 `dart:html`）——
**没有运行时判据**，如实记在这里。

### 2.2 铁律 2：制品文档的 CSP 是一条**写死的串**

服务端 `src/app-serve.js` 的 `cspFor()` 拼出来的响应头**逐字**是这一条
（顺序与内容都是故意的）：

```
default-src 'none'; script-src 'unsafe-inline'; style-src 'unsafe-inline';
img-src data: blob:; connect-src 'self'; base-uri 'none'; form-action 'none';
frame-ancestors <壳>
```

| 那一段 | 为什么是这个值 |
|---|---|
| `default-src 'none'` | **默认什么都不许**（fail-closed） |
| `script-src 'unsafe-inline'` · `style-src 'unsafe-inline'` | 制品是**一份自包含 HTML** ⇒ 样式与脚本**内联**；⚠️ **没有 `'self'`** ⇒ 它**引不了同原点的别的文件** |
| `img-src data: blob:` | 图片只能内联或现做；**没有 `'self'`** |
| `connect-src 'self'` | 只许对它**自己那个原点**发请求 —— 那就是 §四那条窄口。**别人的站一个都不在白名单里** ⇒ 它**出不去**；`net` 那一叠（§三）**按 app 叠在这后面** |
| `base-uri 'none'` · `form-action 'none'` | 堵住"改 `base` 之后把请求发到别处"和表单提交 |
| `frame-ancestors <壳>` | **只许壳嵌它**，别处嵌不了（⚠️ 不发 `X-Frame-Options`，靠这一条） |
| **没有 `media-src`** | 音频/视频**文件**一律取不到（`<audio src=…>` 落进 `default-src 'none'`）⇒ 想要声音只有 `AudioContext` **当场合成** |
| **没有 `font-src`** | 引不到外部字体 ⇒ 只用系统自带的字体族 |

**`connect-src` 按 app 算**：`netHostsFor()` 三道一起才算
（① 制品**声明了** `net` ② **他没关掉**（在 `granted` 里）③ `meta` 里那份名单）——
任何一种读不出来 ⇒ **空名单**（宁可连不出去，也不许"读不出来就放行"）。
拼响应头那一处在 `app-serve.js` 里按 app 调 `cspForApp()`；名单里的每一串**已经过
`apps.js` 的 `checkNetHosts`**（安全边界只有那一处），到 `cspFor()` 里只再兜一道**形状**。

**判据**：`v2/services/core/test/apps.test.js`（制品口：带 CSP ＋ **没有 X-Frame-Options**）·
`test/app-db.test.js` 的 **D7**（`connect-src` 只放它自己那个源 —— **明禁退回 `'none'`、明禁 `*`**）·
`test/app-net.test.js`（N1–N6，见 §三）· `test/app-live.test.js` 的 **V3**
（**活地址与制品同一条 CSP**）。
⚠️ **别把 `connect-src` 写成 `'none'`**：那是**更松**的一条（`'none'` 会让"对自己源发请求"这条
唯一的窄口也断掉，`/db`、`/ask`、`/agent` 全部作废），判据逐字钉着它。

### 2.3 铁律 3：**禁原生桥**

**原生那一侧不许有桥**，一条都不许：

| 不许出现的东西 | 现状（`grep` 得到的） |
|---|---|
| `JavaScriptChannel` / `addJavascriptInterface` / `evaluateJavascript` / `runJavaScript` | `lib/` 里**真代码 0 处**（唯一命中是注释） |
| 一个宽泛的"原生给页面递能力"的通道 | **没有** —— 原生那份运行时里连 `onAsk` 都**故意不接** |

> 代码里那句话值得抄下来：**"收了却做不到比不收更坏"**。

**原生那一层到底是什么**（`docs/dev/129-NATIVE-ANDROID-BUILD.md`）：

| 项 | 它是什么 |
|---|---|
| 载体 | **一个普通 `WebView`**，加载那条**现签的**入口 URL（制品仍然在**另一个原点**） |
| 存储 | **独立的数据存储** —— 那个 WebView 自己原点的存储它用得了，但它**读不到壳的令牌**（令牌在 Flutter 那侧的 `TokenStore` 里） |
| 导航 | **只许在制品自己那个 `origin` 里走** —— 纯函数 `miniNavigationAllowed`（`lib/models/mini_frame.dart`）：别的域名 / `javascript:` / `data:` / `file:` / 协议降级**全拦** |
| `ask` | **原生上没有**，而且**不假装有** —— 壳**不发** `hupo-ready` |
| iOS | 🔴 **商店版不发布小程序运行时**：装钩子那一步**只在 Android 上做**，`kNativeMiniRuntimeIOS` **恒假** |

**这条与"两端一致"是什么关系**（这是整套设计里最要紧的一处推导）：

- 桥**只有网页那一侧有** ⇒ 凡是"走壳的桥"的能力，**平板上那个小程序一件都用不了**；
- 而铁律 3 不许我们为了补齐它去装一条窄桥；
- ⇒ 于是**唯一**能把能力给到两端的路是：**让制品对它自己那个原点发一次请求**
  （`fetch` 在 WebView 里本来就能用）＋ 一个**按人按 app 签名的受限接口**。
  §四那条 `/db` 与 §三的 `/ask`、`/agent` **全是这个形状**；
- ⇒ 所以"两端一致"不是两边各写一遍，而是**天生同一份**（两边吃同一个 CSP 头、走同一条路）。

**判据**：`v2/apps/mobile/test/unit/mini_native_test.dart` ——
"这棵树的 `lib/` 里，原生桥 API **命中 = 0**"（还量了"扫过的文件数"防空转）
＋ **负向对照**：把"改坏的源码"喂给那个扫描函数 ⇒ **必须报出来**；
`test/unit/mini_runtime_test.dart`（Android 有 / iOS 没有 · 没装钩子就说实话 ·
`webview_flutter` 白名单 · 两端签名一致）；
`test/app-lint.test.js` 第 ③ 条（制品源码里出现 `webkit.messageHandlers` / `HupoNative` / `Android.*`
⇒ 报 `native-bridge`）。

### 2.4 沙箱通信认的是**挂载账**，不是域名

`event.origin === "null"` 是 opaque origin 的**正常**值 ⇒ **不能拿域名做校验**。
今天代码认的是三样（`mini_runtime_web.dart`）：① 这一帧 `viewId` **在挂载那本账里**
（`miniViewLedger.isHosted(viewId)`）② `origin` 是 `'null'` 或空串
③ `kind` 是我们认得的那一种。

⚠️ **未核实 / 无实现**：旧手册 §14.1 写着"沙箱通信必须改用**一次性 nonce**（打开时下发，关闭即废）"，
但 `v2/` 的 `.dart` / `.js` 源码里 `nonce` **命中 = 0** ⇒ **那条要求今天没有实现**，
代码走的是上面那三样。**别照 nonce 那句话去验收。**

### 2.5 一条平台层的事实：Web 上平台视图是**真的 DOM**

Web 上那个 `<iframe>` 是**真的 DOM 元素**，它**盖在 Flutter 画布上面**。
⇒ 平台视图一"铺满整屏"，画在画布上的**聊天浮窗就整个被它盖住**（点不着、也看不见）。
**规矩是**：平台视图的矩形**不许盖到聊天浮窗的矩形**，而"被盖住"那一档
（聊天展开着）**只压暗、不缩小、不圆角**；
同时往每一个 root（`document` ＋ 每个 shadow root）注一条
`pointer-events: none !important` 并在开/关之间切换 ——
**那就是"聊天的浮窗永远在最上面"这句话成真的东西**。
契约与判据：[`../dev/150-APP-FULLBLEED.md`](../dev/150-APP-FULLBLEED.md)（⚠️ 那一篇顶上写着
"**方向做反已撤**"—— **被撤的只有"铺满整屏"那半边**；"聊天在最上"、只压暗、以及
**服务端那条 `pt`/`pb` 注入（老客户端还在带，照旧要认）**都有效）·
[`../dev/145-MINIAPP-EATS-POINTERS.md`](../dev/145-MINIAPP-EATS-POINTERS.md) ·
`test/widget/mini_app_test.dart` · `test/widget/safe_area_test.dart`。

## 三、能力与授权

### 3.1 能力到底有几样、哪几样要他点头

**一共六样**，但它们分两档 —— 混成一档是这一整节最容易犯的错：

| 档 | 那几样 | 要不要声明 | 要不要他点头 | 出现在"打开时那张弹窗"里吗 |
|---|---|---|---|---|
| **天生就有** | **存储（`db`）** | **不用** | **不用** | **不在** |
| **要他点头** | **问一句（`ask`）** · **上网（`net`）** · **拍照（`camera`）** · **跟它的助手说话（`agent`）** · **定时（`tasks`）** | 要（声明 = "它想要什么"） | 要（他第一次打开时一次问完） | 在（还没问过的那几样） |

🔴 **两处必须说清，不然后面全读错**：

- **存储不算"要他允许的那样"**：`granted` / `unanswered` **两张表都不含 `db`**，
  弹窗里也没有它，设置页那张卡上**没有存储那一行、也没有那个开关**。
  它天生就有自己那一格库（§四）；老制品清单里那个 `db` **照样认**（只是今天没有意义）。
- **"问一句"和"跟它的助手说话"是两样，不是一样**：
  `ask` = **直连模型**问一句（没有工具、不记得上一句、不改任何东西，花他的钱）；
  `agent` = 把问题送进**它那一间**，由**那一间的助手**来答 —— **那个助手是有手的**
  （今天那一轮走"限定档"，见下）。两样**各判各的闸**。

服务端那张权限白名单是**六个名字**（`src/apps.js` 的 `PERMISSIONS`）；
客户端"要问的"是**五个**（`lib/models/app_grants.dart` 的 `knownWants`，`db` 不在里面）。
**两张表不是同一张**，这不是不一致，是"存储不用问"那一条的落点。

### 3.2 🔴 声明 ≠ 已给：三件事必须分开记

制品清单里那行 `permissions` **不是他写的**（是助手写的），它**不是他的签字**；
而他第一次看见一个小程序要什么，恰恰是**打开它的那一瞬间**。⇒ `/api/apps` 每格回**三样**：

| 字段 | 含义 | 谁写进去的 |
|---|---|---|
| `permissions` | **它想要什么**（制品声明的） | 助手（写进清单，随版本冻结） |
| `granted` | **你给了的** = 声明 ∩ 他点过头的 − 他拒过的（**滤掉 `db`**） | 他（`grant.json` 的 `allowed`） |
| `unanswered` | **还没问过他的** = 声明 − 给过 − 拒过（**滤掉 `db`**） | 现算 |

🔴 **"还没表态"必须与"他拒了"分开记** —— 混成一个集合只有两种坏结果，
而且两种都会真的发生：

| 混成什么 | 坏在哪 |
|---|---|
| 把"还没问过"当成"他拒了" | **一次没答就永远用不了** —— 他根本没表态，东西却废了 |
| 把"他拒了"当成"还没问过" | **每次打开都再问一遍** —— 他点过"不给"还问，那是骚扰 |

⇒ 所以落盘的是**两张表**：`grant.json` 里 `{allowed, denied, at}`。
`grants()` 要求 `allowed.includes(p)`（**默认不给**）；`unanswered()` 只看两张表都没提到过的。
写的时候对外**协议一个字没改**（`POST /api/app-grant {id, permission, allow}`）——
客户端与新老盒子照旧传那一份，"允许清单"在内部被翻成这两张表。

**老文件照旧认**（`apps.js` 的 `#grantBook`）：

| 盘上是什么 | 认成什么 | 为什么 |
|---|---|---|
| `{allowed, denied, at}`（今天） | 两张表 | —— |
| `{permissions: […]}`（更早的"允许清单"） | **认成 `allowed`** = "他当年点过头" | 他当年的点头**不许因为换了一版就作废** |
| `{denied: […]}`（更早的"关掉清单"） | 认成"**他表过态、不给**" | 同上，反方向 |

### 3.3 打开时"一次问完"（那张弹窗）

他**第一次打开**一个小程序时，把 `unanswered` 里那几样**一张窗列全**、一次问完
（`lib/widgets/app_grants_ask.dart`）。六条规矩（每条都有判据）：

| # | 规矩 | 为什么 |
|---|---|---|
| 1 | **一次问完** —— 一张窗列全，不是每样弹一次 | 一次一次弹是折磨；"傻瓜式"那条要求住在这儿 |
| 2 | **默认全开** —— 他按一下「就这样」就等于全给 | 同一个理由 |
| 3 | **关掉哪一样就只是那一样用不了**（人话里点明"别的照旧"） | 免得他以为关一样就废了整个小程序 |
| 4 | **弹窗自己不发请求** —— 它只把"他勾成什么样"交回给屏那一侧 | 那儿才有令牌、才拿得到回执；"没记下来"那一档也才说得出实话 |
| 5 | **划掉不算回答**（`barrierDismissible: false` ⇒ `null` = 没表态） | **替他记一笔"不给"才是假话** —— 什么都没记，下次再问 |
| 6 | **必须在他点开那一屏之前问完** | `net` 那一样的响应头就是照那本账算的 —— 问完再开，它才连得出去 |

`net` 那一行**多一句"它会连这几个站："**（域名清单本来刻意不上屏，
**只在弹窗里破例** —— 那是他点头才生效的几样里唯一会让他意外的细节）。

**设置页那张卡**（`lib/widgets/app_grants_card.dart`）是"**之后还能改**"的地方：
**跟弹窗同一本账**。三条"不画开关"（画个假的就是"页面在说假话"）：
① `granted` 字段**缺失**（老服务端 ⇒ **不知道**，`null` ≠ `[]`）② 认不出的名字 ③ 这一条路没接线。
**关掉是"现在不给"，不是"抹掉"**：文案里明说
"关了只是现在不给，别的什么都不动"，而且**关掉不删他已经存下来的东西**（判据钉着）。

**装别人的 = fork 成他自己的** ⇒ `app_install` 那条路上**没有"外来要先允许一下"那一档**：
清单里那份声明**原样带过来**（主人：*"别人发的东西直接 fork 下来就好了……代码都成自己的了。"*）。
⚠️ "刷新 / 分叉"那个选择**不是权限闸** —— 它是"别把他改过的那份盖掉"，默认分叉。

### 3.4 五样能力：形状、怎么调、被拒怎么说

> 总规矩：**被拒时页面拿到的是一句人话**（`text` / `error` 上），页面**照它说，
> 不许假装成功**；每一样**用不了的时候要能没有它也能用**（至少别白屏）。

#### 3.4.1 存储（`db`）—— **天生就有**

见 §四（那一节是它的正文）。

#### 3.4.2 问一句 `ask` —— 用**他的钥匙**问模型一句话

| 项 | 形状 |
|---|---|
| 什么时候用 | "一句话的事"：出题、起名、翻译 —— **不需要查网、不需要工具** |
| 怎么调 | 制品对它**自己那个原点** `POST /ask`，`{id, v, prompt}` ＋（第一次带 `{u,e,s}`，之后带 `{ticket}`） |
| 回来 | `{ok:true, text, left, max, ticket}`；被拒 ⇒ `{ok:false, error, text}`（**人话在 `error` 上**） |
| 闸 | **四道**：在他这儿 · 清单**声明了 `ask`** · **他允许了** · **配额还有**；**两条口同一道闸**（`/api/app-ask` 与 `/ask` 共用同一个函数，不许各写一份） |
| 花在哪 | 主人 / 单租户 ⇒ **他这台机器上的小代理**；**租户 ⇒ 过隧道进他盒子**（钥匙在他盒里） |
| 被拒怎么说 | 没声明 ⇒ 403「这个小程序没说要问话」· 他关掉了 ⇒ 403「你还没允许它用你的钥匙」· 超配额 ⇒ 429「今天问得够多了」· 太快 ⇒ 429；**被拒的那几条一个字都不花** |
| 数住哪 | `src/apps.js`（每天几次 / 两次之间最小间隔） |

#### 3.4.3 上网 `net` —— 只许访问**声明里那几个站**

| 项 | 形状 |
|---|---|
| 两样一起才算 | 清单里 `permissions: ["net"]` ＋ `net: ["api.…", …]`（白名单） |
| 谁起草 | **助手** —— 它**自己去访问确认过**，再把域名写进清单（它出网**不设限**，见下） |
| 谁执行 | 🔴 **浏览器 / WebView 自己**（CSP 是硬的）：他**点头** ⇒ 那几个站进 `connect-src`；**没点头 / 关掉 ⇒ 只有 `'self'`** |
| 名单是安全边界 | 它会被**拼进响应头** ⇒ 只认规规矩矩的**小写域名**（至少一个点、无空白、无通配、无端口、无路径、无 scheme）；认不出来就拒（**注册与建包两个入口都拒**），`cspFor()` 里再兜一道形状 |
| 只放它自己那几个 | 按 **app** 算（一个 app 的名单不会跑到另一个 app 头上） |
| 加新站 | **新的一版**（重发一次）—— **不许运行时自己往名单里加** |
| 被拒怎么说 | 页面上就是"取不到数据"（浏览器拦的）⇒ 页面要**如实显示**；名单不合形状 ⇒ 工具那侧当时就拒 |
| ⚠️ 看不见的那一半 | **制品发了哪些请求我们看不见**（CSP 由浏览器执行）⇒ 这一样**没有留痕**；挡住它的是**白名单** |

🔴 **两层的分工**（主人把语义说死的一条）：

| 谁 | 网 |
|---|---|
| **助手自己** | **不设限** —— 它查网、取数、核实靠的就是这个；我们只**留痕**（域名/时间/量，**不记正文**）。**没有"给助手出网列白名单"这一层**（那是拍过不做的） |
| **制品页** | **只许声明里那几个站** —— 浏览器/WebView 的 CSP 硬拦，**他能一键关掉** |

⇒ 一句话：**助手无限、app 有名单**；而 app 的名单是**助手写的**、**他能关**。

#### 3.4.4 拍照 `camera` —— **镜头不经我们的手**

| 项 | 形状 |
|---|---|
| 它和别几样不一样 | **谁执行 = 浏览器 / WebView 自己**（`getUserMedia` / `<input capture>`）；我们只做两件：① **要他点头** ② **按授予放开那一层门** |
| 我们碰不碰数据 | 🔴 **不碰**：**不替它拍、不落盘、不进聊天记录**（要存是它自己的事，走它自己那格库） |
| 门在哪 | 网页：iframe 的 `allow` —— **唯一合法写法**是 `allowCamera ? 'camera' : ''`；安卓：WebView 的 `onPlatformPermissionRequest`，**只认摄像头、只认授予过的那个小程序**，**麦克风照拒** |
| 没授予会怎样 | **门是关的**：页面里那句话**当场被浏览器/系统拒掉**（不是我们替它拦） |
| 被拒怎么说 | 页面要**如实说**（**不许转圈假装在拍**）；这一句写进了 `app_create` 的说明 |
| 旧小程序 | **不会自动有这个能力** —— 要拍照就得**重新声明一版**（与 `net` 加站同一条规矩） |
| 安卓清单 | 要有 `CAMERA`；`uses-feature` **不许写 `required="true"`**（没镜头的设备照旧能装） |
| ⚠️ 真机 | **未核实**：拍不拍得出来要**他拿安卓机试**（代码这一侧只能验"门开了没有"） |

#### 3.4.5 跟它的助手说话 `agent` —— **有手的那一个**

| 项 | 形状 |
|---|---|
| 和 `ask` 的分工 | `ask` = 直连模型问一句；**这一样** = 把问题送进**它那一间**，由**那一间的助手**答 |
| 怎么调 | `POST /agent {prompt}` ⇒ `{ok:true, jobId, state:'running'}`；再 `POST /agent {jobId}` 取回执 ⇒ `{state:'running'\|'done'\|'failed'\|'timeout', text}` |
| 凭据 | 与 `/db`、`/ask` **同一套**（入口签名换票）＋ **`jobId` 就是那张票**（绑人绑 app，里面记着"问的是哪一号、什么时候问的"）⇒ **伪造不出别人的回执** |
| 闸 | 没声明 ⇒ 403「这个小程序没说要跟你的助手说话」· 他关掉了 ⇒ 403 · 太快 / 今天够多了 ⇒ 429；**取回执不扣配额**（只有"问"那一趟记） |
| 每次都看得见 | 问题以「**来自小程序「它的名字」**」落进**那一间**的对话，助手怎么答也在那儿 —— **不许做成他看不见的暗线** |
| 🔴 限定档 | 替小程序跑的那一轮**不许有手**：一层**减法补丁**（`hupo-app-agent.yml`）把 `tool-bash` / `tool-pwsh` / `tool-jobs` / 三个 `tool-subagent*` / **`tool-skill`** 全关掉，**不挂能力层** ⇒ 只剩**看**（读文件 / 找文件 / 查网）。⚠️ 关的是 **`tool-skill`** 不是 `skill`（关错会把服务提供者也关掉 ⇒ 整台 dsh 起不来） |
| 🔴 但那一轮要能查网 | **保留**网络搜索与取页（`web` / `web-search-deepseek` / `web-fetch-http` / `tool-web`）—— 判据钉着"这几件**不许**被关掉"；真读数：它去查了 `deepseek.com` 并答出标语，而且自己说清"只做了联网查证，没动任何文件、没跑命令" |
| 等过头 | **不编答案**：如实回 `timeout`（页面说"它还在想，去那一间看"） |
| ⚠️ 如实说一条 | `tool-fs` 是**一整块**（读与写在一起），今天**关不掉一半** ⇒ 那一轮**还写得了它自己那一间**（`cwd` 就在那儿）⇒ 跑完**要核**、动过**要如实说**。要彻底只读得另起一个 `dsh profile`（那是 `strict`，要主人点头） |
| ⚠️ 租户 | **今天不接**（要过隧道进他盒子）：**如实 503「你那台还没跟上」**，不许假装 |

#### 3.4.6 定时 `tasks` —— 他允许了才跑，而且跑在**他盒子里**

| 项 | 形状 |
|---|---|
| 声明 | 清单里 `permissions: ["tasks"]` ＋ `tasks: [{id, title, everyMinutes, prompt}]`（每件四样：短名 · 名字 · 隔多少分钟 · **让它干什么**） |
| 跑在哪 | 🔴 **他自己的盒子里** —— 不是我们的云 |
| 🔴 四条铁规矩 | ① **注册制**（没声明 / 他关掉 ⇒ **一件都不跑**）② **串行**（一次只起一件）③ **先记再跑**（账记不上就不跑）④ **间隔兜底到下限**（少了这一条会变成"每个 tick 都跑一遍"） |
| ⚠️ `/tasks` 没有窄口 | **app 原点上不存在 `/tasks` 路由**（只有 `/db`、`/ask`、`/agent` 三条）—— 定时是**服务端调度器**的事，`tasks` 只是一个权限名 |
| 数字住哪 | 间隔下限 · 每天次数 · 最多几件 · 多久看一遍 —— **只住 `src/app-tasks.js`** |
| 结果去哪 | 🔴 **回到那一间对话**：以「**来自小程序定时任务「它的名字」· 这件任务的名字**」落进去 ⇒ **他看得见** |
| ⚠️ `prompt` 的分量 | 它会被**当成"他让它做的事"**去执行 ⇒ 作者（助手）**只许写他明确要的那种事**（工具与人格里都写死） |
| 被拒怎么说 | 清单不合形状 ⇒ **当场拒**（**不是偷偷夹住** —— 夹住会让他以为"我设的 5 分钟生效了"）；他关掉 / 没声明 ⇒ **一件都不跑** |
| ⚠️ 今天还没有的 | **"到点一定跑"不保证**（服务没起来 / 正忙 ⇒ 跳过，**不补跑**）· **租户那一侧不接**（如实记一句并跳过，不假装跑过） |

### 3.5 授权这件事**只有一处签字**：他

- 助手能**说清**它要什么、能**提申请**；**那一下永远在他手里**（设置页那张卡与打开时那张弹窗，
  同一本账）—— 这一条与 [`05-DECISIONS.md`](05-DECISIONS.md) 的 `P1` / `P2` 是同一条。
- `/api/app-grant` 那条口走**登录态**；**助手那条工具口碰不到它**。
- **以盒子为准**：租户的授予落在**他盒子里**；盒子不通 ⇒ **如实 503**，**绝不**写宿主那一份
  （写了也不算数）。
- **清空它存下来的东西**：那颗按钮**每个小程序都有**（不管有没有声明过什么），先过**二次确认**
  （"它存下来的东西会没掉，拿不回来"），**只有确认之后**才发那一条请求；没成 ⇒ 照服务端那句
  `text` 说，**不许静默、不许先说成了**。⚠️ **别的几样他给不给，都照样能清**（"我的东西我拿走"）。
  实现：服务端 `POST /api/app-db-clear {id}`；租户那一侧**在盒里落**，盒子不通 ⇒ 如实 503。

### 3.6 一句话不许错：**界面上不出现协议名**

`db` / `ask` / `net` / `agent` / `tasks` / `camera` **一个都不许上屏**；
人话只住 `lib/models/space_words.dart`（进**禁用词硬闸**）。
四个例子：`ask` → 「**想用你的钥匙问一句**」· `net` → 「**想连网取数据**」·
`camera` → 「**想拍一张照片**」· `agent` → 「**想跟它的助手说话**」；
认不出的名字 → 「还想再要一样东西」。**存储不摆成一行**（它不是一件要他允许的事）。

## 四、每一格自己的库

### 4.1 单元：一个小程序 ＝ 一个独立的 SQLite 文件

| 项 | 规定 |
|---|---|
| **落点** | `<他那一格>/hupo/apps/<id>/data.sqlite` —— 在 `versions/` **外面** |
| **后果** | 发新版**不动它** · 删那个小程序时**跟着它走**（`appDir` 整个挪进 `.removed/`）· **按人分开**（甲看不见乙的） |
| **不是** | 不是"一个人的所有 app 一张表" —— **一个 app 一个文件** |
| **谁碰得到文件** | 🔴 **只有壳**。制品**永远拿不到文件**，也拿不到别人的库（跨库那条路两道堵死，见 4.5） |

### 4.2 执行在**壳这一侧的子进程**里（为什么不是 worker）

| 路 | 结果 |
|---|---|
| **worker 线程 ＋ `terminate()`** | ❌ **打断不了一条正在跑的本地调用** —— 一条失控的递归会把整个进程卡住（探针实测：`worker.terminate()` 之后 CPU 还在烧） |
| **子进程 ＋ 到点 `SIGKILL`** | ✅ **能硬停**，而且杀完库还能开（SQLite 的热日志自己恢复） |

⇒ 所以：**一条 SQL 卡不死服务**。执行体是 `src/app-db-run.js` 那个**独立子进程**
（Node 24 自带 `node:sqlite`，零依赖），到点 `SIGKILL`。
**判据要看到"那个进程真的没了"**，不是"回了一句超时" ——
`test/app-db.test.js` 的 **D3** 直接去 `/proc` 看它没了（`sig=SIGKILL`）；
⚠️ 这一条是**被自己抓出来的**：第一版判据只验"回了那句话" ⇒ **照样绿**，
所以判据改成"去看它真没了"。

**代价（如实认下）**：每一次调用多一次进程往返（几十毫秒量级，探针读数在
`docs/dev/147-APP-SQLITE.md` §一 / §五）。**没做**进程池 / 常驻子进程 ——
那要另写生命周期与回收；这一步先要"正确"，不要"快"。

### 4.3 制品怎么用它：**对它自己那个原点发一次请求**

**形状**（与 `/ask`、`/agent` **完全同一个形状**）：

```
制品 → POST <它自己那个原点>/db
  第一次：{ id, v, u, e, s, op, sql, params }      ← u/e/s 来自它入口 URL 那三样
          ← { ok:true, rows, changes, lastInsertRowid, truncated, ticket }
  之后：  { id, v, ticket, op, sql, params }
```

**票是什么**：`base64url({u,i,v,e}) + "." + hex(HMAC(...))`（`src/app-db.js`）——
绑**人**（`u`）、绑 **app**（`i`）、绑**版本**（`v`）、有**到期**。
⚠️ **为什么要有票**：入口 URL 是**短时效**的（`src/app-serve.js` 的 `SIGNED_TTL_MS`），
而一个页面可能开着几小时 ⇒ 第一次用签名换票，之后用票。
⚠️ **票只在内存里算**（HMAC，不落盘、不上账）⇒ 重启就让所有票失效（可接受，页面刷新即可）。
⚠️ **权限每次都重查**（撤销立刻生效）。

🔴 **为什么这条形状是整套设计的地基**：网页那一侧是 opaque origin 的 iframe、
安卓那一侧是 WebView **顶层文档**，**两边都从同一个制品原点加载**
⇒ 它们**吃同一个 CSP 头、走同一条路** ⇒ **不需要原生桥**（铁律 3 没破）。
真浏览器端到端量过（一次性实例、不碰线上）：iframe 是 opaque origin，
`fetch('/ping')` **到得了服务器**（服务端看到 `origin: "null"`），
跨源预检真的发生而且过了；盘上真出现那个 `data.sqlite`。
读数与踩过的坑（`chrome --headless --virtual-time-budget` 按虚拟时间 dump，
而跑一条 SQL 要等一个**真**子进程 ⇒ 要真等就用项目自己的浏览器驱动，它按**墙钟**等）
在 `docs/dev/147-APP-SQLITE.md` §四·甲。

### 4.4 给它什么、不给什么

| | 内容 |
|---|---|
| **三条动作** | `run`（写/改）· `get`（一行）· `all`（多行） |
| **参数** | **一律绑定**（`?` 占位符）—— 页面不许拼字符串（那是注入的形状）；只认 `null` / 字符串 / 数字 / 布尔 |
| **一次一条语句** | 多语句**当场拒**；⚠️ **注释与字符串里的 `;` 不算**（真扫一遍状态）—— "一条语句干两件事"是绕过上限最省事的办法 |
| **建表 / 迁移** | `CREATE TABLE IF NOT EXISTS`；改结构用 `PRAGMA user_version` |
| **不许** | `ATTACH` / `DETACH` / `load_extension` / `VACUUM` / 显式事务 / 递归查询 / 别的 `PRAGMA` / `readfile`・`writefile` |
| **上限** | 每库字节 · 一条 SQL 长度 · 参数个数 · 带回行数 · 结果字节 · 单次时长 · 每分钟次数 —— **只住 `src/app-db.js`**（`08-SPEC.md` §十 是总表） |
| **留痕** | **拒的那几档**写审计（`db-deny` / `db-rate` / `db-full`）；**成了的不写** —— "谁想干什么被拦了"要查得到，每调一次写一行会把账淹掉 |

### 4.5 跨库那条路：**两道堵死**

1. **文本守卫**（`guardSql`）：按**词边界**拒 `ATTACH` / `DETACH` / `load_extension` / `VACUUM` /
   显式事务 / `readfile`・`writefile`（`attachment` 这种**列名不误伤**）。
2. **`setAuthorizer`**（在**子进程里**）：`ATTACH` / `DETACH` **直接拒** ·
   `PRAGMA` **只放行 `user_version`**（迁移要用）· `RECURSIVE` **拒**。

⇒ 就算第一道漏了，第二道也过不去；就算两道都漏了，那个文件也**只**在它自己那一格里
（路径由壳定死，**页面报的任何路径一个字节都不采信**）。
**判据**：`D2` —— `ATTACH` 两道都拒，**第二道是直接绕开守卫调的**（验的正是 `setAuthorizer`）；
变异：去掉 `setAuthorizer` 里那两行 ⇒ **D2 红**。

### 4.6 被拒的时候**各说各的话**

混成一句会让人一直重试 —— 所以这几档**分开**：

| 屏幕上发生什么 | 服务端说的是什么 | 页面该怎么办 |
|---|---|---|
| **满了** | 507「这个小程序的存储满了。」 | 如实说，并提示"清一清旧的" |
| **太频繁** | 429「……存得太频繁了」 | 等一下再试 |
| **一条查太久** | 503「这一条查得太久了……」 | 如实说，把范围写小 |
| **这条 SQL 本身不行**（动作/语句/参数不认、多语句、危险关键字…） | 400「这一条它没执行成功。」 | 如实说（那是页面自己的 bug） |
| **行数被截断** | 结果里带 `truncated: true` | **如实说"还有更多"**，别当成全部 |

⚠️ **存储没有 403 那一档**（它不用他允许；`403` 是 `ask` / `net` / `agent` 那几样的）。

### 4.7 他能清空、以及**明确还没做的那几样**

**「清空它存下来的东西」**：见 §3.5 —— **每个小程序都有那颗按钮**，
二次确认、拿不回来、与"给不给它用"无关；服务端 `POST /api/app-db-clear {id}`，
幂等（没存过也回 `{ok:true}`），**只删那一格存储**（连它旁边的 `-wal` / `-shm`），
**制品、工作区、那个 app 本身都不动**（下次打开是一个空库）。

**明确还没有的**（**不是"排后"**）：

| 没有的 | 说明 |
|---|---|
| **BLOB（二进制）** | 只认 `null` / 字符串 / 数字 / 布尔；要开得先定编码与上限 |
| **导出 / 带走** | 库不能导出成文件给他 |
| **跨 app 共享** | **没做，也不打算做** |
| **让助手读这个库的程序化口子** | 助手要查只能走"人话路径"（那是另一件事） |
| **iOS 侧这条能力** | iOS 商店版不许小程序运行时（铁律没变） |

⚠️ **`docs/dev/147-APP-SQLITE.md` §五 里"「清空」那颗按钮没做"那句已经过期** ——
它写的是那一条还没落地的当时；今天那颗按钮**每个小程序都有**（§3.5、§4.7 上面那一段，
判据 `D8` ＋ `G6` ＋ 客户端那两条）。**别照 §五 那句去验收。**
