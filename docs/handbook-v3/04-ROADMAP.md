---

## 计划中的节

| 节 | 回答什么 |
|---|---|
| **一、这一版（3.0）** | 一句话 ＋ 指向 [`01-PROJECT.md`](01-PROJECT.md) §六 的能力全景。**不做增量叙述** |
| **二、"版本"在这个项目里的口径** | 没有发布列车；**一批 ＝ 一个可交付的状态**；三条交付判据（能装到平板上 / 有可自动化的验收 / 能说清修掉了哪个真实放弃点） |
| **三、已定稿的版本各是什么** | V1.0 · V2.0 各一句 ＋ 它们钉在哪个 tag（**锚点不抄在这儿**，见 [`../dev/00-PROGRESS.md`](../dev/00-PROGRESS.md)） |
| **四、还没通的 ＋ 要主人做的** | 每一条：**卡在哪 / 要谁做什么 / 不做会怎样**。⚠️ 这一节必须与代码一致（"真读数没有"就要写真读数没有） |
| **五、"做一半比不做更坏"清单** | 那几条**不许拆着交付**的东西 |
| **六、明确砍掉的** | 一条一行，**说清砍了**（不是"排后"） |
| **七、悬空但不阻塞的** | 记着，别当已经定了 |

## 写这一份时的硬要求

- **砍掉的必须明说**（本项目的纪律：不写"以后再说"）。
- **"还没通"不许美化**：没有真读数就写没有真读数。
- ⚠️ **上一代那张"批 0–6 施工表"不进这一份**（那是考古，去旧手册与 `docs/dev/`）。
