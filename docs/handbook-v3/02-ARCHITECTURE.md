# 02 · 系统由什么组成、边界在哪

**这一份回答什么**：系统由什么组成、每一层的边界在哪、什么东西不许越界。
**谁该读**：所有人。

---

## 计划中的节

| 节 | 回答什么 |
|---|---|
| **一、三层 ＋ 一条旁路** | 终端层 / 调度层 / 工作层各是什么、中间走什么协议；旁路（监控层）为什么存在 |
| **二、三条边界 ＋ 一条安全事实** | 终端只上报事实不做判断 · 调度器不能有表达欲 · 子 agent 永不直接对用户说话；**工作区根目录不是安全边界** |
| **三、多租户** | 一人一台盒子 · 隔离边界落在 **uid** · 容器内目录布局的三条硬规则 · 容器里的 root 该给还是不该给 |
| **四、作用域** | 1:1:1:1（作用域＝工作区＝一条会话＝一个目录＝桌面一格）· 一致性铁律 · 切换＝换会话（不是改字段）· 跨作用域与转交 |
| **五、不变量 N1–N32** | 一条一句：**是什么 ＋ 违反了会怎样 ＋ 判据在哪**（全文在 [`08-SPEC.md`](08-SPEC.md) §一） |
| **六、明说没建的** | 那几个"讲了但不建"的模块，为什么现在不建（不是"排后"） |
