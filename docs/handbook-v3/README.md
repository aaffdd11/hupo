## 四、维护纪律（**破一条这套手册就废**）

| # | 纪律 |
|---|---|
| **1** | **不写数值。** 阈值、超时、容量只住**代码**与 `08` §十 的**阈值总表**。正文写"跟着字算"，不写具体像素。**写死数值的那一刻它就开始过期。** |
| **2** | **协议字段一旦上线就冻结**（旧客户端还在跑）。`03` §三那张表**动工前定完**，之后只加不改语义。 |
| **3** | **纯函数进 `test/unit`，不写界面断言。** `test/widget` 一般是提示档，**但 `accessibility_test.dart` 是硬闸**。新验收写进 `test/unit` 才算有人守。 |
| **4** | **"以后再说"等于永远不做。** 要砍就**明说砍了**（`04` §七）。写不出验收的条目不许进 `04`。 |
| **5** | **删任何一条结论之前，先确认它在这里有家。** 顺序反了就会丢东西。 |
| **6** | **分层，且指针要过闸。** 层与层之间**只许引用、不许复述**（一条事实只有一个家）。`node scripts/check-docs.mjs` 挂在提交前：链接可达 ＋ `#锚点`可解析 ＋ 路由层不许出现数值。 |
| **7** | **现在时。** 不写"原来／后来改成／已作废／补"。**作废的 ID 与被否决的选项不进这里**（映射在 [`dev/225`](../dev/225-V3-HANDBOOK-PLAN.md) §八）。 |

## 五、几个容易搞混的名字

| 名字 | 指什么 |
|---|---|
| **琥珀 / hupo** | 这个产品（个人 AI 助手） |
| **DSH** | DeepSeek Harness，跑 agent 的那层底座（`@deepseek-ai/dsh`） |
| **调度器 / dispatcher** | `v2/services/core`，常驻进程：对用户的路由、agent 之间的邮政、归一化成一条时间线、账号与供给 |
| **作用域 / scope** | 一条 DSH 会话 ＋ 一个目录。⚠️ **界面上永不出现"作用域"三个字** |
| **工作区** | ⚠️ **界面永久禁用词**。它是"作用域"在工程语境里的旧称 |
| **本子** | 作用域在**用户面前**的说法 |
| **浮窗** | 手机上那个唯一的聊天窗口（可拖、可收、可展开） |
| **桌面 / 图标墙** | 铺满整屏；一格 ＝ 一间 ＝ 一条对话 |

⚠️ **"界面不许出现内部词"是缺陷级纪律，不是文风建议**：`03` 把它做成了 `test/unit` 闸（禁用词扫描）。
