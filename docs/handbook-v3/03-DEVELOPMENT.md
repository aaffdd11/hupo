## 计划中的节

| 节 | 回答什么 |
|---|---|
| **一、仓库地图** | `v2/apps/mobile`（终端层）· `v2/services/core`（调度层）· `scripts/`（构建/部署/闸）· `docs/` 的四层分工（路由 / 手册 / 证据 / 代码） |
| **二、模块依赖与楼层闸** | models ← services ← widgets ← screens 的单向依赖；三条禁令；靠 `test/unit/import_rules_test.dart` 强制（`analysis_options.yaml` 加不了 import 禁令） |
| **三、协议** | 事件表（九个）· 每条字段与语义 · 三条语义规则（取号 / 补发 / 不占号）· 兼容规则（不认识就忽略）· **协议字段一旦上线就冻结** |
| **四、状态机与数据模型** | 一条消息四态与允许的转移 · 作用域栈与"上屏排队" · 收起/删掉/真删三段 · 过程两档 · 工时账（字段冻结、只追加）· **状态清单**（备份/迁移/删除都照它走） |
| **五、服务端内部契约** | 唯一取号函数 · `MessageWriter`（start→text*→end）· **落盘失败上抛之后谁接** · **轮的稳定键** · `AgentRuntime`（env 白名单 / 进程上限 / LRU）· 淘汰与准入 · 记忆出口 |
| **六、客户端结构** | 屏 / 控制器 / 服务 / 本机存储各是什么；"进哪一屏"只有一处；两条 WebSocket 与地址都是纯函数算出来的 |
| **七、测试地图** | 三道硬闸（analyze / unit / 服务端 `node --test`）＋ `accessibility_test.dart` 是 widget 里唯一的硬闸 · **什么必须写成纯函数** · **不许写什么**（像素坐标 / 控件 key / 行为快照） |
| **八、文件级索引** | 按"我要改什么"查落点与闸（与 [`../CHANGE-MAP.md`](../CHANGE-MAP.md) 的分工） |

## 写这一份时的硬要求

- **路径与符号必须是今天真的在的**（写之前逐个核；上一代删掉的文件不许再出现）。
- **不写数值**（阈值住代码与 [`08-SPEC.md`](08-SPEC.md) §十）。
- 协议那一节**只描述字段与语义**，不抄实现。
