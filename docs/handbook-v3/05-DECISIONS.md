# 05 · 已经拍板了什么

> 🚧 **这一份的正文还没写**（结构已定）。要它现在的内容，先读旧手册
> [`../handbook/05-DECISIONS.md`](../handbook/05-DECISIONS.md)（**只作证据**：
> 里面混着 `·补`、`·补（十三）`、已作废的 `D5.18`／`D5.19` 与"被否决"三段）。

**这一份回答什么**：哪些事**已经拍板**，以及**为什么不能那样做**。
**谁该读**：想改一处"看起来该改"的地方时。

**每条写成三样**：**ID ＋ 现在时的结论 ＋ 最强理由（＋ 连带动作）**。

---

## 计划中的族

| 族 | 管什么 | 代表 ID |
|---|---|---|
| **安全与权限** | 助手不能改自己；执行特权走手动 | `P1` `P1.1` `P1.2` `P1.5` `P2` `P2.2` |
| **承重墙** | 编号 / 协议字段 / 删除三段 | `X1.1`–`X1.4` `X3` |
| **能力与边界** | 能力契约层；不代执行 | `P4` `P5` |
| **命名与登录** | 隐喻与用词；登录页定稿 | `D1` `D1.1`–`D1.6` `D2` `D2.5` |
| **可访问性** | 把默认值改安全（不做"老人档"） | `D3` `D3.5` `D3.6` `D3.10` `D3.13` `D3.14` `D3.16` |
| **设备与小程序** | 手机主目标 / 平板主开发；小程序九件工具与授权 | `D4` `D4.1`–`D4.31` |
| **语音** | 打不了字的人怎么进来 | `D5` `D5.2` `D5.4` `D5.10`（⚠️ `D5.18`／`D5.19` **已作废**，映射在 [`../dev/225`](../dev/225-V3-HANDBOOK-PLAN.md) §八） |
| **数据源** | 第一个真数据源的形状 | `D6` `D6.1` `D6.3` `D6.7` `D6.8` |
| **过程可见性** | 分层展示；推理原文只给主人 | `D7` `D7.1` `D7.2` `D7.4` |
| **多租户与供给** | 一人一台；隔离在 uid；新号自动拿一台 | `T1`–`T11` |
| **客户端结构与传输** | 传输层生命周期；一条可见时间线＝一条日志 | `P-e` `P-f` `P-l` `P-i` `P-j` |
| **store 与序号** | 上抛、谁接、不占号 | `S1` `P-k` `P-g` |
| **通知** | 只进时间线（唯一例外：写盘失败那条） | `N1` `N2` |
| **续做** | 只做只读的活 | `D10.1`–`D10.5` |
