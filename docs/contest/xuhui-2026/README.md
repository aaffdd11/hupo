## 二、三条硬约束（**别再照着旧那份文稿交**）

1. 🔴 **字数上限 3000**。旧文稿 5524 字（实测）⇒ 已重写成 [`作品设计说明.pdf`](作品设计说明.pdf)（2558 字）。
2. 🔴 **作品设计说明里不许出现与申报人相关的个人信息**（模板原话：*"以下不能出现与申报人相关的个人信息，如姓名、所在区域、指导教师、就读学校等"*）。
   ⇒ 新稿把封面那一栏（姓名/学校/指导教师）**整块去掉了**，那些信息只出现在**申报表**里。
3. 🔴 **必须以"作品设计说明"的四段结构交**：一、作品简介　二、设计制作过程　三、使用说明　四、创新点。
   新稿就是照这个顺序写的（另外带 2–3 个关键词与参考文献）。

⚠️ 顺带两条活动的硬规矩：**每名队员只能报一个项目**、**以个人为单位**；**每人至少 1 位指导教师**。

## 三、查新报告：查新点与检索词（可直接抄进那张表）

**查新点（需要查证的创新点，4 条）**

1. ~~语音输入之后不直接执行…加一层听懂…问回去~~ 🔴 **2026-10-07 已删**（主人当天定：去掉那一层，说完就发）
   ⇒ 改成：**语音优先的输入形态** —— 按下说、**按停才发**（不做"每个句号断一次"），识别回来的字直接落进输入框、可当场改；服务的是不会拼音、打字困难的人。
2. 让**非开发者**用自然语言生成只属于自己的**个人小程序**，当场出现在桌面上、点开即用、数据持久保存，并可长期迭代。

4. 把每一轮对话做成**有始有终、可查账的"活"**：做过什么、成没成、花了多少可查；被硬杀后重启能逐件如实交代"做完了 / 已停"。
