## 主用（195 字）

「琥珀」是一个通过对话就能聊天、也能创建可复用应用的助手。① 说一句就办事：找资料、解决问题；
② 复杂的事你一句指令，它当场做个小程序，做完留在桌面上，明天点开还在；
③ 说话不用打字：点一下说、按停就发，说错的字点一下就能改；④ 内容有安全与伦理把关，能对话的小朋友、打字不便的老人、
成年人都能用；⑤ 每个人看到的都是自己的那一份，互相看不见；做出来的东西还能分享到广场，
别人在「发现」里找到直接用。

## 「呈现出来的特点」清单（报告 / 答辩照着说）

**用户屏幕上只有两样东西：一个聊天窗口，一个桌面。**

| 看得见的特点 | 说给人听的话 |
|---|---|
| **一个聊天窗口** | 想说什么就在这儿说；它**在听、在想、在办**都看得见，不用猜 |
| **一个桌面（一格图标 ＝ 一件事）** | 它给你做出来的东西**变成桌面上的一格**：点开就用，关掉再回来还在 |
| **说话不用打字** | 点一下说、按停就发；说错的字**点一下就能改** |
| **它是真去办的** | 不是只陪你聊：查资料、算数、写东西、做图、记一笔账，复杂的事**当场给你做一个小程序** |
| **它的东西留得住** | 说过的话、做过的事都在，**能翻出来**；昨天做的小程序今天还在桌面上 |
| **成没成说清楚** | 做完了回来说一声；办不成也说明白，**不会把"没办成"说成"办好了"** |
| **它记得住你** | 不用每次把话重复一遍；越用越像在跟熟人打交道 |
| **一个人一份，互不打扰** | 每个人看到的都是**自己的那一份**；自己做出来的东西可以**分享到广场**，别人在「发现」里找到直接用 |
| **谁都能上手** | 字能放大不破版、按钮够大、**屏幕上没有看不懂的词**；会说话就能用 |

**一句话**：**说得出口，它就办得到，办出来的东西留在你自己的桌面上。**

## 写这几句时守着的几条

* **不讲底层**（2026-10-07 主人定调）：容器 / 调度器 / 大模型 / 接口 / 沙箱 / 云端 —— **一律不进简介**；
  对应的说法换成**用户那边的现象**（"一台独立容器" ⇒ **"每个人看到的都是自己的那一份"**）。
* **不写个人信息**（姓名、学校、电话一律不进简介）；
* **不写内部词**（工作区 / 口令 / 连接 / 客户端 / 工具名）——那是缺陷，不是文风；
* **不承诺做不到的**：能说的就是那几件（聊天 · 按指令做小程序 · 纯语音 · 内容把关 ·
  各人一份互不可见 · 做出来的能分享）；
* **"适合谁"照实说**：能对话的小朋友、打字不便的老人、成年人 —— 不写"老少皆宜"那种空话。
