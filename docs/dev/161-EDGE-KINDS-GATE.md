## 一、三类边各落在哪（**这是本批的形状**）

| | **能力体版本边** | **经验方法边** | **数据交付边** |
|---|---|---|---|
| **kind** | `capability` | `method` | `data` |
| **住哪（登记）** | `hupo/apps/<id>/lineage.json` | `<scope>/.exp/edges.jsonl` | 这条人自己的**可见日志**（`delivery/*` 四条记录） |
| **谁写** | `apps.noteLineage()`（**唯一写入者**） | `MethodEdges.apply()` | `Delivery.request/consent/deliver/revoke()` |
| **方向** | **只增**（没有删的路） | **唯一有回流方向**（上游 → 我） | **成对、永不回流** |
| **来源住哪** | 边上的 `baseRootHash` | 边上的 `source`（`app`＋`rootHash`＋`role`） | 边上的 `from`／`to`（**人格 key**，`personaKeyOf`） |
| **来源怎么核** | `capabilityEdgeOf()`：`baseRootHash` 要么是**这一版自己**，要么 `apps.manifest(baseVersion).rootHash` **逐字相等** | `MethodEdges.#source()` ＋ 解析那一半：`source.rootHash` 必须**在制品库里立得住**（自己那一版，或某一版的起点逐字相等） | 两端都是**人格 key**（看着像手机号的当场拒）；"同意"只认**他当轮那句话**（`parseConsent`） |
| **为什么是这个形状** | 90 Q4.6／Q4.9：**血缘住登记、不写进不可变清单**（清单会被下一版覆盖） | 92 §③ 阶段 5 原话：**唯一有回流方向的那条** ⇒ 有回流方向而**没有应用点** ⇒ "回流"是一句没有落点的话；**有应用点而没有回退点** ⇒ 应用一次就**回不去**（N5） | 91 §6／§8.2：**平台不带值**；撤回只改**未来**（物理上收不回对面那份） |
| **判据（离线）** | `test/edges-three-kinds.test.js` §5-1…§5-4 · 闸 K1–K4 | 同上 §5-5 · 闸 K5 | 同上 §5-6 · 闸 K6 |

**三条边的形状只有一处定义**：`src/method-edge.js` 的 `EDGE_KINDS`（`capability`／`method`／`data`
各一条，`reflow` 那一栏就是"出去律是路、不是格"在**边**上的落点）。别的模块只许引用它。

### 1.1 "各带来源"到底"带"的是什么

| 边 | 来源那一半 | 它**不是**什么 |
|---|---|---|
| 能力体版本边 | `baseRootHash`（64 位十六进制）＋`baseVersion` | **不是**"谁发给我的"（作者身份不进这条边；共享库那边只存 `authorHash`） |
| 经验方法边 | `source = {app, rootHash, role}`（`author`／`one-to-one`／`upstream`） | **不是**血缘（它不进 `lineage.json`） |
| 数据交付边 | `from` / `to`（人格 key） | **不是**手机号（`PHONE_LIKE_RE` 当场拒）；**不是**内容指纹（值不落登记） |

🔴 **同一句"来源"在三条边上指三样东西** —— 所以它**不可能**塞进一条共用的记录里。
这就是 92 §③ 阶段 5 说"**三条边分开建**"的**机械理由**（不是文风问题）。

### 2.1 一处**如实说清**的读数（不许读成"没变"）

K5 里 `apply()` 的**应用点**本身会拍一张快照 —— 那是"回退点"的实现方式：多留一版
**同内容**的登记版本。⇒ **`version` 这个指针会往前走一格**，但**新那一版的 `rootHash`（内容）
与 `shapeVersion`（形状）与改 `.exp/` 之前逐字相同**（`snapIsBefore` 判的就是这一条）。

判据要问的是"**经验有没有变成能力体的一部分**" —— 答案在**内容与形状**上，**不在指针上**。
⇒ 闸里那句话写的是"内容与形状逐字相同（指针版号会 +1）"，**没有**写成"三个号一个没变"。
⚠️ 这一处**不是** K1：K1 问的是"**只改 `.exp/`**"（**没有任何 `apply()`**）⇒ 那里三个号**真的一个都没变**。
