# 176 · "明说" = 语义上要了，不是某一句格式

> **主人 2026-10-04 原话**：
> *「每次创造小程序，他都要我补足一句：帮我做一个小程序。你帮我把这个问题解决掉。
> 就是语义上说过了那就做到桌面。」*
>
> ⇒ 写进手册 `05-DECISIONS.md` 的 **`D4.25·补`**（升 **v2.42**）。

---

## 一、他为什么老被要那一句（**真机读数**）

那台盒子的流水（`/home/hupo-b/tenant/main.jsonl`）里，**14 次**工具回执带着那句
*"得你亲口说一句『帮我做一个……』我才做"*。把他**真在要东西**的那几句挑出来：

| 他说的 | 当时为什么被拒 |
|---|---|
| 「请创建一个可以玩五子棋的游戏。」 | 闸要"**帮我做**"那一种说法，`请` 单独一个**不算**（怕"请问"）⇒ 拒 |
| 「请创建一个可以玩飞行棋的游戏，而且需要有梯子和骰子…」 | 同上 |
| 「请你立刻把数独内容放到小程序里面。」 | "**放**"不在动词表里 ⇒ 拒 |
| 「骰子要放在各自停机坪旁边」 | 这是**接着说**（同一件事里的改动），单看没有"造"的意思 ⇒ 拒 |
| 「要有存储啊」 | 同上 |

⇒ 助手把这些原样转述回去，他看到的就成了"它又要我补一句"。
**根因**：那条闸是**按格式认的**（`ASK` 两个正则同时命中），而不是**按意思认的**。

## 二、改成什么样

`src/apps-consent.js` 的 `asksToMakeApp()` 现在认**两条**（任一成立就算"他要我做"）：

1. **他张嘴要**（`帮我/给我/替我/请你/请(?!问)/麻烦/能不能/可不可以/我要/我想/我想要/想要/
   需要一个/需要个/要一个/要个/来个/来一个/做一个/做个`）
   ＋（**做了的动作** `做/造/写/加/弄/搞/生成/创建/新建/搭/实现/来/放到/放进/做成/改成/补上/添`
   **或** **那件东西** `小程序/应用/页面/网页/界面/工具/游戏/app/软件/程序/东西`）
2. **做的动作 ＋ 那件东西**（主语省略：「把数独内容放到小程序里面」「做个五子棋」）

### "接着说"那几轮：一个小窗口

新增 **`askedRecently(recentInputs, window = 3)`**：看**同一间里他最近说过的那几句**。

- 那几句从**服务端自己记的**轮次输入来（`dispatcher` 每条会话留最近 **3** 句，
  `RECENT_INPUTS_MAX`，**住代码**）。
- 🔴 **只在"这一轮他确实说了话"时才看** —— **助手自己发起的那一轮**（没有票 ⇒ 他那句话是空的）
  **照旧一律拒**（那条老规矩一个字没松）。
- 窗口小是刻意的：**"他刚才说过"**不等于"他历史上说过"（窗口越大，很久以前那句越可能一直生效）。

### 拒的时候那句话也改了

不再教他套格式，改成：*「往你桌面上放东西，得你亲口说一句要什么 —— 直接说你想要什么就行
（比如"做一个记账的""我要一个能玩的小页面"），不用套哪一句格式。」*

### 人格与工具描述同步

- `hupo-persona.yml`：三处讲"触发"的地方都加了 *"说法不限"* ＋ 🔴 **不许**要他补一句、
  **不许**反问"你是要我做吗"（其中"① 动手"那条还写明"接着说那几轮也算同一件事"）。
- `src/mcp-apps-server.mjs` 的 `app_create` 描述：同样加了一段。

## 四、没动的（明说）

- **`app_publish` / `app_install` / `app_grant` / 卸掉**那几条口**都没动** ——
  它们要的是"发出去""装上"这种**动作词**，与"造"不是一件事（各有各的闸）。
  ⚠️ **也就是说"语义上说过了"这条放宽只作用于"造一个新的"**。
- **请求里的字段**照旧一个都不看（判据钉着）。
- **助手自己发起的那一轮**照旧一律拒（判据钉着）。
