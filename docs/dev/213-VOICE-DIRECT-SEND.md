# 213 · 语音：那一层「抽离」删掉，字到手就发（＋"前面那句话没了"的根子）

> 主人 2026-10-07：*"我发现语音一个问题，就是一句话出现识别句号以后，后台会做点什么事情，
> 然后前面那句话就没了。……我们之前对语音，是抽离出来做了一层，没问题才发给聊天的。
> 现在我需要把这个抽离的部分给去掉。用户会说很多话的。不可能每个句号做断点，
> 也必须是用户说完，语音变成文字拿回来了，我们再发出去。"*

两件事：**① 把那一层删掉**（他要的）；**② 他报的那个现象，根子找到了**（在下面 §二）。

---

## 一、"抽离那一层"原来是什么，现在删了什么

V2.0 第一件（`dev/181`／`182`）那条链原来是：
**语音 → 文字 → 「听懂那一层」`/api/hear`（改错别字、不确定就问一句、最多两轮）→ 才发**。
2026-10-06 主人说"先暂停语义检查"（`dev/202`）⇒ 当时只加了一个**开关**
（`models/semantic_switch.dart` 的 `semanticCheckOn = false`），**代码与判据都留着**。

他说的是"**去掉**"，不是"暂停"。所以这一趟**真删**：

| 删掉的 | 在哪 |
|---|---|
| 那个开关（整个文件） | `lib/models/semantic_switch.dart` |
| 调那一层的那两处 | `chat_controller.dart`（`_composeThink` 整段）· `screens/hear_drill_screen.dart`（`_think` 整段） |
| 那一层的接口那一侧 | `services/api.dart` 的 `hear()` ＋ `HearOutcome` ＋ `hearOutcomeOf` |
| 那一层带出来的状态 | `hear_drill.dart`：`DrillPhase.asking` · `DrillTurn` · `turns` · `question` · `round` · `canAskMore` · `drillMaxRounds` · `heardBack` · `payload` |
| 那些话（数据源） | `hear_words.dart`：在问 / 问够了 / 念不出来 / 那条路接不上 / 怎么答 / 暂停那一句 |
| "还没校正"那条下划线 | `voice_bar.dart` 的 `raw` ＋ `design.dart` 的 `voiceRawUnderline`（**没有第二步了**，留着那条线等于一直在说"这份还不算数"） |

**留下来的两条**（都是有意的，写在这儿免得下次有人"顺手清掉"）：

* **服务端 `/api/hear` ＋ `hear.js` 一个字没动** —— 老包（手机上已经在跑的那些）里有人在调它，
  协议一旦上线就冻结（手册 §二 纪律 2）。删它会把老包那一段打成空白，而收益是零。
* **`hear_drill.dart` 这台状态机还在**（它本来就是纯逻辑，聊天那颗话筒与设置里那场演练共用一台）。

现在那条链只剩一句话：**按一下说 → 想说多少说多少 → 按停 → 字拿回来 → 发**。

## 二、"前面那句话没了"：根子在**发完之后那一档掉回了"非连贯"**

⚠️ 这一条不是猜的，代码里指得出来（判据 `hear_drill_test.dart` ⑧ 钉着它）：

`_composeSendNow()` 发完一场之后，原来收场那一行写的是 **`const HearDrill()`** ——
而 `HearDrill` 的 `continuous` **默认是 `false`**。于是：

```
第一场：continuous = true  ⇒ 到点接着开、按停才发      ✅
（发出去了）→ _voiceFlow = const HearDrill()          ⇒ continuous 变成 false
第二场：非连贯那一档 ⇒ 55 秒上限那条 asr/end 走到"他说完了"那条老路 ⇒ 半路就把话发出去
        ⇒ 框当场清空 ⇒ 屏幕上看着就是"前面那句话没了"
```

⇒ 改一行：**`_voiceFlow = const HearDrill(continuous: true)`**（聊天那颗话筒**永远是连贯那一档**）。
判据里有两条钉着它：源码级（不许再出现 `const HearDrill();`）＋ 控制器级
（第二场到点**不许发**、字必须还在、按停之后才发那一整段）。

⚠️ **一并说清现在这条链的形状**（他要的"不可能每个句号做断点"）：
豆包按句给字（句号）⇒ 那**不是**"说完"；服务端那条 55 秒上限（`ASR_MAX_MS`，为了省钱）
⇒ 那也**不是**"说完"（客户端当场接着开下一轮，字接在 `settled` 后面，一个字不清、一次不发）。
**只有他按停**才算说完。
