# 55 · 语音那一刀：**先做"假的"**（形状真、数据明标演示）

> 主人 2026-09-22：*"对话框要学习微信。要能切语音，能切听筒。语音和听筒都要实时转文字。"*
> 我问了平台与决策（见下），他答：**"先做假的。"**

---

## 一、⚠️ 为什么"先做假的"这件事必须写在最前面

这个项目栽过**三次"页面在说假话"**（`07-APPENDIX.md` §一 事故一），
而且 `D5.13` 专门规定：**不录音时禁用"听"字**（并进了禁用词扫描）。
⇒ 所以这一版的纪律是**两条**，缺一条就是缺陷：

1. **形状可以是真的** —— 话筒/键盘、按住说话、听筒/扬声器、实时文字区，**都做真的**；
2. **数据必须是假的，而且一眼看得出是假的** ——
   ① 一个**「演示」小标**常驻（`voiceDemoChip`）；
   ② 一句**实话**（*"演示：还没有真的开麦，这些字是假的。"*）；
   ③ 吐出来的字**本身**就写着"这是一句演示"（万一被发出去也不会被当成真话）；
   ④ **绝不出现"正在听"**（我们根本没开麦）；
   ⑤ **松手不自动发送**（D5.4）—— 字只落进打字框，发不发**他自己决定**。

⇒ 判据（`test/widget/voice_demo_test.dart`，6 条）钉的正是这些，
**不是**"功能对不对"（功能还没有）。

## 二、形状（学微信）

```
┌────────────────────────────────────────────────┐
│ [演示] 演示：还没有真的开麦，这些字是假的。        │  ← 演示提示条（切语音/听筒时出现）
│        这是一句演示…                            │     "实时转文字"的形状
├────────────────────────────────────────────────┤
│ [🎤] [📋] [ 说点什么        ] [🔊] [ ↑ ]        │  ← 键盘档
│ [⌨️]      [   按住 说话     ] [🔊] [ ↑ ]        │  ← 语音档
└────────────────────────────────────────────────┘
```

| 那个按钮 | 切什么 | 现在真的会做什么 |
|---|---|---|
| 🎤 / ⌨️ | **切语音**（话筒 ⇄ 键盘） | 只切外观；**不开麦** |
| 按住 说话 | 按住 = 出字、松手 = 停 | **演示**：按 90ms 一个字吐出来；松手把这句话**放进打字框** |
| 🔊 / 👂 | **切听筒**（听筒 ⇄ 扬声器） | 只切图标 + 显著式那一句实话；**不朗读** |

⚠️ `按住 说话` 用 **`Listener`**（不是 `GestureDetector` —— 那份源码级禁令还在）。

## 三、为什么**没有**真的接上（两件事都卡在决策上）

### 3.1 你的声音走哪条路 —— 与 **D5.2** 直接冲突

| 路 | 代价 |
|---|---|
| **网页版 + 云端识别** | 快、准、能实时。但**声音出境给第三方** —— `D5.2` 原话是"与 **P1 同类**；且**地下车库恰好最需要它**，云方案在那归零" |
| **网页版 + 本地模型** | 守住 D5.2。代价：模型几十 MB、首帧慢、手机上吃力 |
| **安卓包 + 系统识别器** | 就是 `D5.2` 定的那条（"用手机自带的识别器"）。但**安装包还没上线**，而且 `D5.11` 要 `RECORD_AUDIO` 权限 |

⚠️ 还有一条**路线图上的账**：批 5（语音）是**主人 2026-09-21 亲口砍的**
（*"语音不做"*），理由是**输入法自带的语音已经覆盖了一部分**。
⇒ 真要对齐 D5，得先回答"**为什么还要自己做**"（微信这套 UX：听筒 + 实时转文字，
确实是输入法麦克风给不了的）。

### 3.2 "听筒"这一半**手册里根本没有**

`D5` 只定了"进"（话筒 → 字），**没定"出"**。而"听筒"隐含一件新能力：
**把助手的话读出来**（语音输出）。而且它是个**手机上的概念** ——
网页上没有"听筒"这个出口（浏览器只有扬声器/耳机，`setSinkId` 在 iOS 上无效）。

⇒ 所以这一半**连形状都还没定档**；这一版只是把按钮摆出来、并**如实说"还没做"**。

## 四、要真做时，这些是**硬要求**（别忘）

| 出处 | 要求 |
|---|---|
| `D5.3` | **按住说话**，只在按住时开麦；无唤醒词、不申请后台录音 |
| `D5.4` | **绝不自动发送** |
| `D5.5` / `D5.13` | "正在听…"**分两个词**；不录音时**禁用"听"字** |
| `D5.6` / `D5.12` | 权限**用人话交代**，时机 = **第一次按话筒** |
| `D5.7` | **一步**（松手即发）+ 回答首句**回显原话** |
| `D5.8` / `D5.9` | 字出来**能点一下就改**；写进记忆的（名字/日期/钱数）**额外确认一次** |
| `D5.10` | 🔴 **硬闸**：四类问题各 20 条，**句子级命中率 <90% 不上线** |
| `D5.14` | **打字框永远不许锁** |
| `D5.15` | 认识不到就说人话；**不许拿猜的字顶上** |

⚠️ 也就是说：真接上不是"加个插件"，而是**连同那 80 条语料一起做**。
