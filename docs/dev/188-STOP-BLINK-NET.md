# 188 · 按停的响应、在录时的闪、小程序的网络

> **主人 2026-10-05 一次报了三件**：
> ① *「我们录音和停止录音上，点击停止录音响应很慢。看看是否有问题。」*
> ② *「录音按钮在激活的时候，要有一个循环的效果，就是颜色一明一暗的闪烁。」*
> ③ *「天气小程序，新增了网络访问权限，但是显示网络无法联通的问题。」*
>
> 手册：`D3.14` 再补两处（① ② ）· 升 `v2.56`。③ 是**真缺陷**（不是新规矩）。

## 一、按停"响应很慢"（查出来是什么）

**不是麦没停** —— 按下去那一瞬间麦克风就撒手了（`hearing_*.dart` 的 `stopHearing`）。
慢的是**屏幕**：按停之后那一台状态机**还停在 `listening`**，要等对面把最后那一份字
（`asr/end`）吐回来才动 ⇒ 那一秒多里**屏幕上什么都没变**（圆圈照旧闪着"我在录"）
⇒ 看起来就是"点了没反应"。

**改法**：新加一档 `DrillPhase.wrapping`（"收尾中"）——

| 在哪 | 干什么 |
|---|---|
| `models/hear_drill.dart` | 新档 `wrapping` ＋ `stopListening()`（**只换档，一个字都不动**）＋ `event()` 在这一档**照收帧**（`asr/end` 一到照旧进 `thinking`） |
| `services/chat_controller.dart` | 按停 ⇒ `_stopHear()` ＋ `stopListening()` ＋ **当场 `notifyListeners()`**；收尾中再点**不许开第二场**；兜底钟 `stopLinger`（8 秒，与 `hearing_*.dart` 的 `_lingerLimit` 同量级）：对面一直不吐就**用手上那份字往下走**（一个字都不丢） |
| `widgets/voice_bar.dart` | 这一档画成"淡淡的、按不动"＋ 那句话「收下了，正在整理……」；🔴 **在不在录按 `phase` 判，不许按 `hearing.listening`**（后者要等 `asr/end` 才收 ⇒ 拿它当判据就会继续闪"我在录"） |

## 二、在录时那颗圆圈"一明一暗"

* 新 `widgets/rec_blink.dart`：一个**永不结束的呼吸**，把"这一帧多亮"（0…1）交给下面那一层；
* `design.dart` 两个 token：`accentLit`（亮的那一档）＋ `recBlinkPeriod`（一个来回 800ms）；
* 🔴 **动的只有颜色**：尺寸 / 位置 / 命中区**一个像素都不动**（圆圈自己跳 = 更难按）；
* 🔴 照旧读总开关（`models/motion_switch.dart`，手册 §6.1.1 M1–M4）：关掉之后**照旧画**、停在第 0 刻。

## 三、天气小程序"网络无法联通"（真缺陷 · 根子不在小程序里）

**现象**：他给「上海天气」授了 `net`（页面上那格真是 `granted:['net']`，声明也真是
`net:['api.open-meteo.com']`），可页面就是连不出去。**实测**：那一页响应头里

```
connect-src 'self'            ← 少了 api.open-meteo.com
```

**根子**：`app-serve.js` 的 `netHostsFor()` 判"他点头了没有"时**只问 `apps.grants()`**；
而**租户那一侧是"盒代理"**（`apps-box.js`）—— 它**只有 `list()`**，没有 `meta`、没有 `grants`
⇒ `granted` 恒为空 ⇒ 名单恒为空 ⇒ **声明的站永远进不了 CSP**。
（盒子那条 `/internal/apps` 其实**一直把 `granted` 一起带回来了**，宿主那一侧只是没读它。）

**改法**：没有 `grants()` 时读清单里那格 `granted`；**老盒子不带那一格 ⇒ 仍是空名单**
（fail-closed：宁可连不出去，也不许猜"他点头了"）。

**验**（线上真读数）：同一条签名活地址，改前 `connect-src 'self'`；
改后 **`connect-src 'self' https://api.open-meteo.com`**。

⚠️ **这一批没做的事**：没有替他动"授予"那一下（那是他自己的设置）；
也没有把"小程序要连的站"这条规矩改一个字（`148` §二那三道闸照旧）。
