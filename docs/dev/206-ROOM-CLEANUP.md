## 三、怎么清掉的（用**产品自己那条路**，不是 `rm -rf`）

```
POST /api/room-remove  {"scope":"aoshu"}   → 200（带走 workspace ＋ 39 条对话 ＋ 助手那边那份原件）
POST /api/room-remove  {"scope":"math"}    → 200（带走 workspace）
POST /api/room-remove  {"scope":"harness"} → 200（带走 workspace）
```

* 落点是**同一个回收处**：`.removed/ws-<id>-<at>/`，每格带 **`reclaimed.json`**（谁、什么时候、
  带走了哪几样）＋ `workspace/` ＋（有的话）`conversation.jsonl` / `session` ⇒ **能退回来**；
* 审计留了 3 行（`tenant/audit.log`：`reclaim-room · owner · aoshu（带走 39 条对话 ＋ 助手那边那份原件）`…）；
* 🔴 **为什么不用 `rm -rf`**：这条口自带**四道闸**（`main` 不许 · 内置那两格不许 ·
  制品库里还有它 ⇒ 走 `/api/app-remove` · 认不出这一间 ⇒ 404 **不猜**），
  而且它把"那一间的对话"从时间线上**抽走并留底**（号洞有留痕）—— 手动删目录会留下
  "对话指着一个不存在的房间"这种脏账。
