# 149 · **小程序的开发方案与标准**（做小程序的 agent 照这一份干）

> **这一份是给"制作小程序环节的那个 agent"的作业指导书**：它怎么从主人一句话走到
> 一个**能用、两端一致、不越界**的小程序。判据在 `src/app-lint.js`（写完当场自查）
> ＋ `test/app-lint.test.js`；机制与契约在 `147`（存储）· `148`（全套能力）。
>
> ⚠️ **它不是新东西**：是把已经在跑的那些规矩**收成一份作业指导书** ——
> 免得每次都得从 `147`/`148`/手册里拼。

---

## 一、角色与现场（先认清自己在哪儿）

| 谁 | 在哪儿 | 干什么 |
|---|---|---|
| **主人** | 桌面 / 某个图标的对话里 | 说一句需求（"帮我做个…"） |
| **那个 agent（你）** | **那个图标自己的工作区**（你的 cwd 就是它） | 写页面、声明能力、交付一句话说明 |
| **壳** | 他这台机器上 | 起 agent、执行存储/问话/定时任务、管闸与配额 |
| **制品** | `apps.stalkerai.cn`（另一个原点） | 一份**自包含 HTML**，跑在网页 iframe 或平板 WebView 里 |

🔴 **三条最要紧的现场事实**：
1. **一个图标 = 一个工作区 = 一条对话**；你写下来的东西**落在它自己那一间**；
2. **你看不见浏览器**：写错了（引外部资源、碰 `localStorage`、连没声明的站）在你那儿**完全静默**
   ⇒ 所以 §六 那份自查**必须**过（回执里会当场摊给你看）；
3. **两端都要能用**：同一份 HTML 同时跑在**网页**（不透明源的 iframe）与**平板**（WebView）

## 二、开发方案（从需求到上桌，六步）

| # | 这一步 | 产出 | 判据（做完怎么知道对了） |
|---|---|---|---|
| 1 | **听懂要什么** | 一句话复述（"你要的是：…"） | 拿不准的**先问一句**（名字、要记什么、要不要联网）；**不问"要哪个平台"**（只有他桌面这一个） |
| 2 | **定能力清单** | 四样里选：`ask` / `net` / `agent` / `tasks`（★ **存储不用选** —— 天生就有） | 只用**真正需要**的（多一样他就多一份要留意的）；**不确定先不加**（以后要加 = 再调一次 `app_create`） |
| 3 | **写页面** | 一份 `index.html`（内联样式/脚本） | §三 制品标准逐条过；拿不到数据/存不进去时**如实显示** |
| 4 | **声明** | `app_create` 的 `permissions`（＋`net` 名单 ＋ `tasks` 清单） | 声明与用途**一一对上**（§四）；★ **存储不用声明**；别的几样**他第一次打开时会问你一遍**，他点头的才生效 |
| 5 | **自查** | `app_create` 回执里那一段"跟标准对不上" | 🔴 **有报必改**（改完再交）—— 只报不拦不等于可以不改 |
| 6 | **交付** | 一句人话（§五 的模板） | 名字 / 能做什么 / 会不会记住东西 / 联不联网 / 有没有定时任务 / **打开时他会看到一张弹窗**（先说一声） |

⚠️ **加东西 = 新的一版**：改页面或加能力都要**再调一次 `app_create`**（不许指望"它自己会变"）。

## 三、制品标准（页面那一份）

| # | 标准 | 为什么 |
|---|---|---|
| 1 | **一份自包含 HTML**：样式/脚本**内联**；**不许引外部资源**（CDN 脚本、外部样式、外域图片、Google 字体、`@import`） | CSP 是 `default-src 'none'` + `'unsafe-inline'` ⇒ 引了**取不到**，屏幕上就是空白/没样式 |
| 2 | 图片用 **`data:`** 或 `blob:`；图标用**内联 SVG / emoji** | 同上（`img-src data: blob:`） |
| 3 | 🔴 **不许碰 `localStorage` / `sessionStorage` / `indexedDB`** | 网页上它活在**不透明源**里 ⇒ **一碰就抛** `SecurityError`。要记住东西 ⇒ 走 `/db`（★ **存储默认就有，不用声明**） |
| 4 | 🔴 **不许假设有原生桥**（`webkit.messageHandlers` / `HupoNative` / `Android.*`） | 手册铁律 3：**禁原生桥** ⇒ 写了就是"点了没反应"（网页与平板都没有） |
| 5 | **不许开长连接**（`new WebSocket`） | CSP 不放它 |
| 6 | **正文里的中文照常写**；不要靠"同原点的别的文件"（引不了） | `script-src 'unsafe-inline'` **没有 `'self'`** |
| 7 | 页面要有 `<title>`（它的名字） | 有些地方会用到；空着不好看 |
| 8 | 名字 ≤ 十来个字；短名只许小写字母/数字/短横 | 硬校验（超了 `app_create` 当场拒） |
| 9 | ★ **别自己留"状态栏 / 聊天条"那两条边距，也别把内容贴在底边** | 页面**铺满整屏**是壳要的（主人 2026-10-01 报过"没铺满、底色不同"）；那两条边距**壳已经替你加好**（注入到页面 `body` 的 `padding-top`/`padding-bottom`，见 [`150`](150-APP-FULLBLEED.md)）⇒ 自己再加一份 = 白边。⚠️ 但 `position:fixed; bottom:0` 那种**顶不动**壳给的 padding ⇒ 要紧的东西走正常文档流 |
| 10 | ★ **宽屏要铺得开，内容别只有一层**（主人 2026-10-06：*"小程序的复杂度就没那么高，页面内容也不是很丰富……因为我们使用 pad 使用的。"* · [`203`](203-APP-RICHER.md)） | 他是在**平板**上点开它的（小程序**全屏**打开，整屏都给它）⇒ ① 页面**宽屏要自己铺开**（`grid-template-columns: repeat(auto-fit, minmax(…, 1fr))`，或按宽度分的 `@media`）—— **别把内容锁在一条窄栏里居中**；② **一页有主有次**：主角是一件事，但那件事**别只有一层**（该并排的并排）；③ **别交"最小能跑"**：几块真有用的内容 ＋ 一处**能点／能填／能选**的地方 ＋ 该记住的**记住**（`/db`）＋ **空／忙／错**三种说法。⚠️ **"复杂"不等于"塞没用的东西"**。判据：`app-lint.js` 的 ⑨（`no-wide-layout` / `thin-page`，只报不拦）|
| 11 | 🎯 **要有"玩头"：深度与趣味**（主人 2026-10-06：*"一个简单的就像五子棋的棋盘挺好看，可是呢他实际跟他下的时候，你会发现他的这个下的套路是一样的……能不能让后面的整体的这个可玩性"* · [`204`](204-APP-PLAY.md)） | **游戏／玩具**：对手或关卡**每局得有变化**（随机加权、按局数提难度、局面打分挑步子这类；**每局一模一样 = 没做**）· 要有**难度档** · 落子/得分/输赢都要有**动静** · 战绩走 `/db` **记下来**。**工具**：内容**分层**（列表↔明细、筛选、最近用过、历史），别一屏只干一件事。**两者**：**做完有回响**（成功/失败有样子）＋ 文案有人味。🔴 要声音就 `AudioContext` **当场合成**（音频/视频**文件**取不到：CSP 没给 `media-src`）。⚠️ **趣味 ≠ 假话**（不许假装有 AI／联机／真实数据）；他说"简单"就简单做。判据：`app-lint.js` 的 ⑩（`flat-play` / `no-feedback`，只报不拦）|

## 四、能力标准（五样：什么时候用、怎么用、不许怎么用）

> 🔴 **总规矩**（2026-10-01 定的口径）：**声明只是"它想要什么"** ——
> 他**第一次打开**它时会看到一张弹窗（你声明过的那样样都问一遍，**一次问完**），
> **他点头的才生效**；他**随时能在设置里改**（关掉的那一样只是那一样用不了）。
> 被拒时页面拿到的是一句**人话**（照它显示，**不许**假装成功）。
>
> 🔴 ★ **存储是唯一的例外**（2026-10-02 主人改的口径：*「我发现做的小程序都不会有
> 存储。这个应该默认有存储。」*）：**每个小程序天生就有自己那一格库** ——
> **不用声明、不用他点头、打开就能存**，它也不会出现在那张弹窗里。

### 4.1 存储 —— 它要"记住东西"（★ **天生就有，不用声明**）

* 🔴 ★ **2026-10-02 起的口径**（主人：*「我发现做的小程序都不会有存储。这个应该默认有存储。」*）：
  **每个小程序都有一格自己独立的库**，`/db` **直接就能用** ——
  **不用在 `permissions` 里声明、不用等他点头**，他那边也**没有存储的开关**。
  ⚠️ 老制品清单里那个 `db` **照样认**（只是今天没有意义）。
* **什么时候用**：进度、历史、他填过的表、清单；**固定内容**（题库/词表）**别用它**（写进文件更省）。
* **怎么调**：对它**自己那个地址** `POST /db`，`op` = `run` / `get` / `all`；**参数用 `?` 绑定**（不许拼串）；
  第一次带入口 URL 里那三样（`u`/`e`/`s`）换票，之后用票（片段照 `147` §3.2 抄）。
* **上限**（数在代码里）：每库 8MB · 一次最多 500 行 · 一次 3 秒 · 每分钟 240 次。
* **建表/迁移**：`CREATE TABLE IF NOT EXISTS`；改结构用 `PRAGMA user_version`。
* **不许**：一次多条语句 · `ATTACH` · 别的 `PRAGMA` · 递归查询 · 把钥匙/别人的数据塞进去。
* **被拒怎么说**：`507`（满了）· `429`（太频繁）· `503`（查太久）· `400`（这条 SQL 本身不行）——
  各说各的那句；**页面要能"存不进去也能用"**（至少别白屏）。
  ⚠️ 存储**没有 403 那一档**（它不用他允许；`403` 是 `ask`/`net`/`agent` 那几样的）。
* **他能清**：设置卡上那颗「清空它存下来的东西」（★ 每个小程序都有 · 二次确认、拿不回来）。

### 4.2 问一句 `ask` —— 用**他的钥匙**问模型一句话

* **什么时候用**：出题、起名、翻译这种"一句话的事"，**不需要查网、不需要工具**。
* **怎么调**：`POST /ask`，`{prompt}`（片段照 `148` §1.4 抄）。
* **代价**：**花他的钱**（每天 40 次 · 间隔 3 秒，数在代码里）⇒ 别拿它当"随便问问"。
* **不许**：把用户的整本书塞进 `prompt`；把回答当"事实"（它是模型话）。

### 4.3 网络 `net` —— 它要**自己去取数据**

* **两层的分工**（他 2026-10-01 说死的）：**你自己出网不设限**（你去查、去核实）；
  **制品页只许访问你写进它声明里的那几个站**。
* **什么时候用**：要他**实时**的数据（天气/价格）⇒ 声明 `net` ＋ 名单。
* **起草名单**：🔴 **你自己先访问确认过**再把域名写进去（只写域名本身：不许 `*`、端口、路径、`http://`）；
  最多 8 个。
* **改名单 = 新的一版**（再调一次 `app_create`）；**关掉开关 ⇒ 名单立刻失效**（页面连不出去）。
* ⚠️ **看不见的那一半**：制品发了什么请求**我们看不见**（CSP 是浏览器执行的）⇒ 这一样**没有留痕**。
* **能静态就别动态**：让**你自己**取好、写进文件（零网络、离线也能用）——那永远是第一选择。

### 4.4 跟助手说一句 `agent` —— 要"想一想/查一查"

* **什么时候用**：需要**推理或查证**的一件事（"这周花钱正常吗"），而不是"一句话的事"（那用 `ask`）。
* **怎么调**：`POST /agent` 问 ⇒ 拿 `jobId` ⇒ 再 `POST /agent {jobId}` 取回执（`running`/`done`/`failed`/`timeout`）。
* 🔴 **那一轮是"限定档"**：它**能**查网（搜索/取页），**不能**动手（没有 shell、不能派活、不能用平台工具）。
* **代价与上限**：每天 20 次 · 间隔 10 秒；等过头 ⇒ 如实说"它还在想，你去那一间看看"。
* **它答的那一句会落在那一间对话里**（他看得见）⇒ **别在 prompt 里塞敏感东西**。

### 4.5 定时任务 `tasks` —— 它要"按点自己做事"

* **什么时候用**：他明说要**重复**做的事（"每天早上看一眼…"）。⚠️ **一次性的活当场做完**，别排任务。
* **怎么写**：每件四样：短名 · 名字 · `everyMinutes` · **让它干什么**。
* 🔴 **`prompt` 会被当成"他让它做的事"执行** ⇒ **写成他会说的那种具体的一句**
  （"看看今天花了多少，一句话告诉我"）；**不许**写"随便逛逛 / 看看有什么能做的"。
* **上限**（数在代码里）：最多 3 件 · 最少 30 分钟一次 · 每天 6 次 · **串行** · 到点没跑**不补跑**。
* **结果回到那一间对话**；他能一键关掉（关掉 ⇒ 一件都不跑）。

## 五、交付标准（他脸上那句话）

**模板**（照这个说，别只说"好了"）：

> 做好了：**它叫什么**，点开就能用。它能**（做什么）**，会**（记住什么 / 不记住）**，
> （要联网的话）会去**（哪几个站）**取数据，（有定时任务的话）**每隔多久替你（做什么）**。
> 它要用的东西**它第一次打开时会问你一遍**，你随时能在设置里改。

🔴 **必须说清的**：① 它叫什么、能做什么；② **它会不会记住东西**（会 / 不会）；
③ 联网的话**去哪几个站**；④ 有定时任务的话**每隔多久做什么**；
⑤ ★ **打开它时你会看到一张弹窗**（问它要用的那几样）—— **要主动说这一句**：
   不然他点开看见一张窗会以为出了什么事；反过来说"你随时能在设置里改"仍然对。

🔴 **不许承诺的**（说了就是假话）：
* "它会一直跑着 / 它会自己去做事"（**只有定时任务**那种，而且是"到点跑一次"）；
* "它能装到手机上 / 发到微信里"（做不到）；
* "我帮你把权限改了"（**那一下永远在他手里**，你只能**说清**它要什么）；
* 🔴 "**它已经能用联网 / 用钥匙问话了**"（**你声明 ≠ 他给了** —— 他还没点过头之前那几样都用不了；
  说成"已经能用"就是把话说过头了。⚠️ **存储除外**：它天生就能用）；
* "它什么都能干"（它有明确的能力清单 —— §四）。

## 六、自查清单（`app_create` 回执里会逐条给你；**有报必改**）

**会真的不好使（`errors`）**：

| 码 | 是什么 | 改法 |
|---|---|---|
| `external-resource` | 引了外部脚本/样式/图片/字体/`@import`/WebSocket | 内联；图片用 `data:` |
| `browser-storage` | 碰了 `localStorage`/`sessionStorage`/`indexedDB` | 走 `/db`（★ 存储默认有，不用声明） |
| `native-bridge` | 假设有原生桥 | **删掉**（没有桥，两端都没有） |
| `ask-not-declared` / `agent-not-declared` / `tasks-not-declared` | 用了那件事却没声明 | `permissions` 里加上（⚠️ 存储**没有**这一条：它默认就有） |
| `host-not-declared` / `net-not-declared` | 去连没声明的站 | 写进 `net`（你先访问确认过），或改成让助手取好写进文件 |

**顺手看一眼（`warnings`）**：声明了没用（`host-unused`）· 调平台口却没读入口参数
（`no-entry-params`）· 定时任务那句太开放（`open-task-prompt`）· 页面没 `<title>`（`no-page-title`）·
🔴 **宽屏上一个字都没交代（`no-wide-layout`）· 通篇只能看（`thin-page`）**（2026-10-06 新增，
见 [`203`](203-APP-RICHER.md)：他是在**平板**上用它 ⇒ 一条窄栏挂中间、或者"只能看不能动"，
都算没做完）· 🎯 **看着像游戏却每局一样（`flat-play`）· 一点动静都没有（`no-feedback`）**
（2026-10-06 新增，见 [`204`](204-APP-PLAY.md)：他点名的"跟他下的时候，他的套路是一样的"）。

⚠️ **自查看的是"屏幕上现在那一份"**：`app_create` 的 `files` 不给（内容已经写在它自己那间目录里）
时，自查会**从那一间把页面读回来**再查 —— 两条写法一样算数（`apps-socket.js` 的 `pageFilesForLint`）。
⚪ 例外：那一格还只是壳给的**占位页**（里面写着「这里还空着」）时，`thin-page` **不报它**。

⚠️ **它是"只报不拦"**：报了不改，东西**照样做出来** —— 但到了他屏幕上就是"点了没反应"。
**标准在这儿，改不改在你。**

## 七、反模式（明确不许做的）

1. **引外部资源**（"反正能加载"——不能）；
2. **拼 SQL 字符串**（参数一律绑定）；
3. **把密钥/令牌/别人的数据写进页面或存储**（页面永远拿不到钥匙：要问话走 `ask`/`agent`）；
4. **把开放式的任务写进 `tasks`**；
5. **假装能力**（没声明就说"它能记住"；被拒了画成成功）；
6. **问他要技术细节**（AppID / 域名 / 证书 / "要哪个平台"）；
7. **不声明就想用**（`ask`/`net`/`agent`/`tasks` 用了才想起声明 ⇒ 那是 `*-not-declared` 那类报错；
   ⚠️ 存储不在此列 —— 它默认就有）；
8. **绕过白名单**（回头让他点"允许"来打通一个没声明的站 —— 那是把风险推给他）。

## 八、这一份标准怎么"有牙齿"（判据）

| 层 | 在哪 | 判据 |
|---|---|---|
