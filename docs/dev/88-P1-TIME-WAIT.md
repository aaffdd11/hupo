## 二、四条硬规矩（辩论收敛，**不许打折**）

1. **票＝欠条**：每条 `user/echo` 必须有一个配对终态；配对键用 **`(agentGeneration, turn)`** —— **不许**靠 `shift()` 的顺序。
2. **一件活只有三种结局**：**做完** / **被明确取消** / **挂着等**。**没有"消失"**。
3. **挂起必须逐件可查**：每件记 `(scopeId, turn/ref, 状态, 起止时间, 票)`；能答"还在 / 已停 / 做完了"，**能提醒**，**能回来**。
4. **时间词必须有落盘依据**：没有口径**不许**说"很快 / 比平常久"；说了就落一行**承诺**，到点没做完**必须再报一次**；统计用**第 90 分位**且**删失（被超时/被杀那轮）也要算**。

## 三、后台语义（主人拍的那个形状）

```
长活 ⇒ 默认进后台（不阻塞用户）
     ① 开跑：一句"我去做，做完叫你"（走 Notice —— 对用户说话的**唯一**出口）
     ② 跑完：主动提醒（+ 结果一句 + 去哪看）
     ③ 失败/被取消：**也要提醒**（不许静默）
     ④ 他随时能问"那件怎么样了" ⇒ 逐件答案
```

🔴 **后台不是"没下文"**：允许挂着，但**必须**可查、可提醒、可回来。
