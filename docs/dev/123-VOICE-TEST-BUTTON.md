## 一、形状（屏幕上）

「语音」那一屏，三个钥匙输入框下面多了一块：

| 状态 | 屏幕上 | 按下去会怎样 |
|---|---|---|
| 闲 | 抬头`试一下` ＋ 一句怎么用 ＋ 按钮`试一下 说话` ＋ **一个空文本框（挂着标签）** | 开始听（会弹浏览器的麦克风权限框） |
| **在听** | 按钮变成`停下` ＋ `● 正在听` ＋ **认出来的字一直长在下面那个框里** | **这一场到此为止**：说"这边完了"（进"收尾中"） |
| **收尾中** | 按钮`收尾中…`（**按不动**） | 等最后一句回来（通常不到一秒） |
| **他按第二下**（这一场结束） | **定稿落在那个框里**；按钮回到`试一下 说话` | 再按就是新的一次（上一次那些字清掉） |
| **引擎自己收尾**（停顿 / 一次连接只担一轮） | **还是在听**：按钮还是`停下`、`● 正在听`还在；那一轮的字**接在后面**（不是重来） | 那一块**自己开下一轮**，接着听 —— **这一场没完**（见 §八） |
| 任意失败 | 那一档自己的那句话（见 §三），**已经听到的字留着** | 按钮还在，再按一次就能重试 |

> ★ 2026-09-26 修（主人：*「语音按钮，点一下进入录音，再点一下结束录音。」*）：
> **"引擎自己收尾"那一行原来写的是"停下"—— 那是错的**（见 §八）。

🔴 **那个框是真的文本框**：认出来的字写进去，**能选中、能复制**（主人要的就是这个）。
⚠️ **空着的时候标签照挂**（"空但有标签"）；**一个字都不许编** —— 没听到就是空的，
而且下面会明说"什么都没听到"。

🔴 **他自己动过那个框之后，迟到的定稿不再覆盖**（收尾那句回来得比手指慢）——
与输入条那条纪律同源（`lib/widgets/composer.dart` 的 `_mirror`）。

⚠️ **和「试一张」的两处刻意不同**（[`image_try.dart`](../../v2/apps/mobile/lib/widgets/image_try.dart) 那一块）：

| | 「试一张」（图片那一屏） | 「试一下」（语音那一屏） |
|---|---|---|
| 什么时候画 | **填了钥匙才画** | **填没填都画** |
| 为什么 | 它没有"没配好"这一档 | 主人点名要"还没配钥匙"也要说出来（上面那三样就是它要用的） |

## 二、🔴 钥匙只有一条路（这一批的硬要求）

那颗按钮**不碰任何钥匙**，也不另算地址。它走的是**聊天里那颗话筒同一条路**：

```
配置页三个输入框 ──提交──▶ POST /api/creds ──▶ data/creds/<他>.yaml
                                                        │
这颗按钮 ──▶ /api/asr（同一个 asrUri）──▶ 服务端按**验过签的身份**现取 ──┘
             （services/hearing.dart 那两个函数）
```

| 这一环 | 住哪（唯一出处） |
|---|---|
| 开麦 / 收手 | `v2/apps/mobile/lib/services/hearing.dart`（网页那份真开麦，别的平台是桩） |
| 地址怎么算 | `v2/apps/mobile/lib/services/stream_uri.dart` 的 `asrUri`（**不许再拼一遍**） |
| 控制器那两个动作 | `v2/apps/mobile/lib/services/chat_controller.dart` 的 `hearOnce` / `stopHearingNow` |
| 接线 | `v2/apps/mobile/lib/screens/chat_screen.dart`（`_appView` 里给设置页那两个口） |
| 服务端按谁取钥匙 | `v2/services/core/src/asr-creds.js` 的 `voiceCredsFor`（三样齐了 ⇒ `his-own`） |
| 表单写去哪儿 | `v2/services/core/src/serve.js` 的 `setCreds` ⇒ `writeUserCreds(cfg.dataDir, userId, others)` |

⇒ **一个字节的钥匙都没进客户端**，也没有第二份存档。判据里那条注释与这一段是同一句
（`lib/screens/settings_screen.dart` 的 `voiceTry` 字段）。

⚠️ **两个已知边界**（都不是这一批新造的）：

- **上面那三样要"送出去"才作数**：识别那头读的是**存好的**那一份，
  不是输入框里正打着的字。所以还没送出去时按这一颗，用的还是旧的那份
  （或这台机器上配好的那份兜底）。见 §六 第一条。
- **租户那台**：只填语音（不带语言那一把）时，中心那份存档**不会被推进他的盒子**
  （`serve.js` 的 `setCreds` 只在带 `model` 字段时走 `setModelKey(...)` 那条推送）
  ⇒ 他那台仍旧"没配"。页面那句边界话（`credVoiceBoundaryTenantHas`）说的就是这个事实。

## 三、失败话：**一条一个原因，绝不静默**

| 什么原因 | 屏幕上那句 | 谁给的 |
|---|---|---|
| 这个页面开不了麦 | `这里开不了麦（换个浏览器打开就能用）` | 客户端（`hearCantHere`） |
| 没拿到麦克风权限 | `没拿到麦克风权限 —— 在地址栏那个锁里放开麦克风，再按一次` | 客户端（`hearDenied`） |
| **这条路连不上**（中间那一跳不认这条路径 / 断网） | `这条路暂时连不上，等会儿再按一次` | 客户端（`hearNoEntry`） |
| 开不了麦克风（没有麦、被系统拒、音频图起不来） | `开不了麦克风，再按一次试试` | 客户端（`hearFailed`） |
| **这台还没配好钥匙**（上面那三样**没填过**） | `这台还没配好语音的钥匙 —— 上面那三样填好、送出去，试一下用的就是它们。` | 客户端（`voiceTryNoKeyEmpty`） |
| **这台还没接通**（上面那三样**填过**、这边还说没配） | `这边说语音还没接通 —— 上面那三样它现在还用不上，得等这台接好。` | 客户端（`voiceTryNoKeyFilled`） |
| 一个字都没听到 | `什么都没听到，再按一次试试` | 客户端（`hearNothing`） |
| **没额度**（上游回 `4004 资源包耗尽`） | `语音这条路还没开通好（没额度了）` | 客户端（`hearNoQuota`） |
| 识别那一头出错 | `识别那一头出错了，再按一次试试` | 客户端（`hearEngineFailed`） |
| **一次到点了**（上游内测版一条连接最多一分钟，服务端提前收手） | `一次最多说一分钟，我先停了` | 客户端（`hearCapped`） |
| 半路断了 | `刚才断了 —— 字都留着，按一下接着说我听着` | 客户端（`hearCutOff`） |
| **读不懂的一帧**（那边回了个我们认不出的东西） | `那边回了个读不懂的东西，再按一次试试` | 客户端（`voiceTryBadFrame`） |

🔴 **两句最容易混的，分开说了**：

- **"一条连接最多一分钟"（`asr/capped`）不是"没额度"**（`4004`）。
  前者是"等一会儿再说"，后者是"去开通/买资源包"——混成一句，他就不知道该干什么。
- **"读不懂的一帧"不是"开不了麦克风"**：麦克风那一步明明成了。
  ⚠️ 而**类型认不出**（对面以后加的新事件）**什么都不做**（不猜、不假装）——
  那条纪律在 `Hearing.event` 里，与聊天那颗话筒完全同一条。

## 六、名不副实（待主人定）

> 主人 2026-09-26 的规矩：**「名不副实的要去掉。」**
> 顺手把配置页扫了一遍。**这里只列，一个都没动**（等主人定）。

### 6.1 视频那一屏：同一屏上两句话互相打脸 🔴

| 证据 | 那句话 |
|---|---|
| `lib/models/space_words.dart` 的 `credTabWhat(credTabVideo)` | *"填上它，我才能给你做小片子。"* |
| 同一屏的 `credBoundaryVideo`（`space_words.dart`） | *"先收在你自己的名下。做片子那条路**不做**（你说不需要）—— 这一栏先只把钥匙收着。"* |

**事实**：服务端**没有**做片子那条路 —— `v2/services/core/src/creds.mjs` 里
`video: 'HUPO_VIDEO_KEY'` 只被**存下来/回报有没有**（`creds-store.js`、`serve.js` 的
`credStatusOf`），**没有任何一处拿它去干活**，也没有 `/api/video` 这条路由
（`server.js` 的路由表里没有）。⇒ 上面那句"我才能给你做小片子"是**空承诺**。

### 6.2 新那颗「试一下」测的是"存好的"那三样，不是框里正打着的字

**事实**：识别那头读 `data/creds/<他>.yaml`（§二那张表），而输入框里刚敲进去、
**还没按"送出"** 的字**还没进那个文件**。⇒ 他可能以为"试一下"用的是眼前这三格。
🔴 **这一批我没有替它加一句"先送出去才作数"**：因为对租户那台，"送出去"也还不作数
（§二 那条边界）—— 加了就会是另一句假话。**这一条要主人定怎么说**（或者：
把"试一下"挪到表单提交成功之后才出现）。

### 6.3 语音那一屏"抬头"那句与事实有出入（轻）

| 证据 | 那句话 |
|---|---|
| `credTabWhat(credTabVoice)`（`space_words.dart`） | *"填上它，我就能听懂你说话。"* |
| `credVoiceBoundaryDefault`（同一屏） | *"先收着。现在听你说话用的是这台机器上已经配好的那一份。"* |

**事实**：主人这台**本来就能听**（`asr-creds.js` 的 `voiceCredsFor` 对主人有
`data/asr.env` 兜底）。⇒ 抬头那句读起来像"填了才能听"，实际是"填了就用你自己那份"。
两句都在屏幕上，所以不算**骗**，但抬头的写法**把边界说轻了**。

## 八、★ 2026-09-26 修：「点一下进入录音，再点一下结束录音」

> 主人原话：*「语音按钮，点一下进入录音，再点一下结束录音。」*

**修之前的毛病**：那颗按钮**是**个开关，但**引擎自己的收尾**（`asr/end`，＝
停顿处那一段说完了）被当成了这一场的结束 ⇒ 停顿之后它看着就"停了"；
他再按一下是**新的一次** ⇒ 框被清空、刚说的话没了。

**根因（两处，缺一不可）**：

1. `Hearing.done()` 把 `asr/end` 一律挪回 `idle`，而 `tapped()` 在 `idle` 上是
   "开新的一场"（`const Hearing(phase: listening)` ⇒ 字清空）；
2. 一次识别连接只担**一轮**（上游说完一段就收，服务端发 `asr/end` 并关掉那条连接），
   而**每一轮的段号又从 0 重来** ⇒ 就算不收场，下一轮的 `index: 0` 也会把上一轮的
   `index: 0` **替换**掉（说了两句只剩后一句）。

**修之后的形状**：

| 时点 | 屏幕上 | 框里 |
|---|---|---|
| 第一下 | `停下` ＋ `● 正在听` | 空（新的一场） |

| 停顿（`asr/end`） | **还是** `停下` ＋ `● 正在听`（这一块自己开下一轮） | `今天天气`（**不动**） |
