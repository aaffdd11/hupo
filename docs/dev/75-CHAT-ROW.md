# 75 · 聊天窗口收成**一行**（抓手 / homeicon / 话筒 / 发送）

> **主人 2026-09-24 原话**：
> *"我们给聊天窗口做优化。我们做成一行，展开用一条杠，杠上面有一个小箭头，箭头比较平，
> 所以不会显得那么突兀，放在上边框的正中央，然后 homeicon 放在聊天窗口左边，
> 语音按钮放在聊天框内部的右侧，聊天框右侧应该是一个发送按钮。一开始是灰色的。"*
>
> 手册同日升 **v1.68**（`05-DECISIONS.md` D3.8 改形状 · `08-SPEC.md` §6.2.1 新增 · §6.3 手势表 · §6.5）。

---

## 一、改成了什么样（一图流）

```
                  ⌃            ← 上边框正中央：一条杠 + 一个"平"的小箭头（单击收起 ⇄ 展开）
        ┌──────────────────────────────────────────────────────┐
        │ ⌂   说点什么                            🔊  🎤   (↑)  │
        └──────────────────────────────────────────────────────┘
          ↑                                        ↑      ↑
     在哪儿说话                            读出来/话筒   发送（没话时说 ⇒ **灰的**）
     （桌面=home；进了小程序=它的图标）     都在框**里面**
```

- 展开态：抓手仍在同一个位置（箭头朝下），下面才是标题行（`助手` + 回收站/导出/过程 + 收起）与时间线。
- ⚠️ **收起态不画标题行** —— "一行"就是这一行（那条旧的"带字的展开入口"由抓手取代）。

## 二、四处改动，各自的理由

| # | 改了什么 | 为什么 |
|---|---|---|
| 1 | **抓手**搬到**上边框正中央**，形状 = **一条杠 + 一个平的小箭头** | 主人原话。⚠️ **箭头自己画**（`_FlatChevron`：26×7 的浅角 V、2px 圆头笔画）—— `Icons.keyboard_arrow_up` 那个角**太尖**，摆在一条杠上就是"突兀" |
| 2 | **单击 = 收起 ⇄ 展开**（**双击拿掉**） | 抓手现在自己就是展开入口 ⇒ 双击 = 两次单击 = **自己抵消**（真机上看起来就是"点了没反应"） |
| 3 | **`home` 图标**从抓手行搬到**输入条那一行的最左边** | 主人原话。它仍然是"这句话在哪儿说的"（桌面 / 某个小程序），只是换了位置 |
| 4 | **话筒进框**（`suffixIcon`，右侧）· **"语音档"没有了** · **发送常驻（灰）** | 主人原话。字**直接落进框**（不再另占一块卡片）；发送钮**一直在**，没话要说时灰的、按不动 |

**两处旧决定被推翻**（⚠️ 都是主人自己拍的板，按他这次的新话改，**不是**我顺手改的）：

| 旧 | 新 | 依据 |
|---|---|---|
| **D3.8：收起态必须有"带字"的展开入口** | 改成"**看得见**的展开入口"：位置固定 + **命中区 ≥44** + tooltip/无障碍名 | 主人这次的形状就是"一条杠 + 小箭头"，没有字。⚠️ **不变的是那三条**（他当初要"带字"是为了**能发现、点得到**）|
| **§6.2：框里有字才画发送钮**（2026-09-23） | **常驻**：没话要说 ⇒ **灰的、按不动**；固定 48×48 | 主人原话"一开始是灰色的" |

## 四、⚠️ 顺手记下的两个坑（都不是这一批的，但都是这次碰出来的）

1. **`Composer` 一进来就在听**（窗口刚重建）时，那半句**不会自己进框** ——
   原来字活在"语音档"的卡片上，框里那份只靠 `didUpdateWidget` 搬。
   现在字**就是**框里的内容 ⇒ `initState` 里必须先搬一次（**测试当场抓住**：`hearing_test` 那条红）。
2. `test/widget` 里那几处 `find.text('展开')` 是**按字找控件** ——
   形状一改（字没了）它们就整片红。⇒ 抓手给了 `chatHandleKey`：
   **判据要找的是"那个能点的东西"，不是"那两个字"**。
