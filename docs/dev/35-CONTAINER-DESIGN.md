## 二、下半要回答的第一个问题：**容器里跑什么**

| 选项 | 好处 | 代价 |
|---|---|---|
| **(甲) 只有 agent 在容器里**，调度器还在宿主 | 隔离面最小、改动最小；V1–V4 说的就是"agent 的手" | 调度器仍与宿主同权限（但它不读外部内容 —— 读外部内容的是 agent） |
| (乙) 整个调度器 + agent 都在容器里 | 一刀切 | 容器要能 spawn `dsh`，而 `dsh` 要**模型凭据**、要写 `~/.dsh/**`（会话/缓存）⇒ 复杂度陡增，而且把"宿主那点事"也搬进去了 |

⇒ **建议 (甲)**：`08-SPEC` §12.1 的 role 是**按会话**分的（owner/untrusted），而 role 是 `AgentRuntime` 在 **spawn 层**决定的
—— 那正好是"agent 那一侧"的事。**调度器不在容器里，也就没有"调度器也要凭据"这个问题。**

## 三、🔴 卡住的那个真问题：**agent 要凭据，而 V4 不许容器里有秘密**

**实测**：
* agent 调模型靠 `~/.dsh/.credentials.yaml`（`0600`，**里面有一个 `sk-` 开头的真密钥**，字段是 `version/records/refs`）；
* `08-SPEC` §13.1 **V4** 要求：容器里 `env | grep -cE '(_API_KEY|_TOKEN|_SECRET|DEEPSEEK)'` **= 0**，
  并且 `grep -rl "sk-" /data /home` **= 0**。

⇒ **两件事直接矛盾**：容器里要么有那个文件，要么有那个环境变量，才算"能调模型"。
而且 V4 **把两条路都堵了**（文件那半 + env 那半）。

| 选项 | 能不能满足 V4 | 评价 |
|---|---|---|
| **(甲) 凭据注入代理**：代理在**容器外**持有密钥，容器里的 agent 指向它（`10.0.2.2:<port>`） | ✅ 容器内**一个秘密都没有**（文件没有、env 没有） | **唯一同时满足"能调模型"和 V4** 的形状。代价：多一个常驻小进程 + 一条本机回环口（要防"容器里别的东西也走它"） |
| (乙) 密钥经 **env** 传给容器 | ❌ **违反 V4 的字面**（env 那半） | 而且进程环境**同机谁都能读**（`/proc/<pid>/environ`）—— 比文件还差 |
| (丙) 把凭据文件挂进去、但放在 `/data`、`/home` **之外** | ⚠️ **字面上过、意思上没过** | 🔴 **明确列为不许**：那正是本项目最忌的"**看着像过了**"（V4 的判据范围是当年的写法，它的**意思**是"容器里不许有秘密"）。要改判据得主人点头，**不许换个路径骗过它** |

⇒ **建议 (甲)**。它同时回答了 `08-SPEC` §13.3 **V12**（"spawn 出来的 env 键集合 == 白名单"）：
白名单里**本来就不该有密钥**，因为密钥在代理那一侧。

## 四、🔴 要主人拍板的（拍完才动手）

| # | 问题 | 选项 | 我的建议 |
|---|---|---|---|
| ① | **容器里跑什么** | (甲) 只有 agent · (乙) 整个调度器 | **甲**（理由见 §二；而且它让凭据问题只出现在 agent 那一侧） |

## 五、动手时的切法（**先按 §四 改一遍**）

| 步 | 做什么 | 判据 |
|---|---|---|
| 1 | **agent 容器的镜像**：node + `dsh` + 仓库（人格/能力层/MCP 服务器）**不带凭据** | `podman run` 里能起 `dsh --profile sdk --dump-config`；且 `grep -rl "sk-" /` = 0 |
| 2 | **凭据注入代理**（容器外，本机回环） | 容器里的 agent 能正常答话；而**容器里** `env` 与文件都搜不到秘密（V4 两半**都真跑**） |
| 3 | **网络策略** | 按 §四③ 定；**带正对照**（"不通"必须配上"本该通的那条确实通"） |
| 4 | **V4 变成能真跑的** | `/data` `/home` **真的挂进去**之后，那两半才作数（现在它是空跑） |
| 5 | **用户之间** | 一条可执行的证：甲写的东西，乙在**自己的容器**里读不到 |
| 6 | 资源上限（§10.3 那几个数） | 真跑，不再纸上 |
| 7 | **上线**：把线上那套换成容器 | ⚠️ **这一步是 P2**：助手只能**提申请**（补丁 + 一条命令），**签字的是主人** |
