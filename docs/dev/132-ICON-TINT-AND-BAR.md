# 132 · **图标底色**（每个小程序一个）＋ **底部那条聊天 bar**（半透明，三段）

> **主人 2026-09-29 原话**：*「所有小程序的icon都需要一个背景颜色。不同的背景颜色。
> 底部的聊天组件我想要首先一个半透明的bar，上面的左侧是home按钮，中间是文字输入，
> 右侧是语音按钮。这些按钮就不是透明的了。」*
>
> 三问问完他当场选的：图标底色 **按 app 的身份算**（不是按它在桌面上排第几）·
> 底上那枚图标还是**深墨色**（跟桌面那套暖色）· 彩色底**只上桌面图标墙**。
>
> 这一份说清：那两件各自的形状 · **判据** · 踩到的 · **没做的**。

---

## 一、图标底色（`models/app_tint.dart` ＋ `widgets/app_desktop.dart`）

```
一格图标 ＝ 圆角方块（`desktopIconBox`）+ 底色（`appTintFor(这个 app 的身份)`）+ 墨色的图标 + 下面那行名字
```

| 规矩 | 落地 |
|---|---|
| 🔴 **按身份算，不按位置** | `appTintFor(id)`：FNV-1a（32 位）落在调色板的第几格。**同一个 app 永远同一色**，换位置 / 前后加东西都不变。⚠️ 不用 `String.hashCode`（Dart 不保证跨版本稳定） |
| 🔴 **代价如实认下** | **两个 app 可能撞成同一个颜色** —— 这是主人当场选的那一项的代价（判据因此**只钉"同身份同色"**，不钉"两两不同"） |
| ⚠️ **唯一钉死的"不同"** | 桌面上**永远同时出现**的那三个（设置 / 发现 / 我自己那台）**必须互不同色**（撞了一眼就看得见）—— 判据 C3 |
| **没有 id 也有色** | `app.id ?? app.label` 兜底 ⇒ 桌面上**不许出现"没底"的一格** |
| **图标还是墨色** | 调色板那一族都够浅（判据 C4 量的是"与 `ink` 的亮度差"），所以**没改**图标本身的颜色 |
| **加号那一格不上色** | `isCreate` ⇒ 照旧透明 + 虚线（它是"空位"，不是一个小程序） |
| ⚠️ **底色不跟主题走** | 它是"这个 app 长什么样"，不是"这块屏现在什么档"（亮/暗两档同一套色） |

## 二、底部那条聊天 bar（`widgets/chat_floater.dart` ＋ `widgets/composer.dart` ＋ `screens/chat_screen.dart`）

```
┌──────────────────────────────────────────────────────┐
│  ╭────╮   ┌──────────────────────────────┐   ╭────╮  │
│  │ ⌂  │   │ 说点什么              🔊  ➤  │   │ 🎤 │  │   ← 三样都是**不透明**的
│  ╰────╯   └──────────────────────────────┘   ╰────╯  │
└──────────────────────────────────────────────────────┘
   ↑ 整条 bar 的底是**半透明**的（桌面/壁纸透过来一点）
```

| 位置 | 是什么 | 不透明怎么保证 |
|---|---|---|
| **最左** | **home 按钮**（点它 = 回桌面 / 关掉这一屏） | 图形外面一层**实底圆片**（`homeButtonFace`）；⚠️ **可点区仍是 ≥44 那个方框**（不许缩成看得见的那一圈） |
| **中间** | **文字输入**（发送在**框里的最右**，没话要说时是灰的） | 框自己 `filled: true` + `fillColor: bgLayer2` |
| **最右** | **话筒**（按一下听、再按一下停） | 它的 `IconButton` 带 `backgroundColor` |

🔴 **只有收起档那条 bar 是半透明的**（`d.barVeilAlpha`）：**展开档必须不透明** ——
那一档里面是时间线，底透了就变成"字压在壁纸上"，读不了。

🔴 **两条"直接画在 bar 上的字"各自带一块实底**（`_noticeStrip` 本来就有；
`_hearingStrip` 这一轮补上）：不然它们的对比度**随着底下那张壁纸变**，
手册 §8.3 那条"正文与底色 ≥ 4.5:1"就成了看运气。

⚠️ **这一轮把 §6.2.1 那两格调了个位置**（都是主人这次的话）：
话筒从**框里**搬到**这一行的最右**；发送从**框外**搬进**框里最右**
（这样这一行的最右才是**话筒** —— 他说的"右侧是语音按钮"）。

## 三、判据（每条都带反例）

| # | 判据 | 在哪 | 反例（变红的样子） |

## 四、踩到的

1. ⚠️ **`IconButton(tooltip:)` 把 `Tooltip` 建在按钮里面** ⇒ 判据要找那颗按钮得**往上**找
   （`find.ancestor(...)`）；往下找是 0 个 —— 第一版判据就是这么假的。
2. ⚠️ **同类型的 widget 再 `pumpWidget` 一次会复用同一个 `State`** ⇒ 判据里"换个档位再量一次"
   必须先把上一棵树拆掉（这次是 `SizedBox`），否则量到的还是上一档。
3. ⚠️ **`P1-8` 那道尺寸棘轮**：新加的一块留白写成数字字面量 ⇒ 当场红
   （`composer.dart: 15 > 上限 14`）⇒ 改用 `d.gapM/gapS`。
4. ⚠️ **`appearance_test` 那一组**拿"浮窗底的色"判"现在是哪一档"：bar 一透，
   那几个 `expect(color, DshPalette.light.bgLayer1)` 就红了（α 0.72）
   ⇒ 判据改成**按色板比、不看透明度**（透不透由 `desktop_floater_test` 单独钉）。

## 五、没做的（**明说，不是"以后再说"**）

* **发现页那一列没动**（主人选的"只改桌面图标墙"）：那一列还是裸图标。
  ⚠️ 但**打开动画的起点不受影响** —— `MiniAppHost` 那层脸**自己不带底色**
  （它盖在桌面上那一格上长大）⇒ 桌面换成彩色底之后，起点仍然逐像素是那一格。
* **不保证两个 app 不同色**（见 §一 第二行）：要"一定不同"得改成"按桌面顺序循环"，
  那是另一半代价（顺序一变颜色就挪）—— 他没选那个。
* **不跟主题走**（亮/暗同一套色）。
* **没有"我自己挑颜色"**：这一版只有那一族固定色板。
