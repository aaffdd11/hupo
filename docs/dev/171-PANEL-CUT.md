## 一、砍的是哪一件

会话头上那一格（动作串**前面**那颗按钮）点开之后，从右缘滑进来的一栏 ——
里面按轮列出"这一窗动过哪些文件"、被哪些工具碰过、某一轮的入参原文。
契约是 [`120-FILE-PANEL.md`](120-FILE-PANEL.md)（**该份随本批作废**）。

**它原来住在哪**：

| 住哪 | 是什么 |
|---|---|
| `lib/widgets/file_panel.dart`（471 行） | 那一栏本体（抬头 / 合计 / 一行行 / 入参折叠） |
| `lib/models/file_panel_words.dart`（78 行） | 那一栏上的每一句字 |
| `lib/models/file_changes.dart`（262 行） | 纯逻辑：按轮分组、去重、"最近改的在上" |
| `lib/screens/chat_screen.dart` | `_panelOpen` / `_panelButton()` / `_panelDocked()` / 缓存 / 布局那一段 |
| `lib/models/dsh_design.dart` | `dshRightPanel*` 那一族几何 token ＋ 滑入时长 |
| `lib/widgets/dsh_look.dart` | 滑入曲线 `dshPanelSlideCurve` |
| `lib/widgets/chat_floater.dart` | 标题行上那个 `beforeActions` 参数（今天只有它在用） |

⇒ 这些**整条删掉**（连 `beforeActions` 这个参数一起 —— 它留着就是一段
"谁也填不了的空位"，下一个人会以为那儿本该有东西）。

## 二、判据怎么处理的（**这一条要说清，免得像"把红闸删了"**）

原来钉那一栏的判据**随功能一起删**，不是跳过：

| 删掉 | 原来钉什么 |
|---|---|
| `test/widget/file_panel_test.dart` | 那一栏的整屏行为（开 / 关 / 分组 / 展开入参 / 大字号） |
| `test/unit/file_changes_test.dart` | 分组、去重、"最近改的在上"那些纯逻辑 |
| `test/unit/file_panel_words_test.dart` | 那一栏上每一句字的逐字口径 |
| `test/widget/accessibility_test.dart` 里那三档 | 五档字号下的"不溢出 ＋ 命中区 ≥44"（右栏收着 / 点开 / 用户字号那一档） |
| `test/widget/expand_input_test.dart` 里那两条 ＋ `'右栏开'` 那一档 | 手机宽下"开右栏不许把聊天挤成 30px" |
| `test/widget/chat_header_test.dart` 里那一条 | "砍轨迹不许把右栏碰坏" |
| `test/unit/forbidden_words_test.dart` 里那一撮 | 那一栏那几句字进禁用词清单 |

⚠️ **没动的**：可访问性那道**硬闸本身**（五档扫全屏那条 `sweep` 一个字没改）——
它扫的是"屏幕上真有的东西"，那栏没了就自然不扫它。
⚠️ 夹具 `_filePanelFeed()` **留下来了、改名叫 `_toolCallsFeed()`**：
它本来就是"一窗里有三条工具调用"，**行级入口那道硬闸**（`DshRowEntry`）还要用它。
