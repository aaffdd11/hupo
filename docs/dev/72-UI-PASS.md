## 一、逐块勘察结果（真图在 `/tmp/ui-*.png`，本机可开）

### A · 桌面那一片

| 看到的问题 | 说明 |
|---|---|
| 六个格子**挤在左上角**，下面一大片空 | 视口 1280×614 上，内容只占顶上一条 |
| **图标与标签偏小** | 目标用户是"不会拼音 / 视力弱"的人（`01-PROJECT.md`）；格子按 48 那一档画，标签只有小号 |
| 桌面格子 / 聊天卡片 / 设置行**三种外观** | 圆角、底色、阴影各一套（见 E） |
| **没有"下一步做什么"的引导** | 一进来就是六个陌生图标 + 一个输入条，没有一句话说"点这里能干什么" |
| 「发现」的含义不清 | 它是"别人的小程序"，但一个放大镜图标说不出这件事 |

### B · 聊天浮窗（展开态）

| 看到的问题 | 说明 |
|---|---|
| 头部四个图标**没有文字** | 🗑 / ▣ / ⚙ / ⌄ —— 手机上**没法 hover**看 tooltip ⇒ 只能瞎点 |
| 标题「助手」很小 | 和那排图标挤在同一行，主次不分 |
| 「读一遍」偏小偏淡 | 要 ≥44 命中区（D3.6 硬闸扫的是整页，这条单独看仍偏弱） |
| 收起态只有一道缝 | 设计取舍（主人要的"贴边"），但里面有什么**一点提示都没有** |

### D · 设置 / 关于

| 看到的问题 | 说明 |
|---|---|
| 「你那串钥匙」是**强调色小标题** | 看着像警告；下面那张卡只是一句解释 ⇒ 层级不清（该是"分区标题 + 说明 + 动作"） |
| 关于页 | ✅ **本次已修**（那句假话） |
| 退出登录 | ✅ 红色、够清楚（这一处不用动） |

### E · 配色 · 圆角 · 阴影

| 看到的问题 | 说明 |
|---|---|
| **三种卡片外观** | 桌面格子（浅底大圆角）/ 聊天卡片（白底）/ 设置行（白底 + 描边）—— 圆角与阴影各用各的 |
| token 有，但**各屏挑着用** | `models/design.dart` 里已经有那几档；需要一次"**一屏一屏对表**"，而不是再造一套 |
