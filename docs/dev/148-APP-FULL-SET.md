### 三·补·二 · **"白名单"到底是谁写的（主人 2026-10-01 把语义说死了）**

> **他的原话**：*「问一句也要有网络搜索工具。这样的话所谓的白名单，是 dsh 有无限网络访问权限，
> 然后如果小程序有任务爬虫功能，则可以访问 dsh 开发设计时写入的允许访问的网站。」*

⇒ **两层，各管各的**（这一条是理解整套网络模型的关键）：

| 谁 | 网 | 说明 |
|---|---|---|
| **dsh（助手自己）** | **不设限**（他拍的） | 它查网、取数、核实，靠的就是这个。我们只**留痕**（`egress-log`：域名/时间/量，**不记正文**）——**没有**"出网白名单"这一层（账 `#65` 由此**关掉**：不是欠着，是**他拍过不做**） |
| **小程序（制品页）** | **只许它自己声明的那几个站** | 名单**由助手在开发那个 app 时写进制品**（它自己去访问过 ⇒ 写进去的就是它真用到的）⇒ 浏览器/WebView 的 CSP 硬拦；**他能一键关掉** |
| **小程序的"任务/爬虫"** | 同上（那两样都**跑在助手这一侧**） | 「问一句」那一轮**有**网络搜索（能查证）；「定时任务」跑的是同一套助手 ⇒ 也用 dsh 的网 —— 而**结果回到那一间对话**（他看得见） |

⚠️ **一句话**：**助手无限、app 有名单**；而 app 的名单是**助手写的**、**他能关**。
⚠️ 判据：`test/app-agent-ro.test.js` 的 **L1** 现在钉着"**那一轮的网络搜索必须留着**"
（`web` / `web-search-deepseek` / `web-fetch-http` / `tool-web` 都不许被关）—— 将来谁把"限定档"
改狠了，当场红。

## 四、④ 自动化任务：它要"按点自己跑一件小事"（✅ 2026-09-30）

> 主人：*「这些功能都要有」*（这一样他点名过两次：*"可以有自动化任务（注册制，在设置里可以看到也可以关闭）"*）。

### 4.1 形状

| 那一刻 | 形状 |
|---|---|
| 声明 | 清单里 `permissions: ["tasks"]` ＋ `tasks: [{id, title, everyMinutes, prompt}]`（每件四样：短名 · 名字 · 隔多少分钟 · **让它干什么**） |
| **谁定规矩** | 🔴 **数字只住 `app-tasks.js`**：一个 app 最多几件 · **最短间隔**（比这更频的声明**直接拒**，不许偷偷夹住）· 名字与"让它干什么"的长度 · **每天最多跑几次**（所有任务合起来算）· 多久看一遍 |
| 跑在哪 | 🔴 **他自己的盒子里**（宿主就是他那台；盒子里那个服务自己跑）—— **不是我们的云** |
| 怎么跑 | **注册制**：没声明 / **他关掉了** ⇒ **一件都不跑**；**串行**（一次只起一件）；**先记再跑**（账记不上就不跑）；到期就交给**那一间的助手**去做 |
| 结果去哪 | 🔴 **回到那一间对话**：那一句以「**来自小程序定时任务「它的名字」· 这件任务的名字**」的样子落进那一间，助手怎么做、怎么答都在那儿 ⇒ **他看得见** |
| 他能关 | 设置页那张卡上 `tasks` 那一项 —— **关掉之后一件都不跑**（判据 T3） |
| 排下一趟 | 跑完记 `{lastAt, nextAt, day, n}` 到 `<id>/tasks.json`；**跨天重新数**（"每天几次"不会变成"永远几次"） |

### 4.2 🔴 四条不许破（每条都有判据）

1. **注册制**：没声明 `tasks`（或他关掉了）⇒ **一次都不跑**（判据 T3）；
2. **串行**：一次只给一件（判据 T5）—— 盒子只有那么点内存，也免得两件同时改一个文件；
3. **先记再跑**：账记不上 ⇒ **那一趟不跑**（判据 T6）—— 宁可少跑一次，也不许"跑了没记"
   （那会变成"重来一遍"或"一天跑十次"）；
4. **间隔兜底**：万一 `everyMs` 丢了 ⇒ 按**下限**算（判据 T7）—— 少了这一条，
   一件任务会变成"**每个 tick 都跑一遍**"（盒子被拖住、他还收到一串莫名其妙的回答）。

### 4.3 判据（`test/app-tasks.test.js` 12 条）

| # | 钉什么 |
|---|---|
| **T1** | 清单形状：重名 / 间隔太短 / 不是整数分钟 / 太长 / 太多 / 缺东西 ⇒ **拒**（**不是夹住**：偷偷夹会让他以为"我设的 5 分钟生效了"）；两个入口（`register`/`create`）都拒；有任务却没说要用那一格权限 ⇒ 也拒 |
| **T1·往返** | 🔴 `meta()` 交回来的那一份（`everyMs`）**再喂回 `register` 要收下** —— 那是"装上来 / 复制一份 / 迁移"走的路（只认 `everyMinutes` 的话那三条路会当场报错） |
| **T2** | 到期判定：**新声明的这次就跑**（他当场看得到它会动）· 跑过要等够间隔 · 到点才跑 |
| **T3** | 🔴 他关掉了 / 没声明 / `allowed` 不是 `true` ⇒ **一件都不跑**（fail-closed） |
| **T4** | 🔴 每天上限（所有任务合起来）⇒ 跑满不跑 · **跨天重新数** |
| **T5** | 🔴 串行：一次只给一件（哪怕两件都到期） |
| **T6** | 🔴 执行器：到期的跑一件 ＋ **先记再跑** ＋ **间隔记进账**；**账记不上 ⇒ 不跑**；账落在盘上（`tasks.json`，含"跨天重新数"与审计一行） |
| **T7** | 🔴 间隔丢了 ⇒ 按下限算（**绝不许**变成每个 tick 跑一遍） |

### 4.4 如实说（这一片的边界）

- **"到点一定跑"不保证**：服务没起来 / 那一遍正忙 ⇒ 跳过；起来之后按"下一次"排，**不补跑**
  （补跑会在他不知道的时候一口气干好几件）。
- **租户那一侧今天不接**（要过隧道进他盒子）：调度器遇到租户**如实记一句并跳过**，不假装跑过。
- **`prompt` 会被当成"他让它做的事"**：所以工具说明里写死"只写他明确要的那种事"，
  而人格里也写清（不然一个声明就能让助手每天自己动一次 —— 那是要被诱导的形状）。
- **设置卡上 `tasks` 的人话**（"想按点自己跑一件事"）跟这一批一起上。

### 4.5 给**创建小程序的 agent** 的规则

* **他要的是"会自己动"** ⇒ 声明 `tasks` 并把每一件写清：短名 · 名字 · 每隔多少分钟 · **让它干什么**；
* 🔴 **`prompt` 写成"他会说的话"**（例如"看看今天花了多少，一句话告诉我"）——
  它会**当成他让做的事**去执行 ⇒ **不许**写"随便逛逛""看看有什么能做的"这种开放的话；
* **最短间隔与每天上限**在服务端有铁规矩（超了**当场拒**，别指望它给你夹住）；
* 做完用一句人话说清"**它每隔多久替你做一件什么事**"，并提一句"他随时能在设置里关掉"。

## 三、③ 跟"它的助手"说一句（✅ 2026-09-30）

> 主人：*「这些功能都要有」*。这一样是我审计里那句"**跟它的助手对话 ❌ 没有**"的欠账。
> ⚠️ **它和 `ask` 是两样，别混**：
> · `ask` = **直连模型**问一句（没工具、没记忆、不改东西）；
> · `agent` = 把问题送进**它那一间**，由**那一间的助手**来答 —— **那个助手是有手的**。

### 3.1 形状

| 那一刻 | 形状 |
|---|---|
| 声明 | 清单里 `permissions: ["agent"]`（声明了默认就给；**他能关掉**） |
| 问 | 制品对它**自己那个原点** `POST /agent {prompt}` ⇒ `{ok:true, jobId, state:'running'}` |
| 取回执 | `POST /agent {jobId}` ⇒ `{state:'running' \| 'done' \| 'failed' \| 'timeout', text}` |
| 凭据 | 和 `/db`、`/ask` **同一套**（入口签名换票）＋ **`jobId` 就是那张票**（绑人绑 app，里面记着"问的是哪一号、什么时候问的"）⇒ 伪造不出别人的回执 |
| 🔴 **看得见** | 问题以「**来自小程序「它的名字」**」的样子**落进那一间的对话**（`user/echo`），助手怎么答也在那儿 —— 他随时翻得到，**不是暗线** |
| 配额 | **每天几次 ＋ 两次之间最小间隔**（数只住 `apps.js`：`AGENT_PER_DAY` / `AGENT_MIN_INTERVAL_MS`）——这一样会真的请动助手，所以比 `ask` 紧 |
| 等多久 | 数在 `server.js`（`AGENT_WAIT_MS`）；等过头 ⇒ **`timeout`，不编答案**（页面说"它还在想，你去那一间看"） |
| 🔴 它**不能**让助手动手 | 人格里写死：来自小程序的问题**只回答**，要动手**先问他**（那是"助手只能提申请，签字的是主人"那条原则） |
| 租户 | ⚠️ **今天不接**：要过隧道进他盒子里那一间（另一片）⇒ **如实 503「你那台还没跟上」**，不许假装 |

### 3.2 判据（`test/app-agent.test.js` 6 条 · 真房间 ＋ 真时间线 ＋ 真 HTTP）

| # | 钉什么 |
|---|---|
| **A1** | 问 ⇒ 200 ＋ 票；🔴 **那一句真落进那一间**（`user/echo` 里带着"来自小程序…"和他的原话）＋ **投递真发生** |
| **A2** | 取回执：还没答 ⇒ `running`（`text:null`）；那一间按**真形状**（`start → text → end`）答完 ⇒ **`done` ＋ 拼起来的正文** |
| **A3** | 闸**和 `ask` 各判各的**：没声明 `agent` ⇒ 403（"没说要跟你的助手说话"）· **他关掉了** ⇒ 403 · 太快 ⇒ 429 · 今天够多了 ⇒ 429；**闸没过 ⇒ 一个字节都不许送进那一间** |
| **A4** | 没签名 403 · **拿另一个 app 的票** 403 · 伪造的票 403 |
| **A5** | **租户今天不接 ⇒ 如实 503**（"还没有这个能力" ≠ "你不许说"） |
| **A6** | 等过头 ⇒ `timeout` 且 `text:null`（**不编答案**） |

### 3.3 如实说（这一片的边界）

- **`timeout` 之后助手可能还在跑**：回执那张票还在，页面可以再问几次；那一间的对话里也看得到进展。
- **"限定档"这一版没有**：助手用的是它平时的能力（有工具）。护着的是**三条**：
  **配额** · **每次可见** · **人格里那条"只答不动手，要动先问他"**。
  真正的"只读档"（给这一条路一个只能读、不能写的工具集）**还没做** ——
  那是另一刀（要在 spawn 那一层按 scope 收工具），**明说欠着**。
- **租户那一侧没接**（§3.1 最后一行）。
- **设置卡上 `agent` 的人话**（"想跟它的助手说话"）跟客户端那一批一起上。

### 3.5 🚧 **限定档**（取代"只答不动手"那条人格规矩的那一层）—— 补丁 ＋ runner 已落地

> 目标里那句"**限定档**"：替小程序跑的那一轮**不许有手**。这一节记它今天到哪儿了。

**已经做并验过的**（2026-10-01）：

| 件 | 形状 |
|---|---|
| `hupo-app-agent.yml`（新） | 一层**减法**补丁（`- id: <已有的> ＋ disabled: true`）：把 **`tool-bash` · `tool-pwsh` · `tool-jobs` · `tool-subagent` · `tool-subagent-fork` · `tool-subagent-control` · `skill`** 全关掉；**不挂能力层**（记账号/小程序库/画图那几件 MCP 工具**根本不在**）⇒ 留下来的只有**看**的：读文件 / 找文件 / 查网 |
| `src/app-agent.js`（新） | `runAppAgent({cfg, cwd, title, prompt})`：起一台**无头 dsh**、挂上那一层、问一句、收正文、**跑完核一遍工作区**、收干净；认不出来 / 一句话没说 ⇒ **如实失败**（**绝不编回答**） |
| `src/review-agent.js` | 加了 `extraPatchPaths`（**不传 ⇒ 命令行一个字节都不变**，评审那条路原样）——"这一层只加在替小程序跑的那一轮上" |

**判据（这一刀）**：`test/app-agent.test.js` **8 条** —— **A1** 问句真落进那一间 ＋ **那一轮真被叫了**
（cwd 是**它自己那一间**、正文带上他的原话、**不许再投给那一间有手的助手**）· **A2** 跑完 ⇒
回答**写进那一间** ＋ 回执 `done`（时间线里找得到 ⇒ 重启之后也答得出）· **A3/A4/A5/A6** 闸与凭据
原样 · **A7** 🔴 **取回执不扣配额** · **A8** 🔴 那一轮动过它自己那一间 ⇒ 回答里**如实带一句**。

**判据**（`test/app-agent-ro.test.js` 4 条）：**L1** 拿真 `dsh --dump-config` 看那一层**真管事**
（那七样关掉了；**反向对照**：不挂补丁时是开的；读/找那两样**留着**）· **L2** `runAppAgent`
真把它挂上命令行、而且 `--patch` 在 `--profile` 之后、cwd 是那个小程序自己的那一间 ·
**L3** 正文里"只回答、别动手"那两句在 · **L4/L5** 动过工作区**如实报**、没正文**不许编**。

**✅ 已接进 `/agent`（2026-10-01 第二步）**：`askAgentFor` 现在是这么走的 ——
**把问句落进那一间（他看得见）→ 起一台无头 dsh 跑"限定档"那一轮（`runAppAgent`）→
把回答也写进那一间（他同样看得见）→ 回执给它**。
🔴 **意义**：以前"只答不动手"靠的是**人格里那句话**（提示层）；现在**那些工具根本不在**
（能力层）—— 那句话降级成第二道。

**回执两路**：进程内那本账（快）＋ **那一间的时间线**（服务重启之后照样答得出）。

**顺手修掉一个真 bug**：取回执（`/agent` 带 `jobId`）原来也会走 `checkAppAgent` ⇒
**每轮询一次就扣一次配额**（页面问一句、轮询几次就把一天的额度扣光）。现在闸加了
`bump` 开关：**只有"问"那一趟记**，取回执只判"还能不能看"（判据 **A7**）。

**⚠️ 如实说一条**：`tool-fs` 是一整块（**读与写在一起**），今天**关不掉它一半** ⇒
那一轮**还写得了那个工作区**。所以 cwd 是**它自己那一间**（写了也写在自己家里），

### 3.4 给**创建小程序的 agent** 的规则（页面里那段）

```html
<script>
// 跟"它的助手"说一句（请动那一间的助手 —— 他每天能看到几次，而且每次都看得见）。
const Q = new URLSearchParams(location.search);
const VER = (location.pathname.match(/^\/a\/[^/]+\/([^/]+)\//) || [])[1] || 'live';
let ticket = null;   // 这张票同时就是 jobId
async function askAgent(prompt) {
  const r = await fetch('/agent', {
    method: 'POST', headers: { 'content-type': 'application/json' },
    body: JSON.stringify(ticket
      ? { id: APP_ID, v: VER, ticket, prompt }
      : { id: APP_ID, v: VER, u: Q.get('u'), e: Q.get('e'), s: Q.get('s'), prompt }),
  });
  const j = await r.json();
  if (!r.ok || j.ok !== true) throw new Error(j.text || '没问成');
  ticket = j.jobId;
  return j.jobId;
}
async function pickUp(jobId) {
  const r = await fetch('/agent', {
    method: 'POST', headers: { 'content-type': 'application/json' },
    body: JSON.stringify({ id: APP_ID, v: VER, ticket: jobId, jobId }),
  });
  const j = await r.json();
  if (!r.ok || j.ok !== true) throw new Error(j.text || '取不到');

```

⚠️ **拿不到回执也要有话说**：`running` ⇒ 页面上转着；`timeout` ⇒ "它还在想，你去那一间看看"；
`failed` ⇒ 如实说没答上来。**不许**编一个答案、也不许画一个按了没反应的入口。

## 二、② 网络（访问网站）：**声明域名 ⇒ 那条 CSP 只放它自己声明的站**（✅ 2026-09-30）

> 主人原话：*「这些功能都要有」*（而这一样是我审计里说"❌ 没有"的那一条：
> 制品页的 CSP 是 `connect-src 'self'` ⇒ 它**出不去**）。

### 2.1 形状（两样一起才算）

| 那一刻 | 形状 |
|---|---|
| **声明** | 清单里 `permissions: ["net"]`（"它要上网"）＋ `net: ["api.example.com", …]`（**白名单**） |
| **谁起草** | **助手**（主人 2026-09-30：*「agent 可以去访问网站并为小程序建立白名单」*）—— 它写页面前**自己去访问过**，把用到的域名写进清单 |
| **生效** | 🔴 **声明了就能用**（傻瓜式）：那一条 CPS 里就有那几个站；**不用他点任何东西** |
| **他能关** | 设置页那张卡上的 `net` 那一项 —— **关掉 ⇒ 名单立刻不进 CSP**（判据 `N4`），制品当场连不出去 |
| **加新站** | **新的一版**（重发一次 `app_create`/`register`）——**不许运行时自己往名单里加**（判据 `N6`） |
| **谁来执行** | **浏览器 / WebView 自己**（CSP 是硬的）。⚠️ **我们看不见制品发了哪些请求** —— 挡住它的是**白名单**，不是我们的日志（这一条如实说，见 §2.4） |

### 2.2 🔴 名单是**安全边界**（这一节的规矩最要紧）

那一串会被**拼进响应头**（`connect-src …`）—— 一条带 `;` / 空格 / 换行的"域名"就足以**改写整条 CSP**。
⇒ `apps.js` 的 `checkNetHosts`（**只有这一处**）只认：小写字母/数字/`-`/`.`，**至少一个点**、
标签不以 `-` 开头或结尾、**一个空白字符都不许有**、不许 `*`、不许端口、不许路径、不许 `http(s)://`；
最多几个（数在代码里）。**认不出来就拒**（不猜、不修）——注册与建包**两个入口都拒**
（判据 `N3`），而且**真发出去的那条头上只可能出现规规矩矩的域名**（`cspFor` 里再兜一道形状）。

## 一、① `ask` 搬到 app 原点（✅ 2026-09-30）

> **原话**：*「这些功能都要有」*。而这一片是**已经在用的能力**在补齐两端 —— 比新做一样更值钱。

### 1.1 它原来为什么"只有网页有"

`ask` 原来只有**一条**路：制品 `postMessage` → 壳（Flutter）→ `/api/app-ask` → 本机小代理 → 模型。
🔴 而**安卓那一侧不许装桥**（手册铁律 3）⇒ 平板上那个小程序**问不了话**（页面收不到"壳在"那句
`hupo-ready`）。这不是漏做，是那条路**天生**只有网页能用。

### 1.2 现在什么样（和存东西**同一个形状**）

| 那一刻 | 形状 |
|---|---|
| 制品发一句 | **`POST /ask`**（**对它自己那个源**），正文 `{id, v, u/e/s 或 ticket, prompt}` |

### 1.4 给**创建小程序的 agent** 的规则（页面里那段）

```html
<script>
// 用他的钥匙问一句（花他的钱：每问一次算一次，每天有上限）。
// 规矩：① 对它**自己那个地址**发一次请求（两端都通，不用等壳）
//      ② 第一次带入口 URL 里那三样（u/e/s）换一张票，之后用票
//      ③ 被拒就**如实显示**（"没说要问话" / "还没允许" / "今天问得够多了" / "问得太快了"）
const Q = new URLSearchParams(location.search);
const VER = (location.pathname.match(/^\/a\/[^/]+\/([^/]+)\//) || [])[1] || 'live';
let askTicket = null;
async function ask(prompt) {
  const body = askTicket
    ? { id: APP_ID, v: VER, ticket: askTicket, prompt }
    : { id: APP_ID, v: VER, u: Q.get('u'), e: Q.get('e'), s: Q.get('s'), prompt };
  const r = await fetch('/ask', {
    method: 'POST',
    headers: { 'content-type': 'application/json' },
    body: JSON.stringify(body),
  });
  const j = await r.json();
  if (!r.ok || j.ok !== true) throw new Error(j.text || '没问成');
  if (j.ticket) askTicket = j.ticket;
  return j.text;
}
</script>
```

⚠️ **页面要能没有它也能用**：`ask` 要**声明了 ＋ 他允许了**才有；拿不到就问不了 ——
那时候**别摆一个按了没反应的按钮**，说一句人话（"这一句得先允许它用你的钥匙"）。
