## 二、② 网络（访问网站）：**声明域名 ⇒ 那条 CSP 只放它自己声明的站**（✅ 2026-09-30）

> 主人原话：*「这些功能都要有」*（而这一样是我审计里说"❌ 没有"的那一条：
> 制品页的 CSP 是 `connect-src 'self'` ⇒ 它**出不去**）。

### 2.1 形状（两样一起才算）

| 那一刻 | 形状 |
|---|---|
| **声明** | 清单里 `permissions: ["net"]`（"它要上网"）＋ `net: ["api.example.com", …]`（**白名单**） |
| **谁起草** | **助手**（主人 2026-09-30：*「agent 可以去访问网站并为小程序建立白名单」*）—— 它写页面前**自己去访问过**，把用到的域名写进清单 |
| **生效** | 🔴 **声明了就能用**（傻瓜式）：那一条 CPS 里就有那几个站；**不用他点任何东西** |
| **他能关** | 设置页那张卡上的 `net` 那一项 —— **关掉 ⇒ 名单立刻不进 CSP**（判据 `N4`），制品当场连不出去 |
| **加新站** | **新的一版**（重发一次 `app_create`/`register`）——**不许运行时自己往名单里加**（判据 `N6`） |
| **谁来执行** | **浏览器 / WebView 自己**（CSP 是硬的）。⚠️ **我们看不见制品发了哪些请求** —— 挡住它的是**白名单**，不是我们的日志（这一条如实说，见 §2.4） |

### 2.2 🔴 名单是**安全边界**（这一节的规矩最要紧）

那一串会被**拼进响应头**（`connect-src …`）—— 一条带 `;` / 空格 / 换行的"域名"就足以**改写整条 CSP**。
⇒ `apps.js` 的 `checkNetHosts`（**只有这一处**）只认：小写字母/数字/`-`/`.`，**至少一个点**、
标签不以 `-` 开头或结尾、**一个空白字符都不许有**、不许 `*`、不许端口、不许路径、不许 `http(s)://`；
最多几个（数在代码里）。**认不出来就拒**（不猜、不修）——注册与建包**两个入口都拒**
（判据 `N3`），而且**真发出去的那条头上只可能出现规规矩矩的域名**（`cspFor` 里再兜一道形状）。

### 2.3 判据（`test/app-net.test.js` 7 条 ＋ `apps-chain` 里那 1 条 · 真响应头）

| # | 钉什么 |
|---|---|
| **N1** | 声明了 `net` ＋ 名单 ⇒ 真制品那一条 `connect-src` 里**真有那几个站**；**没声明的站一个都不在** |
| **N2** | 没声明 ⇒ **只有 `'self'`**（一个字节都不放宽） |
| **N3** | 坏名单（`evil.com; script-src *` / `*` / 端口 / 路径 / 空白 / 超长 / 太多）⇒ **注册与建包都拒**；**手改盘上的注册表**也进不了 CSP |
| **N4** | 🔴 **他关掉 ⇒ 名单立刻不进 CSP**；再打开 ⇒ 又回来（"现在不给"不是"抹掉"） |
| **N5** | **一个 app 的名单不会跑到另一个 app 的头上**（按 app 算，不是全局白名单） |
| **N6** | 名单**不许自己长**：加站要重新登记一版 |
| **工具那一条** | 助手在 `app_create` 里声明 `net` ＋ 域名（真 MCP → 真套接字 → 真制品库）⇒ 清单里真有 ⇒ `netHostsFor` 真给出那几个站；**坏域名在工具那一层就被拒、而且不留 app** |

**变异**：把 `netHostsFor` 里"他关掉就不给"那一句去掉 ⇒ **3 条红**（`N4` ＋ `netHostsFor` ＋ 租户那条）。
⚠️ **如实说一条**：`netHostsFor` 里"**声明过 `net`**"那一句今天**是冗余的** ——
因为"他能用哪几样"（`grants`）本来就是从声明推出来的（`#213` 那次翻面），
所以把那一句删掉**判据不会红**（实测）。留着是**第二道防线**（比如以后 `grants` 换成别的来源）。

### 2.4 如实说（这一片的边界）

- **制品发了哪些请求，我们看不见**：CSP 是浏览器/WebView 执行的，我们这一侧只有响应头那一下。
  ⇒ "留痕"这一半**没有**（不像 `ask`/`db` 那样过一次我们的门）。
  要"看得见"只有两条路：① 制品**别直连**，改走我们中转（那就多一跳、也多点延迟）；
  ② 或者哪天有了"自己的源 ＋ 反向代理"再谈。**今天选的是白名单**（他关得掉、加站要他点头）。
- **`https` 之外的站连不了**（名单里的域名一律按 `https://` 放行）——这是刻意的。
- **设置页那一项的人话**（"想连网取数据"）跟第 ⑤ 片（清空那颗按钮）**一起上**：
  今天那张卡对 `net` 会用兜底那句（"还想再要一样东西"）——**能看能关，只是话不够准**。

## 一、① `ask` 搬到 app 原点（✅ 2026-09-30）

> **原话**：*「这些功能都要有」*。而这一片是**已经在用的能力**在补齐两端 —— 比新做一样更值钱。

### 1.1 它原来为什么"只有网页有"

`ask` 原来只有**一条**路：制品 `postMessage` → 壳（Flutter）→ `/api/app-ask` → 本机小代理 → 模型。
🔴 而**安卓那一侧不许装桥**（手册铁律 3）⇒ 平板上那个小程序**问不了话**（页面收不到"壳在"那句
`hupo-ready`）。这不是漏做，是那条路**天生**只有网页能用。

### 1.2 现在什么样（和存东西**同一个形状**）

| 那一刻 | 形状 |
|---|---|
| 制品发一句 | **`POST /ask`**（**对它自己那个源**），正文 `{id, v, u/e/s 或 ticket, prompt}` |
| 凭据 | 和 `/db` **同一套**：入口签名换一张**会话票**，之后用票（`appTicketOf`，绑人绑 app） |
| 判定 | 🔴 **和 `/api/app-ask` 同一个函数**（`server.js` 的 `askForApp`）：**声明 → 他允许 → 配额 → 花在谁的环境里** |
| 花在哪 | 主人 / 单租户 ⇒ **本机**那个小代理；**租户 ⇒ 过隧道进他盒子**（钥匙在他盒里 —— `app-ask.js` 顶上那条） |
| 回来 | `{ok:true, text, left, max, ticket}`；被拒 ⇒ `{ok:false, status, error, text}`（**人话在 `text` 上**） |

⇒ **网页与安卓吃同一个 CSP 头、走同一条路** ⇒ **两端都通，而且不再依赖壳**。
⚠️ **壳的桥一个字没删**（旧页面照旧能用）；新页面**不必**再等 `hupo-ready`。

### 1.3 判据（`test/app-ask-fetch.test.js` · 5 条 · 全是**真链路**）

|---|---|
| **K1/K2** | 真 app 原点：入口签名 ⇒ **200 ＋ 回答**（真过了一次代理）· 那张**票能接着用** |
| **K3** | 没凭据 ⇒ 403 · 别的 POST 照旧 405 · `OPTIONS` 预检答得上 · 被拒的那几条**一个字都不花** |
| **K4** | 🔴 **闸还是那道闸**：没声明 ⇒ 403（"这个小程序没说要问话"）· **他关掉了** ⇒ 403（"你还没允许它用你的钥匙"）——**一次都不许打到代理** |
| **K5** | 🔴 **配额照记**（`ask.json`）：问一次记一次，**记在它自己那一格**里 |
| **K6** | 这条口没接线（`askApp: null`）⇒ **503 ＋"还没跟上"**（"这一台还没有这个能力" ≠ "你不许问"） |

（不是我重写一遍 —— 重写一遍就证明不了"两条口同一道闸"）。

⇒ **K4 ＋ K5 红**（实测；跑完逐字节还原）。

### 1.4 给**创建小程序的 agent** 的规则（页面里那段）

```html
<script>
// 用他的钥匙问一句（花他的钱：每问一次算一次，每天有上限）。
// 规矩：① 对它**自己那个地址**发一次请求（两端都通，不用等壳）
//      ② 第一次带入口 URL 里那三样（u/e/s）换一张票，之后用票
//      ③ 被拒就**如实显示**（"没说要问话" / "还没允许" / "今天问得够多了" / "问得太快了"）
const Q = new URLSearchParams(location.search);
const VER = (location.pathname.match(/^\/a\/[^/]+\/([^/]+)\//) || [])[1] || 'live';
let askTicket = null;
async function ask(prompt) {
  const body = askTicket
    ? { id: APP_ID, v: VER, ticket: askTicket, prompt }
    : { id: APP_ID, v: VER, u: Q.get('u'), e: Q.get('e'), s: Q.get('s'), prompt };
  const r = await fetch('/ask', {
    method: 'POST',
    headers: { 'content-type': 'application/json' },
    body: JSON.stringify(body),
  });
  const j = await r.json();
  if (!r.ok || j.ok !== true) throw new Error(j.text || '没问成');
  if (j.ticket) askTicket = j.ticket;
  return j.text;
}
</script>
```

⚠️ **页面要能没有它也能用**：`ask` 要**声明了 ＋ 他允许了**才有；拿不到就问不了 ——
那时候**别摆一个按了没反应的按钮**，说一句人话（"这一句得先允许它用你的钥匙"）。
