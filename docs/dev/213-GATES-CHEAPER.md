# 213 · **把"少跑闸"从纪律变成结构**（窄闸脚本 ＋ 全闸留戳）

> **主人原话**（2026-10-07）：*「现在用dsh来修改软件非常的慢了，是不是项目闸太多了？
> 是不是一些修改可以不用去测试闸？」*
>
> 读数与七条纪律在 [`212`](212-DEV-SLOW-WHERE.md)（**不是闸太多，是同一道闸跑了两遍**：
> 最贵那一轮工具时间的 2,138 秒里 **1,454 秒**是它）。这一篇补的是**两件结构性的事** ——
> 那个项目的老规矩：**光记纪律没用，改成结构上不可能**。

---

## 一、`scripts/gate-quick.sh <改动的路径…>`（迭代期用它）

按"**改哪块 ⇒ 跑哪条**"的**唯一映射**挑闸；认不出就**如实说"认不出"**（让你判断，绝不悄悄放过），
结尾一定提醒"收尾还要跑全闸"。

| 改了什么 | 它跑什么 |
|---|---|
| `v2/services/core/src/<名字>.js` | `node --test test/<名字>.test.js`（同名约定）；**找不到同名判据 ⇒ 退回 `npm test`**（宁可慢，不许漏） |
| `v2/services/core/test/<x>.test.js` | `node --test test/<x>.test.js` |
| `v2/apps/mobile/lib/**/*.dart` | `flutter analyze` ＋（有就）`test/unit/<同名>_test.dart` ＋（有就）`test/widget/<同名>_test.dart` |
| `v2/apps/mobile/test/**` | 那一个文件 |
| `*.md` / `docs/**` / `AGENTS.md` / 人格 / 能力层 | `node scripts/check-docs.mjs`（人格再加 `scripts/check-persona.sh`） |
| `scripts/*.sh` / `*.mjs` | `bash -n` / `node --check`（脚本本身只有语法闸） |

`--list` 只说要跑什么、不跑。**它不当全闸用**：结尾那句提醒是硬写死的。

## 二、全闸**留戳**（`scripts/gate-server.sh` · `check-client.sh`）

* 跑完**留一枚戳**（`v2/services/core/data/gate-stamp.json`，本机、不进仓库）；
* 下一次**同一棵树、同一个工具链、半小时内**再跑 ⇒ **当场跳过**，并告诉你"这一版几分钟前刚跑过"；
  真要再跑一遍：`--again`；
* **指纹 ＝ 源码 ＋ 判据 ＋ 依赖清单（`pubspec.lock` / `package-lock.json`）＋ 工具链版本**
  （flutter / node 那一行）—— **内容一变，戳就作废**（`touch` 不算：改的是 mtime，不是内容）；
* 🔴 **fail-closed**：指纹算不出、戳读不出、json 坏了、过了窗口 ⇒ **一律照跑**（绝不因为"读不出"而跳过）。

`scripts/deploy-web-v2.sh` 里那道服务端闸也改成走 `gate-server.sh`
⇒ **收尾刚跑过的那些，部署时不会再白跑一遍**（判据一个字没变，还是 `npm test`）。

## 三、判据（真读数 · 这一趟亲手验的）

| # | 验什么 | 读数 |
|---|---|---|
| A | 窄闸的映射 | `gate-quick.sh --list <四类路径>`：客户端那条挑出 `flutter analyze` ＋ `test/unit/hearing_session_test.dart`；服务端挑出 `node --test test/asr.test.js`；文档挑出 `check-docs.mjs`；脚本挑出 `bash -n` |
| B | 窄闸的收尾提醒 | 结尾一定打印「这**不是**收尾：收尾仍要跑全闸（…）」 |
| C | 戳：没跑过 | `gate-stamp.sh check server` ⇒ **退出 1**（该跑） |
| D | 戳：跑过、同树 | 写戳之后 `check server` ⇒ **退出 0** ＋「这一版 0 分钟前刚跑过全闸」 |
| E | 🔴 戳：**内容变了** | 往 `src/asr.js` 追加一行 ⇒ `check server` **退出 1**（作废）；还原 ⇒ **退出 0** |
| F | 戳：`touch` 不算改 | 只改 mtime ⇒ 指纹不变（**指纹认内容，不认时间**） |

**变异验证**：把 `check-client.sh` 里那两行戳去掉 ⇒ 同一棵树会再跑一遍（回到 212 §二那种浪费）；
把 `fp_of` 换成"只看时间" ⇒ E 那条当场假。

## 四、如实说

* ⚠️ **它省的是"重复"，不是"闸"**：`212` §四那句话照旧成立 —— **砍闸 = 拿"页面在说假话"换速度**，
  所以这一篇一条判据都没松（服务端还是 `npm test`、客户端还是那三道）。
* ⚠️ **窄闸的映射是"同名约定"**：改 `src/foo.js` 而判据叫 `test/bar.test.js` 时它**认不出**
  —— 那种情况它会退回 `npm test`（服务端）或提醒你"没有同名判据，建议收尾跑全闸"（客户端）。
  **不许**把"没跑"当成"过了"。
* ⚠️ **戳是本机的**（`data/` 下、不进仓库、别人那台看不到）。它**不是判据**，只是一句"刚跑过"。
* ⚠️ **没量"省了多少分钟"**：这一趟只验了"行为对不对"（上表六条）。
  真实的省时读数要等下一次收尾（到时候把"这次跑了几遍闸"记在账本那一行）。
