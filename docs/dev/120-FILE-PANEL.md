## 〇、一句话

DSH 的右栏是"**会话旁边的第二块地方**"：会话头右上角一颗按钮 ⇒ 右边多一栏；
栏里顶上是一条 tab 带（文件 / 文档预览），底下是内容。
我们这一批只做**那根柱子和那一栏**，栏里只放**一样**东西 ——
**这一窗动过哪些文件**（从工具行抽出来的事实，不新增任何接口）。

🔴 **这一批的灵魂还是"不猜"**：路径只从入参 **JSON** 里取；取不到就**那一行不出现**
（不是"未知文件"）；"看过"不算"改过"；DSH 那张表上的**增删行数 / 文件内容 / 工作目录**
我们**一样都没有** ⇒ **一个字都不许出现**（§六 逐条列出）。

## 一、那一栏从哪来（DSH 的形状）

| # | DSH 的事实（`115-raw/A-layout.md` §3） | 我们怎么办 |
|---|---|---|
| 1 | **右栏是三轨网格里的一轨**（`sidebar px / 1fr / rightbar px`），它一开**中间那一列就变窄** | **够宽就照它**（`Row`：聊天那一块真的变窄，左边仍看得见一条边）；**不够宽就改成"盖满"**（§3.1 写了为什么） |
| 2 | 宽度：`0` 或 `clamp(300, viewport*0.45)`，上限 `viewport*0.70` | 逐条照抄（`dshRightPanelWidth`，四个数都在 `models/dsh_design.dart`） |
| 3 | 窄屏：`available < 300` ⇒ **右栏 0**（它自己关掉） | 🔴 **我们反过来：盖满**。理由见 §3.1 |
| 4 | 会话头右上角**一颗 28×28 的按钮**（`aria-label` = 打开右侧边栏），**面板开着时不画它** | 同一颗（`FilePanelButton`）；**图形 28、命中区 44**（D3.6 量的是命中区，见 `dshPanelIconButtonSize` 那段）；开着就不画它 |
| 5 | 栏里顶上是一条 **tab 带**（文件 / 文档预览） | 🔴 **不做 tab 带**：栏里只有一样东西 ⇒ 做一个只有一颗 tab 的切换器 = 摆一个死键 |
| 6 | 隐藏时 `transform: translate(100%)`（滑出右缘，不是消失） | 同一招（`AnimatedSlide`：`Offset(1,0)` ⇄ `Offset.zero`） |

* **服务端**：`v2/services/` 一个字节没碰。四帧事件（`tool/call` 等）的形状

## 二、纯逻辑：从工具行里抽出"改过哪些文件"（`lib/models/file_changes.dart`）

### 2.1 抽的规矩（每一条都有判据）

| # | 规矩 | 为什么 |
|---|---|---|
| 1 | 只认**改动类**那四件工具：`write` / `edit` / `str_replace_editor` / `apply_patch`（**显式名单**） | 入参里带 `path` 的工具不止一种：`read` / `grep` / `glob` 也有 —— 但**"看过"不是"改过"**，混进来就是这一栏在说假话。⚠️ **不写通配**（`*edit*` 那种会把将来某个只读工具算成"改过"） |
| 2 | 路径只从入参那串 **JSON** 里取：`path` 优先、其次 `file_path`，第一个**非空串** | `115-raw/B-render.md` §2.1：DSH 自己这两个字段就是这两个名字。**不拼、不规范化、不猜后缀** |
| 3 | **解不出 JSON ⇒ 那一行什么也不贡献** | 服务端把入参裁到上限（`MAX_ARGS_CHARS`）⇒ 裁过的 JSON **解不出来**。留一行"未知文件"比丢一行更坏（拿猜的东西上屏） |
| 4 | 分组**按轮**（`ToolRow.turn`），**同一轮里按路径去重**、留**第一次**那一步；跨轮**不合并** | "这一轮动过它"是**每一轮各自的事实**（第 2 轮又改了一遍，第 1 轮那一行不该消失） |
| 5 | 顺序 = **第一次见到的顺序**（轮与文件都是） | 排序只发生在**界面那一层**（倒着遍历 = 最新在上）；数据那一层保持原样 ⇒ "数据的顺序"与"屏幕上的顺序"不会变成两处会漂的东西 |
| 6 | 同一轮里同一个路径被碰了两次 ⇒ `tools` **并起来**（`['write','edit']`） | 只画"最后一次"会把"改过两次"说成"改过一次" |
| 7 | **坏输入绝不抛**（`null` / 数组 / 数字 / 空串 / 字段类型不对 …… 全部走"不贡献"） | 这一层的输入来自服务端，可能是任何东西；坏数据的后果只许是"少一行" |

### 2.2 `ToolRow` 多存了两格（**入参**的 `bytes` / `truncated`）

`tool/call` 上服务端本来就报了这一对（`v2/services/core/src/tool-rows.js` 的
`toolArgsSummary`），而 `116` 那一版只存了**结果**那一半
（[`116`](116-CHAT-OPEN-AND-REDESIGN.md) §2.3 缺口 5：*"界面只说'结果被截'"*）。
这一批要**逐字给对方看入参** ⇒ 把它存进 `ToolRow.argsBytes` / `ToolRow.argsTruncated`
（默认值 ⇒ 老调用处一字不用改）。

⚠️ **两对互不干扰**：`bytes`/`truncated` 仍是**结果**的，`argsBytes`/`argsTruncated`
是**入参**的。⚠️ 只有**服务端明确报了 `true`** 才是 `true` ——
`1` / `'yes'` 这类坏值**不许**被当成"截了"（Dart 里 `1 == true` 是真的，真栽过：
用 `== true` 写会凭空多出一句"已截断"）。

## 三、那一栏画在哪（`lib/widgets/file_panel.dart`）

### 3.1 两条路：**够宽就挤、不够宽就盖**

这一栏开在**浮窗里面**（派活单点名：*"不是新的一屏"*），而
"收起来 / 回收站 / 导出 / 过程 / 配置 / 退出"那一排动作住在**同一根标题行**上。
地方不够的时候，"挤"会把标题行挤成**负宽** —— 那个 `IconButton` 的语义矩形量出来
是 `Size(-281, 48)`（**真栽过**，`sweep` 那道硬闸当场红）。

| 情形 | 形状 | 为什么 |
|---|---|---|
| **够宽**（`dshRightPanelFits` 且算出来的宽 < 可用宽 **且挤完聊天还剩得下**） | `Row`：`_viewArea` ＋ 那一栏 | 与 DSH 的三轨同一个形状：聊天真的变窄，左边仍看得见一条边 |
| **不够宽** | `Stack` ＋ `Align(centerRight)`：那一栏**盖在聊天上面** | 窄屏下面板**按不动**（关掉 = 点了没反应）比"盖住聊天"坏得多 —— 他就是在点那颗按钮 |

> 🔴 **2026-09-26 补上"够宽"的第三个条件**（真机缺陷，见 [`121`](121-EXPAND-INPUT-FIX.md) §四）：
> 光判"**这一栏自己**放得下"（`available ≥ 300`）是不够的 —— 手机那一档
> （浮窗里那一块 ≈ 屏宽 − 60 ⇒ 330 上下）算出来的栏宽正好 **300** ⇒ `Row` 里聊天只剩
> **30 像素**，气泡那一行当场 `RenderFlex overflowed by 41 pixels`（`bubbles.dart:141`）。
> "挤"的本意是"**还看得见一条边**"，30 像素不是"看得见"，是把聊天弄坏了。
> ⇒ 现在还要问 `dshRightPanelLeavesRoomForChat`（**两根柱子各自都要有一块能用的宽度**；
> 那个最小值与 `dshRightPanelNarrowWidth` **同源**，不各写一份）；不够就走"盖"。

⚠️ **两条路底下聊天那一棵子树是同一个 `_viewArea(c)`**（同一个 `State`、同一个
`ScrollPosition`）⇒ 开 / 关这一栏**不会丢滚动位置**（判据钉着这一条）。

### 3.2 栏里长什么样

```
CustomScrollView                     ← 抬头与那一行行**住同一个滚动面**
├─ SliverToBoxAdapter  抬头：这一窗动过哪些文件 ＋（收起这一栏）
│                             N 轮 · M 处 ＋ 一句口径（最近改的在上…）
├─ SliverToBoxAdapter  0.5px 发丝线（dshHairline）
└─ SliverList（最新那一轮在最上面）
   ├─ 分组头：第 N 轮 ＋ N 个文件
   └─ 一行 = 一整颗 TextButton（命中区 ≥44）
        ├─ 路径（**等宽、一行、超了省略号**）
        ├─ 被这些工具碰过：write · edit   （名字空着就不画那一句）
        └─ 点开：那一次的入参原文（有界、能滚、SelectableText）
```

🔴 **为什么抬头与列表要住在同一个滚动面里**（真栽过）：五档字号 3.1x 下抬头会长到
**比整块地方还高** —— 按"上下分"摆，列表会分到 0 高 ⇒ **一行都建不出来**，
`ensureVisible` 当场抛 `Bad state: No element`，屏幕上看起来就是"那一行点不到"。
⇒ 合成一个滚动面：**谁也不挤谁**，超了就在这一栏里滚到底（与 `116` 那两块正文
同一条老规矩：**有界 ≠ 截断**）。另配一小段 `cacheExtent`（`dshPanelCacheExtent`，
让"刚出视口"的那几行也建出来）。

⚠️ **如实记**：我先试的是"把 `cacheExtent` 加大"（一路加到 2000）——**没用**：
只要抬头与列表还是上下分家，列表就是 0 高，缓存段再大也建不出东西来。
真正的修法是**把两者合进同一个滚动面**。

### 3.3 🔴 关着的时候它**一个可点的东西都不算**

这一块只是"滑出右缘"，元素还在树里（动画要用）。不挡的话：读屏会念到它，
`sweep` 也会去量它 —— 而**滑出屏幕的语义矩形是负的**（真栽过 `Size(-281, 48)`）。
做法是 `Semantics(blockUserActions: !open)`：关着时那颗「收起这一栏」只是一个字。

### 3.4 数值 / 颜色 / 字号全部从 token 来

宽度、按钮图形尺寸、时长、缓存段都在 `models/dsh_design.dart`；
颜色与字号走 `DshLook.of(context)`（**第四批**那条唯一的取值口）⇒
这一栏跟着**用户选的亮 / 暗 / 跟随系统**与**那条 12–17 的字号轴**走。
新文件里**一个写死的尺寸都没有**（`design_tokens_test.dart` 那条棘轮盯着）。

### 4.1 负向对照（每条判据都反着验过）

* 坏 JSON / 半截 JSON ⇒ **那一行不出现**（不是"未知文件"）；
* `read` / `bash` / `grep` 的入参里也有路径 ⇒ **一行都不加**；

## 六、🔴 我们**没有收到**、所以这一栏里**一个字都不许有**的

| # | 没有的东西 | 事实（不是猜） |
|---|---|---|
| 1 | **每次改动的增删行数 / diff** | DSH 那张 diff 卡要 `write` / `edit` 的**完整入参**（`115-raw/B-render.md` §2.1 的 `diffCardModel`），而我们**没存** `old_string` / `new_string` 那一对，也没有任何"改了多少"的权威数字 ⇒ **一个数都没有** |
| 2 | **文件现在长什么样 / 预览 / 下载 / 打开** | 那要**读盘**（DSH 的 文件 / 文档预览两个 tab）。这一批**没有服务端接口**，客户端更不许碰文件系统（派活单：只读、不碰 FS） |
| 3 | **工作目录 / 绝对根 / 这个路径相对于哪** | `path` 是模型给的**原样字符串**（可能是相对路径）⇒ 我们**不拼接、不规范化、不猜**（拼一次就是编一个路径）。⚠️ 所以这一栏里可能出现**相对路径**，而那是**如实**（我们手上就这个） |
| 4 | **`bash` 里改的文件** | `echo x > f` 只出现在命令字符串里 ⇒ 我们**看不到**那个文件名。⇒ 那种改动**这一栏不会出现**，也**不许**编一条出来 |
| 5 | **读过的文件** | `read` / `grep` / `glob` 的入参里也有路径 —— 但"看过"不是"改过"（§2.1·1） |
| 6 | **"整条聊天记录"到底动过哪些** | 更早的轮在客户端是**翻页才有的**（`older_*` 那一套）⇒ 抬头底下那句口径写的是"**只算这一窗已经摊开的这些轮**"，绝不把它说成"整条" |
| 7 | 那一句里的 `工具` | 它**就是** `forbidden_words.dart` 表里的词。主人 2026-09-26 已在聊天窗口内放开（`D1.1·补`），而**词表这一批一个字都不许改** ⇒ 与 `toolStatusWord` / `trajectoryKindWord` 同一处境：那个常量**故意没进**禁用词那道"必须干净"的清单，其余几句进了 |

## 七、明确不做的（**现在就说清，不留"以后"**）

| # | 不做 | 为什么 |
|---|---|---|
