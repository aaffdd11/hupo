# 58 · 让**用户能造小程序**（把"写死的一屏"改成"一份可以造的数据"）

> 主人 2026-09-22：*"我看到奥数题和登录以后聊天的那个不是一起的。我希望用户可以创造小程序啊。"*
>
> 这两句其实是**一件事**：现在的小程序是**我（开发者）写死的一屏**，编译在客户端里 ——
> 所以它①跟你的聊天、你的数据没关系；②只有我能加，用户（和助手）谁也造不出来。

---

## 一、先说清现在为什么"不在一起"

| | 现在 | 结果 |
|---|---|---|
| 那个奥数题小程序 | `screens/math_quiz_screen.dart` —— **Flutter 代码**，题库是 `models/math_bank.dart` 里的**常量** | 你说"再加十道题"，**助手办不到**（它改不了客户端代码）；你刷新也看不到变化 |
| 聊天 | 服务端按人存事件（`store` / `timeline`），**每个用户一份** | 聊天里说过的话**进不了**那个小程序 |
| 助手 | 手里只有"写文件、记账"这类工具，**没有"装一个进入桌面"的路** | 它要么假装能做，要么直说做不到（人格已经改成后者） |

⇒ **根子是**：小程序的"内容"和"界面"都住在**代码**里，而不是住在**你的数据**里。

---

## 二、要变成什么样（三步，一步步来）

### 第 1 步：**内容搬进你自己的数据**（聊天与小程序就"在一起"了）

- 服务端按人存一份 **小程序内容**（跟 `store`/`timeline` 一样，一人一份）；
- 助手**能写**它（那是"填内容"，不是"改界面" —— 正好补上它那条边界）；
- 客户端读它来画。

⇒ **效果**：你在聊天里说*"给奥数题再加十道关于面积的应用题"*，它加进去，
你说*"打开奥数题"*，**新题就在那儿**。这才是"在一起"。

### 第 2 步：把"奥数题"抽象成**一种形状**（于是谁都能造）

一份小程序 = **一个形状 + 一份内容**，都是数据：

```jsonc
{
  "shape": "quiz",                 // 形状：题库（第一版只做这一种）
  "title": "四年级奥数题",
  "icon": "calculate",             // 只许从这个白名单里挑
  "cards": [
    { "q": "鸡兔同笼：20 个头 56 只脚，兔几只？", "a": "8 只", "why": "…" }
  ]
}
```

客户端里那个渲染器**只认这几种形状**，把任何一份这样的数据画成一屏。

⇒ **效果**：桌上那个小程序不再是"我写的一屏"，而是**你数据里的一条记录**。
**用户可以造小程序** = 选一个形状 + 填内容（自己填，或者让助手填）。

### 第 3 步（以后）：更多形状 + 一句话新建

更多形状（清单 / 账本 / 打卡 / 倒计时…），以及*"给我造一个记喝水的小程序"*这种一句话新建。

---

## 三、⚠️ 三条不能破的（否则这是个大窟窿）

1. 🔴 **声明式，不许执行代码。** 小程序是**数据**，不是插件、不是脚本。
   客户端只认**白名单里的形状与块**（文字 / 卡片 / 按钮 / 题目…），认不出来的一律**不画**（fail-closed）。
   ⚠️ 理由：这个项目的威胁形态不是"它干一次坏事"，而是"**坏事能不能留下来**"——
   一个能执行代码的小程序，等于给"每轮开机都读一遍"开了个后门（`AGENTS.md` §八）。
2. 🔴 **"谁按的按钮"决定它能不能自己动手**（2026-09-22 主人确认了这条读法）：
   * 主人**明说**"帮我创建一个奥数 app" ⇒ 那次点击**就是他按的按钮** ⇒ 助手**直接造**，
     不用再问一遍（再问一遍是把已经说过的话当没说过）；
   * 助手**自己想到**、或者**从别处读到的**（网页、别人发来的内容）说"应该加个小程序"
     ⇒ **只能提**，不许自己造 —— 那正是 P1/P2 要挡的形态：
     **它读到一段看不见的内容 → 被诱导写进自己的配置 → 从今往后每轮开机都读那一段**。
   ⚠️ 判据要落在**这一条**上，而不是"造东西"这个动作本身。
3. ⚠️ **内容只进你自己那一份**（一人一份，跟聊天记录同一条规矩）。

---

## 四、这一刀怎么切（**不许做一半**）

| 批 | 做什么 | 做完能验什么 |
|---|---|---|
| **1** | 内容进用户数据 + 助手能写 + 客户端读 | 聊天里加十道题 ⇒ 小程序里真多了十道 |
| **2** | `shape: "quiz"` 的渲染器（把写死那屏换成通用渲染） | 换一份数据就换一个小程序（**不用改代码**） |
| **3** | "新建 / 放上桌面"那一步 + 人点头 | 用户自己造出第三个、第四个小程序 |

⚠️ **第 1 批不做完不许开第 2 批**（`04-ROADMAP.md` §十一：做一半比不做更坏）。
