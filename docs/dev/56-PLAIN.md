# 56 · 用最白话把它说清（以及首页为什么这么排）

> 主人 2026-09-22：*"总结整个项目，用最白话的语言，告诉用户这是以什么项目，有什么能力。
> 然后重新规划设计首页内容，能让用户看明白。"*
>
> 这一篇是**两份东西**：§一 是"说给人听的那一版"（首页与对外都从这个口径来），
> §二 是**首页怎么排、为什么这么排**（改文案之前先读它）。

---

## 一、最白话的那一版

### 它是什么

> **琥珀是一个替你办事的助理，不是陪你聊天的机器人。**
> 你说一件事，它**记住**、**自己去办**，办完**回来告诉你结果**。
> 它有一个只属于你的地方，别人看不到你的东西。

### 它现在**真的能**做什么

| 能做什么 | 具体是什么样 |
|---|---|
| **记住你说过的事** | 关掉、重启、过几天回来，都不用重说一遍 |
| **自己去办** | 该查的去查、该记的记上；**办的时候屏幕上看得到它在做什么** |
| **办完回来告诉你** | 一轮结束，结果就在那儿；不是"转个圈然后没了" |
| **没办成就直说** | 查不到就说查不到；你那把钥匙它说用不了，它会直说并让你重新填 |
| **删错了能拿回来** | 删掉的东西先进回收站；想把记录带走，能导出成一段文字 |
| **说话像同一个人** | 它有自己的性格和规矩，不是每次换一个客服 |
| **卡住了会自己收场** | 就算程序被硬杀，它也能收拾干净；只读的活会自己重做 |

### 它现在**还不能**做什么（如实说）

| 还不能 | 现在是什么样 |
|---|---|
| 手机安装包 | ❌ 还没有。**现在能用的是网页版** |
| 语音 | ⚠️ 还在做。屏幕上已经有那个形状了，但**是演示、没真的开麦**（`55-VOICE-DEMO.md`） |
| 短信登录通道 | ❌ 没接（现在用临时码） |
| 导出的东西里**没有**"它记在脑子里的那一层" | 导出的末行**如实写着**这件事 |

### 跟"光是聊天"最本质的一句

> **聊天机器人给你一段回答；琥珀给你一件事办完的结果** —— 它记得住、看得见、认账。

## 二、首页为什么这么排

### 五条设计原则（改文案之前先读）

1. **第一句就回答"这是什么"** —— 用**具体身份**（"替你办事的助理"），不用形容词；
2. **能力用"事情"说**，不用形容词（全篇没有"智能""强大""高效"）；
3. **先给"现在能用的"，再说"还不能用的"** —— 诚实，但别当头泼冷水；
4. **每块只有一个主题，小标题本身就是那句话** —— 扫标题就能懂；
5. **不许内部词、不许写做不到的事**（禁用词硬闸 + "说了做不到 = 撒谎"）。

### 版块顺序与它回答的问题

| 顺序 | 版块 | 回答用户心里哪一句 |
|---|---|---|
| 1 | 标志 + 小标 + **那句承诺**（手册原文） | 「这是个啥？」 |
| 2 | **它是一个替你办事的助理…** | 「跟聊天机器人有啥区别？」 |
| 3 | [开始用] + 「用手机号登录，第一次要花一点时间给它安个家」 | 「怎么开始？要什么？」 |
| 4 | **它能替你做什么**（四张卡：记 / 办 / 实 / 回） | 「具体能干嘛？」 |
| 5 | **跟聊天机器人不一样在哪**（对照四行） | 「凭什么是它？」 |
| 6 | **在哪儿用**（网页版在最前，安卓/苹果如实标"还没上线"） | 「我现在能用吗？」 |
| 7 | **你可能想知道**（六条 FAQ） | 「我还有几个担心的」 |

⚠️ **四张卡与对照块不许重复**：四张卡讲**"能做什么"**，对照块讲**"形态上的区别"**
（谁给你什么 / 记不记得 / 说不清时怎么办 / 东西放哪儿）。

### ⚠️ 排这一版时踩到的两条（留给下一个人）

1. **`scrollUntilVisible` 在内容变多之后会冲过头** —— 它一步 240px 地跳，卡片一多就跳过去了，
   然后报 `Bad state: No element`。⇒ 判据改成**一路滚下去、边滚边收**（"每一张都被画出来过"）。
2. **判据自己会"滚走"**：我在滚动之后才去查顶部那句提示 —— 而 `ListView` 已经把它回收了
   ⇒ 顶部的东西要在**滚动之前**查。
