# 56 · 用最白话把它说清（以及首页为什么这么排）

> 主人 2026-09-22：*"总结整个项目，用最白话的语言，告诉用户这是以什么项目，有什么能力。
> 然后重新规划设计首页内容，能让用户看明白。"*
>
> 这一篇是**两份东西**：§一 是"说给人听的那一版"（首页与对外都从这个口径来），
> §二 是**首页怎么排、为什么这么排**（改文案之前先读它）。

---

## 一、最白话的那一版（**完整版**）

> ⚠️ 第一版只讲了"能做什么"，主人回了一句 **"不够全面"**。
> 缺的是三块：**它是谁的 / 你的东西怎么保的 / 它靠什么不骗你**。这一版补上。

### 1. 它是谁、给谁用

* 它是一个**替你办事的私人助理**，不是陪你聊天的机器人。
* 主要给**手机上、不方便打字的人**用（比如不会拼音的长辈）；也给任何"想把事交出去"的人用。
* 现在能用的是**网页版**（手机浏览器、电脑浏览器都行）。

### 2. 一个人一台，东西是你自己的

| 这一条 | 具体是什么样 |
|---|---|
| **一台只属于你的机器** | 不是共享的聊天窗口。你的话、你的记录都在你自己那一份里，**别人看不到** |
| **你自己的钥匙** | 它拿**你自己的钥匙**去说话；钥匙**不写进任何记录、不进日志** |
| **你想删就删** | 删掉的东西先进**回收站**，能拿回来；也能一次真删 |
| **你想带走就带走** | 记录能**导出成一段文字**（能直接粘走） |

### 3. 能做的事（**现在真的能用**）

| # | 能做什么 | 具体是什么样 |
|---|---|---|
| 1 | **记住** | 你说过的事它记着；关掉、重启、过几天回来都不用重说 |
| 2 | **去办** | 该查的去查、该记的记上 |
| 3 | **看得见它在做** | 屏幕上写着它正在做什么（四档：一句话 ↔ 详细步骤），不是只转个圈 |
| 4 | **记账** | 说一句"今天干了八小时"，它替你记进账本；能翻出来，也能导出去 |
| 5 | **办完回来说结果** | 结果是结果，不是"转个圈然后没了" |
| 6 | **没办成就直说** | 查不到就说查不到；你那把钥匙它说用不了，它直说并让你重填 |
| 7 | **能反悔** | 删错的东西进回收站，能拿回来 |
| 8 | **会喊你** | 有事要你处理时，屏幕上给一条通知（带「知道了」「撤销」） |
| 9 | **卡住会自己收场** | 被硬杀也能收拾干净；只读的活会自己重做；**重启不会打断你正在说的那一轮** |
| 10 | **说话像同一个人** | 它有自己的性格和规矩，不是每次换一个客服 |
| 11 | **不会突然把你踢出去** | 登录状态自己续（滑动半年；最长一年要重新登录一次） |

### 4. 它靠什么保证**不骗你**

| 规矩 | 什么意思 |
|---|---|
| **没办成就直说** | 不许拿猜的凑。这是硬规矩，不是文风 |
| **界面上不许出现内部词** | 工作区 / 口令 / 连接 / 客户端 / 云端 …出现就是**缺陷**，有闸守着 |
| **页面不许说假话** | 没有安装包就写"还没上线"，点了**不会假装开始下载** |
| **每个"做完了"都要指得出来** | 要能在代码里指出文件与测试名；**指不出来的不算做完** |

### 5. 现在的样子

* 登录之后：**一个桌面 + 一个聊天窗口**（聊天永远在底下浮着，能收起、能展开；收起时也能直接打字）。
* 桌面上有**设置**（退出登录 / 注销账号 / 改钥匙）。点它从图标那儿**扩开**到全屏。
* 字号放大**五档都不溢出**，能点的地方**不小于 44 像素**。

### 6. 现在**还不能**用（如实说）

| 还不能 | 现在是什么样 |
|---|---|
| 手机安装包 | ❌ 还没有。**现在能用的是网页版** |
| 语音 | ⚠️ 还在做。屏幕上已经有那个形状了，但**是演示、没真的开麦**（`55-VOICE-DEMO.md`） |
| 短信登录通道 | ❌ 没接（现在用临时码） |
| 导出的东西里**没有**"它记在脑子里那一层" | 导出的末行**如实写着**这件事 |
| 容量上限 | ⚠️ 是写死的数，不是按磁盘算出来的 |

### 7. 它现在有多大

**一个人在做、一点点长起来的。欠的账明写着**（`docs/dev/00-PROGRESS.md` §六）。

### 8. 跟"光是聊天"最本质的一句

> **聊天机器人给你一段回答；琥珀给你一件事办完的结果** —— 它记得住、看得见、认账。

## 二、首页为什么这么排

### 五条设计原则（改文案之前先读）

1. **第一句就回答"这是什么"** —— 用**具体身份**（"替你办事的助理"），不用形容词；
2. **能力用"事情"说**，不用形容词（全篇没有"智能""强大""高效"）；
3. **先给"现在能用的"，再说"还不能用的"** —— 诚实，但别当头泼冷水；
4. **每块只有一个主题，小标题本身就是那句话** —— 扫标题就能懂；
5. **不许内部词、不许写做不到的事**（禁用词硬闸 + "说了做不到 = 撒谎"）。

### 版块顺序与它回答的问题

| 顺序 | 版块 | 回答用户心里哪一句 |
|---|---|---|
| 1 | 标志 + 小标 + **那句承诺**（手册原文） | 「这是个啥？」 |
| 2 | **它是一个替你办事的助理…** | 「跟聊天机器人有啥区别？」 |
| 3 | [开始用] + 「用手机号登录，第一次要花一点时间给它安个家」 | 「怎么开始？要什么？」 |
| 4 | **它能替你做什么**（四张卡：记 / 办 / 实 / 回） | 「具体能干嘛？」 |
| 5 | **跟聊天机器人不一样在哪**（对照四行） | 「凭什么是它？」 |
| 6 | **在哪儿用**（网页版在最前，安卓/苹果如实标"还没上线"） | 「我现在能用吗？」 |
| 7 | **你可能想知道**（六条 FAQ） | 「我还有几个担心的」 |

⚠️ **四张卡与对照块不许重复**：四张卡讲**"能做什么"**，对照块讲**"形态上的区别"**
（谁给你什么 / 记不记得 / 说不清时怎么办 / 东西放哪儿）。

### ⚠️ 排这一版时踩到的两条（留给下一个人）

1. **`scrollUntilVisible` 在内容变多之后会冲过头** —— 它一步 240px 地跳，卡片一多就跳过去了，
   然后报 `Bad state: No element`。⇒ 判据改成**一路滚下去、边滚边收**（"每一张都被画出来过"）。
2. **判据自己会"滚走"**：我在滚动之后才去查顶部那句提示 —— 而 `ListView` 已经把它回收了
   ⇒ 顶部的东西要在**滚动之前**查。
