> **主人 2026-09-29 原话**：*「帮我解压缩这个 zip，里面是一些壁纸，你在设置里，
> 帮我增加壁纸的选项。现在帮我分类，选项有模型设置，点开才是设置模型。
> 其他的也是列表中来做配置。包括壁纸。」*
>
> 追问之后他当场选的形状：**九项** —— 四把钥匙**分开**（模型设置 / 语音 / 图片 / 视频）
> ＋ **壁纸** ＋ **这块窗口** ＋ **关于 / 退出登录 / 注销账号**。
>
> 这一份说清：那一列**长什么样** · 壁纸**换的是哪一层**（以及哪一层不许动）·
> **判据** · **没做的**。

## 一、形状（两件事一起做的，分开说）

### 1.1 设置＝**一列分类**（不是一列配置）

```
设置（一列）
├─ 模型设置      ← 点开才是"填模型那一把"（原来四个 tab 里的「聊天」）
├─ 语音          ← 点开是那三样 ＋「试一下」＋「录一段」
├─ 图片          ← 点开是一串 ＋「试一张」
├─ 视频
├─ 壁纸          ← 点开是 28 格缩略图 ＋ 一格「不设」
├─ 这块窗口      ← 点开才是外观 / 字号
├─ 关于          ← 整页（那一页自带顶栏）
├─ 退出登录      ← 点一下就走
└─ 注销账号      ← 点开才是"先说清会没掉什么、再点一次确认"
```

🔴 **顶层只有名目**：每一行是**图标 ＋ 名字 ＋ 一句小字**（小字说的是**现在**：
"已经有了 / 还没有填"、"现在用的是哪一张"）。子页里那些正文**一句都不许**出现在这一列上
—— 判据里有一条负向对照钉着它（`settings_test.dart` ①）。

🔴 **子页左上角一行「回到设置」**：小程序容器**不画顶栏**（这是 `126` 定的），
而子页是 `push` 出来的**新路由** ⇒ 回程那一行**必须子页自己画**。
⚠️ 那一行同时是判据走"像用户那样切页"的入口（`goTab` 系列助手先点它）。

⚠️ **为什么把"四把钥匙分开"**：原来四个 tab 是**并排**的（`TabBar`），
主人这次要的是**列表**。"点开才是配置"这件事在两处形状上都成立，
但他点名的是列表 —— 而且列表在窄屏 + 大字号下**更好滚**。

### 1.2 壁纸＝**桌面那张底图**

```
桌面（铺满整屏）
├─ ★ 壁纸那一层（`_WallpaperBackdrop`）：图 ＋ 一层纸色罩（`d.wallpaperScrim`）
└─ 图标墙 ＋ 点击（原来那一套，一个像素没动）
聊天浮窗（贴在底部浮着）—— **不受壁纸影响**，还是 `design.dart` 那张暖纸
```

🔴 **三条不许破**（`08-SPEC.md` §6.1 的 Z5 照旧，壁纸只是**装饰**）：

| # | 不许 | 落在哪 |
|---|---|---|
| 1 | **不许接输入** | 那一层外面套着 `IgnorePointer`：点空白仍然是 `InkWell` 那一条路 |
| 2 | **不许说话** | 那一层里**一个字都不画**（只有 `Image` ＋ 罩色） |
| 3 | **不许改排布** | 图标墙的位置、列宽、命中区**一毫米不动**（壁纸在它下面一层） |

🔴 **罩一层纸色**（`design.dart` 的 `wallpaperScrim`）：壁纸是**用户自己挑的**
（深的、花的都有），而图标名字是**墨色**画的 ⇒ 没有这层罩，字会掉进图里。
⚠️ 半透明的**纸色**（不是黑、不是灰）：罩上去之后整块桌面还在同一套暖色里。

## 三、存哪、怎么认（`models/wallpaper.dart` ＋ `services/wallpaper_store.dart`）

* **一个 key**：`hupo_wallpaper`，存的就是那个 id（`wp-07` / 空串）。**按设备存**（同外观与字号）。
* 🔴 **认不出来一律当"不设"**：空串 / `wp-99` / `wp-1` / `WP-01` / 一个路径 / 一段中文
  —— 全部回默认那张暖纸。**偏好读坏了最多是回到默认底图，绝不能让桌面打不开**。
* 🔴 **`wallpaperLabel('wp-99')` 念的是"不设（默认那张纸）"**，不是"壁纸 99"
  —— 后者会让人以为盘上真有第 99 张。**这一条是判据当场抓出来的**（第一版就是那样写的）。

## 五、踩到的东西（都记下来，别重踩）

1. 🔴 **子页是 `push` 出来的新路由 ⇒ 它看不到上层 `setState` 的重建**。
   第一版只把 `appearance` 当快照递下去 ⇒ 在「这块窗口」里
   **14 →大一点→ 15，再按小一点 ⇒ 13**（而页面上那个数字还写着 14）。
   **那是"页面在说假话"**，判据（`appearance_test.dart` 那条"不重连"）当场抓住。
   ⇒ 修法：状态仍然只有一份，但改成 **`ValueNotifier`**（`_appearanceVN` / `_wallpaperVN`），
   子页用 `ValueListenableBuilder` **订阅**它（`settings_screen.dart` 的 `_live<T>`）。
2. 🔴 **子页不许用"列表那一页的 `context`"建**（`Theme.of(那个 context)`）。
   那一页被拆掉之后路由还会重建一次 ⇒
   **"Looking up a deactivated widget's ancestor is unsafe"**（判据收尾时抓到）。
   ⇒ 修法：`builder: (page) => _subPage(page, …)` —— 谁的孩子用谁的 `context`。
3. ⚠️ **子页要自己带一层 `Material`**（透明那一种）：路由是 `Navigator` 的孩子，
   **不在**原来那个 `Scaffold` 的 `Material` 里 ⇒ 壁纸那 28 格的 `InkWell`
   当场报 "No Material widget found"（按钮的水波也会没）。
4. ⚠️ **判据里的 `ensureVisible` 对"还没建出来"的行会当场抛**
   （顶层那一列是**懒加载**的，滚过之后上面那几行就找不到了）
   ⇒ 判据像用户那样 `scrollUntilVisible`（`goTab` 助手）。
5. ⚠️ **同类型的 `MaterialApp` 再 `pumpWidget` 一次不会拆掉已 push 的路由**
   （`Navigator` 的 state 被复用）⇒ "关掉这一屏"那一档判据要换一个 `key`。

## 六、没做的（**明说，不是"以后再说"**）

* **壁纸不改聊天窗口**：浮窗还是那张暖纸（要改的是另一件事 —— 它归 `119`）。
* **没有"从相册里挑一张"**：这一包是**主人给的那一批**，id 是序号，没有上传那条路。
* **没有深色档的一套壁纸**：暗色那一套本身还没做完（`settingsAppearanceDarkNotReady` 那句就是明说）。
* **子页没有转场动画**：`MaterialPageRoute` 的默认那个（与别处一致）。
* **`.webp` / 更小的整图没做**：源图是 jpg，2.9MB（28 张）＋ 381KB（缩略图）——
  包大一点，但它一次装进去就完了（不做动态下载）。
