# 229 · 跨用户联机 ＋ 媒体：**一个通用中央、一张接入规范、一套颗粒度**

> **谁问的**：主人 2026-10-09 连着三轮 ——
> ① *"如果我做一个中央服务器，用于用户 app 间的数据互换……两个用户可以下棋"*；

## 〇、一句话

中央只提供**原语**：**身份 ＋ 授权 ＋ 房间 ＋ 有序转发 ＋ 房间级少量共享状态**。
它**不认识任何棋**、**不跑用户代码**、**不解析内容**、**不持久化隐私**。
app 作者从**五种范式**里挑，写在清单里；**颗粒度**决定"他能不能只给麦、不给摄像头"。

## 一、五种范式（作者挑一种，清单里声明）＋ 三种权威

| 范式 | 形状 | 单向/双向 | 谁权威 | 典型用途 |
|---|---|---|---|---|
| **P1 `emit`** | 一方发 ⇒ 其他人收 | **单向** | 发送者 | 状态同步、观战、房主裁判 |
| **P2 `req/ack`** | 发一条 ⇒ 回一条 | **双向（成对）** | 中央配对 | 落子确认、入座、认输 |
| **P3 房间 KV `room.*`** | 共享文档 `set/patch/append/incr/claim` | 读写都双向 | **中央** | 棋盘、分数、轮次、房间设置 |
| **P4 私有 KV `seat.<n>.*`** | 每人一份，**别人读不到** | 只有本人读写 | **中央执行 ACL** | 手牌、身份、私有目标 |
| **P5 事件日志 `log`** | 只追加，中央给序号 | 单向 | **中央定顺序** | 棋谱、断线续、事后对账 |

房外还有两件：**中央的钟**（`clock`：谁超时谁输 —— 客户端的表一律不信）与**撮合**（`match`）。

**谁算规则 —— 三种权威，必须声明、而且在大厅名片上看得见：**

- **`host`**：房主客户端算。最简单，**能作弊但看得见**（熟人局）。
- **`atomic`**：平台不懂规则，但给**原子原语**（`claim`/`incr`/`cas`）⇒ 抢地主、抢庄、先手、计分这类公平性**建在它上面就够**。
  ★ 这是"通用"的真正来源：**不需要平台懂象棋，只需要平台能原子地判一次抢。**
- **`lockstep`**：双方跑同一份确定性逻辑，只交换输入；中央保证**输入顺序与广播顺序一致**。

## 二、KV 的语义（"什么类型的 KV"就住这儿）

| 项 | 定死成什么 |
|---|---|
| **键空间** | `room.<path>` · `seat.<n>.<path>` · `meta.<path>`（`meta` 只读，中央写） |
| **值的形状** | 只许 UTF-8 小 JSON（字符串/数/布尔/小数组/小对象）；**不许**二进制、不许文件、不许 base64 塞图（那走存储 ＋ 地址）；`NaN/Inf` 拒 |
| **五种写** | `set`（覆盖）· `patch`（浅合并）· `append`（只追加）· `incr`（计数）· **`claim`（原子抢，只有一个成功）** |
| **乐观锁** | 每次写带 `rev`；不匹配 ⇒ `conflict`（客户端重读再写，**中央不替它猜**） |
| **顺序** | 中央给每个房间一条**单调 `seq`**；广播／KV 变更／日志**都带它** ⇒ "谁先谁后"全世界只有一个答案 |
| **读** | `get`（回 `rev`/`seq`）＋ `watch`（订阅增量） |
| **生命周期** | 房间有 TTL；按人数/时长/键数/字节数设上限；**房间一散 KV 就没了**（默认不持久化）。要留结果 ⇒ **各写各的盒子** |
| **阈值** | **全住中央**（写进 `08-SPEC` §十），客户端不许自己定 |

## 三、接入规范（第一版：少而稳）

1. **端点挂在"小程序自己那个原点"上**：`wss://apps.stalkerai.cn/api/pvp`，子协议 `hupo-pvp/1`。
   🔴 这是最省事也最安全的一处：制品页 CSP 是 `connect-src 'self'` ＋ 声明过的站 ⇒
   **挂在它自己的原点上，CSP 已经覆盖，不用他再勾域名、不用放宽任何白名单**。
   ⚠️ 今天制品口上**一个 WebSocket 都没有**（实测 `app-live.js` / `app-serve.js` 里 `upgrade|WebSocket` 零命中）⇒ 这是第一条。
2. **握手**：出示平台令牌（与网页同源）＋ `appId` ＋ **制品指纹** ＋ 想干什么（`create` / `join:<code>` / `match`）。
   🔴 **中央自己从令牌认身份**；客户端**不许自称身份**（自称的一律不算）。
3. **消息集**（每条带 `v:1`）：`hello` · `joined{seat,room,seq,peers[]}` · `peer_joined` · `peer_left` ·
   `kv.set/patch/append/incr/claim` · `kv.changed{key,rev,seq,by}` · `emit` · `log.append` ·
   `clock{deadline}` · `ack{id,ok,code}` · `error` · `ping/pong` · `bye`。
4. **断线续**：重连票据 ＋ `since=<seq>` ⇒ 补增量，**不重不漏**。
5. **拒绝要给人话**：`no-permission` · `rate_limited` · `room-full` · `bad-app`（指纹对不上）· `conflict` · `too-big` · `expired`。
6. 🔴 **协议字段上线即冻结**（平台纪律）⇒ 第一版**宁少勿多**：宁可留一个 `ext`，也别事后改语义。

## 四、🔴 颗粒度：能力是**四元组**，不是一个名字

主人这次点名的就是这一条。今天的授权是"六个名字"（`db` 天生；`ask`/`net`/`camera`/`agent`/`tasks` 要他点头）。
**够不够？不够** —— 因为"能不能只给麦、不给摄像头"，现在的模型答不了。

每一样能力都拆成**四元组**：

| 面 | 问什么 | 例 |
|---|---|---|
| **方向** | 发 / 收 **分开授权** | `media.video.send`（给对方看）≠ `media.video.recv`（看对方） |
| **对象** | 给谁 | 只给**同 app 分会场里已配对的对手**；不给"任意在线用户" |
| **时长** | 到什么时候 | 房间散了就断；**通话中可逐项关**；`tasks` **不许**发起媒体（他不在场） |
| **可见性** | 对方能不能留 | 明确"**不许保存**"？——如实说：**做不到**（他那端能录屏）⇒ 只能写清"可能被对方录下" |

**能力表（提案）**：

| 名字 | 档 | 说明 |
|---|---|---|
| `db` | 天生 | 自己那一格库 |
| `ask` / `net` / `camera` / `agent` / `tasks` | 点头 | 今天那五样 |
| `peers` | 点头 | **能被连**（握手要它） |
| `lobby` | 点头 | **能被找到**（进分会场名单） |
| `media.audio.send` / `.recv` | 点头 | 语音通话（**麦**今天是壳在用，小程序没有这一样 ⇒ 新增） |
| `media.video.send` / `.recv` | 点头 | 视频 |
| `media.screen.send` | 点头 | 共享屏幕（更敏感，**最后做**） |

**组合矩阵（"逐样都合理、合起来就是木马"）**——这些组合**单独再问一次**，或第一版**一律不给**：

| 组合 | 它意味着什么 |
|---|---|
| `camera` ＋ `net`/`peers` | **把你这台看到的传出去** |
| `tasks` ＋ `net`/`peers` | **你不在场时传出去** |
| `media.*.send` ＋ `tasks` | 你不在场时开摄像头/麦 —— **一律不许**（硬规则） |
| `agent`/`ask` ＋ `net` | 借你的助手把东西问出来再发走（今天每次调用都留痕，但仍要频次与额度） |

## 五、视频通话：它会**逼出一个结构决定**

技术上只有一条路：**WebRTC**（1:1）＋ **我们的 PvP 通道当信令** ＋ **TURN 兜底**（对称 NAT 下必然用得上 ⇒ **还是要中继，省不掉**）。

两条**硬前置**（⚠️ **我都没核过**，是"开工前必须先量"的两条）：

1. **不透明源沙箱里 `getUserMedia` 能不能用。** 今天的制品是 `<iframe sandbox="allow-scripts">`
   —— 不透明源（`Origin: null`），而 `getUserMedia` 要安全上下文和权限策略。
   ⇒ **可能根本起不来**。这一条没量之前，"小程序自己做视频"这句话不算数。
2. **要不要给 app 一个自己的源**（`<id>.apps.stalkerai.cn`）——
   这正是 `B51` 里等你拍的第 ② 点（泛域名证书 ＋ 按 Host 路由 ＋ 每 app 配额）。

⇒ 于是有两条路，**我建议乙**：

| | 甲：app 自己做 | **乙：壳代做（建议）** |
|---|---|---|
| 媒体在哪 | 小程序沙箱里 `getUserMedia` ＋ 建连 | **壳**采集 ＋ 建连 ＋ 传输；**小程序只是发起入口** |
| 与"禁原生桥"的关系 | 要给沙箱开设备能力（新口子） | **不冲突**（是平台在自己这一侧做，不是给 app 开桥） |
| 颗粒度落点 | 每样要分开授权（方向×对象×时长） | 授权在**壳**这一层，app 拿到的是**受控的"通话中"这一格** |
| 前置 | 那两条硬前置都得过 | 只依赖壳（今天壳已经在用麦做语音输入 ⇒ 有先例） |
| 代价 | 每个 app 一份媒体实现 | 它**不是小程序了**，是**平台内置的一格**（同"内置那几屏"） |

**成本要如实说**：视频 ≈ 每人 1–2 Mbps 量级（按实测为准）；1:1 尚可，多方要 SFU（**那是另一个量级的东西，第一版明说不做**）。盒子（1536MB / 4 CPU）**不参与**媒体 —— 连上来的是浏览器，盒子不联网。

## 六、木马：今天最便宜的那条路是"**换版**"（不是传输层）

木马要成事需要：**① 秘密的来源 ② 出去的路 ③ 他不在场的时机**。

**沙箱已经把 ① 砍得很小**（实测/手册事实）：不透明源读不到壳的 DOM／localStorage／令牌 · 无原生桥 ·
跨 app 的库两道堵死 · CSP `default-src 'none'` ＋ `connect-src 'self'`（＋声明过的站）· 表单/`base` 禁 ·
没有 `media-src`/`font-src`。⇒ **它没有"值钱的东西"可偷**，除非他亲手给（打字/拍照）或给了 `agent`/`ask`（那两样每次看得见）。

**② 与 ③ 今天最便宜的一条是更新那一步**，而且这是**你拍过的两条决定**的结果（不是 bug）：

| 事实 | 出处 |
|---|---|
| 装 ＝ fork（装上来是他自己那份）；**升级默认"按用户整体跟"**（留旧版要显式设置） | `D4.24` **C3**（`docs/dev/161-OWNER-DECISIONS-11.md`）· 闸 `scripts/check-publish-run-upgrade.sh` 判据 ⑦ |
| **契约版逐字相同 ⇒ 整版换字节、不请 AI** | `D4.24` **C1** · `src/app-upgrade.js`（`byte-swap` 的定义）· 手册 §5.8（正开着的那一屏会自己换上） |
| **下架只把那一格改成"没上架"，别人手上那份还在** | 手册 §5.7 |
| 署名是**可换可弃的假名**（带键 HMAC，存量只读） | 手册 §5.7 |

⇒ **木马的路**：先交一个干净的五子棋拿到 `peers`/`net` ⇒ 再把**同一契约**的实现换成木马 ⇒
他那边**默认跟新**、**不再问他一次**。⚠️ 如实说：这一条**我没抓真机读数**（读的是判定、账与手册的定义）。

**该加的五道闸**（按性价比）：

1. 🔴 **带能力面的 app，换版要他点一下。** 窄例外：`peers`/`lobby`/`net`/`camera`/`tasks`/`agent`/`media.*` 只要声明了其中任何一样 ⇒
   **换版必须他点头**（"这一版换了实现，装不装"）。纯本地的照旧静默换（判据 ⑧ 的"不过度"仍然成立）。
2. **清单里写"行为面"**（`pvp:{paradigm,seats,authority}` · `net` 域名 · `tasks` 频率 · `media` 哪几样）——
   今天新**声明**会变成 `unanswered`（这条已经对）；**实现偷偷变**要靠第 1 条。
3. **组合矩阵**（§四）。
4. **PvP／媒体的行为把关**：只碰**元数据**（谁跟谁、几条、几字节、多久）＋ 限额 ＋ 阈值告警 ＋ **当场剪断**。
   🔴 **做不到的别假装**：**隐蔽信道堵不死**（棋子落点与时间本身就是比特），中央也**不解析内容**。
5. **召回**（今天没有）：被下架的那一版 ⇒ 他手上那份**下次打开被拦下并说明原因**。

## 七、判据总表（都能真跑，每条带反例）

| # | 判据 | 反例/负向对照 |
|---|---|---|
| 1 | **原子性**：20 个并发 `claim` 抢同一个键 ⇒ **恰好 1 个 ok** | 放开串行 ⇒ 多个 ok 当场红 |
| 2 | **一致性**：两边看到的 `seq` 逐条相同；乱序注入 ⇒ 按 `seq` 渲染 | 按到达顺序渲染 ⇒ 红 |
| 3 | **私密性**：A 读 B 的 `seat` ⇒ 拒；**广播里从没出现过** B 的私有键 | 把 seat 塞进广播 ⇒ 红 |
| 4 | **身份**：广播 JSON 里逐字不含 `sub`/手机号/地址/令牌 | 抽掉一个字段的过滤 ⇒ 红 |
| 5 | **授权**：没 `peers` ⇒ 握手拒；关开关 ⇒ **当场剪断**、两边各自收场如实说 | 只判握手不判在线 ⇒ 红 |
| 6 | **限额**：一个"五子棋"打到 500 条/秒 ⇒ `rate_limited` 一句人话 ＋ 留一行痕 | 静默丢 ⇒ 红 |
| 7 | 🔴 **换版**：同契约版换实现 ⇒ **必须出现"要他点头"那一步** | ⚠️ **今天会红** —— 这就是要的那条复现 |
| 8 | **组合**：只给 `camera`、不给 `net`/`peers`/`media.*.send` ⇒ 拍到的内容**发不出去** | 给上 `net` ⇒ 红（说明这道闸真的在拦） |
| 9 | **不落盘**：通话/对局结束后，媒体与消息**不进**日志、时间线、助手上下文 | 往助手那一轮塞一条对端消息 ⇒ 红 |
| 10 | **召回**（做了才有）：下架 ⇒ 他手上那份**下次打开被拦** | —— |
