## 四、⚠️ 对不上的地方（**这三条是真欠账，不是"排后"**）

### 4.1 ✅ S2 状态取号：**已修**（`08-STATUS.md`）

```
服务端  dispatcher.js:238   emitTransient({ type:'message/status', messageId:'', state })
客户端  timeline.dart:216   _findMessage('')  → 恒 null → 直接 return
客户端  全文没有任何地方**读** message.status
```

⇒ 修完了。**而且不是"补个 id"** —— 量过之后发现那个地址**没有可能的值**
（DSH 的 `session.status` 都落在消息生命周期之外），所以地址改成了**轮**。
屏幕上现在真的有一行「它正在做这件事…」，公网实测比第一个字**早 2.1 秒**。

⚠️ 顺带补掉一个洞：`forceClose` 原先**看不见"一轮开了、一个字没说"的轮**
（它只找有 writer 的），于是那种轮**永远不说话、也永远删不掉**。见 `08-STATUS.md` §三。

### 4.2 ✅ v2 的安卓包**没有 `INTERNET` 权限** —— **已修**（第 ② 条）

```
v2/apps/mobile/android/app/src/main/AndroidManifest.xml   ← 0 条 uses-permission
android/app/src/debug/…   ← 只有这里和后两个有 INTERNET
```

⚠️ **旧 app 修过一模一样的 bug**（commit `3084b37`），**新 app 又犯了一遍**。
⇒ 现在打出来的 release APK 装上去**没有网**，而且现象只是"它连不上"。

**为什么值得单独记一笔**：`AGENTS.md` §三 说"旧代码只当参考"，
但**`07-APPENDIX.md` §一 那份缺陷清单是"不许再出现"**——
它得**逐条对着新代码核**，光"新写一遍"是不够的。**这一条就是漏核的结果。**

**修法与"防第三次"**（⚠️ 一个坑踩两次，就说明缺的不是注释而是闸）：

| 层 | 做了什么 | 什么时候跑 |
|---|---|---|
| 源头 | `main/AndroidManifest.xml` 加 `INTERNET`，并**把"这里栽过两次"写进注释** | —— |
| **闸（快）** | `test/unit/android_manifest_test.dart`（3 条） | 每次 `flutter test test/unit` |
| **闸（真）** | `scripts/check-apk.sh` —— 从**打出来的包**里 `aapt2 dump permissions` | 发版前 |

⚠️ **为什么两层都要**：源文件对**不等于**包对——权限会被 ManifestMerger 合并、
被库 manifest 注入、被 `tools:node` 覆盖。**交付出去的是包。**
而快闸管的是"平时别改回去"，慢闸管的是"这一版真的对"。

**实测**：
```
$ bash scripts/check-apk.sh
    uses-permission: name='android.permission.INTERNET'
  ✓ INTERNET 在
  ✓ 没有后台录音权限
  · 没有 RECORD_AUDIO（语音是批 5；到那时 V10 要求它**必须**在）
✅ 通过
```
外加**负向对照**：拿一个不是 APK 的文件去，它**拒绝通过**（不是静默放过）——
手册 §13.1「负向对照不能省」是同一个道理。
以及**变异验证**：把源码里那行删掉，快闸当场变红。
