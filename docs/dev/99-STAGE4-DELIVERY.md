# 99 · 阶段 4：**一对一交付，只建登记面**（不建真传输）

> 依据：`92-TRIPLE-PLAN.md` §③ 阶段 4（依赖阶段 1／2／3，**都已落地**）＋
> `91-TRIPLE-CONTRACT.md` §六（一对一那条路的四步与全部判据 `6.1.1`–`6.4.4`）。
> 本篇只写**这一阶段要建什么、判据是什么、以及一条最要紧的诚实边界**。

---

## 一、这一阶段建什么（**四步的登记面**，就这四件）

```
① 索要（request）  要哪一份 · 哪个形状版本 · 哪个范围／时段 · 拿去做什么   → 落一条【请求】
② 同意（consent）  **只读他当轮自己说的那句话**；逐项：哪一份/哪个形状版本/哪个范围 → 落一条【同意】
③ 交付（deliver）  这一阶段**只登记"该交了"**（真搬运不在这一阶段）           → 落一条【交付】
④ 撤回（revoke）   给的人随时能撤；撤回后**未来的请求一律拒**                 → 落一条【撤回】
```

🔴 **最要紧的一条诚实边界**（否则这一阶段会自己造一句假话）：

> **"落了一条【交付】记录" ≠ "对方收到了"。**

这一阶段**没有传输**。⇒ 任何回执、任何给用户看的话，**只许说这边真的发生了什么**：
"记下了要给你这份"／"你同意了"／"这一版还没有把东西送过去的路"。
**不许**说"已经给他了""对方那边有了"——那是**声明 ≠ 事实**（`92` 纪律），而且今天根本做不到。
⇒ 判据里有一条专门打它（**S4-5**），文案表也在判据里扫。

---

## 二、落哪、怎么落（**照现有形状，不新造第二套**）

- 落在**这个人自己的**账上（与 `ledger.jsonl` / `pending.jsonl` 同一种做法：**只追加**、带 `at`）；
- 🔴 **P-l**：**同一条可见日志、同一套编号**（多作用域只是事件上的标签）—— 一行一个事件，
  `type` 形如 `delivery/request` · `delivery/consent` · `delivery/deliver` · `delivery/revoke`；
- 每一条都带：**谁对谁**（`from`/`to` 两个人格 key，**不许**把手机号写进去）· 哪一份（`packId`）·
  `shapeVersion` · `range`（可空）· 「为什么」（人话，来自他当轮那句话）· `at`。
- **不许**在这一阶段造"数据包"的第二种存储。

---

## 三、判据（每条都要能反着验 · 全在 `test/` 里）

| # | 判据 | 反例（必须红）|
|---|---|---|
| **S4-1** | **四步都留痕**：一次完整的"请求→同意→登记交付→撤回"在盘上**四条都查得到**，而且能列出来 | 少任何一条 ⇒ 红；只在内存里 ⇒ 红 |
| **S4-2** | 🔴 **无同意 ⇒ 交付失败**（fail-closed）：没有可识别的【同意】就**不许**落【交付】 | 助手自己判断"他应该会同意"⇒ 落了【交付】⇒ 红（照 `apps-consent.js` 的保守默认）|
| **S4-3** | 🔴 **同意只读"他当轮自己说的那句话"**：请求里带什么字段都不算（`agreed:true` 不算） | 请求里写 `agreed:true` 就放过去 ⇒ 红 |
| **S4-4** | 🔴 **同意逐项**：哪一份 · 哪个形状版本 · 哪个范围 **三项都要有** | 一次泛泛的"行吧"就把**全部**数据放出去 ⇒ 红 |
| **S4-5** | 🔴 **回执如实**（这一阶段的核心）：文案里**不许**出现"已删除""已经给到对方""对方那边有了"这类断言；**要说清这边真的做了什么** | 说"已经删干净了"／"对方收到了" ⇒ **页面在说假话** ⇒ 红（扫文案表）|
| **S4-6** | 🔴 **撤回后新请求 ⇒ 拒**，而且**撤回这件事本身落盘** | 撤回后还能再交一份 ⇒ 红；撤回只是"界面上一个开关"、盘上无据 ⇒ 红 |
| **S4-7** | **请求必须指形状版本**：没有 `shapeVersion` ⇒ 拒 | 拿到一份"形状对不上的值"还静默算对 ⇒ 红 |
| **S4-8** | **算不出就如实标「不可算」**：比如"对方那份还在不在"今天**没有信号** ⇒ 回执里写**不可算**，**不许**安静地写成"已删除" | 没有信号却给一个确定的答案 ⇒ 红 |
| **S4-9** | **四步是唯一的路**：数据包**只能**从这四步出去（这一阶段：**没有任何一条路能把字节带出去**） | 共享库／发现页／制品口／随装复制里出现数据包的字节 ⇒ 红（阶段 3 的闸已经管住前三条，这里补"随装复制"那一条）|

> 🔴 每条都要**变异验证**（把实现改回错的形状 ⇒ 那条判据当场红），变异命令与读数写进报告。
> 🔴 **判据打在真调那条路**上（不是自己算一遍）：照 `apps-consent.js` / `outbound.js` 那套接线来。

---

## 四、明确**不做**的

1. **不做真传输**（不建"把那份数据复制给对方"的路）——这一阶段只有登记面；
2. **不做界面**（"索要/同意/撤回"的按钮与流程是后面的事；今天它们只在对话里、由服务端读他当轮那句话）；
3. **不做结算**（钱的账是 `95-PAID-LAYER.md` 那条线，且主人拍的是"先只做授权+结算的账，不碰真钱"）；
4. **不动**阶段 3 的出界闸、不动锚那套、不动 `apps-consent.js` 的既有语义（只**复用**它的保守默认）；
5. **不许**把"版权保护"写成能力：这一阶段换来的是**留痕**，不是保护 —— 文案里不许出现"保证不再扩散"。
