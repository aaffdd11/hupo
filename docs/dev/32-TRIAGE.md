## 三、⚠️ 判"砍"的两条为什么值得单独拿出来

* 手册 §十一 的原话：**"要砍就明说砍了"**。留着不砍的代价不是"多一张待办"，
  而是**每次改客户端/改架构都要为它留一条岔路**（iOS 那个平台分叉尤其贵）。
* 但**判据是不能自己改的**（`docs/handbook/**` 是 `strict`）⇒ 这两条**只能建议，不能执行**。
  ⇒ 主人一句话就能落：**"砍"** 或 **"留着，排到 X"**。两种都行，**唯独"先放着"不行**。
