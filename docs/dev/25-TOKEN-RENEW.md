## 一、两个窗（⚠️ 我改过我自己那张表里的一个数）

| | 值 | 为什么 |
|---|---|---|
| **空闲窗** | **180 天**（= 今天的 TTL，**不倒退**） | ⚠️ 我一开始给主人的表里写的是"30 天没用就过期"——**那会装回 D2 好不容易去掉的东西**：D2 把 TTL 从 30 提到 180，理由正是**那位不会拼音的用户不能被反复要求登录**。⇒ 空闲窗和今天一样 |
| **绝对上限** | **365 天**（新增） | 它**只有一个用途**：给"**令牌被盗**"一个止损点。一直用就一直续 = 永远不过期，所以必须有天花板。一年重新登录一次是普通人能接受的频率（30 天不是） |

两个数都在 `auth.js` 里**具名 + 写清理由**（`TOKEN_IDLE_WINDOW_MS` / `TOKEN_ABS_CAP_MS`）。

## 二、怎么做到"不动 `verify()` 一行"

续期**只把 `exp` 往前挪**，`iat` / `jti` / `sub` **都不动**：

```
签发：  iat = 现在        exp = min(现在 + 空闲窗, iat + 上限)
续期：  iat 不动          exp = min(现在 + 空闲窗, iat + 上限)     ← 从**现在**算
```

* **绝对上限靠 `exp` 封顶**实现 ⇒ `verify()` 里那句 `exp <= now` **一个字没改**
  ⇒ **协议字段的语义没有变**（`03-DEVELOPMENT.md` §三：上线即冻结）。
* **`jti` 不动** ⇒ 撤销它，新旧两份**一起作废**（不会留下一个"续出来的野令牌"）。

⚠️ **踩过的坑（测试当场抓住）**：第一版把 `exp` 算成"**相对 `iat`**"——
那意味着"续期续出来的 `exp` 和原来一模一样"，**等于没续**。
⇒ 滑动那一项必须从**现在**算，封顶那一项才从 `iat` 算。

## 三、契约

```
POST /api/renew      authorization: Bearer <当前令牌>
  200 → {"token": "<新的>", "expiresAt": …}
  401 → {"error": "expired"}        （过期 / 被撤销 / 过了绝对上限）
```

⚠️ **`/api/renew` 不是公开路由**：`PUBLIC_ROUTES` 仍然**只有三个**
（`/api/version`、`/api/auth`、`/api/login`）—— 有一条测试专门钉这件事，
免得下一个人顺手把它开成公开（那等于谁都能换一个令牌）。

## 四、客户端的规矩（那半边）

* 续成功 ⇒ 存新令牌、用它；
* **401 ⇒ 这才是"令牌真的不行了"**：清令牌 + 回登录页（这条路上清是**对的**，B1 的纪律说的是"**网络失败不许清**"）；
* **网络问题 ⇒ 一个字节都不许清**，拿旧令牌照常往下走；
* ⚠️ 续期**不许挡在"先画本机一屏"前面**（`17-LOCAL-FIRST.md` 的教训）：要等网络的事，不能拖住冷启动那一屏。

## 六、客户端那半边（已齐）

* 顺序**钉死**：**先画本机一屏 ⇒ 再续期 ⇒ 再连流**（续期要等网络，**不许**拖住冷启动那一屏）。
* 四档语义（纯函数，逐档有闸）：`200 可解析` ⇒ 用新令牌；`200 坏回执` ⇒ **不入库也不清**；
  **`401` ⇒ 清令牌 + 回登录页**（唯一该清的情形）；`其它/抛异常` ⇒ **一个字节都不许清**，拿旧令牌照常走。
* 挂点是 `ChatController.start()`（每次 start 都续）——**不是**只在 `_boot()`：
  它是 `_boot` 与 `_onLoggedIn` 的**唯一咽喉**，将来任何新开机路径都自动带上；
  代价是"刚登录成功也多一次续期往返"（服务端只是把 `exp` 重算一遍，等于没变）。
  ⚠️ 这是**刻意的取舍**（漏续的代价 >> 多续一次的代价），记在这里免得下一个人以为是漏了。

## 六·补、⚠️ 客户端的验收到"看得见"为止

"12 条单测绿了"只能证明**代码对**，证明不了"**装出来的那个页面上真的续了**" ——
而它的失败是**静默的**（拿旧令牌照样能连，只是半年后某天会被踢出去）。

⇒ 给 `scripts/check-web-browser.mjs` 加了一条**看得见**的判据：
**App 有没有把 localStorage 里那个令牌换掉**。真机结果：

```
续期       ✅ 令牌**被换新了**（App 开机续了一次）
页面里建过的 WebSocket：1（断过 0）｜ 收到的帧：75
✅ 浏览器那条路通了（https://w.stalkerai.cn/）
```

⚠️ 三档都**如实报**：换新了 ✅ / 被清掉了（401 那条路）⚠️ / 值没变（续期没发生或失败后留着旧的）⚠️。
