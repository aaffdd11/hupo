# 130 · **app 的图标**（主人给的那张琥珀气泡）

> **主人 2026-09-28 原话**：*「用这个做 app 的 icon」*（附一张 2048×2048 的图：
> 一个发光的琥珀色对话气泡，里面一群星星，底色深蓝）。
>
> 这一份说清：**哪几张图要换** · **怎么从那一张变出来的**（含安全区与水印那两条）·
> **判据** · **没做的**。

## 一、换了哪些（一处都不能漏）

| 落在哪 | 是什么 | 谁看得见 |
|---|---|---|
| `android/app/src/main/res/mipmap-{mdpi,hdpi,xhdpi,xxhdpi,xxxhdpi}/ic_launcher.png` | 传统启动图标（48/72/96/144/192） | 老启动器；新系统只在没有自适应图标时才用它 |
| 同目录 `ic_launcher_foreground.png` | **自适应图标的前景**（108dp 那套：108/162/216/324/432） | 安卓 8+ 的桌面（系统按厂商形状裁） |
| 同目录 `ic_launcher_round.png` | **圆形**那一套（每个密度一张） | 点名要圆图标的启动器（`android:roundIcon`） |
| `mipmap-anydpi-v26/ic_launcher.xml` · `ic_launcher_round.xml` | 自适应图标的声明（前景 ＋ 底色） | 同上 |
| `values/ic_launcher_background.xml` | 底色 **#0E101F**（**从源图左上角取的**，不是我瞎配的色） | 同上 |
| `web/favicon.png` · `web/icons/Icon-{192,512}.png` · `Icon-maskable-{192,512}.png` | 浏览器那一栏、加到桌面那一个 | **所有人**（不用装包） |

⚠️ `deploy-web-v2.sh` 会把 `v2/apps/mobile/web/` 一起发出去 ⇒ 网页那四张**部署一次就换**；
安卓那几张要**重新打包**（`scripts/publish-apk.sh`），他手机上才会变。

## 二、怎么从那一张变出来的（`scripts/make-app-icons.py`）

```
源图 2048×2048
  └─ ① 按"主体（亮部）"裁紧 → 1718×1718（**水印落在框外**，见 §三）
       └─ ② 传统图标 5 档（原样缩）
       └─ ③ 圆形那一套 5 档（同一张，按圆裁，圆外透明）
       └─ ④ 自适应：把主体**按亮度抠出来**（软的 alpha 斜坡）⇒ 前景 5 档，
             缩到画布的 **62%**（108dp 里那 66dp 的安全区，再留一点余量）；
             底色 = 源图左上角的中位数
       └─ ⑤ 网页：favicon（64）＋ PWA 普通/可蒙版（192/512；可蒙版那张也是"底色铺满 ＋ 主体 62%"）
```

🔴 **两条必须守的**：

1. **安全区**：安卓会把自适应图标**裁成圆/方/水滴** ⇒ 主体只占 **62%**。
   不留的话，圆角一裁就切到气泡的边。
2. **水印一个像素都不许进图标**：源图**右下角**有"元宝 AI生成"那行字。
   裁紧之后它在框外（实测：水印亮部 `(1832,1891)-(1992,1984)`，
   裁剪框 `(166,125)-(1884,1843)` ⇒ **y 不重叠**）。判据钉着图标的右下角那一块。

⚠️ **依赖 Pillow**（`python3 -c "import PIL"` 本机是好的）。这不是 Flutter 那边的依赖 ——
那个脚本只在"换图标"时跑一次。

## 三、判据

| 在哪 | 钉住了什么 |
|---|---|
| 新 `test/unit/app_icon_test.dart` **5 条** | ① 五档都在、尺寸对（从 PNG 头读，不解码）② **不是 Flutter 模板那五张**（sha256 钉着模板的值，改了模板就红）③ **自适应那一套在**（两层 drawable ＋ 底色是合法颜色 ＋ 前景五档 ＋ **圆形那套 ＋ 清单里 `android:roundIcon` 指着它**）④ 🔴 **解出像素来数**：暖色（`r > b+40 且 r > 120`）必须占 **>25%** —— 模板那张是蓝的（0%）⑤ 🔴 **右下角 15%×15% 那一块里不许有亮像素**（水印就住在那个方位） |
| `scripts/check-apk.sh`（＋图标那一条） | **从包里核**（源文件对 ≠ 包对）：release 构建里 AAPT2 会把资源文件**改名**（`res/o-.png` 这种），**而且有了自适应图标之后** `badging` 的 `application-icon-640` 指的是一个**编译过的 XML**（`res/BW.xml`，二进制 AXML，解不出像素）⇒ 改走**资源表**：`aapt2 dump resources` 里资源**名字**还在 ⇒ 从 `mipmap/ic_launcher`（xxxhdpi 那一档）拿到真正的 PNG，解出来数暖色比例（阈值 25%）。⚠️ **负向对照实测过**：换图标**之前**那一个包 ⇒ **同一个路径** `res/o-.png` · 192×192 · 暖色 **0.0%**（模板那张蓝的）⇒ 这条会红；换完之后同一个路径 **54.9%** ⇒ 绿 |
| `test/unit/android_manifest_test.dart` | 桌面名字是「琥珀」（上一批加的）；清单仍是合法 XML（注释不许住进标签里） |

**跑法**：

```bash
python3 scripts/make-app-icons.py <源图>          # 换图标（一次性）
cd v2/apps/mobile && ~/sdk/flutter/bin/flutter test test/unit/app_icon_test.dart
bash scripts/publish-apk.sh                       # 重新打包 + 发到首页（顺带从包里核图标）
bash scripts/deploy-web-v2.sh                     # 网页那四张
```

## 四、如实说（没做到 / 没验到的）

| # | 事 |
|---|---|
| 1 | **iOS 那套图标没做**（`ios/Runner/Assets.xcassets/AppIcon.appiconset/`）：本机没有 Mac、也没在编 iOS —— 真做 iOS 那天要用同一张图生成 15 种尺寸 |
| 2 | **安卓 13+ 的"主题图标"（monochrome）没做**：系统会拿单色版去配合壁纸取色，我们没有那一层 ⇒ 开了主题图标的人看到的还是我们这张彩色图（不算错，只是没跟随） |
| 3 | **真机上"桌面那一格长什么样"没看过**：判据量的是"包里那张图是不是暖色的琥珀"，**排版好不好看他眼睛说了算**（裁得紧不紧、圆角裁完还剩多少） |
| 4 | **源图本身是 AI 生成、右下角带水印**：我们裁掉了水印，但**没有那张图的其他来源** —— 要换一版得他再给一张（或允许我们重画） |
| 5 | **自适应前景是"按亮度抠"的**：气泡外面那圈光晕会跟着留一点点半透明（在深蓝底上看着自然）；换个浅色底的启动器（主题图标那种）可能会看出来 |

**明确没做**：iOS 图标 · 单色/主题图标 · 启动画面（splash）那张图 · 应用商店的 512×512 宣传图。
