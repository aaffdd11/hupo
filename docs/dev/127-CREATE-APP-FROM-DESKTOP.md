## 一、屏幕上多出来的一格

桌面图标墙的**最后一格**：**空心加号 ＋ 「创建小程序」**（`createAppLabel`）。

- 🔴 **长相上与别的图标明显分开**（主人：*"要比较显著的有 UI 上面的区分"*）：
  **没有那张白卡、也没有阴影**（别的图标都是有白卡 + 影子的方块），图形是**加号**、
  比别的图标大一点（它没有名字可认，全靠形状）。线上实拍：
  [`127-raw/desktop-plus-tile.png`](127-raw/desktop-plus-tile.png)
  —— 图标墙末尾那一格就是它：**[＋ 创建小程序]**。
- ⚠️ 命中区仍是整格（`desktopIconBox` ≥44，D3.6）—— 图形大小不影响它。
- ⚠️ 那一格**没有菜单**：不改名 / 不复制 / 不从桌面删（三样都是"东西已经有了"才有的动作）。
- ⚠️ **它只长在桌面上** ⇒ 小程序容器一开就把整页盖住，进了小程序**点不到它**
  （"里面不能再建一个"在**看得见**这一侧就成立）。

点它 ⇒ **一层浮窗**（`AlertDialog`，形状与改名那一层同源）：**名字（必填）＋ 描述（选填）**
＋ 两个按钮（`建好` / `算了`）。描述那一栏的标签上**就写着"可以不写"** —— 不许让他猜。
线上实拍：[`127-raw/create-dialog.png`](127-raw/create-dialog.png)。

## 二、建成之后是什么

**一个空白项目 ＋ 一个桌面上的一格**：那张卡片自己长出来（界面**重拉清单**，不自己拼），
点它就能进去；进去看到的是那个**占位页**（`这里还空着。`）——

🔴 **"空白"不等于 404**：建出来的是**工作区 ＋ 登记**（`registerBlankApp()`），
工作区那个 `index.html` 由 `ensure()` 的**占位页**填上（`placeholderIndex`）。
⇒ 点进去看得见一个空页面，而不是浏览器的 404。

⚠️ **不打成包**（`114`：*"所谓的版本快照，只在市场中存在。不在用户端。"*）：
建成之后助手（或他）在那个目录里写文件**就是部署** —— 屏幕上就是新的。

## 三、那一条口（`POST /api/app-create`）

| 项 | 规矩 |
|---|---|
| 请求 | `{title, description?}`（都要令牌；身份只从令牌来） |
| **名字** | **必填**：空 / 只有空白 ⇒ **400 ＋ 一句人话**；超上限（`MAX_TITLE_CHARS`）⇒ 400 |
| **描述** | **选填**：不填 ⇒ 存空串；超上限（`MAX_DESC_CHARS`）⇒ 400（"一句话就够了"） |
| **短名** | **服务端生成**（`newAppId()`：`app-<随机>`，撞了再抽、有界重试）。⚠️ **名字里的中文不"音译"成 id** —— 那是编 |
| **图标** | 服务端按名字自动配一个（`resolveIcon`），回执里**带上最后配的那个**（不然界面说不出实话） |
| 回执 | `{ok:true, id, title, icon, description}`；认不出 / 越界 ⇒ 400/404 ＋ 一句人话 |
| 落点 | **以盒子为准**：租户这一下经隧道在他**盒子里**落（`/internal/app-register` → `registerBlankApp()`）；盒子不通 ⇒ **如实 503**，绝不退回宿主那份 |

⚠️ 与 `/api/app-rename` / `/api/app-copy` 同一个形状（宿主 → `appsFor(sub)` → 盒代理 → 盒里那条内部口），
**协议只加不改**：老客户端不认识它，照旧。

## 四、🔴 "只有 main 里面可以指导它创建小程序"落在哪

主人那句话有两半，**落在两个地方**：

| 谁在建 | 闸 | 在哪 |
|---|---|---|
| **他自己**（那颗加号） | 那颗按钮**只长在桌面上** ⇒ 进了小程序就点不到（结构上） | `screens/chat_screen.dart` 的桌面那一格 |
| **助手**（工具 `app_create`） | **"现在这一间是不是已有的一个小程序 / 内置那一格"** ⇒ 拒，并回一句人话 | `apps-socket.js` 的 `create`（判据 `isAnAppRoom`） |

🔴 **判据不是 `scope !== main`**，而是"**这一间已经是一个小程序了**"：
主人还说了 *"main 里面也可以指导它，让它创建小程序"* —— 而**派活那间**
（长活"另开一处做"，`job.js` 抬头上写着它自己会调 `app_create`）本来就要在那里
把新 app 造出来，**那条路照旧放行**。`main` 与派活那间 ⇒ 放行；小程序 / 内置那几格 ⇒ 拒。

拒的时候说的是人话（模型原样转述给他）：
`小程序里面不能再开一个小程序。回桌面上说一句"帮我做一个……"，我在桌面上给你造。`
⚠️ 它进 `APP_FAIL_QUIET_REFUSALS`（**不额外喊一条"没做成"**：那句话本身就是答复）。

## 五·补、线上读数（2026-09-27 部署后当场做的）

```
POST /api/app-create  {title:"临时验收小程序", description:"这条是助手当场验的，马上删"}
⇒ {"ok":true,"id":"app-0nhabfhz","title":"临时验收小程序","icon":"document",
   "description":"这条是助手当场验的，马上删"}
GET  /api/apps       ⇒ 它在清单里：icon=document · description 在 · entryUrl 有（现签）
POST /api/app-remove ⇒ {"ok":true} ⇒ 再问一次清单：**没有它了**（痕迹清干净）
```

⚠️ **那一条是"当场验完就删"**（他桌面上不留助手造的东西 —— 与"明说才许写"同一条纪律）。
⚠️ 那一次建出来的**图标是 `document`**（服务端按名字自动配的）—— 回执里如实带回来了。

## 六、如实说（没验到的）

| # | 事 |
|---|---|
| 1 | **手机上的手感没验**：那颗加号在真机上多大、那一层浮窗在 3.1 倍字号下滚不滚得动 —— 判据量的是 VM（可访问性那道硬闸扫的是**五档**，不是真机） |
| 2 | **描述只"存下来"**：它进了清单（`/api/apps` 与 `list()` 都回它），但**屏幕上暂时没有一处显示它**（桌面上只有名字）。👉 它的用处是"这一间是干什么的"，接下来要接到**助手那一侧的口径**上（现在还没接） |
| 3 | **空白项目进去之后**：那一屏是占位页（`这里还空着。`）—— 没有"在这儿跟助手说一句"的引导按钮（那些话在 chat 那一层，不在制品里） |
| 4 | **助手在 `main` 里说"帮我做一个"**：走的还是原来那条（`app_create` 工具，需要他明说），**不经过那颗加号** —— 两条路都通，但**不共享"名字/描述"那张表单**（工具那条是模型自己决定名字） |

**明确没做**：给描述一个显示的地方 · 加号那一格的长按菜单 · 从"发现"里直接装（那是另一条路） ·
给新建的项目预置一个模板/样式（主人说的是**空白项目**）。
