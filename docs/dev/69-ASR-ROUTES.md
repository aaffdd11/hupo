## 一、那两分钟怎么验（**主人自己做，助手做不了**）

用**他平时那台手机/平板**、**平时那个输入法**（不是我们的页面）：

1. 打开任何能打字的地方（微信输入框就够），点输入法上那一行的**麦克风**。
2. 说**三句他真会说的话**，各说一遍：
   - 家常一句：*"帮我记住，下周三上午十点去体检。"*
   - 带数字/专名一句：*"这个月电费多少钱？卡里还剩多少？"*
   - **中间会停顿**的一句：*"我那个……就是上次说的那个……那个药，还剩几盒？"*
3. 看三件事：
   - ① 出来的字**对不对**（尤其**名字 / 数字 / 日期**）
   - ② **停顿**会不会把一句话切成两半
   - ③ **把网关掉再试一次**（还能不能出字）

顺手记一句：**他用的是哪个输入法**（微信键盘 / 讯飞 / 搜狗 / 系统自带）——
"自带"到底是谁，决定了这条路能覆盖多少。

## 二、判据（**我按这个分档**）

| 结果 | 怎么判 | 接下来 |
|---|---|---|
| 三句**都对/基本都对** · **停顿不断** · 关网也能出字 · **他自己觉得顺手** | **够用** | ⇒ 建议**明说砍掉"语音本体"**（形状留着，界面上那句"还没真的开麦"照旧如实说）—— 这也是 `04-ROADMAP` §十一要的"要砍就明说砍了" |
| 有**一两句明显错**（尤其数字/日期）**或**停顿会被切断 **或**关网就不行 | **不够用** | ⇒ **真做**，并在那一刻从下面三条路里选一条 |
| 他说"我平时根本不用输入法那个麦克风"（不会用/找不到） | **够用是假象** | ⇒ 也**真做** —— 那说明这条路对**他**不成立（D5 的客户就是"打不了字的人"） |

⚠️ **这一档不是技术判断，是"对他成不成立"** —— 所以判据里必须有"他顺手吗"这一条，
不许只看识别率。

## 三、三条路（**验出来"不够用"时才选**）

> 三条路**都要过 `D5.10` 那道硬闸**：**四类问题各 20 条语料、句子级命中率 ≥90%**，
> 不到 90% **不上线**。⇒ 选哪条路都要先把那 80 条语料备出来（那是主人/他口音的语料，
> **别人替不了**）。

### A · 网页 + **国内云端**识别（讯飞 / 腾讯 / 阿里那一类）

| | |
|---|---|
| 它怎么工作 | 页面上录音（`MediaRecorder`）→ 送到**我们自己的服务端** → 服务端拿**一把 ASR 的 key** 转文字 → 回给页面 |
| 要动什么 | 客户端录音与权限那句人话（`D5.6`）· 服务端一条**只做转写**的口 · 一把 ASR key（**与用户填的模型钥匙不是一回事**）· 计费与配额 |
| 代价 | 🔴 **声音出境给第三方** —— 与 **`D5.2` 直接冲突**（"与 P1 同类"）⇒ 这不是工程问题，是**要主人改一条决策**；而且**没网就没声**（"地库归零"）· **花钱** |
| 什么时候能上线 | 最快（录音 + 一条服务端口 + 一把 key） |
| 笔记 | ⚠️ **别默认"用 Chrome 那个自带的"**：Chrome 的语音识别走 **Google 的服务器**，**国内基本不通** ⇒ 那条路在我们这儿等于不成立（要用就得真机验一次） |

### B · 网页 + **本地模型**（声音不出设备）

| | |
|---|---|
| 它怎么工作 | 把一个小模型（几十 MB）打进产物，在浏览器里跑（WASM/WebGPU） |
| 要动什么 | 模型文件**自托管**（🔴 **不许用 CDN** —— `61-WEB-PERF.md` 那一课：外链在国内会变成"一个字都没有"）· 首帧策略（先出"正在准备"的人话，不许白屏）· 缓存与体积 |
| 代价 | 守住 `D5.2`、没网也能用；代价是**几十 MB 下载 + 首帧慢**（平板吃力）· **工程量最大** · 命中率要自己调（可能过不了 `D5.10`） |
| 什么时候能上线 | 慢（这一版最重） |

### C · **安卓包** + 手机自带识别器（`D5.2` 原话那条）

| | |
|---|---|
| 它怎么工作 | 装一个 App，用**系统自带**的识别器（`D5.2` 的原话："用手机自带的识别器"） |
| 现状（**核过**） | 仓库里 `v2/apps/mobile/android/` **目标在**、`INTERNET` 已声明；**`RECORD_AUDIO` 还没加**（正是 `D5.11`）· **从来没发过包** |
| 要动什么 | 加权限（`D5.11`）· 申请时机那句人话（`D5.12`）· 打包装包与**分发**（怎么给他装？）· 以及 `04-ROADMAP` §十二 #6 那条"iOS 分叉"要一起想 |
| 代价 | 最贴原决策、声音走系统那一层；代价是**先得有一个能装能发的 App** |
| 好处 | 顺带把"手机上的一个 App"这件事推进（它在待办上本来就有一条） |

## 四·补、🔴 **`hy-asr-3.0-preview` 这条路查实了**（2026-09-23）

> 主人：*"hy-asr-3.0-preview 这个我开通了"* + 给了一对 `ak-…` / `sk-…`。

**它是什么**（官方文档核过）：**[腾讯云 → 语音识别 → 混元 ASR（内测版）](https://cloud.tencent.com/document/product/1093/135476)**，`engine_model_type` 选 **`Hy-ASR-3.0-preview`**（中英 + 20 种方言的大模型引擎）。

| 项 | 事实 |
|---|---|
| 走哪条口 | **只有实时语音识别（WebSocket）**：`wss://asr.cloud.tencent.com/asr/v2/<appid>?{参数}` |
| 鉴权 | **AppID + SecretID + SecretKey** 三样（[控制台 API 密钥管理](https://console.cloud.tencent.com/cam/capi)），签名 = `Base64(HMAC-SHA1(SecretKey, "asr.cloud.tencent.com/asr/v2/<appid>?<参数按字典序>"))` 再 urlencode |
| 协议 | 连上 ⇒ 服务端回一条 JSON（`code:0` = 通了）⇒ **持续发 binary**（16k 建议每 200ms 一片 = 6400 字节）⇒ 发 `{"type":"end"}` ⇒ 收到 `final:1` 收尾 |
| 🔴 内测限制 | **1 分钟以内** · **只收 16k 单声道 PCM** · 不支持话者分离 / VAD / 词汇替换 |
| 钱 | 走**大模型 2.0** 的计费方案（**按用量花钱**）；内测给的是 **20 路免费并发**（不是免费时长）|

⚠️ **主人给的那一对 `ak-…`/`sk-…` 不是这条路要的凭据**（实测两处）：
· 拿它签腾讯云 TC3（`tts/asr.tencentcloudapi.com`）⇒ **`AuthFailure.SecretIdNotFound`**（腾讯云不认识这个 SecretId；腾讯那套是 `AKID…`）；
· 单独拿 `sk-…` 打混元 OpenAI 兼容口 ⇒ **`invalid_api_key`**；而 `/v1/audio/*` 是 **404**（那套口根本没有语音端点）。

**所以我写了一条自测命令**：`scripts/check-asr-tencent.mjs`（**凭据只从环境变量读** —— 不经过助手、不进文件、不进日志；输出里也没有密钥，可以直接贴）：

```bash
TENCENT_APPID=… TENCENT_SECRET_ID=… TENCENT_SECRET_KEY=… \
  node scripts/check-asr-tencent.mjs              # 送 200ms 静音走一遍：拿到 final=1 就说明这条链通了
  node scripts/check-asr-tencent.mjs --pcm a.pcm  # 想用真音频（16k 单声道裸 PCM）
  node scripts/check-asr-tencent.mjs --selftest   # 不联网，只看签名那一步的形状（8 条）
```

⚠️ **判据是腾讯那边的回话**（握手 `code:0` + `final:1`），不是我们自己说通就通。
⚠️ 自测当场抓到我自己一处不纯：`voice_id` 原本在签名函数里随机 ⇒ 同输入两次不同签名。
   已改成**由调用方给**（每次连接一个新 UUID 是文档要求，但函数本身要纯）。

### 4.5 接进产品是什么形状（等上面那条通了再动）

| 步 | 谁做 | 要点 |
|---|---|---|
| 按住说话（`D5.3`） | 壳（网页） | 只在按住时开麦；用 WebAudio 采 **16k 单声道 PCM**（内测只收这个）|
| 音频送上行 | 壳 → **我们自己的服务端** | 🔴 **SecretKey 绝不许进浏览器** —— 签名只能在服务端做 |

| 收口/失败 | 两边 | 松手 ⇒ `{"type":"end"}`；认不出**说人话**（`D5.15`：不许拿猜的字顶上）|

### 四·补2 的续：主人给了 **正规的 SecretId** ⇒ 缺的是另外两样（2026-09-23 晚）

主人接着给了 `secretid: AKIDvAEG…`（**`AKID` 开头 36 位 —— 这才是腾讯云的 SecretId 形式**；⚠️ **这里只留前 8 位**：整串写进仓库会被 GitHub 的密钥扫描挡下（2026-09-23 当场被挡过一次），而且"密钥不进文件"本来就是本项目的第 1 条纪律）。

🔴 **顺手修掉自测脚本里一句假话**：它原来在 WS 一连上就打印
