# 106 · 长按聊天里某一条 ⇒ 菜单里多两项：**复制 / 多选**

> 主人 2026-09-25：*"聊天窗口长按某个聊天内容，可以出现一个菜单，多选，复制。"*

---

## 一、形状

```
长按聊天里**任意一条**（他说的 / 它回的）
  └─▶ 底栏那个菜单（**现有的** `BubbleMenu`，`28-DELETE.md` §二 第 2 条）
        ├─ 复制        ← 新
        ├─ 多选        ← 新
        ├─ 先放进回收站  ← 现有，一字不动
        └─ 取消
```

**多选态**（点了【多选】之后）：

```
每一条：点一下 = 选中 / 取消（选中的看得出来：勾 ＋ 高亮）
底栏一条工具条：  已选 N 条    【复制】  【取消】
                 └─ 按**时间顺序**、**一条一行**进剪贴板；做完退出多选态
```

⚠️ 多选态下**点气泡就是选中/取消**：不许顺手打开链接 / 重发 / 弹那个长按菜单
（"手一滑把别的动作也叫出来"是这个项目一直在挡的形状）。

---

## 二、复制，复制什么（**这一条最要紧**）

🔴 **只复制正文** —— 不许把界面上的装饰带进去（出处、时间、边框、"我说"那种标签、
或者气泡里没显示的那些字段）。规则：

| 那一条是 | 复制的是 |
|---|---|
| **他说的** | 他那一句话（逐字）|
| **它回的** | 气泡里**能看见的那段正文**（有长文就复制长文，没有就复制那一句短话）|
| 图片/别的东西附近那一条 | 照上面两条办（**只复制文字**；图不复制，也不写"[图片]"这种我们自己造的东西）|

⚠️ 空正文（比如只有过程、没有话的那种）⇒ **复制不了就如实说一句**（不许把空串塞进剪贴板还告诉他"复制好了"）。
⚠️ 剪贴板写入**必须由他那一下手势触发**（网页上读剪贴板要手势 —— 顺手写也是同一个道理）。
⚠️ 措辞照旧：**不许出现内部词**（app / 小程序 / 工作区 / 数据 / id / 工具名）。

## 三、判据

| **S8** | 新加的措辞**过禁用词硬闸**（住一处表；和气泡菜单那几句同一份）| 出现内部词 ⇒ 红 |

> 🔴 S2/S4 必须**变异验证**（把"只复制正文"改成"带上出处"、把"一条一行"改成"挤一行"

## 四、明确**不做**的

1. **不做**"批量删"（主人这次只说了复制 —— 批量删是另一批；单条"先放进回收站"照旧一字不动）；
2. **不做**"全选"（他没说；要的话下一刀）；
3. **不动**现有的回收站/重发/出处那几条路；
4. **不写**数值到文档。
