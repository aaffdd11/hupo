# 183 · 乙期：整个聊天默认没有输入框（说完由系统判断"语义没问题"就发出去）

> **主人 2026-10-04 原话**：
> *「所以，我们这里整个聊天，就要默认不需要输入框。那么个人说的话都会以这个模式，
> 先理解语义，写在大屏幕上，然后用户不需要点击确认才能发出去，是系统认为语义没问题就发出去。」*
>
> ⇒ 写进手册 **`D5.19`**（升 **v2.47**）。甲期（设置里那一场演练）见 [`182`](182-HEAR-DRILL.md)。

## 一、这一期要变成什么样（一句话）

**聊天那一屏，默认没有输入框。** 他说话 ⇒ 字一行行长在大屏幕上 ⇒ **听懂那一层读一遍**
（`D5.18`：只解决错别字 —— 听见的字改对了、这句话通顺，就好了）⇒ 语义没问题 ⇒ **自己发出去**（不用点确认）。
不确定 ⇒ **问一句**（语音 ＋ 文字）⇒ 他答 ⇒ 再判；问满两轮还不确定 ⇒
**按已经听懂的那一份发，并如实说一句**（绝不把没听懂的东西悄悄发走）。

```
今天：  [输入框] 打字 / 按麦 → 字落进框 → 他按发送        → 助手
乙期：  按麦 → 字长在大屏幕上 → 听懂那一层读懂
              ├ 语义没问题 → 自己发出去（屏幕上留着"我听到的是…"）
              └ 有不确定   → 问一句（说话 ＋ 写在屏幕上）→ 他答 → 再判（最多两轮）
```

## 四、如实说

* ⚠️ **这一期还没开工**：本页是契约（先写清楚再动代码）。甲期那场演练已经上线，
  他**现在就能在设置里把这条链子走一遍**（判据 3/3 含变异）。
* ⚠️ **"问完还不确定就发"这一条是照主人原话推的**（他说"语义没问题就发出去"，
  没说"一直不确定怎么办"）：⇒ 按**已经听懂的那一份**发 ＋ 屏幕上说一句；
  **绝不**默默丢、也**绝不**卡在那儿不动。
* ✅ **打字的退路那一处已经定了**（2026-10-04 主人：*「我只需要一个大按钮，语音。」* ⇒ 手册 **`D3.14`**）：
  默认**只有那一颗大按钮**，旁边**不许**再摆一排小按钮；麦克风真用不了时才**换成**打字的退路。
* ⚠️ **语音合成（手机上出声）还没接**：那一半等火山那把钥匙（`181` §六 第一问的**乙**）。
  乙期可以先把"文字问 ＋ 自动发"跑通，声音到了再接上（同一处接线）。
