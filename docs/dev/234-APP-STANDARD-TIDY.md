## 四、🔴 顺手逮到的一处真缺陷（**工具说明在说假话**）

整理时对照发现：`src/mcp-apps-server.mjs` 里 `app_create` 的 **`net` 那一格**写着

> 🔴 **声明了就能用**（不用他去点任何东西）

而代码那边（`src/app-serve.js` 的 `netHostsFor`）：

```js
if (!Array.isArray(meta.permissions) || !meta.permissions.includes('net')) return [];
...
if (!granted.includes('net')) return [];      // ← 要他点头才进 CSP
```

人格 / 规范 / 昨天那份技能三处写的都是"**要他点头才生效**" ⇒ **工具说明与代码相反**。
后果不是小事：模型会照它告诉他"**它已经能联网了**"，而那个页面**连一个站都出不去**
（2026-10-01 主人报的"天气小程序加了网络权限却连不通"就是这一族）。

**处置**：① 那句话改成"**声明了 ≠ 他给了**：他第一次打开时会看到一张弹窗…他点头的才生效"；
② **补一条判据把两侧钉在一起**：`test/app-net.test.js` 的 **N7**（描述里不许出现"声明了就能用"、
必须说"点头/弹窗"；**同时**断言代码那一行还是 `if (!granted.includes('net'))`）——
⚠️ **这一类漂移以前没有任何判据守**，它就是这么漂到今天的；
③ 顺带改掉两处会误导下一个人的旧注释（`src/apps.js` / `src/app-tasks.js` 里同款"声明了就能用"）。
