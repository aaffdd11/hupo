# 198 · **左下角那颗「清单」：正在干的活**

> **主人原话**（2026-10-06）：*「我觉得应该在左下角有一个清单按钮，点击会出来浮窗，
> 浮窗里有正在干活的聊天的列表。」*

---

## 一、这一件是什么

* 聊天窗口**底下那一行最左**多一颗**「清单」**（图形按钮，与右边那三颗同一套面子：
  白底 ＋ 一圈琥珀 ＋ 墨色图形；开着的时候整块变琥珀）。两个档（收起／展开）都在
  **同一个位置** —— 与那三颗同一条规矩（换档不许让按钮跳）。
* 点它 ⇒ 那一行**上面**长出一张浮窗：**一间一行**，写着"哪一间" ＋ "在干活 · 几件 · 干了多久"。
* 点某一行 ⇒ **去看那一间**（切到那一间的对话、需要时打开它那一屏、并把聊天拉满）。
* 再点一下那颗按钮 / 点浮窗右上角「关上」/ 换档（点抓手、点桌面空白）⇒ 收掉。

## 二、事实只有一个出处

这张清单**不自己判断**"谁在干活"，它只报**活账**上那一条事实 ——
就是桌面上那颗"在做"的小圈、以及助手自己能被问到的那一件事
**读的同一本账**（`world.work.live()`）。⇒ 三处不可能给出三个答案。

```
GET /api/working          （令牌照旧只走 Authorization 头）
→ { ok: true, working: [ { scope, title, since, count } ] }
```

| 字段 | 是什么 | 读不到时 |
|---|---|---|
| `scope` | 哪一间（**内部 id**，只用来切房间 / 认名字，**绝不上屏**） | 这一行直接不出现 |
| `title` | 他自己给那一格起的名字（只从**他自己那份小程序库**里取） | `null`（**不猜一个名字出来**） |
| `since` | 这一间里**最早**那件活是什么时候开干的（毫秒） | `null`（界面就不报时长） |
| `count` | 这一间里有几件活着（至少 1） | 缺省 1 |

* 排序：**先干的先列**；同一时刻按名字（免得清单自己跳）。
* `title` 认不出就是 `null` —— 🔴 **绝不把那串内部 id 发到屏幕上**。
* 这一条也在 `TENANT_ROUTES` 里：租户的活账在**他盒子**里 ⇒ 由**盒子自己**算
  （宿主那一层没有租户的活账，"代算"只会算出一个空清单）。

## 三、界面上那几句话（`models/work_words.dart` 一处出处）

| 什么时候 | 说什么 |
|---|---|
| 有活 | 名字（服务端给的 → 壳里那份清单 → 内置那三格各自的词 → 主对话用窗口那句 → **都没有 ⇒「另一个对话」**）／`在干活 · 3 件 · 干了 2 分钟` |
| 问上了、一件都没有 | 「现在没有在干的活」 |
| **没问上** | 「没问上，过一会儿再看」 |
| 头一次还在问 | 「稍等一下」 |

🔴 **"没问上"与"一件都没有"必须分得开**（`null` vs 空表）：看不见 ≠ 没有 ——
说错这一句就是这一件最坏的形状（同 `appsOrNull` 那条纪律，而这条更硬）。

**时长**：不到一分钟说「刚开始」（报"干了 0 分钟"是句笨话）；`since` 读不到就**不报**
（不是报 0）；时钟倒着走也不报。

## 四、几处不肯将就的地方

* **那一行的高度**：清单最多占可用高度的一半，而底下那一行**先留出来**
  （收起档里它是 `Flexible` —— 地方不够时**是清单自己让位**，里面能滚；
  展开档里时间线那个 `Expanded` 会吃掉剩下的，所以**不用** `Flexible`：
  两个 flex 子会一起分，清单会把时间线白白让掉一半）。
* **整张清单能滚**（连抬头一起）⇒ 外面给多高都不溢出。这一条是判据当场抓出来的：
  第一版把抬头留在滚动区外面，窗口矮的时候**溢出 10 px**。
* **一行是"整行可点"**（`DshRowEntry`）：按**面积**过 D3.6（≥44×44），
  不用 `GestureDetector`（源码级禁令）。
* **不读 `AppearanceScope` 的色板**：那四颗（清单 ＋ 那三颗）无论整机亮暗都是暖白纸
  那一套 —— 混用会在暗色下变成"白底 ＋ 近白的字"。

## 七、如实说（这一版还欠什么）

* **手机上那颗包还没重打包**（按规矩等主人开口）⇒ 安卓上现在**看不到这颗按钮**
  （网页已经有了）。
* **真浏览器里"点开那张浮窗"的样子没拍到**：无头 Chrome 上给语义节点派 `click()`
  是**已知的死路**（`docs/dev/118` 附节记过），而这一版没有"启动即打开"的调试开关。
  ⇒ 那一屏的样子是**在渲染层看的**（上面那一格），**不是**在真浏览器里点的。
* 那张清单**只在点开的那一下去问一次**：开着它的时候别的房间刚好干完，行不会自己消失
  ——再点一下（关上再打开）就是新的。
* 一行的时长**按分钟起跳**（不到一分钟说"刚开始"）：这是给人看的粗粒度，
  不是"精确到秒的进度"。
