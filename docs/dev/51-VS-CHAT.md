# 51 · 它跟"单纯的 AI 聊天"到底差在哪

> **这份文档回答一件事**：把一个**聊天窗口**和**琥珀**摆在一起，区别是什么。
> **写给谁看**：① 主人（判断这东西值不值得做下去）；② 下一个接手的人（别把它做成一个聊天框）。
>
> **口径**：每一条都要能在**代码里指出来**（文件 + 测试名）。**指不出来的不算数**，
> 而且**做不到的要明写"还没有"**（§三）—— 这一节和 §二 一样重要：
> 首页上写的每句话都得是真的（`07-APPENDIX.md` §2.2：写了做不到 = 撒谎）。

---

## 〇、一句话

> **聊天机器人给你一段回答；琥珀给你一件事办完的结果 —— 而且它记得住、看得见、认账。**

三件事把它和"聊天"分开：**一个属于你的地方**、**一条持久的事**、**一套不许说假话的规矩**。

---

## 一、区别（七条，逐条带证据）

### 1. **它有一个"家"，不是一个"窗口"**

| | 聊天机器人 | 琥珀 |
|---|---|---|
| 你的东西在哪 | 在别人那套系统的账号里 | **在属于你自己的那台机器/那份世界里** |
| 别人看不看得见 | 取决于对方的隐私政策 | **看不见**（不是承诺，是结构） |

**凭什么**：每个用户一套**完整的自己的世界**（`v2/services/core/src/worlds.js`：
store / timeline / notice / trash / ledger / dispatcher 各一份），新用户**一台自己的容器**
（`src/tenants.js`、`src/provision.js`、`scripts/create-tenant-pool.sh`），家目录 `0700`。
判据：`docs/dev/37-MULTITENANT.md`、`38-ISOLATION-SPLIT.md`、`39-PERMISSIONS.md`、
容器那一路 `docs/dev/34-CONTAINER.md`。

### 2. **它记得住 —— 而且"记得住"是落盘的，不是上下文里的**

| | 聊天机器人 | 琥珀 |
|---|---|---|
| 换个话题 | 前面就淡了 | **你的事记在它自己那本账上** |
| 关掉再回来 | 看它心情 | **重启之后还在**（实测过） |

**凭什么**：事件**只追加**落盘（`src/store.js`，`append` 出错**一律上抛**、不吞），
时间线按序号重组（`src/timeline.js`）。判据：`test/store-append.test.js`、
`test/seq-monotonic.test.js`；"重启还记得"写在 `AGENTS.md` §四 的线上那一行。

### 3. **它会自己去办，而且**你**看得见它在办**

| | 聊天机器人 | 琥珀 |
|---|---|---|
| 你要等的时候 | 一个转圈 | **它在做什么，屏幕上写着**（四档） |

**凭什么**：过程四档（默认"在做什么" / 更多细节，`lib/models/process_levels.dart`
+ `src/timeline.js` 的过程事件）。判据：`docs/dev/26-PROCESS-LEVELS.md`、
`test/unit/process_levels_test.dart`、`test/unit/process_level_store_test.dart`。

### 4. **没办成，它直说**

| | 聊天机器人 | 琥珀 |
|---|---|---|
| 说不清的时候 | 猜一个像样的 | **说"这条我没办成"** |

**凭什么**：失败被分类，**认得出的那一档说人话**（`AUTH` ⇒ "你填的那串钥匙它说用不了，
刷新一下这一页，就能重新填"），而且**不许用别的失败冒充它**。
判据：`v2/services/core/test/auth-failure.test.js`（带负向对照）、`docs/dev/44-CONTAINER-MODEL-KEY.md` §六。

### 5. **卡住会收场（被硬杀也算）**

| | 聊天机器人 | 琥珀 |
|---|---|---|
| 进程崩了 | 那一轮就没了 | **收干净，然后接着做** |

**凭什么**：进程级兜底 + 崩坏环降级（`src/process-guard.js`），跨重启对账
（`src/reconcile.js`）。判据：`test/process-guard.test.js`、`scripts/check-crash-recovery.sh`；
"被硬杀能自己收干净、只读的活还会自己重做"写在 `AGENTS.md` §四。

### 6. **你说错话能反悔，你要东西能拿走**

| | 聊天机器人 | 琥珀 |
|---|---|---|
| 删错了 | 没了 | **进回收站，能拿回来** |
| 想把记录带走 | 截图 | **导出一段能粘走的文字** |

**凭什么**：删除 → 回收站 → 恢复/真删（`src/` 那一路 + `lib/screens/trash_screen.dart`），
导出是 `GET /api/export` 一段纯文本。判据：`docs/dev/28-DELETE.md`、`30-EXPORT.md`、
`test/unit/trash_test.dart`、`test/unit/export_test.dart`。

### 7. **它是"同一个人"，不是每轮重置的通用助手**

| | 聊天机器人 | 琥珀 |
|---|---|---|
| 说话像谁 | 一个很礼貌的客服 | **它自己**（有一套不许越的规矩） |

**凭什么**：人格层（`v2/services/core/hupo-persona.yml`，10 条规则），
每开一个新 agent 就喂一遍。判据：`docs/dev/09-PERSONA.md`、`scripts/check-persona.sh`。

## 二、为什么这些差别是**结构**带来的，不是文案

聊天机器人的形状是：**一次请求 → 一段回答**。
琥珀的形状是：**一个常驻的东西 + 一本只追加的账 + 一套判据**。

三处结构性选择（想抄这个产品的，先看这三条能不能接受）：

1. **账本只追加**（`store.js`）：所以有历史、能对账、能恢复；代价是**要管保留期**。
2. **一个用户一份世界**（`worlds.js` + 容器）：所以"别人看不到"是结构不是承诺；
   代价是**每多一个用户就多一份资源**（容量成了真问题，见 `AGENTS.md` §1.1 内存那一行）。
3. **界面上不出现内部词**（`lib/models/forbidden_words.dart`，**硬闸**）：
   代价是**每加一句界面文案都要过闸**；换来的是"用户看得懂"。

## 三、⚠️ 现在**还做不到**的（写清楚，不许含糊）

| 还差什么 | 状态 | 出处 |
|---|---|---|
| **手机安装包**（安卓 / 苹果） | ❌ **还没有**。现在能用的是**网页版** | `lib/models/landing_words.dart`（三张平台卡都如实写着"还没上线"） |
| **真短信通道** | ❌ **没接**。现在开着临时验证码 ⇒ **任何手机号 + 它都能进** | 欠账 **#45**（`docs/dev/00-PROGRESS.md` §六） |
| **语音** | ❌ 没做（明确砍到"先复核"） | `04-ROADMAP.md` |
| **导出里的"记忆那一层"** | ❌ **导不出来**（导出的末行如实写着这件事） | `docs/dev/30-EXPORT.md` |
| **容量上限** | ⚠️ 是模板里一个**常数**，不是按磁盘算出来的（会算给你看，但不替你改） | 欠账 **#35** |
| **跨容器的"甲看不到乙"** | ⚠️ 服务内部有判据；**跨 uid 的边界**靠容器那一层（已建，但过渡层还在） | `docs/dev/38-ISOLATION-SPLIT.md` §二·补.2 |

## 四、这份总结怎么落到**首页**

首页（`lib/screens/landing_screen.dart`）上只有**一块**新东西：**对照块**（§一的七条里挑
**最有画面感、且此刻是真的**四条），文案在 `lib/models/landing_words.dart`：

| 对照块那一行（"光是聊天" → "琥珀"） | 对应本文哪一条 |
|---|---|
| 说完就完了 → 你说的事它记下来 | §一.2 |
| 换个话题就忘 → 下次不用重说 | §一.2 |
| 只能陪你聊 → 该查的去查，办完回来告诉你 | §一.3 |
| 猜不准也照说 → 没办成就直说 | §一.4 |

**为什么不把七条都放上去**：首页是给"第一次来的人"看的，四条已经够了；
其余三条（自己的家 / 会收场 / 能反悔）**要么在别的卡里已经说了，要么说了也不信** ——
它们得靠用出来（`01-PROJECT.md` 的五条产品原则里就有这一条：**别用形容词，用事情**）。

⚠️ **新加的每一句都必须过禁用词硬闸**（`test/unit/forbidden_words_test.dart` 逐条列了
landing 用到的字符串）——**没进那个清单的句子等于没验过**。

## 五、这一块**怎么验的**（顺手修好了"看一眼"这条工具）

判据分三档，**缺一档都不算**：

| 档 | 验什么 | 怎么跑 |
|---|---|---|
| **硬闸（可访问性）** | 五档字号**不溢出**、命中区 ≥44 | `flutter test test/widget/accessibility_test.dart`（landing 每档都跑） |
| **提示档（widget）** | 这一块**真的画到屏幕上**（一路滚下去，每句都见过） | `test/widget/landing_test.dart` |
| **生成期（禁用词）** | 每一句都不含内部词 | `test/unit/forbidden_words_test.dart` |

🔴 **还差一档：真站点"看一眼"** —— 而首页下半屏**原来根本看不到**（截图只拍视口，
那一块在折叠线以下）。⇒ 顺手给 `scripts/check-web-browser.mjs` 加了
**`--scroll-px <像素>`**（页内合成 **touch** 指针事件拖一段：桌面网页上**鼠标拖不会滚动**）：

```bash
node scripts/check-web-browser.mjs --no-token --scroll-px 1100 --shot /tmp/home.png
```

⚠️ 它是"**看一眼**"的工具，**不是判据**（判据是上面那三档）；但"屏幕上到底长什么样"
在 Flutter web 上**只能这样看**（字画在 canvas 上，查 DOM 查不到）。
