# 68 · 读出来（把它说的话念出来）

> **主人 2026-09-23**：功能清单里选了「听筒 / 读出来」，并在形状那一问上选了
> **"每条都能念 + 一个自动念开关"**。
>
> 契约依据：手册 **`05-DECISIONS.md` D5.16**（这一批新定的）；相关的是 `D5` 那一组
> （**语音的客户是"打不了字的人"**）与 `D5.13`（假的一眼看得出 / 不录音时禁用"听"字）。

---

## 一、这一件为什么值得做

那个「听筒」图标原来**只是个图标**：点它只换一个图标 + 一句实话
（"演示：读出来也还没做，先看形状"）。而**看不清字 / 打不了字**的人恰恰最需要
"让它念给我听" —— 这是 `D5` 那一组决策服务的同一批人。

---

## 二、形状（**定下来的**）

| 项 | 定成什么 | 为什么 |
|---|---|---|
| **"听筒 / 扬声器"那套语义** | ⛔ **砍掉** | 那是"微信里声音从哪儿出"（贴耳 ⇄ 外放）。**网页上没有"听筒"这个出口**（浏览器只有扬声器/耳机，`setSinkId` 在 iOS 上无效 —— `55-VOICE-DEMO.md` §3.2 自己写着）⇒ 留着它 = **假装有一个做不到的东西** |
| 真做得到的那半 | ✅ **念出来** | 走**设备自带**的合成器（浏览器/系统），我们**不把文字送到任何地方** |
| 每条回答 | **一个"读一遍"**（正在念时同一个按钮变成**"别念了"**） | 最直白、可发现；收起态/键盘档也能用 |
| 全局 | **一个"读出来"开关**（打开 ⇒ 它**新说的话**自动念） | 对"看不清字"的人是省事的那一半；⚠️ **默认关**（突然出声会吓人，安静要可预期） |
| 开关画在哪 | **语音档那一格**（原来"听筒"站的位置） | 主人定案里就是这么定的；⚠️ 键盘档那一格留给输入框 |
| 念不了的时候 | **不画那个按钮/开关**，页面上用一句实话说明 | 界面上**不许出现按不动的东西**（`AGENTS.md` §六 第 4 条那一族） |
| 什么时候**不念** | ① 首屏那段**历史**（一登录就把它以前说过的话全念一遍 = 骚扰）② **没说完的**（半句 /"这条没说完"/卡住了 —— 念出来等于**替它把话说圆**）③ 空文本 | 每条都有判据 |
| 什么时候**停** | 点"别念了" · 关掉开关（**立刻停**）· 离开这一屏 · 念完（复位） | ⚠️ "按钮说关、它还在念"就是假话 |

⚠️ **隐私要说清**：合成器是**设备自带**的（浏览器/系统）—— 这个功能里
**没有任何网络调用**。但**有些平台上那个合成器自己会用云端音色**：
那和"系统读任何一段文字"是同一件事，**不是我们在传**。⇒ 对外一句话是
"**让它念出来**"，**不承诺"纯本地"**（那会是一句我们保证不了的话）。

## 五、真机验证

| 验的什么 | 读数 |
|---|---|
| 按钮**真的画在屏幕上** | 真浏览器打开 `w.stalkerai.cn`（`u2` 的令牌）→ 展开浮窗 → 滚到底 → 读**无障碍语义树**：树里出现 **「读一遍」**（每条说完了的回答下面一个） |
| 念不了时不画 | 同一台机器上 `speech_stub` 那一档（`flutter test` 的环境）⇒ 判据里**一个按钮都没有**（见 `test/widget/speak_test.dart` 第 3 条） |
| 合成器在不在 | `typeof window.speechSynthesis` = **object** ✅；但**音色数 = 0**（这台无头浏览器没有音色）⇒ 见下面 |
| 🔴 **没有音色时点"读一遍"会不会卡住** | **不会**：点完 2 秒后按钮**还是"读一遍"**（不是"别念了"），`speechSynthesis.speaking=false / pending=false` ⇒ 合成器**当场报错**，我们的 `onError` 把它接住、状态自己复位。这正是判据「**念不了不许显示在念**」在真机上的表现 ✅ |

⚠️ **没验到的那一半（如实说）**：**真的有没有声音**，这台机器上验不了 ——
取证用的浏览器是**无头的**（没有音频输出），实测 **`getVoices().length` = 0**，
`speak()` 在这种环境下不出声、当场报错。
⇒ 所以这一条的证据是：**界面与状态机**（19 条判据）+ **真机上的按钮确实画出来了** +
**没有音色时不会卡在"别念了"**；**"耳朵听到"**这一步要**你在自己的设备上点一下**。
（这一段记在这儿，免得下一个人以为"验过了"。）

## 六、这一版**没做**的（**明说**）

| 没做 | 为什么 |
|---|---|
| "听筒 / 外放"（声音从哪儿出） | 网页上没有这个出口（见 §二）。要做得先分安卓/桌面两套并拿到真机证据 |
| 音色 / 语速 / 音量可调 | 用设备默认。多一套设置 = 多一份"用户以为它会记住"的期待 |
| 一句话念到一半再点"读一遍" | 现在点它就是**从头念**（`speak()` 里先 `cancel()`）。"从哪儿断的接着念"要记朗读位置，这一版不做 |
| 念**用户自己**说的话 | 只念它的回答。"把我说的话念一遍"不是这个功能要解决的（他刚说过，他知道） |
| 自动念时**逐句跟读**（边生成边念） | 那要在流式分片那一层做，而且和"一句话可能被改"打架。先做"说完了再念" |
