# 214 · 语音推倒重来：stream 回来的字进输入框，按停就发

> 主人 2026-10-07（接 `213` 之后）：*"我认为，原本的语音转文字全套方案都应该推倒重来，
> 忘记我们要修正语义。我们就是 stream 回来的文字输入到文本框等待发送。"*
>
> 当天他定的三样：**① 按停就发**（不改成"等他按发送"）· **② 字直接流进底下那个
> 能改的真输入框** · **③ 设置里那屏「说一句试试」删掉**。

---

## 一、新的形状（一条链，三步）

```
按一下那颗圆圈（开始）
   → stream 回来的字**直接长在底下那个真输入框里**（他随时能点进去改）
   → 按一下停 ⇒ 等 `asr/end` 那份**整段**回来 ⇒ 发出去（只发一次）
```

| | 现在 | 说明 |
|---|---|---|
| 那份字住哪 | **一个真 `TextField`**（`VoiceBar` 里那个框） | 半句/定稿**边听边长**；他点进去就能改，也能混着打字 |
| 谁算"框里那份字" | 控制器一处：`ChatController.composeText` | `_voiceWriting ? _voiceBase + _hearing.text : _typed` |
| 他一动手 | `voiceEdited(text)` ⇒ `_voiceWriting = false` | 从此**语音不再往框里写**、发的是**他手上那份**（不让他改的字被下一帧顶掉） |
| 什么时候发 | **按停**（他定的） | `asr/end` 那份整段回来就发；15 秒兜底（`stopLinger`）只兜最坏情况 |
| 说很多句 | **55 秒上限留着**，到点只是**接着开下一轮** | 字接进 `Hearing.settled`、一个字都不清、**一次都不发**（`210` 那条不变） |
| 打字那条兜底 | **同一个框 + 一颗「发送」** | 开不了麦的机器上才有那颗「打字」；发出去走 `sendComposeLine` |
| 中间那一层 | **没有了** | 语义 / 反问 / "最多两轮" / 演练状态机 —— 全删（`213` + 这一篇） |
