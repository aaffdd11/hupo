# 103 · 桌面图标：**右键 / 长按 ⇒ 从桌面上删掉**

> 主人 2026-09-25：*"你需要帮我开启右键点击桌面的 app icon，或者 web 端长按以后，出现删除功能。"*
> 这一批只做**典型情况**（他能点出来、能删掉、删完桌面上真没了），别扩。

---

## 一、形状

```
桌面上一个图标
  ├─ 右键（桌面端 / onSecondaryTap）──┐
  └─ 长按（web / onLongPress）────────┴─▶ 底栏一个小面板（照 `bubble_menu.dart` 那个形状）
                                            ├─ 一句人话（见 §三）
                                            ├─ 【从桌面上删掉】
                                            └─ 【取消】
   按下【从桌面上删掉】 ⇒ POST /api/app-remove {id}
                        ⇒ 服务端 `apps.remove(id)`（**软删**：挪进 `.removed/` ＋ 审计）
                        ⇒ 客户端把桌面清单刷一遍 ⇒ 图标没了
```

🔴 **网页上还得把浏览器自己那份右键菜单关掉**（主人 2026-09-25 签字："关掉"）：
引擎默认是**开着**的（`browser_context_menu.dart` 原话 *"On web, by default, the
browser's context menu is enabled and Flutter's context menus are hidden."*）⇒
右键图标时浏览器那份会盖在我们这个面板上面，**右键删除在网页上根本点不到**。
⇒ `lib/main.dart` 里 `if (kIsWeb) BrowserContextMenu.disableContextMenu();`
（硬闸钉在 `test/unit/web_shell_test.dart`）。
边界：**只关这一层壳**——小程序那层是独立 iframe（另一个文档），它里面的右键照旧；
代价是聊天输入框里**右键粘贴**没有了（`Ctrl+V` 照旧），主人认了。

---

## 二、服务端（**以盒子为准**，照 B17 那条已有的做法）

| 件 | 怎么做 |
|---|---|
| 新路由 | `POST /api/app-remove`（body `{id}`）—— **宿主那条路**，因为 `appsFor(sub)` 在租户那儿解析成**他盒子里那份**（同 `/api/apps` 的理由：签名与公开基址在宿主）|
| 租户 | 盒代理要**新增**一个能力 `remove()`（现在只有 `list/read/gateAsk/create`）＋ 盒侧一个内部口（照 `/internal/app-ask-check` 那条的形状：**只在 0600 可信 UDS 上**，公网口 404）|
| 🔴 **不许退** | 盒子不通 / 答的话认不出 ⇒ **如实 503**，**绝不**去动宿主那份（那正是"两处库"那句假话）|
| 认不出的 id / 那个 app 不在 | **404 ＋ 一句人话**（不许静默成功）|
| 手册 | §2.1 接口表要**加这一行**（`test/route-shape.test.js` 会拦：代码里的 `/api/…` 必须在表里）⇒ 这是 `strict` 文件，改完**要重建开机清单** |

## 三、措辞与诚实边界（**这一节是这一批最要紧的**）

- 面板上**只有两句**（措辞住 `models/` 里的一份表，进 `test/unit` 的**禁用词硬闸**）：
  - 主句：**从桌面上删掉**
  - 取消：**取消**
- 🔴 **不许说"还能拿回来"**：服务端确实是软删（`.removed/`），但**今天没有任何一处能把它列出来、也没有拿回来的入口**（`grep .removed` 只有 `remove()` 写它）⇒ 界面上写"可恢复"就是**假话**。
  ⇒ 想做"可恢复"就**先把入口做出来**（那是下一批；记在 `77-BLOCKERS.md` **B29**）。
- 🔴 **不许出现内部词**：`app`／`小程序`／`工作区`／`图标 id`／"卸载"这类工程词**不上屏**（面板只说"从桌面上删掉"）。
- 删掉之后**对话与工作区照旧还在**（`remove()` 只动制品库那一格）—— 但**界面这一版不给入口**，所以**也不说**这件事（说了就是承诺一条走不到的路）。

## 五、明确**不做**的

1. **不做**"拿回来"的入口（先记账 B29；**界面上也不许提**）；
2. **不做**批量删、**不做**长按拖拽排序（那是别的批次）；
3. **不做**"删掉要不要连工作区/对话一起删"这个决定 —— 今天 `remove()` 只动制品库那一格，**这个行为不改**；要改得先有人拍；
4. **不动**转交/派活/未读那几件（`100`／`102`）；
5. **不写**数值阈值到文档（命中区那些住代码与 `accessibility_test.dart`）。
