# 103 · 桌面图标：**右键 / 长按 ⇒ 从桌面上删掉**

> 主人 2026-09-25：*"你需要帮我开启右键点击桌面的 app icon，或者 web 端长按以后，出现删除功能。"*
> 这一批只做**典型情况**（他能点出来、能删掉、删完桌面上真没了），别扩。

## 一、形状

```
桌面上一个图标
  ├─ 右键（桌面端 / onSecondaryTap）──┐
  └─ 长按（web / onLongPress）────────┴─▶ 底栏一个小面板（照 `bubble_menu.dart` 那个形状）
                                            ├─ 一句人话（见 §三）
                                            ├─ 【从桌面上删掉】
                                            └─ 【取消】
   按下【从桌面上删掉】 ⇒ POST /api/app-remove {id}
                        ⇒ 服务端 `apps.remove(id)`（**软删**：挪进 `.removed/` ＋ 审计）
                        ⇒ 客户端把桌面清单刷一遍 ⇒ 图标没了
```

🔴 **网页上还得把浏览器自己那份右键菜单关掉**（主人 2026-09-25 签字："关掉"）：
引擎默认是**开着**的（`browser_context_menu.dart` 原话 *"On web, by default, the
browser's context menu is enabled and Flutter's context menus are hidden."*）⇒
右键图标时浏览器那份会盖在我们这个面板上面，**右键删除在网页上根本点不到**。
⇒ `lib/main.dart` 里 `if (kIsWeb) BrowserContextMenu.disableContextMenu();`
（硬闸钉在 `test/unit/web_shell_test.dart`）。
边界：**只关这一层壳**——小程序那层是独立 iframe（另一个文档），它里面的右键照旧；
代价是聊天输入框里**右键粘贴**没有了（`Ctrl+V` 照旧），主人认了。

**还没做出东西**的工作区（没有制品，或者制品早被删了）**根本走不到它**
（`/api/app-remove` 会如实回"这个小程序不在你这儿"）—— 那一间就只能永远躺在盘上。
`#152` 真机在开发者入口的清单里一口气见到**十来个**这样的空壳。

**新门**：`POST /api/room-remove {scope}` ⇒ `{ok:true, record:{scopeId, takenSeqs, items}}`

| 项 | 怎么规定 |
|---|---|
| 拿走的 | **工作区目录** · **那一间的对话**（那条日志里 `scopeId` 是它的行）· **助手那边那一间的会话记录** |
| **不动** | **制品库**（留痕里 `items.app` 如实 `false` —— 不许记成"拿走了一个制品"） |
| 留痕 | 与 `§7.3` **同一套**：`reclaimed.json` 的 `takenSeqs`（N22 的唯一例外） |
| 审计 | 多一行（`what:"reclaim-room"`，落在**那一个**审计文件里：`<dataDir>/audit.log`） |
| 谁来做 | 🔴 **一处实现**：还是 `src/reclaim.js` 的 `reclaimScope()`（新增 `hasApp:false` 那一档）—— 宿主那条口与盒里那条内部口**都落到它** |
| 以谁为准 | 🔴 **以盒子为准**（同 `§7.2`）：租户这一下在他盒子里落；**盒子不通 ⇒ 如实 503**，绝不退回宿主那份 |

### 8.1 四道闸（缺一条就有"按错名字把别人的房间删了"的形状）

| # | 拒什么 | 回什么 |
|---|---|---|
| 1 | **`main`** —— 那是他自己的主线 | **409 ＋ 人话**（"主线不许回收 —— 那是他自己那条对话。"） |
| 2 | **内置那几间**（`settings` / `discover` / `harness`）—— 桌面上就有它们的图标 | **409 ＋ 人话** |
| 3 | **制品库里还有它** ⇒ 这一间有东西在桌面上 | **409 ＋ 人话**（指他去走"从桌面上删掉"那条路 —— 那条**连制品一起搬**） |
| 4 | **认不出这一间**（工作区目录不在） | **404 ＋ 人话**（"没有这一间。"） |
| ＋ | **名字不合法**（`../` / 大写 / 斜杠…） | **400 ＋ 人话**（防穿越：**不许**拿一个字符串去拼路径） |

⚠️ 被拒的那几下**盘上一个字节都不许动**（判据 R2 用整棵树的字节指纹比）。

### 8.2 判据与读数

**判据**：`v2/services/core/test/room-reclaim.test.js`（R1 三样一起走 ＋ 留痕 ＋ 审计 ·
R2 四道闸各自如实拒且盘上不动 · R3 真隧道 ⇒ 盒里落、宿主那份一个字节不动 ·
R4 盒子不通 ⇒ **503**）。**每一条都变异验过**（五刀：放开"有制品"那道闸 / 拿掉内置那道闸 /
拿掉 `main` 那道闸 / 留痕把 `items.app` 写死 `true` / 租户那条路不走盒子 ⇒ **各自当场红**）。

**顺带修掉一处**（同一个病，三条口都受它影响）：隧道上的**传输层**错误
（连接被拒 / 对端析构）原先原样抛出去 ⇒ 落到"盒子不通"那条分岔的 `else ⇒ 500`，
而契约写的是**503**。⇒ 在 `apps-box.js` 的 `requestOverSocket` **一处**
把非 `BoxError` 的传输错误包成 `unreachable`（`/api/app-remove`、`/api/app-rename`、
`/api/app-copy`、`/api/room-remove` 四条一起对上）。
