⚠️ 但这条**要主人拍板**（§六 Q1）—— 项目在这上面栽过一次（"底部"读错，整套布局返工）。

## 三、聊天记录：**自动显示最新 + 往上滑加载更早**

现在：客户端**只留一屏**（`17-LOCAL-FIRST.md`：本机缓存一屏，只缓存不判断），再往上**没有路**。
要做的：

| 要什么 | 怎么做 | 怎么验（判据） |
|---|---|---|
| **自动显示最新**（已有） | `scroll_follow`（打开停在**最新**那一条，用户自己往上翻过才不跟） | 既有 `test/widget/scroll_follow_test.dart`（已在） |
| **往上滑加载更早** | 服务端**新加一条只读接口**：按 `seq` **往前取一页**（新接口，**不改老字段语义** ⇒ 不违反"协议冻结"）；客户端滚到顶自动取一页 | 新判据：① 取回来的一页**接在前面**且**视觉锚点不动**（不许跳）② 连取多页**不重不漏**（按 `seq` 去重）③ **真删过的**不许被"翻出来"（回收站那本账要一起筛） |
| **内容数量**（留多少） | 上限**住代码里**（纪律 1：阈值不住文档）；超过上限时**从最老的开始丢内存**，但**"还能再取"这件事要记住**（丢了不等于没有） | 判据：丢过之后往上翻**照样能取回来** |

| **"往上还有"提示 + 回到底部** | 顶部一行小字（`↑ 往上还有 N 条 · 松手加载`）；用户翻上去过之后右下角出现"回到底部" | 判据：**有字**（D3.8）、命中区 ≥44 |

⚠️ **"老消息滑动加载"要动服务端**（现在没有往前取的口）⇒ 这是一条**新接口 + 新判据**，

## 四、计划条的数据：**信号到得了，只是被我们丢了**（已实证）

### 4.1 事实（都不是猜的）

| 事实 | 证据 |
|---|---|
| 产品里那个 agent **确实带着这两个工具** | `dsh --profile sdk --dump-config` 里有 `goal` / `goal-round-driver` / `command-goal`；`@deepseek-ai/dsh-base` 的 bundle 挂 `tool-todo`/`tool-goal`（容器里用的就是**自带的 `sdk` profile**：`scripts/build-tenant-image.sh:96`） |
| `todo_write` **每次都往会话里写一个快照** | `@deepseek-ai/dsh-tool-todo` 的类型文档原文：*"Each call appends a `todo/write` snapshot to the calling agent's session; **replay is last-write-wins**, and **UIs render from session events**"* |
| dsh 自己的客户端**就是靠这些事件渲染的** | `@deepseek-ai/dsh-client-connection/lib/client.js` 里有 `goal/change`、`goals/{create,complete,edit,get,pause,resume,clear}`、`plan/mode` |
| 🔴 **我们这一侧把它们丢了** | `src/session-translate.js:317-355`：`case 'tool/call'` 只读 `data.name`（工具名）→ 映射成过程**类别**；**`objective` / `todos` 的内容一个字节都没读**（全文没有 `data.input` / `args`）。两种工具都不在 `TOOL_STEP_STATE`(204-214) ⇒ 只落成一条 `state:'thinking'` |
| 已有规矩：**工具名不许发给客户端** | `26-PROCESS-LEVELS.md:180`「工具名与 callId **一律不发**（有闸）」· `08-SPEC.md:1121`「不许提内部词」 |

### 4.2 要做三步

1. **服务端认那两类事件**（`todo/write`、`goal/change`）⇒ 翻译成**一条新人话事件**：
   `plan/updated { goal?: {text, done, rounds?}, todos: [{text, now, done}], doneCount, total }`
   * **工具名、callId、原始入参一律不发**（照 `26-PROCESS-LEVELS.md:180` 那条规矩扩到新事件）；
   * 任务文案是**模型自己写的那几句人话**（例如"读现有登录代码"）⇒ 直接可用，
     **但过一遍禁用词闸**（万一模型写了"工具"/"上下文"这类词）。
2. **落盘 + 补发**：它是持久事件（有 `seq`）⇒ 新连上的客户端**立刻就有**当前计划，
   不用等下一次工具调用（否则"刷新一下计划条就空了"，那又是一句假话）。
3. **客户端**画 §二 选定的那一条；**没有计划时一个像素都不画**（不许摆空壳 —— `08-SPEC.md` §6.6 空态禁令）。

### 4.3 怎么验

| 判据 | 为什么 |
|---|---|
| 发给客户端的帧里**没有工具名 / callId**（正向 + 负向对照） | 已有那条规矩，**扩到新事件**（`26-PROCESS-LEVELS.md:180`） |
| **last-write-wins**：连发两个快照 ⇒ 只剩最后一版 | 这是 dsh 的语义（"replay is last-write-wins"），我们照抄就会错 |
| **没有计划 ⇒ 那条不画**（负向对照） | §6.6 空态禁令 |
| **目标做完 ⇒ 那条要收起来/打勾**（不许一直挂着） | 否则"看得见"变成噪声 |
| 3.1 倍字号下**不溢出** + 那几个可点的 ≥44 | 硬闸 `accessibility_test.dart` |

## 五、发送 / 语音 / 作用域图标：**现在的样子 + 我建议改成什么**

**现在**（`composer.dart:194-285`，从左到右）：

| 位置 | 控件 | 现状 |
|---|---|---|
| 1 | **话筒 / 键盘**（`voiceToMic`/`voiceToKeyboard`） | 常驻；切到语音档后"粘贴"消失、输入框换成"按住 说话" |
| 2 | **粘贴**（`composerPaste`） | 只在键盘档 |
| 3 | 输入框 / 按住说话 | ≤6 行自适应；**永不锁**（D5.14）；点它会把窗口打开 |
| 4 | **听筒 / 扬声器**（`voiceEarpieceOn/Off`） | **常驻**（键盘档也占一个 48px） |
| 5 | **发送**（`IconButton.filled` 48×48，箭头） | 常驻；框里没字时 `onPressed:null`（**看起来"按不动"**）；按下后清空 + 焦点留框 + **窗口拉满** |

**我建议改成**（都要主人点一下 —— §六 Q4/Q5）：

1. **发送钮**：保留圆钮，但**框里没字时它不出现**（只留出同样的宽度，位置不跳）。
   ⚠️ 关键：**宽度必须固定**，否则它一出现/消失就抖（同 D4.8 的病）。
2. **听筒**：**只在语音档出现**（键盘档不需要它；省下的位置给输入框）。
3. **语音切换**：留在最左（微信形态①）；**不改成"长按说话"**（形态②）——
   因为 D5.13/D5.4 那一套诚实规矩（不录音时禁用"听"字、松手不自动发）已经落在这套形状上，
   换形态要重做一遍那几条判据，收益只是"像微信"。
4. **作用域图标**：留在**抓手行**（现在的位置，主人 2026-09-23 刚定）；
   可选升级：变成"图标 + 名字"的小胶囊（代价：收起态变宽，窄屏要横滚）—— §六 Q3。

⚠️ **语音那一半仍然是"假的"**（不开麦、不识别、明标"演示"）—— 这次**只改形状，不改真假**；
真做要主人先拍板走哪条路（`63-OWNER-DECISIONS.md` 第 3 条）。
