# 144 · **不要浮窗**（那条"我去做，做完叫你"）

> **主人 2026-09-30 原话**：*「顶部会出来一个浮窗，叫我去做做完叫你。这个不对。**不要浮窗**。」*
>
> ⚠️ 这条**改的是他自己 2026-09-21 定过的形状**（`29-NOTICE.md` 开头那句：
> *「浮窗喊一声，时间线留住 + 撤销」*）—— 约束 1（**浮窗是 overlay**）**撤了**。
> 约束 2（时间线里必须有那一条）与约束 3（撤销）**一个字没动**。

---

## 一、现场（他看到的那个东西是什么）

服务端那条"到点还在跑就说一声"：

```
dispatcher.js  #armBackgroundNotice（到点还在跑）
   ⇒ #announceWorkStarted() ⇒ #sayProactive('我去做，做完叫你。')
   ⇒ Notice.work({kind:'work-started'}) ⇒ timeline.emit({type:'notice', …})   ← **带号、落盘**
```

客户端收到它做**两件事**（`chat_controller.ingest`）：

1. `timeline.apply(event)` ⇒ 时间线里**留一条**（`NoticeLine`）；
2. `_showNotice(...)` ⇒ **顶部那一个浮窗**（`NoticeOverlay`，`Stack` + `Positioned(top:0)`，6 秒后自己走）。

⇒ **同一句话，屏幕上出现两次**：对话里一条 ＋ 顶上飘一条。他说的就是顶上那一条。

---

## 二、改了什么（一处判断 ＋ 一处位置）

| # | 在哪 | 改法 |
|---|---|---|
| ① | `chat_controller.dart` | **带号的通知（`notice`）不再"喊一声"** —— 只走 `timeline.apply`（进时间线）。`notice/urgent`（瞬态那条：写盘失败）**照旧**要喊（它**不进时间线**，不喊就没人知道） |
| ② | `chat_screen.dart` | 那个 `Positioned(top:0, …NoticeOverlay…)` **撤掉**；瞬态那条改画在 `_composerBody` 的 Column 里（**输入条上面**，与排队那条 `QueueStrip` 同一种形状）—— **参与布局**，收起档也看得见 |
| ③ | `widgets/notice.dart` | `NoticeOverlay`（浮的那一层：`Material`/`SafeArea`/`Align`/`Positioned` 语义）⇒ **`NoticeStrip`**（一条普通的条，只留 padding）。`NoticeCard` 一个字没动（两处共用、撤销仍是一件事） |

**今天的两条路**：

```
带号的通知（我去做/做完了/这件事我没做完/只读的活接着做…）
   ⇒ **只进时间线**（NoticeLine：在列表里、跟着滚、经得起"你不在"）
瞬态那条（notice/urgent：写盘失败）
   ⇒ **只画在浮窗里面**那一条（NoticeStrip）＋ 自己说清"这条没能写进记录里"
```

🔴 **一条都不许浮在内容上面**：两条都**参与布局**。

## 四、没做的 / 边界（**明说**）

* **瞬态那条会占一点高度**（它画在输入条上面 ⇒ 时间线那一块矮一点点）。
  这是**要的**（与排队那条同一种形状）—— 而"浮在内容上面"是**不要**的。
  ⚠️ 它是**稀有的**：只有写盘失败（盘满）才出现。
* **没有动"卡住收口"与后台那四句话本身**（服务端一个字没改）：改的只是**它长什么样**。
* **收起档**：带号的通知**只进时间线** ⇒ 窗口收起时看不见（要打开窗口）。
  ⚠️ 这是他的口径的直接后果（"不要浮窗"）；如果他还要"收着也能看见那一声"，
  那就是**另一件事**（例如画在收起档那一条里）—— **一句话就加**，见 §五。
* **安卓真机没验**（同 `142`：这条量在真浏览器上）。

## 五、他的口径（留着，别再读错）

> **不要浮窗。**（2026-09-30）

⇒ 通知这一类东西**默认进对话**（时间线），**不许**再出现"飘在内容上面"的形状。
真正需要"立刻看见"的只有**写盘失败那条瞬态**（它进不了时间线），它的家是
**窗口里面那一条**——不是浮窗。
