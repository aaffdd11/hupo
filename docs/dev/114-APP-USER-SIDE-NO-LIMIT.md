# 114 · 用户端没有"包"：他自己那一份不落版本快照、不查尺寸/文件数

> **这一篇是什么**：`D4.21`（`05-DECISIONS.md` O 组）在这一批代码上的**落点** ——
> 形状、动了哪几个字节、判据怎么反着验、真机读数是多少、还欠什么。
>
> **形状的原话记录**在 [`113-APP-SHAPE-LIVE.md`](113-APP-SHAPE-LIVE.md)（父 agent 当场记的）；
> **规范落点**在 [`08-SPEC.md`](../handbook/08-SPEC.md) **§14.6**；
> **"桌面点开的是活的那一份"那一半**在 [`112-OWN-APP-IS-LIVE.md`](112-OWN-APP-IS-LIVE.md)。
> 这一份做的是**另一半**：**用户端不该有"包"的任何规矩 —— 包括那三道上限。**

---

## 一、真机现场（主人 2026-09-26：*"这个问题是很严肃的"*）

主人在他的「奥数小站」里让助手扩充题库，助手撞上一堵墙，然后**停下来等他挑**：

> *"这一页现在 246,522 字节，离 256KB 的那条线只剩 15,622 字节。按现在这个写法，
> 每道题平均占 114 字节，也就是说这一页最多还能再装一百三十来道题。而你要的
> 「每个小类都有好几个年级段」，125 个小类每人再补两段就是 2000 道 ——
> 一条页面根本装不下，差着十几倍。"*
>
> 三个选项：**把答案写短** / **拆成两个图标** / **只补几个模块**。
> 下一句：*"就差你说的那一步把它推上桌面。"*

⇒ 两处都是**我们造出来的墙**：

| 助手以为的 | 真实应该是 |
|---|---|
| 一个页面最多 256KB，装不下要压缩或拆成两个小程序 | 他自己那一份**没有上限**（就是一间工作区，改完就是新的） |
| 做完要"推上桌面"（发布）才看得见 | **不用发布** —— 桌面点开的就是他正在改的那一份（`112`） |

根子（`113` §三·2）：我们把**"包"的规矩**（不可变版本 ＋ 单文件 256KB／总 2MB／40 个文件）
**挂在了用户端**。主人定的形状是：*"版本快照只在市场中存在。不在用户端。"*

---

## 二、形状（这一批之后）

```
用户端（他自己那一份 · 桌面那一格）            包（市场那一侧）
  workspaces/<id>/       ← 内容（活的，改完就是新的）   published-apps/<authorHash>/<id>/versions/<n>/
  hupo/apps/<id>/app.json ← 那张脸（登记：名字/图标/入口/权限/版本计数）      ↑ 发布那一步从工作区打出来
  ✗ versions/  ✗ current.json                          ✓ 单文件 / 整版 / 文件数 → 在这里查
```

| 动作 | 走哪条 | 查上限吗 |
|---|---|---|
| 造一个（`app_create`） | 工作区 `ensure` ＋（给了 `files` 才 `write`）＋ `apps.register()` | 🔴 **不查** |
| 改内容 | 助手在**那一间目录里**写文件（cwd 就是它）⇒ `app/workspace-changed` | 🔴 **不查** |
| 打开 | `/w/<id>/<entry>?u&e&s`（`112`） | 🔴 **不查** |
| 发到市场（`app_publish`） | 先把工作区**打成一版**（`snapshotWorkspace` → `apps.create`）再上架 | ✅ 查（打不成 ⇒ 如实拒，**他自己那份照旧能用**） |
| 从市场装（`app_install`） | 把共享库那一版复制进他的制品库 ＋ 镜像进工作区 | ✅ 查（那本来就是别人打好的包） |
| 改名 / 复制 / 删除 | 认人走 `apps.meta()`；活的那一份复制的是**工作区里的字节** | —— |

**认人只有一处**：`Apps.meta(id)` —— **登记（`app.json`）与包（`manifest`）都读**，
所以"活的那一份"与"装来的 / 发过一版的"不可能分成两套读法；
`schema` / `title` / `icon` / `entry` / `permissions` / `version` 这些协议字段**一个都没改**。

## 五、真机读数（u2 那台盒子 · 产品层 `cd782714a751` · 2026-09-26）

**① 盒子自己换到了新层**：容器内 `GET /api/version` ⇒ `{"buildId":"cd782714a751",…}`
（`--verify` 时那个一次性容器自报同一个指纹）。

**② 盒子里拿产品层自己的代码真跑一遍**（`/tmp` 临时数据目录，**不碰他真那一份**）：

```
① 用户端写入 300KB： 过了（旧形状会拒）
② 登记： {"ok":true,"version":1,"error":null}
   落了什么： app.json | versions/ 在不在： false
   清单里看得见： probe-big v1 live=true
③ 打成包（同一份内容）： 照旧拒 → 单个文件太大：index.html
⑤ 1MB 走真那条口（工具→套接字）： {"ok":true,"version":1,"error":null} | 工作区里： 1048576 字节
```

⇒ **同一份 300KB 内容**：用户端过 · 打成包拒 —— 上限**没消失**，只是回到了它该在的那一侧；
**1MB 的页面**走真那条工具口也过（旧那一行上限是 512KB）。

**③ 他真那一份（只读）**：

```
④ 真那一份： {"id":"aoshu-bank","title":"奥数小站","version":1,"live":false}
   工作区 index.html： 246522 字节 | 制品那一版： 17470 字节
```

⇒ 正是现场那一页（**246,522 字节** —— 助手算的就是它），而制品那一版只有 17,470 字节：
**桌面点开的是大的那一份**（`112` 已经在做的那一半），这一批补的是**它不必再被打成包**。
`live:false` 是因为他这一份还**只有包**（登记还没写过）—— 老形状照旧读，**下一次助手动手时会登记上**。

**④ 宿主那一侧端到端**（真令牌 `Auth.issue()` 现发、**不写进任何文件**）：

```
GET /api/apps                ⇒ HTTP 200 | aoshu-bank v1 live=false 「奥数小站」
GET <entryUrl>（活地址）      ⇒ HTTP 200 | 246,522 字节 | apps.stalkerai.cn /w/aoshu-bank/index.html
```

⚠️ **这一条走的是"以盒子为准"那条路**（u2 是租户 ⇒ 宿主经隧道问盒子）。

## 六、如实说（这一批**没有**做的 / 还欠的）

| # | 事项 |
|---|---|
| 1 | **他真那一份还没登记**（`live:false`）：我没有替他写 —— 那是"往他桌面上放东西"那一类动作，规矩是**他明说才许写**。下一次他让助手在那一间里动手，`app_create` 会顺手写 `app.json`（也可能他永远不写 —— 只有包的老 app 照旧能用，**不是缺陷**） |
| 2 | **助手下一轮才会知道"没有上限"**：`app_create` 的描述改了，而工具的说明是**每次会话装配时**给模型的；盒子里那台 agent 要在**下一次开工**时读到新描述。⇒ 建议主人跟它说一句"**继续补，没有大小限制了**"，它就不会再按 256KB 那套思路压缩 |
| 3 | **他自己那一份没有版本可回退**（这是形状的代价，已写进 `D4.21`）：要留底 ⇒ 先发一版（那就有包了）。`rollback` 对活的那一份**如实说"没有那一版"**，不假装 |
| 4 | **发布作为"界面功能点"的落点还没定**（`113` §五·2：甲 桌面图标面板 / 乙「发现」页"我发出去的" / 丙 小程序自己那一屏）—— 要主人拍一次；今天只有对话里那条 `app_publish` 工具 |
| 5 | **市场那一侧的"打成包 / 拉下来变源代码部署"**只有"落一版进共享库"那半（老路没动）；"装上来变成他自己那份源代码部署"那半是 `112` 的 `mirrorArtifactIntoWorkspace` |
| 6 | **`app_publish` 之后作者自己那格会多一个 `versions/<n>/`**（发布那一版留在他的制品库里）—— 形状上"包"出现在他这一格是刻意的（发布这个动作本来就属于市场那一侧），但**它算不算"用户端有包"**这件事我没有再往下改 |

## 七、这一批之前那些"容量"相关的症状，逐条对表

| 症状 | 今天 |
|---|---|
| 助手说"单页 256KB 上限，最多再放 130 道题" | 用户端**没有**这条上限；工具描述也不再这么说 |
| 助手说"就差你说的那一步把它推上桌面" | 不需要发布：改目录里的文件 ⇒ 屏幕上就是新的（`112`） |
| 助手为了装得下**压缩答案 / 拆成两个图标** | 不必；`app_create` 也可以**不交内容**（写在目录里就是它） |
| "没做成"只有他自己知道（助手说了句"我试几种压法"就没了） | 发布那一步真失败时，屏幕上有一条人话（`111` §六那条，这一批把措辞改成"**要发给大家的那一份**……**你自己那份照旧能用**"） |
| 一排 512KB 的套接字行上限 | 抬到 8MB（内存防呆）＋ **大内容不必走那一行** |
