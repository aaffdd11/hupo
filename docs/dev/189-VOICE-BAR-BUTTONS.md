# 189 · 那一格三颗按钮：录音 · 展开聊天 · 播放语音

> **主人 2026-10-05 原话**：*「语音按钮的右侧，需要两个按钮。一个是展开聊天，一个是播放语音。
>   所谓播放语音，就是开启和关停的状态，如果开启，会将对 agent 的回复进行语音转换和实时播报。
>   如果关闭，则不播报。播报只播报核心内容，也就是字体较大的那个内容。」*
> ⇒ 手册 `D3.14` 再补 · 升 `v2.57`。

## 二、播放语音那一颗说什么、不说什么

| | |
|---|---|
| **开** | 它**新说的话**（`message/end` 且 `reason == 'completed'`）会被念出来；那颗图标是实心喇叭 + 琥珀色 |
| **关** | 一个字节都不念，而且**关掉的那一刻立刻停下正在念的那一段**（不许"按钮说关、它还在念"） |
| **念哪一份字** | 🔴 **只念核心内容** ＝ 气泡里那两段**大字**（`quick` ＋ `deep`，`AssistantMessage.displayText`）。工具那一行 / 过程 / 出处 / 每轮 token 那些**小字一个都不念** |
| **什么时候念** | 那一条**说完**了才念（半句 / "没说完" / "卡住了"不念 —— 念出来会让人以为事情做完了）；**首屏那段历史不念**（一登录就把它以前说过的话全念一遍是骚扰） |
| **谁念** | 网页：浏览器自带的合成器（`window.speechSynthesis`，一个字都不往外发）。**安卓那一侧今天还念不出来**（`speech.dart` 那一条桩）⇒ **那颗按钮不画**，等火山那把语音合成接上再说（见 `181` §六 第一问的乙） |

⚠️ **念不出来的设备一个按钮都不许画**（`speech.dart` 纪律 ②）——
调用处那一句 `canSpeak ? … : null` 就是那道门，判据钉着它。

🔴 **网页上的一个真坑（顺手修了）**：浏览器给音色是**异步**的，而 `canSpeak` 是**同步**读的
⇒ 第一帧上还没有音色 ⇒ 那颗按钮**先不画**；没有别的原因重建的话，它要等很久才出现。
⇒ 新加 `watchSpeakReady()`（`speech_web.dart` 听 `voiceschanged`，别的平台空操作）：
音色一到位就举手一次，界面重建 ⇒ **按钮自己出现**。

## 五、如实说

* **安卓包里没有这颗按钮**（那一侧念不出来）：要真机上也能念，得先接火山的语音合成
  （主人要在控制台把「语音合成」开通）。
* **"实时"落地成"那一条说完就念"**：半句就念会念出改写过的中间态（模型边写边改），
  听起来像说错话再吞回去 —— 所以按"说完才念"办。要他改成"边写边念"说一声。
* **设置里那一颗「读出来」还留着**（同一个开关的第二个人口）：它带着"这台念不出来"那句解释。
  两颗并存是不是多余，等他一句话（要撤就撤设置里那条）。
