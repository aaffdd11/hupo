# 139 · **那颗「发送」在网页上点不到**（Flutter web 的输入法层盖住了整个输入框）

> **主人 2026-09-29 原话**：*「出现无法输入的问题」* → 追问之后：*「文字已经写好了，但是无法发送」*。
> 三选一他选的是：**琥珀色、能按，但按下去一点反应都没有（框里的字还在）** · 发生在**网页**。

---

## 一、根因（线上实测，不是推断）

上一轮（`#191`）按主人的话把「发送」（和「读出来」）放进了 `TextField` 的
**`suffixIcon`** —— 那是最省事的写法，而且 **widget 判据全绿**。但在**网页**上：

```
线上 1280 宽实测：
  发送钮的矩形                          [900, 554, 52×36]
  Flutter web 盖的那个 <textarea>       [328, 550, 630×50]   ← 把按钮整个盖住
  document.elementFromPoint(按钮中心)   ⇒ TEXTAREA（pointer-events: all）
```

🔴 **浏览器上"输入法那一层"是真的 DOM 元素**（`<textarea>`），位置正好是
**整个 `TextField` 的矩形**（含 `suffixIcon` ⇒ 含里面那两颗按钮）
⇒ 手指落在发送钮上的那一下**根本到不了 Flutter** ⇒ 按钮是琥珀色、`onPressed` 也接好了、
**就是点不到**（框里的字当然也还在）。

⚠️ **为什么一直没被发现**（三条，都记下来）：

1. **手机上没有那层 DOM** ⇒ 同一份代码在安卓上**是好的**（他在手机上是能发的）；
2. **widget 判据里也没有那层 DOM** ⇒ `tester.tap(find.byKey(chatSendKey))` 一路绿
   （`enterText` 也一样 —— 它是直接喂 `TextEditingController`，不走 DOM）；
3. 我这一轮为别的事拍的截图**都停在"没打字"那一帧**（空框时那颗按钮是灰的、也不该按）
   ⇒ 看不出问题。

## 二、改了什么（**看起来没变，结构变了**）

```
改前：  ┌─────────────────────────────┐
        │ 说点什么          🔊  ┌────┐ │   ← 按钮在 `TextField` 的 suffix 里
        │                        └────┘ │      （网页上被输入法那层 DOM 盖住）
        └─────────────────────────────┘

现在：  ┌─────────────────────────────┐   ← 这一圈 ＋ 实底住 `_messageBox` 那层容器
        │ 说点什么          🔊 │发送│ │   ← 里面是 `Row[输入框, 读出来, 发送]`
        └─────────────────────────────┘      按钮**不在输入框的矩形里**
```

* `composer.dart` 新增 `_messageBox`（`chatMessageBoxKey`）：**圆角容器 ＋ 实底 ＋ 描边**，
  里面 `Row[Expanded(TextField), 读出来?, 发送]`；
* 输入框自己改成 `border: InputBorder.none`、不再 `filled`（那一圈与实底归外面那层）；
* 🔴 **视觉上"发送还在消息框里面"**（主人 2026-09-29 那句照旧成立），
  而它在 DOM 那一层**不在输入框的矩形里** ⇒ 点得到；
* 「读出来」那颗**同一个病**（它原来也在 suffix 里）⇒ 一起搬出来。

## 四、没做的（**明说**）

* **没有把发送挪到框外面**（那能修好，但违背主人 2026-09-29 那句"发送按钮在消息框里面"）
  —— 现在这个形状两样都占：**看起来在框里、DOM 上在框外**。
* **没有自动化的"真浏览器点一下发送"判据**：`scripts/check-web-browser.mjs` 的合成指针
  送不进画布（老限制），而语义节点点击**能**点（这次就是靠它量的）—— 但那需要
  "框里先有字"（合成键盘事件送不进 canvas，所以那条路今天做不成）。
  ⇒ 这一条**如实记着**：E1 只能钉结构，钉不住"网页上真的点得到"。
* **没有去动 Flutter web 的输入法那一层**（那是框架的东西）。
