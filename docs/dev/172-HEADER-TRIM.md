# 172 · 聊天窗口那一行只剩"名字 ＋ 收起聊天"（回收站 / 导出 / 过程 三样砍掉）

> **主人 2026-10-03 原话**：
> *「回收站，导出，过程，我们也不需要。然后让收起聊天变成右侧的一个按钮，就叫收起聊天。」*
>
> ⇒ 他当场在两条路里选了 **甲**：**这三样整个不要了** ——
> **功能一起删掉**，首页那两句承诺也一起改（不再说"能拿回来 / 能带走"）。
> ⇒ **是删掉，不是藏起来**（手册 §六 纪律 6：要么做，要么明说砍了）。

---

## 一、改完长什么样

**会话头那一行**：`[ 名字 ]  …  [ 收起聊天 ]` —— 就两样。

- 名字那一格：**唯一会伸缩的那一格**（地方不够就截字）。
- 右边那颗：**带字的按钮**（原来是只有图形的箭头 ＋ tooltip）。命中区 ≥44（D3.6）。
- 原来那一串动作（回收站 / 导出 / 过程）＋ 装它们的那条**横滚**（`chatActionsStripKey`）
  **整条删了** —— 横滚那条账（`124` §三·五「390 宽下那几颗点不到」）**跟着结了**：
  没有那几颗了，就没有"点不到"。
