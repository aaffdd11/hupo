# 202 · **先暂停语义检查：说完就发**

> **主人原话**（2026-10-06 晚）：*「app对话响应很慢。我觉得我们现在先暂停语义检查。
> 不要检查语义，直接快速语音转文字，点击结束就发送。」*

---

## 一、量出来的代价（先摆读数）

| 量什么 | 读数 | 怎么量的 |
|---|---|---|
| `POST /api/hear` 那一次往返 | **0.61 秒 · 1.40 秒**（两次） | 现发令牌走**线上那条路**（宿主 ⇒ 他盒子 ⇒ `deepseek-chat`），body `{"text":"帮我做一个英语题的网站"}`；回执 `{heard, ask:null, fact:"", scene:"make-app"}` |

⇒ 那是"说完之后、发出去之前"**白白等**的一段时间（每说一句都要等一次）。

## 二、改成什么样

```
按下圆圈 → 说 → 按停（或对面 `asr/end` 收尾）
   ├─ 以前：送进听懂那一层（0.6~1.4 秒）⇒ 它可能反问一句 ⇒ 通了才发
   └─ 现在：🔴 **手上那份字直接发**（不改字、不问、不等）
```

* 用的是 `Hearing` 攒出来的**整段**（`asr/end` 那条带的，就是"总结"那一份）✓；
* **一个字都没有** ⇒ 照旧如实说「这句我没听清，再说一遍。」（不装发过）；
* 发出去之后 `voiceSent += 1` ⇒ 界面照旧把聊天记录窗口打开 ✓（与老那条路同一个落点）；
* **打字那条退路**（开不了麦时）走同一条：打完直接发 ✓；
* 设置里「试一下」那一屏也跟着不问：显示的是**语音转文字的原话**，并在屏幕上明说一句
  （`hearDrillPausedNote`：「现在不做语义检查：下面显示的就是你说出来的原话。」）。
