## 一、V1.0 是什么（一句话 ＋ 一张清单）

> **一句话**：**一人一台盒子、桌面上摆着他自己的小程序、说话它真去做、做完主动告诉他、
> 卡住会收场、重启还记得。**（`AGENTS.md` §一 那张"线上"表就是这张清单的别名。）

| 那一块 | V1.0 里已经有的 |
|---|---|
| **进来** | 手机号 ＋ 码（**临时验证码开着**：任何号都能进，这不是上线形态）· 没设密码时 fail-closed |
| **说话** | 打字 · 按一下说话（语音转文字落进输入框）· 画图 · 记账 |
| **它答话** | 会答 · 说话像它自己（人格 8 层）· **看得见它在做** · **卡住会收场** · **重启还记得**（跨重启接记忆） |
| **桌面** | **一格 ＝ 一间 ＝ 一条对话**；切房间**不重连**；**在建**那一格是灰的转着圈；**在做**那一格右下角一个圈；**做完自己变回来**；**桌面自己会刷新**（`D4.29`） |
| **小程序** | 从桌面加号建 · 助手在对话里说清就**当场做**（`D4.25`）· 能装（别人的 fork 成自己的）· 能上架 · 发现有 · 打开时一次把权限问完 |
| **长活** | 默认放后台 · **先说一声** · 做完 / 失败都**主动提醒** · 随时能问"那件怎么样了" · **不设时长限制** |
| **他自己的那台** | 「我自己那台」（开发者入口）· 配置页（模型 / 语音 / 图片 / 视频钥匙、界面亮暗与字号、壁纸） |
| **念出来** | 「读一遍」＋「自动念」（**今天只有网页能出声**，手机上念不出来 —— 见 §三） |
| **多租户** | 一人一台盒子（`hupo-a` / `hupo-b` / `hupo-t3`）· 盒里的助手**真能自己跑命令** · 每台 **4 GiB** 内存 · 产品层只读挂载、空闲时自己重开 |

## 三、冻结 = 什么（三条规矩）

| # | 规矩 |
|---|---|
| 1 | **线上停在 V1.0**：不删、不动、不顺手升级（盒子照旧"空闲时自己重开"到**已经发布的那一层**） |
