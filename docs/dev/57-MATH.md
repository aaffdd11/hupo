## 一、它长什么样

```
← 四年级奥数题                      ← 容器给的顶栏（小程序自己不许画）
   第 3 题 · 共 40 题                 ← 进度（不是"系统编号"，是他自己知道的数）
   ┌───────────────────────────┐
   │ 鸡兔同笼：一共 20 个头、        │  ← 题目
   │ 56 只脚。兔有几只？            │
   └───────────────────────────┘
   [ 看答案 ]                        ← 点开才给（先让他想）
   [ 换一题 ]                        ← 随机换一道，**答案自己收起来**
```

答开之后是：

```
   答案
   8 只                              ← 大字
   为什么
   全算成鸡是 20×2=40 只脚，多的 16 只脚 ÷2 = 8 只兔。   ← ★ 永远带这一句
```

## 二、这一刀最要紧的一条：**每道题都必须能被人验**

> **一道算错的奥数题，比"没有题"坏得多。** 这个项目最忌"看着像真的"。

⇒ 所以题库每一条都是 `(题目, 答案, 一句话"为什么")`，而且：

1. **界面上永远把"为什么"一起给出来** —— 不是只丢一个答案；
2. 🔴 **判据里用代码把能算的题重算了一遍**（`test/widget/math_quiz_test.dart` 里 21 道）：
   等差数列和 · 鸡兔同笼 · 植树（两端栽 / 圆形）· 盈亏 · 相遇 · 追及 · 火车过桥 ·
   归一 · 容斥 · 方阵 · 搭配 · 正方体棱长和 · 锯木头 · 敲钟 · 平均数 · 长方形面积 …
   ⇒ **不是"信我写的答案"，是"当场再算一遍"**；
3. 另有三条形状判据：每题都有答案与"为什么" · 题目不许重复 · 题库里**一句禁用词都不许有**。

## 三、加一个小程序要动哪几处（下次照这个清单做）

| # | 改哪儿 | 说明 |
|---|---|---|
| 1 | `models/<名字>_words.dart` | 文案集中一处（才进得了禁用词闸） |
| 2 | `models/<名字>_bank.dart` 或页面本身 | 内容（题库这类是纯数据） |
| 3 | `screens/<名字>_screen.dart` | 那一屏。⚠️ **不画 `Scaffold`/`AppBar`** —— 顶栏由容器给；整屏用 `ListView`（五档不溢出） |
| 4 | `screens/chat_screen.dart` | ① 桌面 `apps:` 里加一个 `DesktopApp` ② `_openMiniApp(from, '<名字>')` ③ 容器里按名字给 `title` 与 `child` |
| 5 | `test/widget/<名字>_test.dart` | 内容判据 + 那一屏的判据 |
| 6 | **`test/widget/accessibility_test.dart`** | 🔴 **两处都要注册**（D3.5 五档不溢出 + D3.6 命中区）—— 新界面不进那道闸，它就会随时间失效 |
