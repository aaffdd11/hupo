# 18 · **楼层闸**（让禁令有约束力，而不是口号）

> **这一批只做一件事**：把手册 §2.3 那三条禁令**变成一条会响的硬闸**。
>
> ⚠️ 它不是"新功能"，是**债**：手册 §2.4 自己写着——
>
> > `analysis_options.yaml` 是 `flutter_lints` 模板，**加不了 import 禁令**
> > —— 写在文档里就是**没有闸**。…这是"禁令有约束力"与"禁令只是口号"的**唯一区别**。
>
> **手册依据**：`03-DEVELOPMENT.md` §2.3（三条禁令）· §2.4（怎么强制）·
> `04-ROADMAP.md` 批 1.5 第 4 件 · 风险 **H7**（"只拆纯函数、不补楼层闸"）
> **代码**：没有——**这一批一个生产文件都没改**
> **测试**：`test/unit/import_rules_test.dart` **+5**（unit 85 → **90**）

## 一、为什么这件事比它看起来重要

`import` 方向错了，**编译器一声不响**：

* `models/` 里 `import material` ⇒ 纯逻辑被 UI 绑住 ⇒ **那个文件的测试从此要 `pump`**
* `services/` 里 `import screens` ⇒ 传输层认识界面 ⇒ 换界面要动传输
* `widgets/` 里 `import services` ⇒ 组件绕过 controller 直连 ⇒ **状态变成两份**

这三种烂法都**不是一次写成灾难**，是**每次图省事加一行**。
而它们全都有一个共同特征：**没有任何闸会响**。
⇒ H7 说的就是这个：拆得再漂亮，禁令没人守，下一个人的一行 import 就把它吃回去。

> 这一批还顺手证明了一件事：**v2 今天的方向是对的**（下面那张表）。
> 但"今天对"正是最容易在某次省事里被破坏的东西。

## 二、v2 的楼层（`lib/` 下就这五层）

```
main.dart     入口：谁都认识
  ├── screens/    装配层：什么都行
  │     ├── services/   传输与状态：**不许碰屏幕**
  │     │     └── models/   纯逻辑：**不许碰 UI、不许碰 I/O**
  │     └── widgets/    傻组件：**只看 models**
```

| 层 | 允许指向 | 点名不许 |
|---|---|---|
| `models` | `models` · `flutter/foundation` | `material` / `widgets` / `cupertino` · `http` · `web_socket_channel` · `shared_preferences` · `dart:io` |
| `services` | `models` · `services` · 第三方 · flutter | `screens` · `widgets` |
| `widgets` | `models` · `widgets` · 第三方 · flutter | `services` · `screens` |
| `screens` | 全部 | —— |
| **认不出来的新目录** | **什么都不能指向**（fail-closed） | 全部 |

⚠️ 最后那一行是**刻意**的：新加一层目录**必须回来把 `allowedTargets` 补上**。
默认放行等于"新楼层悄悄继承最宽松的规矩"——那正是禁令烂掉的方式。

## 三、三道自证（**闸本身也是要证的东西**）

一条"永远为绿"的闸比没有闸更坏（它给人已经守住了的错觉）。
所以这一份有三道自证：

| # | 自证 | 防的是什么 |
|---|---|---|
| ① | 真树必须**扫到 ≥15 个文件**，且四层**每层都非空** | **扫到 0 个文件也能"全过"** |
| ② | 六种**合成违规**必须**全都抓得住**（models 碰 UI / 做 I/O / 直接调服务、services 碰屏幕、widgets 绕过 controller / 碰屏幕） | 规则写错、正则写漏 |
| ③ | 一份**干净的样子不许误报** | 误报的闸会被绕过 |

**变异验证**（在真树里塞一行违规）：

```
lib/models/timeline.dart + import '../services/api.dart';
→ 🔴 红：lib/models/timeline.dart → ../services/api.dart（models 层不许指向 services 层）   ✅
```
