# 49 · 一套外观（首页是基准，另外三屏向它看齐）

> 主人 2026-09-22：*"我们现在统一一下页面风格。看看首页，就知道登录页需要改了，
> 配置页也要改。聊天页也要改。"*
>
> **他是对的，而且原因很具体**：首页自己长成了一套（暖纸底 + 陶土红 + 白卡），
> 而**另外三屏是 Material 默认样**（蓝顶栏、蓝按钮、冷灰底）——
> 四屏摆在一起**不像一个产品**。

---

## 一、基准长什么样（首页那六个颜色）

首页原来把这六个常量**写在自己文件里**（`_paper` / `_accent` / …）——
所以别的屏想跟着它，只能**再抄一份**，而"同一份数字写两处 = 一定会漂"是这个项目的老毛病。

| 名字 | 值 | 用在哪 |
|---|---|---|
| `paper` | `#F8F5EE` | 全站底色（暖纸） |
| `accent` | `#C8452F` | 主按钮、强调、小标（陶土红） |
| `ink` | `#2B2320` | 正文（**不是纯黑**：纯黑压在纸底上偏硬） |
| `muted` | `#7A6E66` | 说明文字、提示 |
| `card` | `#FFFDF9` | 卡片白（比纯白暖一点） |
| `line` | `#E8E0D4` | 描边 / 分隔线 |

外加三档圆角（`radiusCard 18` / `radiusField 12` / `radiusChip 10`）与三档间距（`gapS/M/L`）。

---

## 二、**数值只有一处出处**

| 文件 | 是什么 | 为什么住这儿 |
|---|---|---|
| `lib/models/design.dart` | 上面那六个颜色 + 圆角 + 间距 | **纯数据**（只 import `dart:ui` 的 `Color`）⇒ 进得了 `models` 那一层（楼层闸：models 不许碰 material） |
| `lib/screens/app_theme.dart` | 把 tokens 拼成 `ThemeData` | 拼主题要用 material ⇒ 只能住界面层；但**数值一个都不在这儿写** |
| `lib/widgets/brand_mark.dart` | 那个小红方块 + 名字 | 首页与登录页**共用一个实现**（原来只有首页有，登录页光秃秃一句"助手"） |

🔴 **四屏统一靠的就是 `buildAppTheme()` 这一个函数**：动手之前先量过 ——
全站**只有一处**硬编码颜色（`widgets/notice.dart` 的 `Colors.transparent`），
其余**全走 `colorScheme`** ⇒ 把主题拼对，四屏**一起跟着变**。

---

## 三、逐屏还改了什么（主题之外）

| 屏 | 改了什么 |
|---|---|
| **首页** | 把那六个常量**换成共享 tokens**（它原来是源头，现在只是使用者）；标志改用 `BrandMark` |
| **登录页** | 顶上放**同一个标志**（居中）；底色/按钮/输入框跟着主题（陶土红胶囊 + 暖白圆角输入框） |
| **配置页** | 从"一行行字 + 一条分隔线"改成**小标 + 白卡**（首页那套语言）：钥匙一张卡、关于一张卡 |
| **聊天页** | 顶栏变纸底无阴影；助手那一条 = 暖白卡、用户那一条 = 陶土淡色；通知条 = 暖红 |

⚠️ **一个字号的数值都没新写**（手册 D3：容器跟字算）：标志那块固定的是**图形尺寸**，
里面的字仍然用 `labelLarge`（跟系统走）。

### 4.1 闸在这一次改动里抓到的两件事（都值得记）

1. 🔴 **「关于」在 3.1x 那档被挤到折叠线以下** —— 配置页改成"卡片 + 可滚列"之后，
   `ListView` **不会把屏幕外的孩子建出来** ⇒ 判据里 `find.text('关于')` 一个都没找到。
   ⇒ 不是把那一行硬塞进屏幕，而是**让判据像用户那样先滚再点**（`scrollUntilVisible`）。
2. ⚠️ **改完主题要重新量一眼**：我用像素采样确认过底色 `#F8F5EE`、
   助手那一条 `#FFFDF9` —— **肉眼看纸底上的暖白会误判成灰**（我第一眼就判错了）。

## 五、顺手把"看一眼某一屏"这条工具修好了

改版期间最缺的能力是**看见**每屏长什么样。原来那份浏览器检查：

| 原来 | 现在 |
|---|---|
| **点不动**：CDP 的 `Input.dispatchMouseEvent` / `dispatchTouchEvent` 都送不到 Flutter（连聚焦模拟也加了，**页面逐字节不变**） | ✅ `--click-at X,Y`（可给多次）：走**页内合成 pointer 事件**（Flutter 监听的就是它，**不查 `isTrusted`**）。实测能一路点进"配置 → 关于" |
| **没令牌就不干活**（未登录那两屏看不到） | ✅ `--no-token`：只看屏幕，**不判那条流**，而且用**单独的退出码 4**（免得"0 = 路通了"被读成一句没验过的好话） |

⚠️ 它**只用来"看一眼"**，不是判据 —— 判据仍然是 `test/widget/*`（真点真断言）。
⚠️ **点按要按实际视口量坐标**：这台机器上默认视口是 `1280×614`（`--width/--height` 传了也未必是你以为的那个）——
所以"页面现场"里现在把 `w/h/dpr` 一起打出来。
