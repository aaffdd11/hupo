## 一、我怎么看的（**先看，再改**）

用**他自己那个号**登录（手机号 ＋ 临时验证码那条路），真浏览器（`scripts/check-web-browser.mjs`）
拍了这几张：宽屏 1280×757 与手机档 430×932 的聊天窗口（收起 / 展开 / 滚到历史）、
右侧那一栏（「这一窗动过哪些文件」）、「导出」页、「回收站」页。
⚠️ **令牌是现发的、不进任何文件**（`auth.issue`／登录回执都只走环境变量）。

**看到的三件事**（每一条都是屏幕上真的那样的）：

1. **通知把那一条时间线吃掉了**：连着 9 个「我去做，做完叫你。」那样的一模一样的粉色块
   （`NoticeCard`：`accentTint` 底 ＋ 描边 ＋ ⓘ），其中一句还被截成「…」再带一句
   「（在「数独」里）」。真正说的话（它那一整段回答）**被压在中间**，
   一眼看过去像"满屏报错"。
2. **它说的话没有"容器"**：用户那句是蓝色气泡（靠右），而它那一大段是**裸文字**
   —— 一轮到哪里结束、下一句从哪儿开始，只能靠读内容猜。工具行那句是
   `mcp__apps__app_create · 飞行棋 在跑`（**内部词直接上屏**），用量那行是
   「本轮用量：未缓存输入 515 tok …」（**给模型看的口径**）。这些都在**正文那一层**。
3. **两页"记录"看着像没做完**：导出页是一个大框 ＋ 一大段等宽字（`我：` / `它：` 连着排）；
   回收站页只有「3 条 / 彻底删掉的时间：2026-10-22 / 恢复 彻底删掉」——
   **看不见那 3 条是什么**（服务端其实给了每条的预览与他自己的原话）。

## 二、改法（三处，逐条）

### 2.1 聊天窗口（`widgets/{bubbles,notice,tool_row_view,chat_floater,harness_pane}.dart`）

| 项 | 改前 | 改后 |
|---|---|---|
| **它的话** | 裸文字（没有容器） | **一张安静的卡**：`bgLayer2` 底 ＋ 发丝描边 ＋ `r12`，**不画阴影**（平面用描边，见 `design.dart` 那条规矩），限宽与用户气泡同一档 |
| **一轮的边界** | 看不出 | ★ **时间分隔**：每条带 `at`（服务端每个事件都盖了），跨天/隔久了插一条**居中细线 ＋ 人话时刻**（`今天 14:32` / `昨天 09:05` / `10月1日 21:33`） |
| **通知** | 粉色大块、每条一张、重复九张 | **一行安静的字**（小图标 ＋ 次要色，**不铺底、不描边**）；🔴 **连着同样的几句合并成一行带次数**（「我去做，做完叫你。×4」）；只有 `crash` / `diskFull` 那两档留**警示**形状（那才值得占眼睛） |
| **工具行** | `mcp__apps__app_create · 飞行棋 在跑` | 人话：「**做一个小程序** · 飞行棋 · 在跑 / 成了 / 没成」；🔴 **原始名字只留在展开的那一块里**（`toolRowRawNameLabel`，要核对时还找得到）；认不出的工具**那一格留空**（N10，不编）。⚠️ 手册 `05-DECISIONS.md` 的 **D1.1·补**（“聊天窗口内放开”）**没有被撤销** —— 放开的那些东西还在，只是**默认那一行说人话**、核对层在展开里 |
| **用量那一行** | 每一轮正文里都排一行 token | ★ **收进「过程」折叠里**（默认收起）——它是"过程"的一半，不是"他说的话"的一半 |
| **右栏** | 小字、`edit` 这种内部名 | 工具名换人话（「改文件」）；认不出的说「一件我说不上来的事」（**不把内部名补回去**）；路径照实显示（那一栏本来就是他问“动过哪些文件”） |
| **顶栏** | 标题 ＋ 一排"图标＋小字"，挤 | 标题 20/w600；右边那几颗**各自 44 命中区**、图标与字一套色（`labelSecondary`），「收起」仍是钉死的出口 |

### 2.2 导出（**对话记录**那一页 · `screens/export_screen.dart`）

| 项 | 改前 | 改后 |
|---|---|---|
| 形态 | 一个大框里一段等宽字 | **能读的记录**：按天分组（「10月1日」当小标题）、每条前一行 `我` / `它` 的**标签**（不同色）、正文按正文那一档排版 |
| 复制 | 一颗按钮（在下面） | ★ 抬头右边一颗**常驻的「复制全部」**（复制的仍然是**服务端拼好的那段原文**，一个字节都没重拼） |
| 数据 | 只有 `text` | ★ 服务端**顺手把折好的条目也带上**（`items: [{seq, at, who, text}]`，**新增字段**：老客户端看不见就当没有，行为逐字不变；`text` 一个字节没改）；拿不到 `items`（老盒子）⇒ **退回原来那段文字**，一个像素都不少 |
| 空 / 读不出来 | 一句实话 | 照旧那句实话，另外给一句"能干什么"的说明（不给空框） |

### 2.3 回收站（`screens/trash_screen.dart`）

| 项 | 改前 | 改后 |
|---|---|---|
| 一条 | 只有「3 条 」＋ 一个日期 | ★ **一条一张卡**：**他自己那句话**（★ 服务端**新增**一个键，见 §六 第 1 条）＋「什么时候删的」＋「还能放到什么时候」 |
| 抬头 | 「3 条」 | 「**这 N 次删掉的还能放回来**」＋ 一句说清**过了那个时间就没了**（`ttlDays` 由服务端给） |
| 按钮 | 「恢复 / 彻底删掉」小字 | 两颗**≥44**的按钮，「彻底删掉」走**二次确认**（那一步拿不回来） |
| 空 | 一个空页 | 一句「这儿是空的」＋ 下一句（删掉的话会先来这儿） |

## 三、数值/用词纪律（**三处共守**）

* **数值只住 `models/design.dart` 与 `models/dsh_design.dart`**：新代码里**一个写死的字号/圆角/间距都不许有**
  （`test/unit/design_tokens_test.dart` 那条棘轮会红）。要新数就**加 token**，别就地写。
* **界面用词只住 `models/*_words.dart`**（那样才进得了禁用词硬闸）：
  新增的每一句都要过 `forbidden_words` 那条扫。
* 🔴 **内部词不许上屏**：工具名、`tok`、`turn`、`scopeId` 这类一律**不在正文那一层**出现
  （要看得见就收进"展开"里 —— 那是核对层）。
* **命中区 ≥44**、**五档字号（1.0/1.75/2.0/3.1 ＋ 用户字号 12/14/17）不溢出**
  —— `test/widget/accessibility_test.dart` 是硬闸，新界面必须进那棵树。

## 四、判据

| 处 | 判据（真函数 / 真树，不是"控件在不在"） |
|---|---|
| 通知合并 | 纯函数：连着同样的通知 ⇒ **一行 ＋ 次数**；中间夹了别的东西 ⇒ **不合并**（负向对照） |
| 工具行人话 | 纯函数：认识的工具 ⇒ 人话；不认识的 ⇒ **如实"认不出"**（不编一个人话）；原始名**只在展开层** |
| 时间分隔 | 纯函数：同一段里跨天 ⇒ 插分隔；同一天相隔很近 ⇒ 不插（负向对照） |
| 用量收进过程 | `widget`：默认状态下**屏幕上没有 `tok`**；展开「过程」之后才有 |
| 它的话有容器 | `widget`：它那条**有卡**（描边/圆角），且**没有阴影**（平面那条规矩） |
| 导出页 | `widget`：按天分组 ＋ `我`/`它` 标签 ＋ 复制按钮真的复制**服务端那段原文**；`items` 缺了 ⇒ 退回文字块 |
| 回收站 | `widget`：预览那行出自服务端给的 `preview`（**不许客户端自己截**）＋ 两颗按钮 ≥44 ＋ 彻底删掉要二次确认 |
| 服务端 | `test/export.test.js`：`buildExport` **多带一份 `items`**，而 `text` 一个字节没变（同一组输入逐字对） |

## 五、不做什么（**明说砍了，不写"以后再说"**）

* **不改协议语义**：`/api/export` 只**新增** `items`（老客户端看不见就当没有）；别处一个字段不动。
* **不在客户端重拼那段导出文字**：复制走的永远是服务端给的那份 `text`。
* **不做 Markdown / HTML 渲染**：工具输出与正文照旧纯文本（`116` 那条纪律）。
* **不把时间戳塞进排序**：`at` 只用来**显示**，排序照旧按 `(seq, tie)`（`timeline.dart` 那条禁令）。
* **不恢复轨迹那一屏**（`118` 已砍）。

## 六、做的过程中挖出来的两件事实（**都已落地**）

1. 🔴 **`/api/trash` 的 `preview` 不是“他自己的话”**（2026-10-02 实测）：
   `src/trash.js` 里它就是 `` `${messageIds.length} 条` `` —— 截图里那个「3 条」**就是**它
   （那一段的注释还明说“不在这条路上读内容”），而客户端 `models/trash.dart` 的注释写着
   “用户自己的话”。⇒ **不改已上线字段的语义**（协议冻结那条）：
   **`preview` 一个字节不动**，服务端**新增一个键**装“他自己那句话”
   （首选 `user/echo.text`，没有就退第一条 `message/text`，再没有就不放这个键）；
   客户端认新键、**拿不到就退回 `preview`**（新界面 ＋ 老盒子也不空白）。
2. ⭐ **抬头那一档字（20/600）原来是就地 `copyWith(fontWeight:)` 凑的** —— 违反“数值只住 token”。
   ⇒ 收进 `models/dsh_design.dart` 的 **`DshTypes.title`**（20 / 600 / 28），
   三处抬头（聊天窗口 / 导出 / 回收站）**共用同一个 token**。
