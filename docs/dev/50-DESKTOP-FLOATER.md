## 二、我这一版写了什么（已在 `/tmp` 留档，未合入）

| 文件 | 是什么 |
|---|---|
| `widgets/app_desktop.dart` | 图标墙（4 列，带字的图标格，未读小点位置留着）；点空白 = `InkWell`（**不用 `GestureDetector`** —— 那份源码级禁令会红） |
| `widgets/chat_floater.dart` | 三档浮窗：`Listener`（原始指针）跟手拖 + 松手吸附 + 甩（三个条件）+ 双击 + **400ms 防抖** + `Listener(behavior: opaque)` 拦截 + 收起条带字「展开」 |
| `screens/chat_screen.dart` | 组合：`Stack([桌面, 浮窗, 通知])`；原来 AppBar 那 5 个动作搬进抓手行；"发就拉满"接在输入条上 |

⚠️ 两处**当场被闸抓住**（都值得记，下一轮别再踩）：
1. **`Positioned` 必须是 `Stack` 的直接孩子**。我一开始把它包在 `LayoutBuilder` 里
   ⇒ 整棵树报 `Incorrect use of ParentDataWidget` ⇒ **148 个 widget 测试一起红**
   （现象极像"什么都坏了"）。⇒ 用 `MediaQuery` 算高度，别用 `LayoutBuilder` 包 `Positioned`。
2. **抓手行不能横向溢出**：标题 + 6 个图标按钮，窄屏**一定**放不下。
   用 `Wrap` 折行会把它变高 ⇒ 撞上下一条（浮窗高度是定的）。

## 三、🔴 卡住的地方（实测，不是猜）

跑 `accessibility_test.dart`（**硬闸**：五档不溢出 + 命中区 ≥44）：

| 症状 | 实测 |
|---|---|
| **纵向溢出** | `RenderFlex overflowed by 798 / 289 / 175 pixels on the bottom`，出错的是 `chat_screen.dart` 里那个 `Column`（= 浮窗里那一整块：状态条 + 时间线 + 输入条） |
| **命中区** | 收起态那个「展开」`TextButton` 只有 `100.3×14`（要 ≥44）——**已经知道怎么修**（`minimumSize: Size(88,44)`） |

**根因（我的判断）**：浮窗的高度是**定死的**（`maxH = 屏高 - 四边边距`），
而里面那几条 chrome（状态条 + 输入条）在大字号下会**长高**；
`full` 档给的是"屏幕那么大"，于是 `Expanded` 里那条时间线被挤到负数 ⇒ 溢出。
**手册那句话正好是这一条的答案**（D3.5）：**容器跟字算，不是字跟容器** ——
我这一版是**反的**（先定容器高度，再往里塞字）。

**下一轮怎么修**（按优先级）：
1. **浮窗高度改成"由内容算、上限才是屏高"**：`ConstrainedBox(maxHeight: …)` +
   `mainAxisSize: min`，让 chrome 先占它该占的，时间线取剩下的（`Expanded`）。
   ⚠️ 那一档的**下限**也要有（不然大字号下浮窗会缩成一条）——
   下限 = 抓手行 + 输入条 + 一行字，**由字算出来**，不写死。
2. 收起条的「展开」按钮给 `minimumSize`（已知修法）。
3. 那串动作：窄屏 + 大字号下**一行 + 横向滚动**（不折行、不藏）。
4. 然后再补这一批的判据（**每一条都带负向对照**）：
   - **Z1**：对浮窗中心坐标 hit test ⇒ 命中**聊天**（不是桌面/小程序）；
   - **Z3**：四边边距 > 0；
   - 点桌面空白 ⇒ 收起；点浮窗内部 ⇒ **无反应**（negative control：改成 `deferToChild` ⇒ 必须红）；
   - **D4.8**：新增助手消息 ⇒ `chatBodyKey` 那个矩形**高度变化 = 0px**（既有那条闸继续守着）；
   - 三档：发送 ⇒ 最大化；双击抓手 ⇒ 收起⇄上次档位；**400ms 内两次触发只算一次**；
   - 收起态**有带字的展开入口**（D3.8），且命中区 ≥44；
   - 五档不溢出（进现有硬闸）。

## 四、小程序容器（**这一刀没做，明说**）

桌上只有一个「会话」图标，而**它是聊天浮窗本身**（Z1 要求它永远在最上，不是容器里的 app）
⇒ **容器壳这一刀没有东西可装**。摆一个空壳 = "点了没反应的东西"，这个项目最忌那个。

**它下一次的落点**（等第二个图标上桌时一起做）：
* 容器壳 = 顶栏由容器给（返回 / 标题）+ 应用内容跑在**容器自己的 `Navigator`** 里；
* 最现成的第一个 app 是**「关于」**（现在挂在配置页里）——
  搬进容器之后就能验"**应用内部怎么跳都跑不出这个容器**"；
* Z2（被盖住不重建）要**真验**：打开小程序 → 盖住 → 回来 ⇒ 滚动位置/表单内容**都还在**。
