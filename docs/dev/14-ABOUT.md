## 一、⚠️ 那段话**只有在特定条件下才允许那么说**

D3.3 的原话（v1.1 修订）值得整段抄下来，因为**它自己就是一次纠错**：

| 设备情况 | 事实 | 该怎么写 |
|---|---|---|
| **输入法自带语音** | **能用** —— 走的是**输入法**，不是我们的话筒 | ❌ **不许写"用不了"**——那是**假话**，而且会**劝退一个其实能用的人** |
| 输入法没有语音 | 真的用不了 | ✅ 必须明写 |

⇒ 规则：**按当前这台设备如实说**；**检测不到就说得保守**；**不许一刀切**。

⚠️ 而且 **我们检测不到**输入法有没有麦克风（没有那个 API）⇒ 这一页**永远走保守那一路**。
**不假装知道**，也不写死结论。

### 1.1 写出来的三句

```
它怎么听你说话
  能不能用嘴说，取决于你这台设备上的输入法。
  如果你的输入法有麦克风：点麦克风 → 说 → 字进到输入框里 → 按发送。
  我们自己没有另外做一个话筒。
```

第三句不是废话：不写它，用户会去界面上找那个**不存在的**话筒（这正是 D5.5「"正在听…"是假承诺」
的那一类——**一个词两个意思，比什么都不说更坏**）。

另外两条（顺手把 ★2/★4/★5 那三个放弃点也答了）：

```
它记不记得
  记得，但记得不多：关掉再打开，它还能看到最近这一段，大概几十句。
  更早的就不在它眼前了。
  它没看到的，它会说不知道 —— 不猜。

它说的话能信到什么程度
  数字、日期、人名这些，它拿不准会直说拿不准。
  要是你发现它编了，那是它的错，直接说它。
```

⚠️ 「大概几十句」**不是随口写的**：它要对得上实现里的额度
（`recapMaxEntries` / `recapMaxChars`，住在 `services/core/src/recap.js`）。
**写"全都记得"就是撒谎**（★2：黑盒记忆 = 默认没记住）。

## 二、文案是**数据**，不是写在界面里的字

```
lib/models/about_facts.dart    ← 文案（**不许 import flutter/material**）
lib/screens/about_screen.dart  ← 只负责摆
```

⚠️ **为什么这么分**：手册纪律是"**纯函数进 `test/unit`**，那是硬闸"。
文案摆在 `screens/` 里的话，禁用词闸就够不着它——**而这一页的字恰恰是最要紧的那几句**。

| 闸 | 在哪 |
|---|---|
| 禁用词（工作区 / 连接 / 工具 / **正在听**…） | `test/unit/about_facts_test.dart` **+** `forbidden_words_test.dart`（直接引数据源，**不手抄**） |
| D3.3 的三条（按设备 / 保守 / **不许一刀切**） | `test/unit/about_facts_test.dart` |
| 五档不溢出 + 命中区 ≥44 | `test/widget/accessibility_test.dart`（**硬闸**，39 条） |

### 2.1 那条"不许一刀切"是**逐字**查的

```dart
for (final bad in ['用不了', '不能语音', '不支持语音', '打不了字', '不会拼音'])
  expect(t.contains(bad), isFalse, reason: '「$bad」是一刀切 —— 在带语音输入的设备上是假话');
```

⚠️ 这不是洁癖：手册把它记成了一条**教训**——

> 一句本来正确的"诚实说明"，**在前提变了之后会变成另一种谎言**。
> ⇒ 凡是从"某能力缺失"推出的文案，**能力一到位就要回来改它**。

## 三、入口：顶栏一个 i

⚠️ **入口必须"像用户那样"可达**，而且这一点被测试逼出来了：

第一版测试直接把 `AboutScreen` 当 `home` 泵出来量命中区 ⇒
**它没有返回键**（没有可弹回去的路由）⇒ 扫到 0 个可点目标 ⇒
被那条**负向对照**（"一个能点的都没扫到 ⇒ 这条闸是空转的"）拦下来。

⇒ 改成从主界面**点顶栏那个 i** 进去（`_openAbout`）——
这样顺带也验了**那个入口通不通**。

### 4.1 线上实测

⚠️ 一个**差点误判**的地方：`main.dart.js` 里的中文是**转义成 `\uXXXX`** 的，
所以拿中文原文去 `grep` **会得到 0 命中 —— 而那是假阴性**。
要按转义形式查：

```
$ curl -s https://w.stalkerai.cn/main.dart.js > /tmp/pub.js
$ grep -c '\\u9ea6\\u514b\\u98ce' /tmp/pub.js          # 麦克风
1
$ grep -o '\\u53d6\\u51b3\\u4e8e\\u4f60\\u8fd9\\u53f0\\u8bbe\\u5907' /tmp/pub.js
\u53d6\u51b3\u4e8e\u4f60\u8fd9\u53f0\u8bbe\u5907                  # 取决于你这台设备
```

外加 `/api/version` → `{"buildId":"about-1"}`，且公网那份与本地产物**逐字节同大小**
（2388741）⇒ 线上跑的就是刚出的那一版。
