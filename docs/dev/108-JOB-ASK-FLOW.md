# 108 · 派活那一步的体验：**先问一句 · 切过去像没切 · 做完自动给我看**

> 主人 2026-09-25 原话：*"我发送完以后，他会询问我是否开启一个新的工作区……如果我选是的话，
> 那么他会在 dsh 那边创建一个工作区叫做奥数，这个名字其实是 AI 那个 agent 他自己给的。
> 然后我不需要知道这个名字……然后它会自动切入到那个工作区里面的对话……对用户来说，
> 尽管对话已经切了，但是用户是感觉不到的……那我应该会收到一条消息，就是啊说正在干嘛什么的，
> 把这些细节可以显示出来，然后我就是等待它完成……建完以后它应该会自动刷新这个 APP，
> 给呈现出一些东西来给用户。"*
> 三条追问都拍**推荐项**：**① 弹一个两按钮的确认层 ② 那一间里要能看见"接着往下" ③ 做完自动把它打开**。

---

## 一、形状（四步）

```
① 他说"帮我做一个 X"
      └─ 助手（agent）调 `job_start(where, why)`
           └─ 🔴 **不立刻建**！服务端把它记成一笔**待确认的派活**，并给他**推一帧问话**：
              屏上出**一个确认层 + 两个按钮**：  【另开一处做】  【就在这儿做】
              （回给 agent 的话是"已经问他了，等他答" ⇒ 这一轮就此收口）

② 他点【另开一处做】
      └─ **这时才建**（工作区 ＋ 会话 ＋ 登记）＋ 推 `scope/open`
           ├─ 客户端**切过去**（既有那条路）
           └─ 🔴 那一间的视图里**先有他那句原话**（＋"我去做"＋子进程的过程）

③ 他点【就在这儿做】
      └─ **什么都不建**；回给 agent："他说就在这儿做" ⇒ 它**在主对话里**把这件事做完

④ 子进程交回总结（`job/report`）时，**他正开着那一间** ⇒ 客户端**自动把那个东西打开**
   （就是"点开图标"那条路）＋ 旁边留一句总结
```

### 不许破的几条

1. 🔴 **没答之前不许建**（那就是"先做了再问"）；
2. 🔴 **超时 / 不答 ⇒ 不许猜**：那一笔记 `expired`，如实说一句"那件事我还没动手"——**不建**；
3. 🔴 **只有"他正开着那一间"时才自动打开**（别在他看别处时抢屏）；
4. 🔴 两按钮的问话**复用既有那条"反问"那条路**（`SayAsk` / 那个确认层的形状），**别另造一套**；
5. **"接着往下"不许复制事实**：那一间里看到的是**他那句话的视图**＋子进程自己的过程
   （一条事实一个家 —— 复制一份就是两份真相，这个项目不许）。

## 二、判据（草案，实现时逐条补全并变异验证）

**服务端（`v2/services/core`）**
| # | 判据 | 反例 |
|---|---|---|
| **S1** | `job_start` 之后**盘上没有新工作区**（待确认只记一笔） | 先建了再问 ⇒ 红 |
| **S2** | 答【是】⇒ 这时才建（工作区 ＋ 会话 ＋ 登记）＋ 推 `scope/open` | 答了还不建 ⇒ 红 |
| **S3** | 答【否】⇒ **什么都不建**，且 agent 收到"就在这儿做" | 答否也建了 ⇒ 红 |
| **S4** | **不答**（超时）⇒ 不建、如实说一句、那一笔记 `expired` | 超时替他默认 ⇒ 红 |
| **S5** | 那个确认层是**瞬态帧**（不落盘、不占号、不重放） | 进了日志 ⇒ 红 |
| **S6** | 别的用户收不到这一帧（一人一份世界） | 收到 ⇒ 红 |

**客户端（`v2/apps/mobile`）**
| # | 判据 | 反例 |
|---|---|---|
| **C1** | 收到那个问话 ⇒ 出**确认层 ＋ 两个按钮**（文案住一处表；≥44 命中区） | 没出 / 只有一个按钮 ⇒ 红 |
| **C2** | 点【另开一处做】⇒ 发出"答是"⇒ 之后**窗口自己切过去** | 点了没反应 ⇒ 红 |
| **C3** | 点【就在这儿做】⇒ 发出"答否"．**不切房间** | 答否也切了 ⇒ 红 |
| **C4** | 切过去之后那一屏**看得见他那句原话**（"接着往下"） | 切过去只有空屏 ⇒ 红 |
| **C5** | 做完且他正开着那一间 ⇒ **自动把那个东西打开**（不用他点） | 只长出一格图标 ⇒ 红 |
| **C6** | 他不在那一间时**不许**自动打开（不抢屏） | 抢了 ⇒ 红 |

## 三、和 `102` 的关系（**不许推翻它**）

`102` 那套（`job_start`/`job_done`/`job_list` ＋ 登记 ＋ `scope/open`）**照旧**；这一篇只在
**"建之前先问一句"**与**"切过去像没切"**、"**做完给我看**"这三处加东西。
⚠️ 其中"建之前先问"会**改动 `job_start` 的时序**（原来是同步建）⇒ 既有判据（P1–P7）要跟着
改成"**答了之后**才建"，**不许把那些判据删掉**。

## 四、明确**不做**的

1. **不做**"自动替他选默认"（不答就是不答）；
2. **不做**批量的派活确认（一次一件）；
3. **不做**"他把名字改掉"（名字 agent 自己起，他不需要知道 —— 主人原话）；
4. **不写**数值到文档。

## 五、★ 真机读数（2026-09-25 · 打的是**部署出去那一版** · u2 的盒子 · 真模型）

**做的人**：父 agent（不是子 agent 的复述）；**做法**：一条真 WS 连着 `/api/stream`，
用 u2 的令牌 `POST /api/say`（带 `messageId`），盯着帧；答话从**同一条流**回。

| 时刻 | 读到什么 |
|---|---|

`items:{app:true,workspace:true,conversation:5,session:true}` · 审计 create/remove 两行齐。
