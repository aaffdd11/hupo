# 82 · 开发者模式（把某个用户的盒子里那台 DSH 露到他自己域名上）

> 主人 2026-09-24 原话：「你现在给我一个**开发者模式**，也就是说，我想配置某个用户为开发者，
> 然后他的 docker 里的 dsh，就会端口暴露出来，我可以通过 **`dsh19145526557.stalkerai.cn`** 来访问。」
> 随后定的两处：**锁 = 甲（用琥珀的登录锁，App 里点一下就进去）** · **VPS 那一步由主人签字、助手去跑**。

---

## 一、它跟「只出不进」的关系（**先写这条**）

主人同一天先定过：「**docker 里的 dsh，不可能有任何外部访问，只有它访问外部**」。
开发者模式是那条规矩的**例外**，所以必须满足三条：

1. **默认关**：没被标成开发者的用户，今天怎么样以后还怎么样。
2. **按人**：开关挂在**某个用户**身上。
3. **能当场收回**：标记一关，**不需要重启**就进不去了。

⚠️ **实现上的硬约束**：**盒子本身仍然不开端口**（不用 `podman -p`）。"暴露"靠：
VPS 上的门牌号 → **现有那条 visitor** → 本机核心（按 `Host` 分流）→ **现有那条管道** → 容器内**回环**上的 `dsh web`。

## 二、为什么必须给它一个独立域名（天生吻合，别再试路径式）

那台界面把 API 算在 **`location.origin` 的根**上（三重证据见 `81-HARNESS-ENTRY.md` §二），
所以它本来就需要**一个独占门牌号**。`dsh<手机号>.stalkerai.cn` 正好就是那个形状。

## 三、开关落在哪

`data/users.json` 现在是 **手机号 → `{id, createdAt}`**。⇒ 记录加一个可选字段 **`dev: true`**。

- 服务端加 **`isDev(id)`** 与 **`setDev(phone, on|off)`**（原子写盘照 `users.js` 现有那套）；
- 🔴 **每个请求都现查这个标记**（不是启动时查一次）⇒ 关掉 ⇒ **当场**拒；
- 🔴 **只有 `owner` 能翻**（别人 ⇒ 403）；
- 翻一次**记一笔**（谁、什么时候、开了谁）。

## 四、形状（最终）

```
浏览器 → https://dsh<手机号>.stalkerai.cn/     （VPS：nginx + 证书，server_name 就是它）
       → 127.0.0.1:3084（**现成那条 visitor**，不新增隧道/端口）→ 本机核心 8020
       ★ 核心按 **Host** 分流：`dsh<11位手机号>.<HUPO_DEV_BASE>` ⇒ 走 dev 中继，别的照旧走站点
       → 现有那条管道（域套接字）→ 容器里的壳（**只在隧道那条可信口上接**）
       → 容器内 127.0.0.1 上的 `dsh web`
```

| 事 | 做法 |
|---|---|
| DNS | **不用动**（`stalkerai.cn` 泛解析，实测随机名也解析到 VPS）|
| 证书 | **每个开发者一张单名证书**：`certbot certonly --nginx -d dsh<手机号>.stalkerai.cn` |
| nginx | 一个 server 块：`:80 → 301`、`:443 ssl` + 证书 + `proxy_pass http://127.0.0.1:3084`（**复用现有 visitor**）|
| 盒子 | 懒起 `dsh --profile web --patch <模型那条> --host 127.0.0.1 --port 0 --no-open`（**只听回环**）＋壳里 `/h/*` 反代 |
| 免登 | 壳自己 `GET /?token=…` 换 DSH 的 cookie 存住，之后**替浏览器**带上；并把上游的 `Host`/`Origin` 改写成回环（那道 `/api` 栅栏按回环放行，正反例都实测过 —— `81-HARNESS-ENTRY.md` §四）|
| 外层的锁 | **琥珀的登录**（甲）：见 §五 |

## 五、两把锁（甲）

1. **外层的锁 = 琥珀的登录**：`App 里点一下` ⇒ 服务端现签一条**短时效**链接
   `https://dsh<手机号>.stalkerai.cn/__enter?u=<sub>&e=<exp>&s=<sig>`（签名**分域**：payload `d|<sub>|<exp>`，
   HMAC 用同一个 `appsSignKey`，`timingSafeEqual` 比对）。
   验过 ⇒ 在那个域名上种**第一方** cookie `hupo-dev=<签名会话>`（`HttpOnly; Secure; SameSite=Lax; Max-Age=一天`）⇒ 302 到 `/`。
2. **里层那道照旧**：DSH 自己的令牌/ cookie（壳替浏览器拿着）。
   ⇒ 两道都在：**光知道域名进不去**，光有琥珀登录、没有那个签名链接也进不去（链接短时效）。

**没通过外层 ⇒ 一律拒**（不许"先让看界面、再弹登录"）。被扣的人只会看到一句普通话 + 怎么进来。

## 六、判据（每条都要能反着验）

| # | 判据 | 反例（必须红）|
|---|---|---|
| D1 | 没被标 `dev` 的用户 ⇒ 那个域名**一律拒** | 给没标记的人开域名 ⇒ 必须拒 |
| D2 | 标了 + 带我们的 cookie ⇒ **200**，而且**转发路径带 `/h` 前缀**（进容器那条）| —— |
| D3 | 标了但**没 cookie** ⇒ **拒**（不是先给界面）| 放行 ⇒ 这条红 |
| D4 | 把标记**关掉** ⇒ **当场**拒（不是等重启）| 只在启动时读标记 ⇒ 这条红 |
| D5 | `/__enter` 的签名**分域**：拿**制品**签名或**甲**那条签名来当它用 ⇒ **403** | 不验域 ⇒ 这条红 |
| D6 | 只有 `owner` 能翻标记；`/api/dev-harness` 只给自己（owner 可点名给别人）| 拿 `u2` 的令牌去翻 ⇒ 403 |
| D7 | 盒子侧**没有**宿主端口；`dsh web` 只听**回环** | `podman -p` 或听 `0.0.0.0` ⇒ 红 |
| D8 | **真图**：`curl -I https://dsh<手机号>.stalkerai.cn/`（无 cookie）⇒ **拒**；走一次 `/__enter` 签名 ⇒ **302 + cookie** ⇒ 带 cookie 取 `/` ⇒ **200 且 HTML 里有 `__DSH_BOOT__`** | —— |

## 七、明确**不做**的事

1. **不默认开、不给所有人开**（开关必须落在具体某个人身上）。
2. **不做"光域名就能进"**（主人选了甲）。
3. **不在容器上 `podman -p`**（盒子始终无门）。
4. **不让中继自作主张绕过外层那把锁**。
5. **不新建隧道/端口**（复用现成那条 visitor）。
