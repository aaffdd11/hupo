## 一、这一批做的是什么（一句话）

**设置里多一行「说一句试试」**，点进去是**那一整场演练**：

```
按一下麦 → 说一句 → 听成字（半句也看得见）→ 【先由那一层读懂】
      ├─ 有不确定 ⇒ 用话说一句 + 写成字问他 → 他答 → 再懂一遍（最多两轮）
      └─ 可以了   ⇒ 【最终那一份】摆在屏幕上 —— **就此停住，不发送**
```

🔴 **"无效"那两个字落到实处**：那一屏**没有一处**会去按发送
（判据量的就是"整场一次 `/api/say` 都没有"，而且做过变异：真发一次 ⇒ 判据当场红）。

## 二、"听懂那一层"（这一批的新的东西）

`src/hear.js` ＋ 一条口 **`POST /api/hear`**（登录态；**租户那一侧在盒子里算**，
所以它在 `TENANT_ROUTES` 里）。回四样：

| 字段 | 是什么 |
|---|---|
| `heard` | 我听到的（**理顺版**：补标点、顺语序、改明显同音错字） |
| `ask` | 要问回去的一句（**没有 = `null`**） |
| `fact` | 我在不确定什么（**给我们看的，不上界面**） |
| `scene` | 像是要干什么：`chat` / `do` / `make-app` |

**四条地基**（写在 `HEAR_RULES` 一处，判据逐字检查它们真的在提示词里）。
⚠️ **2026-10-04 主人把口径收窄过一次**（当晚就改了）：*「这个语音体系，只去解决语义不对的地方，
语义对了就行了。」* ⇒ 这一层**只管语义** —— 语义对了**一个字都不用改**（没标点、语序颠倒、
说话重复、口语碎都**不算问题**，也不许拿来当问他的理由）；想让文本更漂亮 / 更完整再问 = **犯规**。
（手册 **`D5.18`**；判据 `test/hear.test.js` H1 里那三条"口径"断言钉着。）下面是收窄之后的四条：

1. 🔴 **只许把他说的整理清楚，不许加他没说过的要求**；
2. 想问更多（要不要存数据…）⇒ **必须走 `ask` 问出来**，他答了才算他的意思
   （这一条保住 `D4.25`"他明说才许写"那条闸的意义）；
3. 一次只问一件，短句、口语、不含内部词；
4. 意思清楚了就别再问（**不追求完美**）。

⚠️ **这一层没有手**：只回话 —— 不落盘、不发消息、不动任何东西（判据 H6 钉的就是它）。
⚠️ **钥匙不出这一层**：真调用走盒内那个小代理（与 `app-ask` 同一条路、同一个不吃思考的模型
`deepseek-chat`）；判据注一个假的进去，所以**没有钥匙也能把整条链验完**。

## 六、主人真机报的那一次（2026-10-04 晚 · "能转文字，但是没有后文"）

> **主人原话**：*「没试成功哦。能转文字，但是没有后文。应该来往来的几句。」*

**根因（两条，都在客户端那一屏的"用嘴说"那条路上）**：

1. 🔴 **`asr/end` 带原因时被我当成了"这一场断了"**。真机（网页那一份）在**每次停顿**处
   就收一段，而且**带 `reason: upstream`/`engine`** —— 那台语音状态机于是走 `broke('cut')`，
   相位**不是 `idle`**；而我当时只在"相位走到 `idle`"时才往"听懂那一层"走
   ⇒ **字出来了，然后就没有然后了**。（`voice_try.dart` 那一屏为同一件事专门写过模型：
   "引擎在停顿处把一段说完 ⇒ 不许把这一场结束掉"。）
   ⇒ 改法：**`asr/end` 就是"他这一段说完了"** —— 不看那个 `reason`，拿累积的字往下走。
2. 🔴 **用嘴答那一句会把这一场清空**：那颗麦原来调的是"从零开始"那一下
   （`tapMic()` 返回一整份新的状态）⇒ `first`/`heard`/`turns` 全丢，他答的"上周"会被当成
   **新的第一句**。⇒ 改成 `startListening()`（**只换相位与那台语音状态机，上下文一个字不动**）
   ＋ `utterance(text)`（**麦克风与打字两条路同一个去处**：正等着他答就记成那一轮，
   否则就是这一场的第一句）。

**判据（补上的那一条就是"用嘴说那条路"）**：`test/widget/hear_drill_test.dart` 的第三条 ——
装上一条**假的"真开麦"**（原生那个钩子），照**真机那一串帧**喂：
`asr/ready` → `asr/partial` → `asr/final` → **`asr/end{reason:'upstream'}`**，
然后量"**后文**"：`/api/hear` 被叫了 1 次 ＋ 屏幕上出现它问回来的那一句；
再用嘴答一句 ⇒ 最终那一份；**整场 `/api/say` 仍然是 0 次**。
**变异验证**：把那句判断退回"只认相位走到 `idle`" ⇒ 那条判据**当场红**
（"★ 说完了就要送进听懂那一层"）—— 主人报的那个形状被原样复现。

⚠️ **如实说**：这一条是**主人先用出来的**（我的判据当时只走了打字那条路 —— 说话那条没人走）
⇒ **教训照旧**：**同一个功能的第二条入口，必须各有一条判据**（"打字"验了不等于"说话"验了）。
