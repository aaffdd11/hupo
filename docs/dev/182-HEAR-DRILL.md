## 一、这一批做的是什么（一句话）

**设置里多一行「说一句试试」**，点进去是**那一整场演练**：

```
按一下麦 → 说一句 → 听成字（半句也看得见）→ 【先由那一层读懂】
      ├─ 有不确定 ⇒ 用话说一句 + 写成字问他 → 他答 → 再懂一遍（最多两轮）
      └─ 可以了   ⇒ 【最终那一份】摆在屏幕上 —— **就此停住，不发送**
```

🔴 **"无效"那两个字落到实处**：那一屏**没有一处**会去按发送
（判据量的就是"整场一次 `/api/say` 都没有"，而且做过变异：真发一次 ⇒ 判据当场红）。

## 二、"听懂那一层"（这一批的新的东西）

`src/hear.js` ＋ 一条口 **`POST /api/hear`**（登录态；**租户那一侧在盒子里算**，
所以它在 `TENANT_ROUTES` 里）。回四样：

| 字段 | 是什么 |
|---|---|
| `heard` | 我听到的（**理顺版**：补标点、顺语序、改明显同音错字） |
| `ask` | 要问回去的一句（**没有 = `null`**） |
| `fact` | 我在不确定什么（**给我们看的，不上界面**） |
| `scene` | 像是要干什么：`chat` / `do` / `make-app` |

**四条地基**（写在 `HEAR_RULES` 一处，判据逐字检查它们真的在提示词里）：

1. 🔴 **只许把他说的整理清楚，不许加他没说过的要求**；
2. 想问更多（要不要存数据…）⇒ **必须走 `ask` 问出来**，他答了才算他的意思
   （这一条保住 `D4.25`"他明说才许写"那条闸的意义）；
3. 一次只问一件，短句、口语、不含内部词；
4. 意思清楚了就别再问（**不追求完美**）。

⚠️ **这一层没有手**：只回话 —— 不落盘、不发消息、不动任何东西（判据 H6 钉的就是它）。
⚠️ **钥匙不出这一层**：真调用走盒内那个小代理（与 `app-ask` 同一条路、同一个不吃思考的模型
`deepseek-chat`）；判据注一个假的进去，所以**没有钥匙也能把整条链验完**。

## 五、如实说（这一批**没做**的）

* 🔴 **声音那半还没接上**：那一屏问回去时**只调了现成那条"念出来"** ——
  **网页上能出声，手机上念不出来**（`speech_stub.dart` 如实说念不出来）。
  主人选了「用火山那套语音合成」⇒ 那一条要**等他后台开通**，再做：
  盒子里的合成那一层 ＋ 让手机放得出来（要装一个播音的包）——
  这是**下一批**（`181` §六 第一问的乙）。
* ⚠️ **它还不是聊天那个入口**：这一批只做了**演练那一屏**（在设置里）。
  真把输入框收起来、说完就发，是**这一件的乙期** —— 而且它要先把
  另外两处拍板（打字留不留 · 自动发送前那半拍，见 [`63`](63-OWNER-DECISIONS.md)）。
* ⚠️ **"问一句"那条路用的还是主人那把钥匙**（盒内代理）⇒ 演练也**会花钱**（一次几分钱级），
  **没有另配**、也没记进哪本账（它不属于任何一个小程序）。
* ⚠️ **两轮上限是两处**（`hear.js` 与 `hear_drill.dart`）：判据把它们对起来了
  （跨语言读源码逐个数字），但**真正的一处出处**没做到 —— 如实记在这儿。
