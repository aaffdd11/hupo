一、聊天长什么样（屏幕上那几层）
一个窗口 ＋ 一张桌子。屏幕上永远只有两件事：你在哪、你在跟哪一本说话。

① 桌面（图标墙）

一格 = 一个本子（工程词：工作区 / 作用域）。点一下 = 进这一本。

  • 内置那几格（设置 / 发现 /「我自己那台」）与你的小程序长得一样，都是一格。
  • 点桌面空白 = 把聊天收起来；点一格 = 进那一本，聊天条一直在底下。
  • 桌面的壁纸是按账号存的（换台设备登录还是它），但不影响排布。

② 点开一格：那一屏铺满

真小程序在网页上是 <iframe>（画在画布上面）；在安卓包里是 WebView（画在画布下面）。

  • 底下那条浮窗一直在（聊天永续）：网页上小程序让出底下那一格；安卓上小程序铺满、浮窗压在它上面。
  • 右上角那颗 ✕ = 退出这一屏、回桌面。
  • 小程序跑在另一个原点、沙箱里：碰不到你的钥匙，要什么能力得你点头。

③ 底下那条浮窗 = 唯一的聊天入口

只有两档：完全收起（一颗录音圆圈 ＋ 右边两颗小按钮）／ 完全展开（那条时间线）。
时间线：一条按编号排的流水
（你说的话 · 它的话 · 它做的事 · 出处 · 每一步的账）
说话时：直白转出来的字带下划线 → 只改错别字那一层回来 → 线去掉 → 通顺就自己发出去
  • 录音那颗圆圈：按一下开始说、再按一下停（在录时一明一暗地闪）。
  • 右边那一列：上面「展开 / 收起」、下面「播放语音」（念它回话里那两段大字）。
  • 它没听清 / 要问你一句时，那一行就摆那句话，你按圆圈答一句 ⇒ 用来修正前面那句。
  • 时间线只认编号（不靠猜谁跟谁配对）；新的一来自己跟到底部，往上翻就不打断你。
