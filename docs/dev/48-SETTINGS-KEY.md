# 48 · 页面上唤起「配置」· 在里面填钥匙

> 主人 2026-09-22：*"用户可以在页面唤起配置。配置上可以输入 apikey"*。
>
> **它补的是一个真缺口**：钥匙原来**只有第一次那条流程**能填 ——
> 填过之后**再也回不去那一屏**（只有"被判无效"之后刷新页面才碰巧回得去）。
> ⇒ 想换一把、或者只想看看"我到底填过没有"，用户**没有地方可去**。

---

## 一、做了什么

| 件 | 在哪 |
|---|---|
| 顶栏一个**齿轮**（tooltip「配置」） | `lib/screens/chat_screen.dart`（`onSendKey` 为 `null` 时不画） |
| **配置那一屏** | `lib/screens/settings_screen.dart`（钥匙那一段 + 「关于」） |
| 表单抽成一块（两处共用） | `lib/widgets/key_form.dart` ← 原来长在 `model_key_screen.dart` 里 |
| 那几句人话 | `lib/models/space_words.dart`（`configEntry` / `keyState*` / …） |
| 两个结果枚举搬进 `models` | `lib/models/key_outcome.dart`（楼层闸：`widgets` 只许看 `models`） |
| 服务端补一个**如实字段** | `keyBad`（`src/key-state.js` + `serve.js`） |

⚠️ **「关于」从顶栏搬进了「配置」**：顶栏原来 5 个图标，再加一个就是 7 个 ——
手机上那一条会挤成一团（而且五档字号那道硬闸本来就在盯这个）。
「关于」本来就是配置那一类东西（"这台设备上行不行"）。⇒ 顶栏**还是 5 个**。

---

## 二、🔴 现状必须**分得开**（这一批真正的技术内容）

服务端原来只回 `hasKey: true/false` ⇒ 下面这两种在客户端看来**一模一样**：

| 真实情况 | 原来客户端看到的 | 配置那一屏只能说 |
|---|---|---|
| 还没填过 | `hasKey:false` | "还没有填" ✓ |
| **填过、但上游说它不灵** | `hasKey:false` | "还没有填" ✗ **这是假话** |

⇒ 服务端加一个 **`keyBad`**（纯函数 `src/key-state.js`，`test/unit` 里钉三种状态）：

```
① 还没填过            hasKey:false  keyBad:false
② 有（能用的）        hasKey:true   keyBad:false
③ 填过、但被判无效     hasKey:false  keyBad:true
```

⚠️ **加字段是安全的**（协议纪律：**加不破**；老客户端忽略它）。
⚠️ `keyBad` 只有 `true` 才有意义 —— `hasKey` 为真时它一定是 `false`（纯函数里钉着）。

---

## 三、界面上那几句话（`keyStateLine`，纯函数）

| 状态 | 说的话 |
|---|---|
| 有 | 现在用的是一串已经填好的钥匙。 |
| 没填过 | 还没有填。填上它，琥珀才能开口说话。 |
| 被判无效 | 你填的那串它说用不了。在这儿换一串就好。 |

⚠️ 三种**必须不一样**：②混进①，用户会去重填一把他其实已经填过的；
③混进①，就是**页面在说假话**（他明明填过）。这一条有单测钉着。

## 五、没做的（明说）

* **钥匙被判无效时不会自动弹到配置**（`00-PROGRESS` §六 #34 的另一半）：
  现在的形状是"**随时能进去看，而且它如实说**"，而不是"自动把你推到某一屏"。
  ⚠️ 自动弹那一版要么打断用户正在做的事，要么得先定"什么时候弹" ——
  **没定就不做**（而不是含糊地"以后再说"）。
* **配置里现在是两个分区**（2026-09-24 回填）：**你那串钥匙** · **这个助手**（关于 / 退出登录）；回收站 / 导出 / 过程档**仍在顶栏**。⚠️ 「配置页四个 tab（语言/图片/视频/语音，各一把钥匙）」那件事**还没定** （越界产物已回退，形状要主人亲口定 —— 见 `docs/dev/77-BLOCKERS.md` B1）
  （它们更常用；搬进配置是另一次信息架构的改动，不在这一批）。
* ⚠️ **"点一下再截图"这条证据链没做成**：Flutter 把字画在 canvas 上，
  按坐标派发鼠标/触摸事件（连聚焦模拟都加了）**页面逐字节不变** ——
  送不到它那儿。⇒ `check-web-browser.mjs` **不留这个参数**（宁可没有，也不留一个假装能用的），
  那一屏由 `test/widget` 真点真断言 + `--shot` 看入口在不在屏幕上。
