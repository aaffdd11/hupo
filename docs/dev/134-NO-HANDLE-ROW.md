# 134 · **展开态不再单独占一行抓手（那根杠删掉）**

> **主人 2026-09-29 原话**：*「展开对话那一小排的占地空间太大。我不要那根杠了。」*
> 问过之后他点的办法：*「展开后右上角有个收起按钮。」*
>
> 这一份说清：那一行现在什么样 · **省下多少** · 代价（拖动那个把手）· **判据** · 没做的。

---

## 一、那一行原来是什么（量过的）

```
展开态：
  ┌──────────────────────────────────────────────────────┐   ← 浮窗上沿
  │        ╲╱     ← 抓手那一行（96×48）：平箭头 + 一根 44×4 的杠
  │   助手  ▸   ｜ 回收站  导出  过程  ⌄   ← 标题行（48）        │
  │  ─────────────────────────────────────────           │
  │        时间线                                          │
  └──────────────────────────────────────────────────────┘
```
两行加起来 **96 高**，而抓手那一行在**展开态**其实只提供两件事：
"点它收起" 与 "拖它改高度" —— 而这两件在展开态都另有其主
（标题行右端那颗「收起」；§6.3 本来就写着"抓手 / 标题行"都能拖）。

## 二、现在

```
展开态：
  ┌──────────────────────────────────────────────────────┐
  │  助手  ▸   ｜ 回收站  导出  过程  ⌄   ← 顶上就是这一行      │
  │  ─────────────────────────────────────────           │
  │        时间线                                          │
  └──────────────────────────────────────────────────────┘

收起态：
  ┌──────────────────────────────────────────────────────┐
  │                    ╲╱      ← 只剩那颗平箭头（**没有杠**）    │
  │  ⌂ │ 说点什么 … 🎤                                     │
  └──────────────────────────────────────────────────────┘
```

| 规矩 | 落地 |
|---|---|
| 🔴 **展开态不再单独占一行** | `if (collapsed)` 才画抓手那一行 ⇒ 展开态省掉整行 |
| 🔴 **那根杠删掉** | 那个 `44×4` 的圆角块整个删了；**收起态**只剩那颗浅角的小箭头 |
| **命中区 ≥44 没动** | 收起态那颗仍是 `TextButton(minimumSize: 96×44)`（D3.6 硬闸；图形只有 26×7） |
| 🔴 **拖动那道手势跟着走** | 收起态绑在抓手那一行、**展开态绑在标题行**（§6.3 原文就是"抓手 / 标题行"）—— 不许因为删了一行就把"能拖"弄丢 |
| **收起态仍然是"看得见的展开入口"** | 字挂在 tooltip（`展开`）与无障碍名上（D3.8 那条 2026-09-24 已改口径） |

## 四、没做的（**明说**）

* **收起态那一行的高度没动**（还是 `96×44` 那个命中区框）：要再矮，只能把可点区
  **隐形外扩**到别处（比如压进输入条那一点内边距）—— 那是另一件事，他没说。
* **没有把"抓手"整个删掉**：收起态它是**唯一的展开入口**（点桌面空白那条只在浮窗没盖住时成立）。
* **没动标题行里那一串动作**（助手 / 工具 / 回收站 / 导出 / 过程）与那颗「收起」的位置。
