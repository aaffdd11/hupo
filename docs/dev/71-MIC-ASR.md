## 一、形状（屏幕上）

语音那一档（话筒图标切过去）现在是**一颗大按钮**：

| 状态 | 屏幕上 | 按下去会怎样 |
|---|---|---|
| 闲 | `按一下 说话` + 一句怎么用 | 开始听（会弹浏览器的**麦克风权限**框） |
| **在听** | 上面一块实时文字区 + `正在听…再按一下 结束` | 说"这边完了"，等最后一句回来 |
| **收尾中** | 实时文字区 + `收尾中…（把最后一句接住）` | 这一档**不画按钮**（按它没有意义） |
| 拿到字 | **自动切回键盘那一档**，字在输入框里 | 发送钮出现 —— **发不发由他**（D5.4：绝不自动发送） |
| 没配钥匙 | `语音这条路还没配好（缺钥匙）` | **不画按钮**（做不了的不许摆出来） |
| 没给权限 | `没拿到麦克风权限 —— 在地址栏那个锁里放开麦克风，再按一次` | 按钮还在（他能重试） |
| **这条连接没接上** | `这条路暂时连不上，等会儿再按一次` | 按钮还在 |
| 开不了麦 | `开不了麦克风，再按一次试试` | 按钮还在 |
| 识别那头出错 | `识别那一头出错了，再按一次试试` | 按钮还在 |

🔴 **"连不上"和"开不了麦"必须分开说**：2026-09-23 在线上真的踩到过 ——
公网那一跳（nginx）不认这条路径，而屏幕上写的是"开不了麦克风"（**页面在说假话**）。
⇒ 两句话各有各的出处，判据 `test/unit/hearing_session_test.dart` 里那条分开钉着。

⚠️ 三件**刻意**的事：

1. **字进输入框、不自动发送**。它停在框里，和用户自己打的字一样 ——
   这就是主人那句"用户可以选择发送"。
2. **开麦前框里已有的字留着**：识别结果**接在它们后面**（绝不擦掉他打了一半的字）。
3. 🔴 **"正在听"这三个字只在真的在听时出现**（D5.13 那条纪律的正面用法）。

### 砍掉的（明说，不是"排后"）

| 砍了 | 为什么 |
|---|---|
| `按住 说话` / `松手 发送` 那一套 | 主人要的是**按一下开始、再按一下结束**；"按住"那套语义（微信的）**删掉** |
| `演示` 小标 + `演示：还没有真的开麦，这些字是假的。` + 那串假字 | 它是"先做假的"那一版的产物；现在这一半**是真的**了，留着才是假话 |

## 二、协议（`/api/asr` · 一条**新的** WebSocket）

🔴 **为什么另开一条**：聊天那条（`/api/stream`）的协议**已经冻结**，
而音频要的是**二进制帧**。往里塞新东西 = 动一条上线过的协议。⇒ 另开一条，
身份那一套**完全照抄**（同一个 `bearer` 子协议、同一个 `claim`、同一套租户转发）。

| 方向 | 帧 | 内容 |
|---|---|---|
| 浏览器 → 服务端 | **二进制** | 16k · 单声道 · 16bit **小端 PCM**（一个字节都不加壳） |
| 浏览器 → 服务端 | 文本 | `{"type":"asr/start"}` · `{"type":"asr/stop"}` |
| 服务端 → 浏览器 | 文本 | 见下表 |

| 事件 | 意思 |
|---|---|
| `asr/ready` | 上游握手成了（`code:0`）——**这一条才算真开起来了** |
| `asr/partial{text}` | 还在说的**半句** |
| `asr/final{text}` | **一句话定稿** |
| `asr/end{text}` | 整段收尾 |
| `asr/capped` | 到点了（上游内测版一条连接最多 1 分钟）⇒ 我们**提前**收手 |
| `asr/error{reason,message,code?}` | 上游回错（鉴权 / 没开通 / 参数）——**只说它那句原话** |
| `asr/unavailable{reason}` | 这台部署**没配钥匙**（如实说） |

⚠️ **服务端提前收手的那个点是 `ASR_MAX_MS`**（`src/asr.js`），**比 1 分钟小**：
等它半路把连接掐掉，用户看到的是"说到一半没了"。

## 三、音频怎么走（🔴 密钥**不许**下浏览器）

```
麦克风 ──getUserMedia──▶ AudioContext ──降采样 16k──▶ WebSocket `/api/asr`
                                                          │
                                                （这台机器的 serve.js）
                                                          ▼
                                      wss://asr.cloud.tencent.com/asr/v2/<appid>?…签名…
```

**为什么不让浏览器直连腾讯云**：那样子 `SecretKey` 就得出现在页面里 ——
不是"可能被猜"，是**明文摆在 devtools 里**，谁都能拿它烧我们的额度。
代价是这台机要中转音频：16k 单声道 ≈ 32 KB/s，一次最多一分钟，很小。

- **签名**在 `v2/services/core/src/asr-sign.js`（纯函数）。自测脚本
  `scripts/check-asr-tencent.mjs` **import 同一份** —— 脚本自己再写一遍
  = 判据打在另一侧（V13 那条教训）。
🔴 **顺序是有讲究的**（2026-09-23 在线上实测到才改的）：
**先连上问一句"这台能不能听"，能听才去要麦克风权限。**
原来的顺序是先 `getUserMedia` —— 于是在**没配钥匙**的部署上，
用户先看到一个麦克风权限框、点了允许之后才被告知"没配好"：**白打扰一次**。
⇒ 现在的判定点是上游那句 `asr/ready`（只有它才算"能听"）。

- **换上游**：环境变量 `HUPO_ASR_URL`（给了它就直接连它，不算签名）。
  它是给**取证**用的：没有钥匙也能把整条链验一遍。⚠️ **生产里不许设**。
- **凭据**只从环境变量读：`TENCENT_APPID` / `TENCENT_SECRET_ID` / `TENCENT_SECRET_KEY`
  （引擎名可用 `TENCENT_ASR_ENGINE` 覆盖，默认 `Hy-ASR-3.0-preview`）。
  ⚠️ 多租户下客户端是连**他自己那台容器**的 `/api/asr` ⇒ 容器里也要有这三样。

### 真浏览器取证（**这一批最强的那条证据**）

假麦克风（Chrome 的 `--use-fake-device-for-media-stream` +
`--use-file-for-fake-audio-capture=<16k 单声道 wav>`）+ **假上游**
（`scripts/asr-stub-upstream.mjs`），于是**除了腾讯云自己那台**，每一环都是真的：

```
▶ 假上游：收到收尾请求；一共收到 147420 字节音频（≈4.6 秒）
🧪 【听的时候】… | 今天天 | 发送 | 键盘 | 正在听…再按一下 结束 | …
🧪 【输入框】[{"v":"今天天气怎么样"}] 发送钮在=true
📷 截图里：输入框里就是「今天天气怎么样」，发送钮亮着
```

🔴 **取证当场抓到一个真缺陷**（这是它存在的意义）：按下"结束"之后，
**最后那一句被丢掉了** —— 屏幕上只剩半句「今天天」。根因：状态机一按停就进
`idle`，而收字只在"正在听"时进行。修法：加 **`finishing`（收尾中）** 这一档，
字继续收、等 `asr/end` 才算完（判据：`hearing_session_test.dart` 里那条
"按了停之后来的最后一句必须接住"）。**修完在真页面上复验**：框里是完整那句。

⚠️ **同一批顺手抓到的第二个真缺陷**：`server.js` 的 `close()` 只终止聊天那条
`wss` 的连接，**没管新加的 `asrWss`** ⇒ 只要有一个语音连接开着，
`restart-core.sh` 就**停不下来**（测试第一次跑挂在那儿就是这个原因）。

## 六、生产怎么配

### 6.1 ⚠️ **公网那一跳也要放行这条路径**（2026-09-23 已改，主人授权）

VPS 上 `/etc/nginx/conf.d/w-stalkerai.conf` 原来只有 `location = /api/stream`
带 WebSocket 升级头 ⇒ `/api/asr` 落进普通 HTTP 反代、**握手被丢掉**
（浏览器只看到 `1006`，而这一头一切正常）。改法**一行**：

```nginx
-    location = /api/stream {
+    location ~ ^/api/(stream|asr)$ {
```

改完 `nginx -t` ⇒ `systemctl reload nginx` ⇒ 公网复验：
`wss://w.stalkerai.cn/api/asr` 回 `{"type":"asr/unavailable",…}` 再 `close:1000`
（和本机直连 `127.0.0.1:8020` 一模一样）。备份留在
`/etc/nginx/conf.d/w-stalkerai.conf.bak-20260923215845`。
⚠️ **以后再加 WS 路径，别忘了这一跳**（漏了的表现是"本机好好的、公网握手就断"）。

### 6.2 凭据怎么进服务（**主人自己动手** · 2026-09-23 已把管子接好）

服务从**环境变量**读那三样。而环境由 `scripts/restart-core.sh` 从
**`v2/services/core/data/asr.env`** 装进去（**照 `data/tenants.env` 那条已有的路**）：

```bash
cd /home/deploy/proj/hupo/v2/services/core
umask 077                     # 只有自己能读
cat > data/asr.env <<'EOF'
TENCENT_APPID=你的AppID
TENCENT_SECRET_ID=你的SecretId
TENCENT_SECRET_KEY=你的SecretKey
EOF
chmod 600 data/asr.env        # 0600
cd /home/deploy/proj/hupo && bash scripts/restart-core.sh
```

重启时它**只报"齐没齐"，不打印任何值**：

```
   （读到了 data/asr.env：APPID 有 · SECRET_ID 有 · SECRET_KEY 有）
```

⚠️ **三条**：
1. `data/` **在 `.gitignore` 里**（`git check-ignore` 验过）⇒ 这个文件**不可能被提交**；
2. 这个文件**只有你自己写**（我不碰那个值，也不打印它）；
3. 多租户：容器里那台也要有这三样（客户端连的是**他自己那台**的 `/api/asr`）。
   今天**没配** —— 别人的语音会如实说"没配好"。

### 6.3 🔴 接这根管子时顺手拆掉的一个坑（`restart-core.sh`）

原来那一段长这样：

```bash
setsid nohup env \
  HUPO_DATA="$DIR/data" \
  HUPO_PORT="$PORT" \
  HUPO_WEB="$DIR/web" \
# ← 紧跟一条注释，**它把这个命令结束了**
if [ -f data/tenants.env ]; then … fi
  HUPO_BUILD_ID="$BUILD" \
  node src/serve.js > serve.log 2>&1 < /dev/null &
```

bash 的续行符在注释**之前**就把行接起来了，于是那其实是一条
**没有命令的 `env`**：

- ① 它把**整个环境打印一遍** —— 环境里但凡有密钥（比如我正要接进去的
  `TENCENT_SECRET_KEY`），就会**当场印在屏幕上**（`deploy-web-v2.sh` 调它时那一段
  被 `grep` 滤掉了，所以以前没露出来；**直接跑就不会**）；
- ② `HUPO_DATA / HUPO_PORT / HUPO_WEB` **根本没传给服务** —— 服务一直在用默认值，
  而脚本却照着变量 echo「端口 $PORT」⇒ 谁把 `HUPO_PORT` 改了，**脚本就在说假话**。

⇒ 改成显式 `export`（一个字节都不打印，值真的进服务）。⚠️ **起进程那一段没动**：
线上服务的 cgroup 是 DSH 的 subprocess scope（`AGENTS.md` §一 记着），
换 detach 方式会动到它。

**验过的读数**（2026-09-23，用**不含任何密钥**的 `HUPO_ASR_URL` 当文件内容）：

| 验什么 | 读数 |
|---|---|
| 不打印环境 | 重启输出里 `SESSION_MANAGER=` / `^PATH=` **0 次**（修之前会出现） |
| 只说齐没齐 | `（读到了 data/asr.env：APPID 没有 · SECRET_ID 没有 · SECRET_KEY 没有）` |
| 值真进服务 | `/proc/<pid>/environ` 里 `HUPO_DATA / HUPO_PORT / HUPO_WEB / HUPO_ASR_URL` **都在**，`HUPO_DATA` 正是 `…/core/data` |
| **真页面走通** | **公网** `w.stalkerai.cn` + 假麦克风：框里出现上游那句话、桩那头收到 **141960 字节**音频 |
| 拆完不留痕 | 删文件 + 重启 ⇒ 环境里 `HUPO_ASR_URL` / `TENCENT_SECRET_KEY` **都不在**，页面回到"缺钥匙" |
