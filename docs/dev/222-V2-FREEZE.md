## 一、V2.0 是什么（一句话 ＋ 一张清单）

> **一句话**：**在 V1.0 之上，把"说话"做成真能用的输入方式**（识别回来的字直接长在底下那个
> 真输入框里、**按停就发**、55 秒上限到点**接着开下一轮**、同一句**不重复也不丢字**）；
> 桌面与偏好**跟着账号走**；小程序**有外观基线**、能拍照、能定时、派活那一刻桌上就长出那一格；
> 安卓包**带版本号**挂首页、下载**支持断点续传**；响应慢那两刀（**会话翻页** ＋ **进屏预热**）。

| 那一块 | V2.0 里已经有的（V1.0 之后新增的） |
|---|---|
| **说话（这一版最大的一块）** | 按一下说话 ⇒ 字**流进底下那个真输入框**（他也能点进去改）· **按停就发** · 到点接着开、**字一个都不清** · 第一次按失败**自动再试一次** · 在听的涟漪 · 识别条**不重复不丢字**（整段替换 ＋ 只许变长 ＋ 段号不许覆盖） |
| **桌面 / 外观** | **壁纸与偏好跟着账号走**（换设备也在）· 图标底色 · 底部那条 bar（半透明 ＋ home/输入/话筒）· 展开态不再单独占一行抓手 · 状态栏跟着壁纸走 |
| **小程序** | **外观基线**（写得像样、手机平板都铺得开）· **拍照** · **定时任务** · 派活那一刻桌上长出那一格、做完换成它自己起的名字 · 目录/工作区对账 · 同一间「再登记」不再要"明说" |
| **安卓包** | 名字与下载链接**带版本号**（留档 ＋ 稳定名）· 首页那颗下载按钮指的就是它 · 与 1.0 的包**并排**（不覆盖） |
| **下载** | **断点续传**（`206` ＋ `Content-Range` ＋ `If-Range`；预压那份退回原文）· **源代码压缩包**（`/hupo-source.tar.gz`）· 参赛文稿 / 图标原图挂公网 |
| **响应慢** | **会话翻页**（上下文过大就开口前换一条新的）· **进屏预热那一间的 agent**（省掉约 3 秒） |
| **开发这一侧** | 窄闸 `gate-quick.sh` ＋ 全闸留戳（同一棵树半小时内不重跑）· 人格加"长活交后台、别在轮内干等" |

⚠️ **V1.0 计划里那一件"纯语音 ＋ 先说懂再发"没有按原样留下来** —— 详见 §四 第 3 条。
