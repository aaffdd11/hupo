## 二、系统由什么组成

**三层 ＋ 一条旁路**（`02-ARCHITECTURE.md` §一）：

```
L1 终端层   Flutter（Web / Android）＝ 有序时间线 ＋ 桌面图标墙 ＋ 小程序运行时
            「只上报事实，不做判断」
                 ⇅  HTTPS ＋ WebSocket（Bearer 令牌）
L2 调度层   v2/services/core（常驻进程，听 127.0.0.1:8020）
            取号 / 收口 / 补发 / 排队 / 撤回 / 未读 / 导出 / 长活提醒 / 准入 / 制品分发
            「不能有表达欲」（唯一例外：产品固定话术）
                 ⇅  stdio JSON-RPC（`dsh --profile sdk --patch <role>`）
L3 工作层   一个会话 ＝ 一个真 agent 子进程（人格 / 工具 / 上下文 / 跨重启接记忆）
            「永不直接对用户说话」
旁路 监控层  独立进程、只读档（输入是主 agent 的输出 ⇒ 可被网页污染）
```

- **三条最容易搞错的边界**、**多租户与作用域**（一人一台容器 · 隔离边界落在 **uid** · 作用域 1:1:1:1）、
  **不变量 N1–N32**、**"去掉调度器还能照旧"不成立**：全在 [`02-ARCHITECTURE.md`](../handbook/02-ARCHITECTURE.md)
  （N1–N11 正文在 [`08-SPEC.md`](../handbook/08-SPEC.md) §一）。**这里不抄，去那儿读。**
- **最要紧的一句话**（`02` §1.3）：**工作区根目录不是安全边界** —— 文件沙箱只约束写、保留读；
  记忆隔离靠"会话历史按 root 分区"。

**体量（2026-10-08 现数，会变，别抄死）**：
