# 30 · 导出（批 3 欠的最后一件 · 批 4 的硬前置）

> **契约 v1（2026-09-21）。** 这一件很小，但它堵着一个大件：
> `04-ROADMAP.md` §八 原文——「**记忆出口（批 3 的真清单 + 导出）在批 3 才有** ⇒
> **"写入与出口同批"是硬前置**——**没出口不许登记"要存东西"**」。
> ⇒ 没有它，**批 4（工时账）严格按手册是被挡着的**。

## 一、手册钉死的

| 出处 | 钉死的 |
|---|---|
| `04-ROADMAP.md` 批 3 那行 | 「两处"（待接入）"→ **真清单 + 导出**（**与删除入口对称**）」 |
| `01-PROJECT.md` §一 第 07 条 | 「"删除账号"有入口、**"导出"没有** ⇒ 这个不对称**直接触发信任问题**」 |
| `04-ROADMAP.md` §八（批 4） | **出口形态 = 一段能粘进微信的文字**（**不画表** —— 绕开"渲染排后"） |
| `03-DEVELOPMENT.md` §5 接口表 | 「**记忆出口**…**写入与出口同批**」 |

⇒ 三句话合起来：**导出必须是一段文字**（不是表、不是文件下载），
而且它要和删除入口**对称**（你能删掉，就能拿走）。

## 二、导出的是什么（**这一条要说准，不然就是吹牛**）

导出的是**这条对话的可见时间线**（你说过的 + 它答过的），一段能直接粘走的文字。

⚠️ **它导出不了"它记在脑子里的那一层"** —— 那是 DSH 的会话记录，
**按整段对话整份存**，我们既读不成文字、也抽不出单独一轮
（`28-DELETE.md` §五 已经把这条边界写死了）。

⇒ **导出里必须有一句把这件事说清**，不然用户会以为"导出 = 把它记得的全拿出来"。
那句话和删除清单里那条 `cannot` 是**同一件事的两面**，两边口径不许打架。

## 三、和 ⑲（回收站）的交界（**这一件最容易做错的地方**）

用户按"删掉"的时候，他的预期是"**它不在了**"。

| 情形 | 导出里怎么办 |
|---|---|
| 还在**回收站**里（30 天内） | **不算进去**（用户说过"删掉"） |
| **已经真删** | 当然不算 |
| **恢复**回来的 | 算（它是活的） |

⚠️ 但**不许装作没有** ⇒ 导出末尾如实加一行，只说**条数、不说内容**：
「（有 N 条你说过要删掉的，没有算进来）」。**N = 0 时这一行不出现。**

⇒ 依据：`08-SPEC.md` 的"页面不许说假话"那条纪律 + ⑲ 那份清单的同一口径。

## 四、形态与入口

| | |
|---|---|
| **形态** | **一段纯文字**（`\n\n` 分段、不带 markdown 语法、不带 markdown 链接）——粘进微信就是人话 |
| **入口** | **先做最小的**（和 ⑲/⑳ 同一个套路）：放**顶栏菜单**里；位置**等主人看过再定**，**不属于契约** |
| **长什么样** | 每一条一行到几行：`谁：内容`（"我：" / "它："），按时间顺序；**时间戳只在跨天时出现一次**（"—— 9月21日 ——"），不逐条写（那是表，不是话） |
| **怎么拿走** | 屏幕上一个可全选/复制的框 + 一个"复制"按钮（命中区 ≥44）。⚠️ **不做文件下载**（手册要的是"能粘走"） |
| **空的时候** | 如实说"这条对话还是空的"，**不许给一个空白框** |

## 五、硬闸

| # | 判据 |
|---|---|
| 1 | 🔴 **回收站里的不算**，而且末尾那行条数**对得上**（造 N 条进回收站 ⇒ N 对得上；N=0 ⇒ 那行不出现） |

| 5 | **空对话** ⇒ 那句话，不是空框 |
| 6 | **可访问性硬闸**：新入口/复制按钮进 `accessibility_test.dart` 的扫描（**从真入口进**） |

## 六、切法

一件做完（它小）。服务端只要一个**只读**的取数口 + 纯函数渲染；客户端一页 + 一个入口。

⚠️ **它做完之后**：批 4 的硬前置就解了；而且批 4 的"工时账导出"**正好复用这套出口形态**
（同一句"一段能粘进微信的文字"）—— 所以这一件不是绕路，是**先把出口修好**。
