⇒ 三句话合起来：**导出必须是一段文字**（不是表、不是文件下载），
而且它要和删除入口**对称**（你能删掉，就能拿走）。

## 二、导出的是什么（**这一条要说准，不然就是吹牛**）

导出的是**这条对话的可见时间线**（你说过的 + 它答过的），一段能直接粘走的文字。

⚠️ **它导出不了"它记在脑子里的那一层"** —— 那是 DSH 的会话记录，
**按整段对话整份存**，我们既读不成文字、也抽不出单独一轮
（`28-DELETE.md` §五 已经把这条边界写死了）。

⇒ **导出里必须有一句把这件事说清**，不然用户会以为"导出 = 把它记得的全拿出来"。
那句话和删除清单里那条 `cannot` 是**同一件事的两面**，两边口径不许打架。

## 三、和 ⑲（回收站）的交界（**这一件最容易做错的地方**）

用户按"删掉"的时候，他的预期是"**它不在了**"。

| 情形 | 导出里怎么办 |
|---|---|
| 还在**回收站**里（30 天内） | **不算进去**（用户说过"删掉"） |
| **已经真删** | 当然不算 |
| **恢复**回来的 | 算（它是活的） |

⚠️ 但**不许装作没有** ⇒ 导出末尾如实加一行，只说**次数、不说内容**：
「（你删过 N 次；删掉的那些没有算进来）」。**N = 0 时这一行不出现。**

🔴 **量词必须是"次"，不能是"条"**（2026-09-23 修，账 #46）：`N` 数的是**删除次数**
（回收站里一条记录 = 一次 `remove`），而"**N 条**"读起来是"几句话 / 几轮" —— **那是另一件事**：
`POST /api/trash/remove` **一次可以删好几轮**。今天两者相等，只因为客户端**一次只删一轮**；
靠一个巧合撑着的真话，哪天多选删除一上来就变成假话。判据在 `test/export.test.js`。

⇒ 依据：`08-SPEC.md` 的"页面不许说假话"那条纪律 + ⑲ 那份清单的同一口径。

## 四、形态与入口

| | |
|---|---|
| **形态** | **一段纯文字**（`\n\n` 分段、不带 markdown 语法、不带 markdown 链接）——粘进微信就是人话 |
| **入口** | **先做最小的**（和 ⑲/⑳ 同一个套路）：放**顶栏菜单**里；位置**等主人看过再定**，**不属于契约** |
| **长什么样** | 每一条一行到几行：`谁：内容`（"我：" / "它："），按时间顺序；**时间戳只在跨天时出现一次**（"—— 9月21日 ——"），不逐条写（那是表，不是话） |
| **怎么拿走** | 屏幕上一个可全选/复制的框 + 一个"复制"按钮（命中区 ≥44）。⚠️ **不做文件下载**（手册要的是"能粘走"） |
| **空的时候** | 如实说"这条对话还是空的"，**不许给一个空白框** |

## 六、切法

一件做完（它小）。服务端只要一个**只读**的取数口 + 纯函数渲染；客户端一页 + 一个入口。

⚠️ **它做完之后**：批 4 的硬前置就解了；而且批 4 的"工时账导出"**正好复用这套出口形态**
（同一句"一段能粘进微信的文字"）—— 所以这一件不是绕路，是**先把出口修好**。

**渲染住在服务端**（§六）：只有服务端手里的回收站知道"谁被删过"（§三），
客户端拿到的是**成品文字**，只负责显示与复制 —— 不重算一遍（两处算 = 一定会漂）。

## 八、HTTP（`GET /api/export`，要令牌，**只读**）

```jsonc
// 回来
{
  "text": "—— 9月21日 ——\n\n我：…\n\n它：…\n\n（这儿只是这条对话里你我互相说过的话。…）\n\n（你删过 2 次；删掉的那些没有算进来）",
  "hiddenCount": 2
}
```

⚠️ `text` 是**成品**（上面那些换行就是真换行）；`hiddenCount` 只用来对照
（末尾那行已经写在 `text` 里，客户端**不重算、不重写**）。
⚠️ 空对话 ⇒ `text` 是**空串**、`hiddenCount` 是 0（那句实话由客户端说）。

## 九、契约没写、这一件自己定的（**给主人过目**）

| # | 定的 | 为什么 |
|---|---|---|
| 1 | 跨天那行的形状 `—— 9月21日 ——` | §四只写了"时间戳只在跨天时出现一次"，没给形状 |
| 2 | §二 那句话的原文（`MEMORY_NOTE`） | §二只要求"必须有一句把这件事说清"；口径与 `28-DELETE.md` §五 那条 `cannot` 对齐（说"记忆"，不说"记录"） |
| 3 | 顶栏入口的位置（挨着回收站） | §四 明说"位置等主人看过再定，不属于契约" |
| 4 | 空对话时**不给框、不给复制按钮** | §四说"不许给一个空白框"；按钮跟着一起去掉，否则是一个按了没东西的按钮 |
| 5 | 一个字都没有、但有东西被删过 ⇒ **只报那一行条数** | §三要求"末尾如实说条数"，而那时没有正文可放它后面 |
| 6 | 一天里**第一句也带日期行** | "跨天时出现一次"的最自然读法；否则第一天没有任何时间信息 |
| 7 | `exportItems` 按 `(messageId, block, seqInBlock)` **去重** | "从回收站拿回来"会把内容**按原样重发**（`28-DELETE.md` §8.3）⇒ 盘上两份，不去重导出里会印两遍（客户端那边有同一把钥匙） |
| 8 | 日期用**服务端本机时区** | 导出是服务端拼的；这台机器与主人在同一处 |

⚠️ 「记录」**不在** `forbidden_words.dart` 那张表里（表里只有"时间线"）。
⑳ 的教训写在 `notice_words.dart` 顶上，所以这一件**照样不许用**它 ——
`test/unit/export_test.dart` 有一条断言**单钉**「记录 / 时间线 / 轮」这三个。
