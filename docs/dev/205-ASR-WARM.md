# 205 · **"按下就通"：把语音那条连接先热上**

> **主人原话**（2026-10-06 晚，两段）：
> *「我们对用户的语音转文字，实时语音转文字，我们要尽可能让他响应做到比较极致，所以说啊前面我们使用的时候呢，
> 语音转文字的速度比较慢，这第一个回复的速度会比较慢，这个是不太好的啊，所以我们去掉了这个语义上面的一个检查，
> 这样呢使得它 bug 也不会太多，至少我们先把这一层打通，你看一下刚才我让你做了，你是否已经完成，
> 然后也就是说我们现在就是直接的语音转文字，没有那个语义上面的一个校验。」*
> （选定这一刀的说法：**做"按下就通"的预热 ＋ 打一颗新包**。）

## 二、这一刀改了什么：**预热**（"按下就通"）

**病灶**：那条 `/api/asr` 的连接**冷启那一次真量到 1.1~4.4 秒**（热的时候 16 ms）——
它原来落在**"按下 → 屏幕上出第一个字"**这条路上（`199` 把麦克风那一半修好了：字不再丢，
但**第一个字出现在屏幕上的时刻**仍然要等这条连接）。

**改法**：**进聊天那一屏就把那条连接先连上**，按键那一刻直接拿热的用。

| # | 落在哪 | 改了什么 |
|---|---|---|
| ① | `lib/services/hearing.dart` ＋ `hearing_stub.dart` ＋ `hearing_web.dart` ＋ `hearing_native.dart` | 多一个 `warmHearing` / `warmNativeHearing`：**只连 WS、不发 `asr/start`**（⇒ 上游不开、**不花钱**、不碰麦克风、不弹权限框）。热着的那条**最多挂 3 分钟**（到点自己收），一次会话正开着时不热（那会多一条） |
| ② | 同上（按下那一侧） | `startHearing` / `startNativeHearing` **先取那条热的**（`_takeWarm()`）：热着且还活着 ⇒ 拿去用；**没热 / 已经死了 / 握不上手** ⇒ 丢掉、现连一条（**宁可慢一点，不许拿着一条死的当热的**） |
| ③ | 同上（收场之后） | 一场说完 ⇒ 隔 3 秒**自己热回来**（下一句多半就在几分钟内；不热的话又得付那次冷连） |
| ④ | `lib/services/chat_controller.dart` | `warmHear()`：**开不了麦 / 没令牌** ⇒ 一次都不调；**热身失败一声不响**（它只是"顺手先连上"，不许因此打扰他） |
| ⑤ | `lib/screens/chat_screen.dart` | `initState` 里调一次 `warmHear()` —— **接线只有这一处**（判据钉着它） |

## 三、真读数（本机走他盒子里那条路，不发音频、不花钱）

| 量什么 | 读数 | 怎么量的 |
|---|---|---|
| 那条连接**冷**（隔一阵第一次） | **连上 1102 ms · 说"能听" 1469 ms** | `/tmp/asr-connect.mjs u2 3` 第 1 轮 |
| 那条连接**热**（紧接着） | **连上 16~17 ms · 说"能听" 195~247 ms** | 同一次的第 2、3 轮 |
| 🔴 **热着那条挂了 60 秒还活着吗** | **活着**：60 秒后发 `asr/start` ⇒ **289 ms** 就回"能听" | 新写的一次性探针 `/tmp/asr-warm-survive.mjs 60`（连上 792 ms → 干等 60 s → 那时它仍然 `OPEN` → 发 start → `asr/ready` 289 ms） |
| 🔴 **挂 150 秒呢**（比客户端的 3 分钟保温短一点） | **也活着**：**281 ms** 就回"能听"（那一次连上本身花了 **3735 ms** —— 正好是这一刀要挪走的那种冷启） | 同一个探针换成 150：`/tmp/asr-warm-survive.mjs 150` |
| 服务端会不会把"连上但没开始"的那条掐掉 | **不会**（掐点是 `asr/start` 之后那一个 `maxMs`，见 `src/asr.js`） | 读代码：`cap = setTimeout(…, maxMs)` 挂在 start 那一支上；上面那 60 秒的探针也印证了 |

⇒ **按下那一刻要等的那一段，从"1.1~4.4 秒"变成"~290 ms"**（剩下的就是上游握手那一拍）。
⚠️ 这一步**没有**做端到端（"按住说一句 → 屏幕上出第一个字"）的读数：**那要真麦克风**，
在这台机器上量不了（下面 §五 如实说）。

## 五、如实说（边界 / 没验到的）

* ⚠️ **"按下 → 屏幕上出第一个字"这一整段没有端到端读数**：那要**真的按住说一句**
  （真麦克风），这台机器上量不了。我量的是**这条路上的一跳**（连接＋握手，见 §三），
  以及**判据**（按下时确实拿的是那条热的）。**他按一下才算数。**
* ⚠️ **剩下的那 ~290 ms**（上游握手）**这一刀没动**：要再快就得在"按下"之前把上游也开了
  —— 那是**已经开始计费**的东西，不做（除非他明说）。
* ⚠️ **预热不是无限的**：热着的那条**最多挂 3 分钟**（到点自己收）。他要是隔了十分钟才按，
  那一次仍然付冷连 —— 但**字不会丢**（`199` 那一刀在：麦克风先开、音频攒着）。
* ⚠️ **每条预热都是他盒子里一次"取凭据"**（宿主 ⇒ 盒子那条隧道）：**不花钱**，但不是零成本
  （一次内部往返）。所以：开不了麦的地方不热、没令牌不热、一次只热一条。
* ⚠️ **手机上要重打包才带上**（这一刀是客户端改的）—— 这一趟**打了**：
  **`2.0.0+700`**（55,258,998 字节 · sha256 `df16d3183090…` · 正式签名 `9ecf9fce8936…` ·
  公网逐字节一样），而且**真读包里那几样**（见 §一 那张表的最末一行）。
