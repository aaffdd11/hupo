> 主人原话（逐字）：*"本来就说过了，并不是说聊天，我聊到哪他切到哪，是我在主进程，我说要做一个 APP，

> **自己干过什么，有哪些小程序，有哪些工作区**……那所以说他这东西**都是调度器的工作**。"*

> ⚠️ **这一篇替换掉我上一版写错的形状**（那一版写成"同一轮中途换间"——把主聊天那条收口、

## 一、形状（照着上面那段话，一句一句落）

```
主进程（= 他聊天的那一条；main 会话）
  │  他说："帮我做一个 X 的 app"
  ├─ ① 【派活】调度器把这件活交给**一个子进程**（那一间＝一个新的工作区／图标）
  │      · 建工作区（目录）、建会话（cwd ＝ 那个工作区）
  │      · 把**任务与由来**一起交过去（"他让我做 X"＋他说的那句原话）
  │
  ├─ ② 【子进程干活】它在那间里做 X（写文件、`app_create`、`app_publish` 都**它自己**调）
  │      · 那一间就是"**workspace 切过去以后的那个聊天窗口**"（他点开图标看到的就是这段）
  │      · 主进程里**没有**这段过程
  │
  ├─ ③ 【回报】它做完 ⇒ 做一份**总结**，**扔回主进程**
  │      · 主进程里出现一条**人话**：做完了什么 · 叫什么 · 在哪儿看（"在「X」里"）
  │      · 主进程那条会话**知道**子进程干了什么（未来聊天里也查得到）
  │
  └─ ④ 【主进程侧的简记录】一份**简单的**登记：有哪些小程序、哪些工作区、各自最后一条总结
         · 目的**只有一个**：他未来在主进程聊天时，知道"自己干过什么、有哪些小程序、哪些工作区"
         · ⚠️ **它不是日志副本**（一条事实只有一个家：那段对话仍在它自己那一间）
```

**四条不许破**：

1. **焦点跟他走**（"我聊到哪他切到哪"）—— `84-C` 已建（一条 WS ＋ 焦点路由）；
2. **活在哪间干、就在哪间留痕**（子进程那段是**它自己**的对话，主进程不复制）；
3. **回报必须是"总结"**（人话），不是把子进程那段倒进主进程；
4. **登记是简单的**（谁、什么、在哪、最后一条总结）—— 它是**索引**，不是第二份日志。

## 三、⚠️ 一条要主人拍的：**"派活"这个动作长什么样**

手册 **N16** 说"**转交的前提是目标作用域已存在**"（转交 = 交给**已有**的一间）。
而"派活做一个新 app"是**另一件事**：目标那一间**还不存在**（要现建）。两条路：

| | 形状 | 好处 | 代价 |
|---|---|---|---|
| **甲** | **扩 `handoff_to`**：目标允许是"还不存在的新工作区"，调度器给它建 | 只有一个工具，模型好懂 | 与 N16 那句"目标必须已存在"**正面冲突** ⇒ 得改手册那句或加分档 |
| **乙**（我建议）| **新开一个派活工具**（例如 `job_start(where, why)`）：主进程的 agent 明说"这活给一个**新工作区**做"，调度器建它并把任务交过去 | 与 N16 不冲突（**转交**交给已有的一间 · **派活**新建一间），两种动作各自可判 | 多一个工具（仍加在现有那条 MCP 上 ⇒ **不用补重建清单**）|

✅ **主人 2026-09-25 拍的是「乙」**（派活单独一个工具，加在**现有**那条 MCP 上；`handoff_to` 那套一个字不改）。
⚠️ **另记一条**：P3 那句"叫什么·在哪儿看"**由子进程自己的总结带出来**（它说的是人话名字），**不许**依赖 `whereTitle` —— 因为租户那份 app 的名字在**他盒子里**（宿主查不到，见 `77-BLOCKERS.md` **B20**）。

### 真机：**浏览器那份客户端真的自己跟过去了**（2026-09-25 第 4 枪）

判据用**服务端那份焦点账**（`focus-book`）——它**只有客户端发焦点帧才会被写**：

1. 只开一个浏览器（**故意不挂探针流**：探针会把自己那份焦点写进去，污染这个传感器）；
2. 派活那一句（`scope:"main"`）⇒ `job/start` 落盘（4 → 5 条）；
3. 隔几秒拿 **`hint=main`** 再说一句 ⇒ 回 **`409 focus-mismatch`**，
   正文里写着 `"focus":"count-thirteen-fifteen"` —— **正是刚派出来的那一间**。

⇒ 客户端自己把焦点帧发给了服务端；而全仓 `setScope(` 只有三处调用（另两处都要**点图标**），
所以只可能是那条 `scope/open` 分支干的。**这一枪打中了**（真机上的"窗口自己跟过去"）。
