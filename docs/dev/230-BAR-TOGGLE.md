> 主人原话：*"帮我在左下角的两个按钮左边，放一个高度等于语音按钮高度，宽度非常窄的按钮，
>   icon是一个向左的箭头，用来展开和隐藏底下的聊天工具栏。隐藏时应左移，左移后，
>   出现一个按钮，贴着边显示，是一个向右的箭头。"*
>
> 他另外点了两条（问过再动手的）：**整条底部工具栏都滑走**（清单/键盘 ＋ 输入框＋圆圈
>  ＋ 展开/播放），**只剩左边缘那条窄的**；那条窄的**贴屏幕左边缘**（连浮窗那 10px
> 留白一起吃进去）。
>
> 这一页记：形状 · **三处不明显的坑**（其中两处是框架行为，猜不到）· 判据 · 在哪一端验的。

## 一、形状

```
平时：  ⧏ │清单│  ┌────────输入框────────┐  ◯  │展开│
        │键盘│  └──────────────────────┘     │播放│
        ↑ 那颗窄按钮（看得见 20 宽、64 高）

收起：  ⧐   ← 只剩这一颗，贴在屏幕左边缘；其余**整条左移出屏**
```

| 项 | 值 / 落点 |
|---|---|
| 看得见的面 | `voiceAuxTabW × voiceCircleBox` = **20 × 64**（`design.dart`） |
| 手势那一格 | **44 × 64**（D3.6 硬闸量的就是布局盒子；"视觉仍小、命中区撑够"） |
| 高度 | ＝那颗录音圆圈的高 ⇒ 与四颗小按钮、那颗圆圈**同一条中线** |
| 面子 | 与另外四颗**同一套**（白底 ＋ 一圈琥珀 ＋ 墨色图形）—— 走同一个 `_auxFace` |
| 箭头 | 平时 `chevron_left`（◀）、收起后 `chevron_right`（▶） |
| 字 | 挂 `Tooltip` ＋ 无障碍名（图形按钮同那四颗的规矩）：`收起底下这条` / `展开底下这条` |
| 滑动 | `motionBarSlide`（220ms · `easeOutCubic`）；那一行左移 ＋ 浮窗挪到屏幕左沿**同一个时长** |
| 那一档 | 收起时**浮窗这一格真的缩到 44 宽**（见 §二·1） |

⚠️ **为什么不叫「收起 / 展开」两个字**：那一对已经是那颗「抓手」的 tooltip，
判据里 `find.byTooltip('展开')` 会摸到两颗；⚠️ 也不用「工具栏」——`工具` 在**禁用词**表里。

## 二、🔴 三处不明显的坑（都踩过）

### 1. 光"滑走看不见"是不够的：`Material` **吃点击**

第一版：那一行用 `AnimatedSlide` 移出左边，浮窗这一格**还是整条宽**（不然两列小按钮
会被挤成一团）。结果 —— 屏幕底下留下一条**看不见却点不动**的地带：

```
RenderConstraintsTransformBox / Material ← 它的 `_RenderInkFeatures.hitTestSelf`
                                            `absorbHitTest = type != transparency`
```

读框架源码（`material.dart`）才看清：`Material`（canvas 型）**在任何位置都自己认领命中**
（不是靠 `Listener(opaque)` —— 那一层只是额外挡一道）。而收起档的 `Material` 是全透明的
⇒ 屏幕上什么都没有、却什么都点不到。

⇒ **改法**：收起时**把浮窗这一格真的缩到那一颗那么宽**（`chat_screen` 的
`AnimatedPositioned` 里 `right = 屏宽 − voiceAuxW`），那一行用 `OverflowBox` 按"整条"
排、`ClipRect` 裁掉。**看不见的东西不许占地方** —— 与浮窗铁律同一条道理。

### 2. 那一行必须按"整条"排，而这一格在动画里每一帧都不一样宽

两列小按钮加起来 156 宽 ⇒ 44 宽的一格装不下（`RenderFlex` 溢出，测试当场红）。
⇒ 冻住"整条有多宽"（`_barW`），只在**完全看得见、且没在滑**的时候更新它。

⚠️ 为什么要一个 `AnimationController`（`_barAnim`）：它就是用来回答
**"现在是不是正在滑"** —— 只看 `_barHidden` 的话，放回来那一段里这一格还窄着，
那一行会被挤爆。滑动的位移本身也由它驱动（`Transform.translate`），
不是 `AnimatedSlide`（那样宽度与位移就是两套时钟）。

⚠️ **转屏 / 拉窗口**：完全看得见时会更新 `_barW` ⇒ 跟着变（不是"一次记住就永远"）。

### 3. 那一行只是**被移走**，不是拆掉

`Composer`（输入框那一格）两档用的是**同一个实例**（`chat_floater.dart` 顶上那条规矩）
—— 收起 / 放回**不许**换一棵子树，否则他打了一半的字就没了。
⇒ 判据 ④ 专门钉这件事（打半句 → 收起 → 放回 ⇒ 字还在）。

⚠️ 顺带：**收起来的时候把键盘也收回去**（不然屏幕上会浮着一个"没处可打"的软键盘）；
⚠️ 放回来时**不许自己又摊开**（那是他自己按的开关）。判据 ⑦ 两条都钉。

⚠️ 还有两条跟着走的：**展开着的时候按它 = 把聊天整个收起来**
（"只剩时间线、没有输入条"的窗口不该存在）；**「清单」那张浮窗跟着关掉**
（它挂在这一行上，跟着滑走会变成"开着的浮窗不见了"）。判据 ⑤ / ⑤·补。
